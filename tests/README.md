# HomeCare Twin 测试目录

- `unit/`：事件状态机、候选融合、规则、告警预算、计划安全时间窗和权限谓词。
- `integration/`：MySQL、文件存储、outbox、关系投影、向量检索和外部适配器。
- `e2e/`：从视觉复核到事件、风险、证据解释、计划和照护升级的 P0 主链。
- `safety/`：越权、字段越权、撤权、网络出口、恶意文件、提示词注入、敏感信息和医疗边界回归。
- `fixtures/`：小体积合成、公开许可或不可逆脱敏测试数据。

当前只有目录规划，没有测试代码或检查脚本。首个工程增量必须先建立能失败的最小测试，再实现功能。

测试不得使用真实患者数据，也不得通过关闭授权、人工确认、规则或引用校验来通过。模型评估使用固定数据集，失败样例和旧类别退化必须保留。

P0 还必须证明：药盒多渠道冲突会进入人工修正；子女只能读取授权字段；普通提醒遵守预算而严重提醒不被压制；家庭版断网仍能提供事实/规则/任务；页面和 API 不出现买药、问诊、广告或佣金导流。
