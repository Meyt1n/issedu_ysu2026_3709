# 测试目录

- `unit/`：领域规则和纯函数。
- `integration/`：数据库、对象存储、向量库和模型适配器。
- `e2e/`：MVP 用户主链路。
- `safety/`：越权、提示词注入、隐私泄露和 S0-S3 医疗安全回归。
- `fixtures/`：只允许合成、公开许可或脱敏测试数据。

测试不得依赖真实患者数据，也不得通过关闭认证或安全校验来通过。

当前只有测试目录规划，没有测试代码或检查脚本。首个工程增量必须先建立可失败的最小测试，
再实现功能。计划中的关键安全测试包括令牌轮换与撤销、家庭越权、授权撤销立即生效、
统一错误结构和审计信息脱敏；新增业务资源时补同等级别的所有权和撤权回归。
