# 测试目录

- `unit/`：领域规则和纯函数。
- `integration/`：数据库、对象存储、向量库和模型适配器。
- `e2e/`：MVP 用户主链路。
- `safety/`：越权、提示词注入、隐私泄露和 S0-S3 医疗安全回归。
- `fixtures/`：只允许合成、公开许可或脱敏测试数据。

测试不得依赖真实患者数据，也不得通过关闭认证或安全校验来通过。

一期使用临时 SQLite 数据库快速验证业务规则，Alembic 迁移和运行配置同时兼容
PostgreSQL。执行：

```powershell
.\scripts\check-local.ps1
```

关键安全测试包括刷新令牌轮换与撤销、家庭越权、授权撤销立即生效、统一错误结构和
审计信息脱敏。新增业务资源时必须补同等级别的所有权和撤权回归。
