# HomeCare Twin Mobile Agent Instructions

本仓库是家健镜 HomeCare Twin 的随身照护移动端，配套主仓库 [issedu_ysu2026_3709](https://github.com/Meyt1n/issedu_ysu2026_3709)。

任何 agent 在阅读、规划、修改、测试或评审本仓库前，必须先阅读：

1. 本仓库 [`README.md`](README.md)（定位、分工呼应、诚实状态说明）；
2. [`docs/无障碍模式设计说明.md`](docs/无障碍模式设计说明.md)；
3. 主仓库的开发治理基线：`docs/vibe-coding/开发前必读与Vibe Coding工作流.md`（术语、API、数据与隐私规范以主仓库为事实源）。

Agent 必须遵守：

- 始终使用简体中文回复；
- 术语、API 契约、风险/提醒等级、识别四态以主仓库事实源为准，不自行发明第二套语义；
- 诚实报告状态：演示模式与联机适配的边界必须在 README 中如实维护，不得把 Mock、演示数据或未联调的适配层宣称为已验证能力；
- 禁止提交真实健康数据、真实人物信息、药品实拍图、密钥、模型权重、日志和缓存；演示数据必须虚构并带"演示"标注；
- 不得让应用输出诊断、处方、停药、换药或剂量判断类文案；风险提示只能表达"发现已知资料，需要进一步确认"；
- 无障碍是本仓库的核心验收面：改动 UI 时保持"文字 + 图标 + 颜色"三重状态表达、触控目标 ≥ 44px（长辈模式 ≥ 58px）、焦点可见、语音播报路径可用；
- 修改后运行 `npm run check`、`npm run test`、`npm run build` 并报告真实结果；
- 功能开发走分支 + PR，不直接向 `master` 推送新功能历史；
- 发现与主仓库文档冲突、需求缺口或无法验证时，停下来说明，不自行猜测。
