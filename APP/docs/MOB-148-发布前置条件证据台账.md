# MOB-148 发布前置条件证据台账

本台账配合 [MOB-148 移动端最终发布门禁](MOB-148-移动端最终发布门禁.md) 使用，用于如实记录发布前置条件的完成情况、待补证据和复核入口。它**不是发布批准记录**，不因填写本台账而解除任何门禁。

## 使用规则

1. 初始状态统一为 `BLOCKED`；只有维护者在受控环境中复核完整脱敏证据后，才可改为 `VERIFIED`。
2. `Issue closed`、页面截图、mock 成功或本地单次运行均不能单独作为通过证据。
3. 证据路径只可填写脱敏报告、CI 链接、测试记录或受控环境记录编号；不得写入真实地址、令牌、Cookie、设备序列号、健康数据或 APK 签名材料。
4. 每次状态改变必须同步填写执行日期、APP/服务端提交、复核人和回滚产物位置；任一字段缺失，维持 `BLOCKED`。

## 裁决

- `RUNTIME_RELEASE` 只能在 MOB148-E01 至 MOB148-E10 全部为 `VERIFIED`、版本信息一致且回滚演练成功时由维护者批准。
- 任一 E 项为 `BLOCKED` 时，不得把 APP/PWA/APK 描述为可运行时发布；如仅作课堂演示，应明确为 `DEMO_ONLY`。
- `FULL_VISION_PRODUCTION` 还要求 MOB148-V01、MOB148-V02 均为 `VERIFIED`；否则视觉能力必须禁用或明确受限，不得伪造识别结果。
