# 移动端常见问题 FAQ

> 本文档是家健镜随身版的常见问题解答，覆盖安装、登录、功能使用、无障碍、性能、安全、隐私等方面。面向最终用户和技术支持人员，作为问题排查的第一参考。

## 1. 安装与启动

### Q1.1 如何安装应用？

**PWA 方式（推荐）：**
1. 用手机浏览器（Chrome/Safari/Edge）打开应用地址
2. 浏览器会提示「添加到主屏幕」，点击确认
3. 主屏幕出现应用图标，点击即可使用

**APK 方式（Android）：**
1. 下载 `homecare-twin-mobile.apk`
2. 在手机设置中允许「安装未知来源应用」
3. 点击 APK 文件安装
4. 安装完成后点击图标启动

### Q1.2 安装后打不开怎么办？

**排查步骤：**
1. 确认 Android 版本 ≥7.0（设置 → 关于手机 → Android 版本）
2. 确认有足够存储空间（≥100MB）
3. 卸载后重新安装
4. 清除应用数据（设置 → 应用 → 家健镜 → 存储 → 清除数据）
5. 如仍无法打开，联系技术支持并提供错误截图

### Q1.3 首次启动白屏怎么办？

**可能原因：**
- 网络连接问题
- 服务器地址配置错误
- 浏览器/WebView 版本过低

**解决方法：**
1. 检查网络连接
2. 确认服务器地址正确（首次使用时配置）
3. 更新 Android System WebView（应用商店搜索更新）
4. 使用最新版 Chrome 浏览器
5. 清除浏览器缓存后重试

### Q1.4 应用会自动更新吗？

- **PWA**：会自动更新。打开应用时检查新版本，下次启动生效
- **APK**：不会自动更新，需要手动下载新版本覆盖安装
- 更新不会丢失本地设置（无障碍偏好、服务器地址等）

## 2. 登录与账户

### Q2.1 忘记密码怎么办？

1. 在登录页点击「忘记密码」
2. 输入注册时的用户名
3. 联系家庭管理员重置密码（家庭自部署无邮件找回功能）
4. 管理员在网页端「成员管理」中重置密码

### Q2.2 登录提示「用户名或密码错误」

- 确认用户名拼写正确（区分大小写）
- 确认密码正确（区分大小写）
- 确认服务器地址正确
- 如多次失败，等待 1 分钟后重试（防止暴力破解）
- 仍无法登录，联系管理员重置密码

### Q2.3 登录后频繁被踢出

**可能原因：**
- 修改密码后其他设备会被登出（正常行为）
- 会话过期（默认 24 小时）
- 服务器重启
- 多设备同时登录（同一账户最多 3 个活跃会话）

**解决方法：**
- 重新登录即可
- 如频繁被踢，检查是否有他人使用你的账户
- 联系管理员查看登录日志

### Q2.4 如何注册新账户？

1. 在登录页点击「注册」
2. 填写用户名、密码、显示名称
3. 用户名要求：3-20 位，字母数字下划线
4. 密码要求：至少 8 位，包含字母和数字
5. 注册后需要家庭管理员邀请加入家庭，或创建新家庭

### Q2.5 可以不登录使用吗？

可以使用「演示模式」：
1. 首次启动选择「演示模式」
2. 体验完整功能，但数据是模拟的
3. 演示数据不会保存，刷新后重置
4. 演示模式下部分功能不可用（真实拍照识别、真实天气等）

## 3. 今日任务

### Q3.1 任务时间不对怎么办？

- 确认手机时区设置正确（设置 → 日期和时间 → 自动确定时区）
- 确认家庭时区设置正确（网页端 → 家庭设置 → 时区）
- 任务时间以家庭时区为准，不是手机本地时区
- 如仍不对，联系管理员检查家庭设置

### Q3.2 误点了「确认」怎么办？

- 确认后 5 秒内可在 Toast 中点击「撤销」
- 超过 5 秒无法撤销，但可以在任务历史中查看记录
- 如需更正，联系管理员在网页端调整
- 系统会记录所有操作，包括撤销

### Q3.3 「延期」和「跳过」有什么区别？

| 操作 | 含义 | 是否记录 | 是否影响统计 |
| --- | --- | --- | --- |
| 确认 | 已按时完成 | 是 | 计入完成率 |
| 延期 | 稍后再做，推迟到指定时间 | 是 | 不计入漏服 |
| 跳过 | 今天不做了 | 是，需原因 | 不计入完成率，不算漏服 |
| 记漏服 | 忘记吃了 | 是，需原因 | 计入漏服统计 |

### Q3.4 为什么有些按钮是灰色的？

- 服务端未返回该任务的允许动作
- 任务已完成（已确认/已跳过/已漏服）
- 网络未连接，无法获取最新策略
- 权限不足（非家庭成员无法操作）
- 灰色按钮会有 tooltip 说明原因

### Q3.5 任务列表为空怎么办？

- 确认今天有计划任务（网页端 → 照护计划 → 查看计划）
- 确认成员选择正确（顶部切换成员）
- 确认网络连接正常
- 下拉刷新
- 如仍为空，可能是计划已结束或未配置

## 4. 拍药盒识别

### Q4.1 拍照后一直显示「识别中」

- 正常识别需要 5-30 秒
- 如超过 1 分钟，可能是服务器繁忙
- 可以取消后重试
- 检查网络连接
- 如频繁超时，联系管理员检查视觉服务状态

### Q4.2 识别结果不准确怎么办？

- 确保照片清晰、光线充足、药盒文字朝上
- 避免反光和阴影
- 拍摄药盒正面（有文字和条码的一面）
- 如识别为「冲突」或「未知」，可在网页端复核中心手动确认
- 多次识别失败可手动录入药品

### Q4.3 可以识别视频吗？

可以：
- 支持 ≤30 秒的短视频
- 视频会自动抽帧识别
- 视频文件较大，建议在 Wi-Fi 下使用
- 视频识别比单张图片更准确（多角度）

### Q4.4 照片会上传到服务器吗？

- 是的，照片会上传到家庭服务器进行识别
- 照片仅用于本次识别，识别完成后可配置自动删除
- 照片不会用于训练模型
- 照片存储在家庭服务器，不出公网
- 可在「我的 → 本地数据管理」查看上传记录

### Q4.5 取消识别后还能看到结果吗？

- 取消后任务进入终态，不会再返回结果
- 取消操作不可撤销
- 如需重新识别，需要重新拍照
- 取消不会产生药品记录

## 5. 风险提醒

### Q5.1 风险等级如何划分？

| 等级 | 颜色 | 含义 | 示例 |
| --- | --- | --- | --- |
| 严重 | 红色 | 可能危及健康，需立即处理 | 药物过敏冲突、药品过期 |
| 较高 | 橙色 | 需要关注，建议尽快处理 | 重复成分、库存不足 |
| 一般 | 蓝色 | 信息提示，了解即可 | 天气变化建议 |
| 提示 | 灰色 | 日常提醒 | 用药知识科普 |

### Q5.2 为什么有些风险不显示？

- 一般和提示级风险有每日预算（默认各 3 条/天）
- 超过预算的风险会被压制，第二天显示
- 严重和较高风险不受预算限制，始终显示
- 已「已知晓」的风险从活跃列表移除
- 已过期的风险不显示

### Q5.3 「已知晓」后还会再提醒吗？

- 同一风险事件不会再提醒
- 但如果触发新的风险事件（如新增药品导致新冲突），会生成新的风险提醒
- 风险规则更新后，旧风险可能重新评估
- 可在「风险历史」中查看所有已处理的风险

### Q5.4 风险建议可以相信吗？

- 风险建议基于规则引擎和知识库，仅供参考
- 不构成医疗诊断或处方建议
- 严重风险请及时咨询医生或药师
- 建议中会标注信息来源和置信度
- 如有疑问，点击「查看证据」了解详情

## 6. 语音助手

### Q6.1 语音识别不支持怎么办？

- 部分设备或浏览器不支持 Web Speech API
- 不支持时会自动切换为文字输入
- 建议使用最新版 Chrome 浏览器
- Android 系统需要安装「Google 语音搜索」
- 语音功能需要麦克风权限（首次使用时授权）

### Q6.2 15 秒自动停止可以改吗？

- 不可以，15 秒是固定限制
- 设计目的是防止忘记关闭导致误录
- 如需更长对话，可以分多次提问
- 停止后已识别的文字会保留，可以编辑后发送

### Q6.3 语音会上传到服务器吗？

- 语音识别在设备本地完成（Web Speech API）
- 只有识别后的文字会发送到服务器
- 原始音频不会上传
- 服务器不存储语音数据
- 长辈模式的语音播报也在本地完成

### Q6.4 助手回答不准确怎么办？

- 助手基于家庭健康数据和知识库回答
- 不构成医疗建议
- 回答会展示引用来源，可点击查看
- 如回答明显错误，可反馈（设置 → 反馈）
- 复杂问题建议咨询专业医生

### Q6.5 可以关闭语音播报吗？

可以：
1. 进入「我的 → 无障碍设置」
2. 关闭「语音播报」开关
3. 关闭后助手回复只显示文字
4. 长辈模式默认开启语音播报

## 7. 无障碍设置

### Q7.1 长辈模式有什么不同？

| 方面 | 标准模式 | 长辈模式 |
| --- | --- | --- |
| 字号 | 标准（16px） | 特大（22px） |
| 按钮 | 48px | 60px |
| 底部导航 | 5 项 | 4 项（今日/拍药盒/求助/我的） |
| 语音播报 | 关闭 | 开启 |
| 界面元素 | 完整 | 精简（隐藏次要信息） |
| 操作确认 | 标准 | 更保守（更多确认步骤） |

### Q7.2 如何切换主题？

1. 进入「我的 → 无障碍设置 → 主题」
2. 可选：跟随系统 / 浅色 / 深色 / 高对比
3. 切换后立即生效
4. 高对比模式强制黑白，适合视力障碍用户

### Q7.3 字号太大会不会导致界面错乱？

- 特大字号（1.35x）已测试，不会横向溢出
- 如发现错乱，截图反馈
- 部分图表在特大字号下可能需要横向滚动
- 建议竖屏使用

### Q7.4 读屏软件支持吗？

- 支持 Android TalkBack
- 所有可交互元素有语义标签
- 图标按钮有文字描述
- 动态内容有 aria-live 区域
- 建议配合长辈模式使用

### Q7.5 可以关闭动画效果吗？

可以：
1. 进入「我的 → 无障碍设置 → 减少动效」
2. 开启后关闭所有装饰动画
3. 页面切换、卡片悬浮等动画都会停用
4. 按钮按下的颜色变化保留
5. 也会自动跟随系统「减少动态效果」设置

## 8. 数据与隐私

### Q8.1 我的健康数据存在哪里？

- 联机模式：数据存储在家庭服务器（你或管理员部署的服务器）
- 演示模式：数据是模拟的，不存储
- 本地设置（无障碍偏好等）存储在手机本地
- 健康数据不会存储在手机本地（防止手机丢失泄露）

### Q8.2 数据会上传到云端吗？

- 默认不会
- 家庭服务器如果部署在公网，数据在公网传输（HTTPS 加密）
- 家庭服务器如果部署在局域网，数据完全不出局域网
- 不使用第三方云服务
- 不嵌入分析 SDK（如 Google Analytics、友盟等）

### Q8.3 如何删除我的数据？

1. 联系家庭管理员
2. 管理员在网页端「数据管理」中删除成员数据
3. 手机本地设置可在「我的 → 本地数据管理」清除
4. 卸载应用会清除本地设置
5. 服务器数据需要管理员操作

### Q8.4 别人能看到我的健康数据吗？

- 只有被你授权的家庭成员可以看到
- 授权可以限定可见字段（如只允许看用药，不允许看血压）
- 授权可以随时撤销
- 所有非 Owner 的访问都有审计日志
- 管理员可以查看审计日志

### Q8.5 应用会收集我的位置信息吗？

- 不会收集精确位置
- 天气功能只发送城市编码（6 位行政区划代码）
- 城市编码在设置中手动选择，不使用 GPS
- 不访问通讯录、相册、麦克风（语音用系统 API）
- 不收集设备标识符

## 9. 性能与网络

### Q9.1 应用很卡怎么办？

- 关闭减少动效（设置 → 无障碍 → 减少动效）
- 关闭深色主题（部分设备深色模式更耗性能）
- 清除浏览器缓存
- 关闭后台其他应用
- 如仍卡顿，提供设备型号和系统版本反馈

### Q9.2 弱网下能用吗？

- 已加载的页面可以浏览
- 数据操作需要网络，弱网下会显示加载状态
- 请求超时 15 秒，超时后提示重试
- 建议在 Wi-Fi 或 4G 下使用
- 不支持离线模式（健康数据需要实时同步）

### Q9.3 服务器连不上怎么办？

1. 确认服务器地址正确（我的 → 数据来源 → 服务器地址）
2. 确认服务器正在运行
3. 确认手机和服务器在同一网络（局域网部署）
4. 确认防火墙允许 18800 端口
5. 点击「测试连接」检查
6. 如仍不行，联系管理员

### Q9.4 流量消耗大吗？

- 日常使用流量很小（文本数据）
- 拍药盒识别会上传图片（每张 1-5MB）
- 建议在 Wi-Fi 下使用拍照识别
- 不自动播放视频
- 不后台同步数据

## 10. 其他问题

### Q10.1 支持 iOS 吗？

- 支持 PWA 方式（Safari 添加到主屏幕）
- 不提供 iOS App Store 版本
- iOS 部分功能受限（语音识别、后台刷新）
- 建议使用 Android 获得完整体验

### Q10.2 可以多个人同时使用吗？

- 可以，每个家庭成员有自己的账户
- 同一账户最多 3 个设备同时登录
- 操作会实时同步
- 冲突操作以最后一次为准（有乐观锁）

### Q10.3 如何反馈问题？

1. 进入「我的 → 关于 → 反馈」
2. 描述问题现象和复现步骤
3. 提供设备型号、系统版本、应用版本
4. 如有截图一并提供
5. 反馈会发送到家庭管理员（不发送到外部）

### Q10.4 应用版本在哪里看？

- 进入「我的 → 关于」
- 显示版本号、构建时间、Git commit
- 提供问题时请附上版本号
- PWA 版本会自动更新

### Q10.5 忘记家庭 PIN 怎么办？

- 家庭 PIN 用于敏感操作二次确认
- 忘记 PIN 需要家庭管理员重置
- 管理员在网页端「家庭设置 → 安全」中重置
- 重置后所有成员需要重新设置 PIN
- PIN 错误 5 次会锁定 10 分钟
