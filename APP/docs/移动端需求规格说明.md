# 移动端需求规格说明

> 本文档是家健镜随身版的完整需求规格说明，覆盖功能需求、非功能需求、用户故事、验收标准、优先级。面向产品、设计、开发和测试，作为需求管理和验收的权威依据。

## 1. 文档说明

### 1.1 产品定位

家健镜随身版（HomeCare Twin Companion）是家健镜系统的移动端入口，定位为「随身照护端」。老人和照护者用手机完成每天高频的照护动作，管理、复核、大屏和模型实验室等重度操作由网页端承担。

### 1.2 目标用户

| 用户角色 | 特征 | 核心需求 |
| --- | --- | --- |
| 老年人（60+） | 视力下降、动作变慢、数字技能弱 | 简单操作、大字体、语音辅助、提醒清晰 |
| 慢病患者 | 需长期管理、频繁用药 | 服药提醒、记录方便、趋势可见 |
| 照护者（子女/护工） | 时间紧张、多任务 | 高效操作、异常告警、授权管理 |
| 家庭管理员 | 技术能力较强 | 完整功能、配置管理、审计查看 |

### 1.3 需求优先级

| 优先级 | 定义 | 发布要求 |
| --- | --- | --- |
| P0 | 核心功能，没有则产品不可用 | 首版必须完成 |
| P1 | 重要功能，显著提升体验 | 首版尽量完成 |
| P2 | 优化功能，锦上添花 | 后续版本 |
| P3 | 未来规划 | 暂不实现 |

## 2. 功能需求

### 2.1 今日任务（FR-MOB-001）

**优先级：P0**

**用户故事：** 作为家庭成员，我希望在首页看到今天需要完成的照护任务，方便我逐一确认和记录。

**功能描述：**

1. 展示今日任务列表，按时间排序
2. 每个任务显示：药品名、剂量、时间、状态
3. 支持操作：确认、延期、跳过、记漏服
4. 显示任务完成进度（进度环 + 数字）
5. 操作后显示反馈（Toast + 触觉震动）
6. 全部完成后显示庆祝效果
7. 延期/跳过/记漏服需填写原因
8. 任务操作历史可查看

**验收标准：**

- [ ] 今日任务正确显示，按时间排序
- [ ] 确认任务后状态更新为「已确认」，显示确认时间
- [ ] 延期任务需选择延期时间和原因
- [ ] 跳过任务需填写原因
- [ ] 记漏服需填写原因，不自动补服
- [ ] 进度环实时更新
- [ ] 操作有 Toast 反馈
- [ ] 重复点击不产生重复事件（幂等）
- [ ] 服务端未返回动作策略时按钮置灰
- [ ] 任务操作历史可展开查看

### 2.2 拍药盒识别（FR-MOB-002）

**优先级：P0**

**用户故事：** 作为家庭成员，我希望用手机拍照识别药盒，自动录入药品信息，减少手动输入。

**功能描述：**

1. 大按钮「拍照识别」，调用系统相机或文件选择器
2. 支持图片和短视频（≤30秒）
3. 客户端基础质量检查（模糊、亮度、尺寸）
4. 创建视觉任务，显示识别进度
5. 状态回查：排队中→预处理→识别中→融合中→结果
6. 识别结果四态：MATCHED / CONFLICT / UNKNOWN / REVIEW
7. 排队中/处理中可取消本次识别
8. 候选确认引导到网页端复核中心
9. 未识别时提供手动录入入口

**验收标准：**

- [ ] 可调用系统相机拍照
- [ ] 图片过大/模糊时有提示
- [ ] 识别过程显示当前状态和预计时间
- [ ] 识别结果正确展示候选信息
- [ ] 取消识别复用同一任务，不新建
- [ ] 取消后任务进入终态
- [ ] 失败时显示错误原因和重试按钮
- [ ] 候选确认在网页端完成
- [ ] 视频支持抽帧识别
- [ ] 所有操作有加载状态

### 2.3 家人健康概览（FR-MOB-003）

**优先级：P0**

**用户故事：** 作为照护者，我希望查看被授权家人的健康概况，了解他们的状态。

**功能描述：**

1. 家人列表：头像、姓名、关系、健康摘要
2. 成员详情：基本信息、当前用药、最近风险、最近事件
3. 按授权范围显示数据，未授权字段显示「未获授权」
4. 显示授权范围说明（可见字段、用途、到期时间）
5. 支持切换成员查看

**验收标准：**

- [ ] 只显示被授权的成员
- [ ] 未授权字段不显示数据，显示占位提示
- [ ] 成员详情数据与服务端一致
- [ ] 授权范围说明清晰可见
- [ ] 切换成员数据正确更新
- [ ] 无授权成员时显示空状态

### 2.4 风险提醒（FR-MOB-004）

**优先级：P0**

**用户故事：** 作为家庭成员，我希望及时收到健康风险提醒，了解风险原因和处理建议。

**功能描述：**

1. 风险列表，按等级筛选（全部/严重/较高/一般/提示）
2. 风险卡片：等级标签（颜色+图标+文字）、标题、时间、摘要
3. 风险详情：原因、证据事件、非医疗处置建议
4. 「已知晓」回写（服务端支持时）
5. 严重风险不受预算压制，始终可见
6. 一般/提示级风险有每日预算控制

**验收标准：**

- [ ] 风险列表正确显示，按时间倒序
- [ ] 等级筛选功能正常
- [ ] 风险详情展示完整证据
- [ ] 严重风险始终可见
- [ ] 预算压制的风险不显示或显示「今日提醒已达上限」
- [ ] 「已知晓」按钮在服务端支持时可用
- [ ] 已知晓后风险从活跃列表移除
- [ ] 服务端不支持时按钮置灰并说明

### 2.5 知识条目（FR-MOB-005）

**优先级：P1**

**用户故事：** 作为家庭成员，我希望浏览健康知识条目，了解用药和疾病常识。

**功能描述：**

1. 知识条目列表，只显示已批准条目
2. 关键词检索（检索词只进请求体）
3. 条目详情：来源、许可、索引版本、生效时间、正文分块
4. 引用分块折叠/展开
5. 回到顶部
6. 无结果/无授权/索引空时分别提示

**验收标准：**

- [ ] 列表只显示已批准条目
- [ ] 检索功能正常，结果相关
- [ ] 详情页展示完整元数据
- [ ] 分块折叠/展开正常
- [ ] 三种空状态分别提示
- [ ] 检索词不出现在 URL 中
- [ ] 服务端不可用时如实提示

### 2.6 语音助手（FR-MOB-006）

**优先级：P1**

**用户故事：** 作为老年人，我希望用语音与助手对话，获取健康信息和操作指导。

**功能描述：**

1. 语音输入（Web Speech API）
2. 15 秒无输入自动停止
3. 语音播报回复（长辈模式自动播报）
4. 流式回复显示
5. 「停止生成」按钮
6. 证据面板（可折叠，展示引用来源）
7. 不支持语音时文字输入替代
8. 音频不上传

**验收标准：**

- [ ] 语音识别功能正常（支持设备）
- [ ] 15 秒无输入自动停止并提示
- [ ] 手动停止立即生效
- [ ] 流式回复逐字显示
- [ ] 停止生成后不再追加内容
- [ ] 证据面板展示引用来源
- [ ] 长辈模式自动播报回复
- [ ] 不支持语音时显示文字输入
- [ ] 空识别不发送请求
- [ ] 音频不上传到服务端

### 2.7 紧急求助（FR-MOB-007）

**优先级：P0**

**用户故事：** 作为老年人，我希望在紧急情况下快速拨打急救电话或联系家人。

**功能描述：**

1. 超大按钮「拨打急救电话」（≥120px）
2. 联系家人按钮
3. 当前重要提醒列表（可语音播报）
4. 长辈模式下底部导航直达
5. 拨打前确认（防止误触）

**验收标准：**

- [ ] 求助按钮足够大，易点击
- [ ] 点击后调用系统拨号界面（不直接拨号）
- [ ] 联系家人功能正常
- [ ] 重要提醒可语音播报
- [ ] 长辈模式下底部导航有求助入口
- [ ] 拨打前有确认步骤

### 2.8 我的与设置（FR-MOB-008）

**优先级：P0**

**用户故事：** 作为用户，我希望管理无障碍设置、数据来源和账户安全。

**功能描述：**

1. 用户信息展示
2. 无障碍设置：长辈模式、主题、字号、高对比、减少动效、语音播报
3. 数据来源切换：演示模式 / 家庭服务器
4. 服务器地址配置
5. 修改密码
6. 家庭 PIN 二次确认
7. 隐私与边界声明
8. 本地数据管理（查看/清除）
9. 最近请求与回执（诊断）
10. 关于（版本号、开源声明）

**验收标准：**

- [ ] 所有设置可正常切换并即时生效
- [ ] 设置保存在本机 localStorage
- [ ] 数据来源切换后重新加载数据
- [ ] 服务器地址可配置和测试连接
- [ ] 修改密码需旧密码验证
- [ ] 修改密码后其他设备登出
- [ ] 隐私声明可朗读
- [ ] 本地数据可逐项清除
- [ ] 最近请求展示 request_id 和状态
- [ ] 版本号正确显示

### 2.9 登录与注册（FR-MOB-009）

**优先级：P0**

**用户故事：** 作为用户，我希望登录账户访问我的家庭健康数据。

**功能描述：**

1. 服务器地址配置（首次使用）
2. 用户名密码登录
3. 注册新账户
4. 会话管理（内存存储，刷新需重登）
5. 401 自动跳转登录
6. 登录失败提示（不区分用户名/密码错误）

**验收标准：**

- [ ] 可配置服务器地址
- [ ] 登录成功后进入今日页
- [ ] 注册功能正常
- [ ] 会话过期后跳转登录
- [ ] 登录失败有友好提示
- [ ] 密码输入框可显示/隐藏
- [ ] 表单校验（用户名格式、密码强度）

### 2.10 环境行动卡（FR-MOB-010）

**优先级：P1**

**用户故事：** 作为家庭成员，我希望根据天气情况获得相应的健康行动建议。

**功能描述：**

1. 显示当前城市天气（温度、湿度、AQI、紫外线）
2. 根据天气生成行动卡（高温→药品储存，低温→血压监测等）
3. 行动卡有有效期，过期不显示
4. 只发送城市编码，不发送精确位置
5. 天气服务不可用时降级提示

**验收标准：**

- [ ] 天气信息正确显示
- [ ] 行动卡与天气条件匹配
- [ ] 过期行动卡不显示
- [ ] 请求只含城市编码
- [ ] 上游失败时显示降级提示
- [ ] 频繁请求使用缓存

## 3. 非功能需求

### 3.1 性能需求（NFR-MOB-001）

| 指标 | 目标 | 测量方式 |
| --- | --- | --- |
| 首屏可交互（4G） | ≤1500ms | Lighthouse |
| 首屏可交互（Slow 3G + 4x CPU） | ≤3000ms | 性能脚本 |
| 路由切换 | ≤300ms | 性能脚本 |
| 断网恢复 | ≤500ms | 性能脚本 |
| JS gzip 体积 | ≤170 KiB | 构建统计 |
| CSS gzip 体积 | ≤30 KiB | 构建统计 |
| 滚动帧率 | ≥55fps | Chrome DevTools |
| 输入响应延迟 | ≤100ms | Chrome DevTools |

### 3.2 兼容性需求（NFR-MOB-002）

| 维度 | 要求 |
| --- | --- |
| Android 版本 | ≥7.0（API 24） |
| iOS 版本 | ≥14.0（PWA） |
| 浏览器 | Chrome 90+、Safari 14+、Edge 90+ |
| 屏幕尺寸 | 320px - 1280px 宽 |
| 屏幕方向 | 竖屏/横屏均适配 |
| WebView | Android System WebView 最新版 |
| 折叠屏 | 外屏/内屏切换不丢失状态 |

### 3.3 无障碍需求（NFR-MOB-003）

| 要求 | 标准 |
| --- | --- |
| 文字对比度 | ≥4.5:1（正文），≥3:1（大文字） |
| 触控目标 | ≥48×48px（长辈模式 ≥60×60px） |
| 读屏兼容 | TalkBack 可朗读所有元素 |
| 键盘导航 | 所有操作可通过键盘完成 |
| 焦点可见 | 焦点环清晰可见 |
| 不只靠颜色 | 状态有文字+图标+颜色 |
| 大字号 | 特大字号（1.35x）无横向溢出 |
| 高对比 | 黑白强对比模式 |
| 减少动效 | 尊重系统设置，可手动开启 |
| 语音辅助 | 关键操作可语音播报 |

### 3.4 安全需求（NFR-MOB-004）

| 要求 | 说明 |
| --- | --- |
| 数据传输 | HTTPS（公网），家庭局域网可 HTTP |
| 会话存储 | 仅内存，不持久化 |
| 密码传输 | 不明文存储，HTTPS 传输 |
| 本地存储 | 不存健康数据和认证凭据 |
| 权限最小化 | 只申请 INTERNET 权限 |
| 备份禁止 | Android allowBackup=false |
| 输入校验 | 防 XSS、防注入 |
| 授权校验 | 服务端强制，客户端不缓存越权数据 |
| 隐私 | 不收集行为数据，不嵌入分析 SDK |
| 审计 | 非 Owner 访问有审计日志 |

### 3.5 隐私需求（NFR-MOB-005）

- 健康数据默认不出网
- 不收集位置信息（天气用城市编码）
- 不访问通讯录（紧急联系人手动输入）
- 不使用麦克风（语音用系统 API，音频不上传）
- 不使用相机权限（通过文件选择器拍照）
- 首次使用展示隐私告知
- 提供本地数据清除功能
- 不展示广告和商品推荐

### 3.6 可靠性需求（NFR-MOB-006）

- 崩溃率 <0.1%
- 网络错误有优雅降级
- 弱网下不卡死
- 数据操作幂等
- 应用升级不丢失本地设置
- Service Worker 更新不破坏现有功能

### 3.7 可维护性需求（NFR-MOB-007）

- 代码 TypeScript 类型覆盖率 ≥90%
- 单元测试覆盖率 ≥70%
- 组件单一职责，可复用
- 文档完整（架构、API、部署、故障排查）
- 命名规范统一
- 无魔法数字和硬编码

### 3.8 可部署性需求（NFR-MOB-008）

- PWA 静态资源可由任意静态服务器托管
- APK 构建脚本一键化
- 构建产物有 SHA-256 清单
- 版本号和构建时间注入产物
- 支持回滚到上一版本

紧急情况
