## 3. 可复跑自动化

在 `APP/` 目录执行：

```powershell
npm run check
npm run test
npm run build
npm run android:sync
npm run privacy:scan
npm run audit:android-security
npm run audit:pwa
npm run perf:budget
npm run perf:budget:low-end
npm run test:perf-budget
npm run test:privacy-scan
npm run release:manifest -- --out release
```

本次复核结果为：`check`、测试（31 个文件 / 282 tests）、构建、Capacitor 同步、隐私、安全、PWA、基线性能、低端设备性能、两个回归测试和产物清单均通过。`release/` 只用于本机临时产物，不提交仓库。

性能脚本会在每个新的浏览器 context 中先按真实用户路径确认首次隐私告知，再进入提醒、设置和断网恢复场景。这样既保留隐私告知语义，也避免自动化绕过真实 UI。

## 4. 待补证据

以下项目不能由本机静态检查代替：

1. 启动受控 HTTPS 后端和合成数据，运行 `npm run verify:linkage`，记录 APP/服务端提交、API 版本和种子指纹。
2. 准备 JDK 21–24 与 Android SDK，运行 `scripts/build-apk.ps1`，记录 APK SHA-256、版本和工具链；APK 与签名材料不得提交。
3. 在 Android 真机执行安装、升级、切后台、断网/恢复、权限、TalkBack、TTS、触觉和 320/375px 小屏验收。
4. 安装失败或候选版本撤回时，演练恢复上一份已验证的 PWA shell、APK、API 和合成数据指纹。
5. 由维护者把脱敏记录填入未跟踪的 `mob148-final-release-record.json`，再对 #234 做最终裁决。
