# 移动端数据模型与接口字典

> 本文档是家健镜随身版的数据模型与接口完整字典，覆盖所有 TypeScript 类型定义、API 接口请求响应格式、枚举值、状态机。面向后端和移动端开发者，作为联调和开发的权威依据。

## 1. 通用类型

### 1.1 基础类型

```typescript
// UUID/ULID 标识符
type ID = string;

// ISO 8601 时间字符串（含时区）
type DateTime = string;  // 例："2026-09-03T14:30:00+08:00"

// 日期字符串
type DateString = string;  // 例："2026-09-03"

// 分页游标
type Cursor = string;

// 能力状态
type CapabilityStatus = "available" | "unavailable";

// 通用分页响应
interface PaginatedResponse<T> {
  items: T[];
  next_cursor: Cursor | null;
  has_more: boolean;
}

// 通用错误
interface ApiError {
  code: string;
  message: string;
  request_id?: string;
  details?: Record<string, unknown>;
}
```

## 14. 状态机汇总

### 14.1 视觉任务状态机

```
QUEUED → PREPROCESSING → INFERENCING → FUSING → MATCHED
                                               ↘ CONFLICT
                                               ↘ UNKNOWN
                                               ↘ REVIEW
任意非终态 → CANCELLED
任意步骤 → FAILED
```

### 14.2 任务状态机

```
pending → confirmed（确认）
pending → deferred（延期）→ pending（到时间后）
pending → skipped（跳过）
pending → missed（记漏服/超时）
```

### 14.3 授权状态机

```
active → revoked（主动撤销）
active → expired（到期自动）
revoked → active（不允许，需新建授权）
```

### 14.4 风险状态机

```
active → acknowledged（用户确认）
active → expired（到期自动）
acknowledged → active（不允许，需新事件触发）
```

## 15. 错误码字典

| HTTP | code | 说明 | 客户端处理 |
| --- | --- | --- | --- |
| 400 | VALIDATION_ERROR | 参数校验失败 | 显示字段错误 |
| 401 | UNAUTHORIZED | 未登录或会话过期 | 清除会话，跳转登录 |
| 403 | ACCESS_DENIED | 无权限访问 | 显示无权限提示 |
| 404 | RESOURCE_NOT_FOUND | 资源不存在 | 显示不存在（不区分无权限） |
| 409 | IDEMPOTENCY_KEY_CONFLICT | 幂等键冲突 | 提示操作已提交 |
| 409 | AUTHORIZATION_VERSION_CONFLICT | 授权版本冲突 | 重新加载授权 |
| 409 | PROJECTION_CHECKSUM_MISMATCH | 投影校验和不匹配 | 触发重放 |
| 422 | VALIDATION_ERROR | Pydantic 校验失败 | 显示字段错误 |
| 429 | RATE_LIMITED | 请求限流 | 禁用重试 |
| 500 | INTERNAL_ERROR | 服务器内部错误 | 显示错误，提供重试 |
| 503 | SERVICE_UNAVAILABLE | 服务不可用 | 保留旧数据，提示稍后重试 |
| 网络 | NETWORK_ERROR | 网络连接失败 | 检查网络，重试 |
| 网络 | TIMEOUT | 请求超时 | 15s 超时，提示重试 |
