## 1. 这份脚本保证什么

本脚本把移动端演示收敛为一条可重复的人工路径：进入演示家庭 → Today 首页 → 查看本地季节健康资讯 → 把资讯上下文带入助手 → 观察助手的诚实降级或本地知识引用 → 返回今日任务 → 清理本机状态。它适用于 PWA 和 Capacitor Android debug APK。

脚本不把“页面能打开”说成“模型已部署”。默认演示模式不访问家庭服务器，也不会生成真实助手引用；要演示可点击的知识库引用，必须在同一台可信电脑上启动本地家庭服务器并使用其本地知识/模型能力。外网、云端模型、真实家庭记录和录屏自动化都不属于本 Story 的交付范围。

## 2. 交付物与边界

### 2.1 PWA 与 APK

- `dist/` 是 PWA 构建产物，包含 `index.html`、Manifest、图标和 Service Worker。
- `android/app/build/outputs/apk/debug/app-debug.apk` 是本机临时 debug 包，只用于教学演示，不是商店发布包；APK 不进 Git。
- `npm run demo:ready` 是本地只读预检，不启动服务、不联网、不读取健康数据。它会检查 PWA 外壳、图标、Manifest、Service Worker 的 `/api`/`/health` 不缓存边界，并可选计算 APK SHA-256。
- 发布候选需要另行运行 `npm run release:manifest` 记录源码提交与产物哈希；清单和 APK 均保留在本机受控目录，不把真实局域网地址、签名材料或调试日志写进仓库。

### 2.2 数据与模式

- 默认选择登录页的“改用演示模式”。人物、任务、风险、药品与季节资讯均为应用内虚构教学数据；“本地季节日历（演示）”是预期来源，不是外网新闻。
- Service Worker 只缓存应用外壳；`/api` 和 `/health` 响应不会进入缓存。离线导航最多显示安全外壳，不显示旧的健康页面数据。
- 联机路径只连接操作者明确填写的家庭服务器。服务器可用本地 SQLite/本地夹具；手机与电脑需在同一可信局域网，不能把 `localhost` 填到手机上。

## 3. 一键就绪（每次演示前）

在仓库根目录执行：

```powershell
scripts/start.ps1 setup
```

在 `APP/` 执行以下构建与检查：

```powershell
npm ci
npm run check
npm run test
npm run build
npm run demo:ready
npm run privacy:scan
npm run release:manifest -- --out release
```

`release/` 是本机产物目录，不要 `git add`。若只演示 PWA，可执行：

```powershell
npm run preview -- --host 127.0.0.1 --port 4173
```

再用同一台电脑的浏览器打开预览地址；需要手机访问时，使用电脑在可信局域网中的地址，并确认防火墙只对演示网络开放。

若需要 APK：

```powershell
npm run android:sync:debug
powershell -ExecutionPolicy Bypass -File scripts/build-apk.ps1 -JavaHome "<JDK 21-24 或 Android Studio JBR>"
npm run demo:ready -- --apk android/app/build/outputs/apk/debug/app-debug.apk --require-apk
npm run release:manifest -- --apk android/app/build/outputs/apk/debug/app-debug.apk --out release
```

把生成的 debug APK 通过 USB 或 Android Studio 安装到演示设备。不要把 APK 拷回仓库，也不要把 `android/local.properties`、签名文件或模型文件提交。

### 3.1 联机（可选）准备

只有需要展示“本地知识库引用”时才走此路径：

1. 在仓库根目录按[本地部署与 Demo 操作指南](../../docs/本地部署与Demo操作指南.md)启动本地 API；本地进程端口通常为 `8000`，APP 自带的演示造数脚本默认用于 `18800` 的受控本地服务，按实际服务端口填写，不要猜测。
2. 只使用合成演示家庭。可在 `APP/` 执行 `npm run seed:live -- --base http://127.0.0.1:18800`；脚本写入的账号、成员和事件均带演示标记，不使用真实数据。
3. 在手机“我的 → 数据来源”选择“家庭服务器（联机）”，填写电脑在可信局域网内的地址（例如 `http://192.168.x.x:8000`），选择明确的 `family-care` 访问目的，并使用演示账号。手机端不能填写电脑的 `127.0.0.1`/`localhost`。
4. 若本地模型或知识库不可用，助手必须显示结构化降级和原因；不要把降级文案讲成模型回答，也不要伪造引用。

## 4. 连续演示主线（默认离线/演示模式）

### 4.1 进入与首页

1. 用干净的浏览器站点数据或刚安装的 debug APK 启动应用。
2. 在登录页点击“改用演示模式”，确认页面标有“演示/教学演示”边界；不输入真实姓名、手机号、密码、家庭地址或健康记录。
3. 进入 Today 首页，确认虚构成员和今日任务可见。此时浏览器网络面板不应出现家庭服务器 API 请求；PWA 的 Service Worker 只负责外壳，不负责保存健康数据。

### 4.2 首页健康资讯 → 助手

1. 在首页找到“健康资讯”卡片，确认来源类似“本地季节日历（演示）”，并能看到生成时间/状态“本地季节”。
2. 点击“带着问题问助手”。预期进入助手页，输入框出现包含资讯标题和来源的可编辑草稿；应用不会自动发送。
3. 先不要修改草稿，向观众说明：这是把资讯上下文交给助手的入口，标题和来源可在发送前编辑。
4. 在默认演示模式点击发送一次。预期看到明确的“演示模式不连接家庭服务器”提示；该提示是正常降级，不能宣称“已调用模型”或“已生成引用”。
5. 返回 Today，确认今日任务卡仍可打开，且返回过程中没有把演示草稿或接口响应冒充为服务端事实。

### 4.3 可选的本地引用路径

如已按 §3.1 启动可信本地服务：

1. 在“我的 → 数据来源”完成联机自检，确认地址、家庭、身份和能力状态均来自本地家庭服务器。
2. 回到健康资讯卡片，点击“带着问题问助手”，发送一个不涉及诊断、剂量、停药、购药或个人敏感信息的教学问题。
3. 只有当回答实际返回本地知识条目时，才展开“查看依据”，让观众看到可点击的条目标题、版本/来源和本次回答关联。引用打不开、版本为空或服务端返回无证据时，应按表 1 话术降级，不补写或口头猜测引用。
4. 演示结束后回到“我的”，点击“清理本地设置并退出联机”并按二次确认完成清理；这只清理手机本地设置，不删除服务端事实。

## 5. 离线与弱网故障演练

| 场景 | 预期表现 | 讲解/回退话术 |
| --- | --- | --- |
| 默认演示模式 | 首页虚构成员、任务和本地季节资讯可展示；助手发送显示演示模式诚实降级 | “这是离线教学路径，不连接家庭服务器；真实回答需要切到联机并使用本地模型。” |
| PWA 断网导航 | 已缓存的应用外壳可打开；动态健康数据不显示，必要时出现“当前无法连接网络”安全外壳 | “为保护隐私，应用不显示或缓存旧的健康页面数据；恢复网络后再试。” |
| 家庭服务器不可达/超时 | 页面显示家庭服务器不可访问和重试入口；不重复提交、不伪造成功 | “电脑后端或局域网暂时不可用，先重试；本次没有写入服务端。” |
| 模型不可用 | 助手显示结构化降级原因；不出现伪造引用、诊断、处方或剂量建议 | “本地模型还没就绪，当前只展示可解释的降级状态。” |
| 没有健康资讯 | 首页保留其他任务，资讯卡显示无可用内容；不填充外网文章 | “教学夹具当前没有卡片，其他移动端流程仍可演示。” |
| APK 构建失败 | 停留在 PWA 路径；记录 JDK/SDK 缺失，不把旧 APK 说成新版本 | “今天使用 PWA 演示，APK 待补齐本机 Android 构建环境。” |
| 来源/家庭未确认 | 保持未联机或显示设置入口，阻断家庭数据和写操作 | “先完成家庭服务器地址、身份和访问目的确认。” |

## 6. 演示结束与清理

1. 联机路径先在“我的”执行“清理本地设置并退出联机”，看到成功结果后再关闭应用。若清理报告失败，不能说已清除；按报告提示检查浏览器存储权限后重试。
2. PWA 使用浏览器站点设置清除该演示地址的数据，或使用干净的临时浏览器配置文件。不要清除整台电脑的用户目录。
3. APK 演示完成后卸载 debug 应用；若使用了本地 API，按部署指南停止服务。需要清理服务器合成数据时先使用仓库提供的 dry-run/清理脚本并核对目标，只能清理带演示标记的数据，绝不删除真实家庭记录。
4. 不保留屏幕截图中的账号、局域网地址、访问令牌、请求日志或真实成员信息。发布 PR 时只提交脚本、文档和自动检查证据。

### 当前已知限制

- 本次交付不包含录屏自动化、CI 演示编排、外网抓取或模型权重；不把这些缺口隐藏在“演示通过”里。
- 默认演示模式的助手不会连接家庭服务器，因此没有真实引用；引用验收必须走可信本地联机路径并记录知识库版本。
- Android 真机的安装、断网/恢复、后台恢复、TalkBack、TTS、320/375px 小屏与升级回滚仍需设备持有人按对应 Story 签收。`demo:ready` 通过只代表静态包和缓存边界合格，不代表这些人工验收已完成。
- 该脚本不包含任何账号密码、局域网 IP、令牌或真实健康数据；演示者应在现场通过占位符和本地受控环境填写。
