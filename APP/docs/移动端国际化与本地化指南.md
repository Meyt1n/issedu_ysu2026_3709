# 移动端国际化与本地化指南

> 本文档是家健镜随身版的国际化（i18n）与本地化（l10n）指南，覆盖多语言架构、翻译管理、日期时间格式、数字格式、文化适配。面向移动端开发者，作为国际化开发的权威依据。

## 1. 国际化策略

### 1.1 目标语言

| 语言 | 代码 | 优先级 | 状态 |
| --- | --- | --- | --- |
| 简体中文 | zh-CN | P0 | 默认语言，已实现 |
| 繁体中文 | zh-TW | P2 | 计划中 |
| 英语 | en-US | P1 | 计划中 |
| 日语 | ja-JP | P3 | 未来规划 |

### 1.2 语言检测顺序

1. URL 参数（`?lang=zh-CN`）
2. 用户设置（localStorage）
3. 浏览器语言（`navigator.language`）
4. 默认语言（zh-CN）

### 1.3 架构设计

```
┌─────────────────────────────────────┐
│           应用组件                   │
│     $t('key') / t('key')            │
├─────────────────────────────────────┤
│         i18n 实例 (vue-i18n)         │
│  - 语言切换                          │
│  - 消息加载                          │

├─────────────────────────────────────┤
│        语言包 (locales/)             │
│  zh-CN.json / en-US.json / ...      │
└─────────────────────────────────────┘
```

### 2.2 Key 命名规范

- 使用点号分层：`模块.子模块.键名`
- 全部小写，单词用连字符或驼峰
- 不使用空格和特殊字符
- 语义化命名，不使用编号

```typescript
// 好
t('today.tasks.confirm')
t('vision.status.processing')
t('error.network.timeout')

// 不好
t('button1')
t('text_001')
t('今天的任务确认按钮')
```

### 2.3 插值

```typescript
// 基本插值
t('greeting', { name: '张三' })  // "你好，张三"

// 复数
t('items', { count: 1 })  // "1 个项目"
t('items', { count: 5 })  // "5 个项目"

// 语言包
{
  "items": "{count} 个项目 | {count} 个项目"  // 中文无复数变化
}
```

### 2.4 翻译提取

```bash
# 提取代码中的翻译 key
npm run i18n:extract

# 检查未翻译的 key
npm run i18n:check
```

## 3. 日期时间本地化

### 3.1 格式规范

| 场景 | 中文格式 | 英文格式 | 示例（中文） |
| --- | --- | --- | --- |
| 完整日期时间 | YYYY年MM月DD日 HH:mm | MMM D, YYYY h:mm A | 2026年09月03日 14:30 |
| 日期 | YYYY-MM-DD | MM/DD/YYYY | 2026-09-03 |
| 时间 | HH:mm | h:mm A | 14:30 |
| 相对时间 | x分钟前 | x min ago | 5分钟前 |
| 星期 | 星期一 | Monday | 星期一 |

### 3.2 实现

```typescript
import { useI18n } from 'vue-i18n'

export function useDateTime() {
  const { locale } = useI18n()

  const formatDate = (date: Date | string) => {
    return new Intl.DateTimeFormat(locale.value, {
      year: 'numeric',
      month: '2-digit',
      day: '2-digit',
    }).format(new Date(date))
  }

  const formatTime = (date: Date | string) => {
    return new Intl.DateTimeFormat(locale.value, {
      hour: '2-digit',
      minute: '2-digit',
      hour12: locale.value.startsWith('en'),
    }).format(new Date(date))
  }

  const formatRelative = (date: Date | string) => {
    const diff = Date.now() - new Date(date).getTime()
    const minutes = Math.floor(diff / 60000)
    if (minutes < 1) return t('just_now')
    if (minutes < 60) return t('minutes_ago', { count: minutes })
    // ...
  }

  return { formatDate, formatTime, formatRelative }
}
```

### 3.3 时区处理

- 所有时间存储为 UTC（ISO 8601）
- 显示时转换为用户本地时区
- 家庭时区用于任务时间计算
- 不假设用户在家庭所在时区

```typescript
// 存储
const stored = new Date().toISOString()  // "2026-09-03T06:30:00.000Z"

// 显示（自动转换为本地时区）
const display = formatDateTime(stored)  // "2026年09月03日 14:30"
```

  return new Intl.NumberFormat(locale.value, {

### 4.3 单位

| 物理量 | 中国 | 美国 | 英国 |
| --- | --- | --- | --- |
| 温度 | 摄氏度 (°C) | 华氏度 (°F) | 摄氏度 (°C) |
| 重量 | 千克 (kg) | 磅 (lb) | 千克 (kg) |
| 身高 | 厘米 (cm) | 英尺英寸 | 厘米 (cm) |
| 血压 | mmHg | mmHg | mmHg |
| 血糖 | mmol/L | mg/dL | mmol/L |

```typescript
const formatTemperature = (celsius: number) => {
  const unit = userPreferences.temperatureUnit || 'celsius'
  if (unit === 'fahrenheit') {
    const f = celsius * 9/5 + 32
    return `${f.toFixed(1)}°F`
  }
  return `${celsius.toFixed(1)}°C`
}
```

## 5. 文本方向

### 5.1 RTL 支持（未来）

- 阿拉伯语、希伯来语等从右到左
- 需要 `dir="rtl"` 属性
- 布局镜像（左变右，右变左）
- 当前版本不支持 RTL，仅规划

### 5.2 文字长度适配

- 英文通常比中文长 30-50%
- 按钮和标签预留空间
- 不固定宽度，使用 min-width
- 长文本自动换行

```css
.button {
  min-width: 80px;
  padding: 0 16px;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

## 6. 文化适配

### 6.1 颜色含义

| 颜色 | 中国 | 西方 | 注意 |
| --- | --- | --- | --- |
| 红色 | 喜庆、好运 | 危险、错误 | 风险等级红色通用 |
| 白色 | 哀悼 | 纯洁、和平 | 不用于喜庆场景 |
| 绿色 | 健康、环保 | 自然、通行 | 主色绿色通用 |
| 蓝色 | 科技、冷静 | 信任、专业 | 信息色通用 |

### 6.2 图标与符号

- 避免使用文化特定符号（如龙、十字架等）
- 使用通用图标（对勾、X、箭头）
- 手势图标可能有文化差异，尽量不用
- 数字 4 在中文语境不避讳（医疗产品）

### 6.3 称呼与礼貌

- 中文：您、请、谢谢
- 英文：Please、Thank you、您（无尊称区分）
- 日语：です/ます体
- 长辈模式使用更礼貌的用语

## 7. 语言切换

### 7.1 切换实现

```typescript
// stores/i18n.ts
export const useI18nStore = defineStore('i18n', {
  state: () => ({
    locale: 'zh-CN',
  }),
  actions: {
    setLocale(locale: string) {
      this.locale = locale
      i18n.global.locale.value = locale
      localStorage.setItem('hct-locale', locale)
      // 更新 HTML lang 属性
      document.documentElement.lang = locale
    },
    init() {
      const saved = localStorage.getItem('hct-locale')
      const browser = navigator.language
      this.locale = saved || (SUPPORTED_LOCALES.includes(browser) ? browser : 'zh-CN')
      i18n.global.locale.value = this.locale
    },
  },
})
```

### 7.2 动态加载语言包

```typescript
const loadLocale = async (locale: string) => {
  if (!i18n.global.availableLocales.includes(locale)) {
    const messages = await import(`../locales/${locale}.json`)
    i18n.global.setLocaleMessage(locale, messages.default)
  }
}
```
