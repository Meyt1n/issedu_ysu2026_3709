# 移动端无障碍设计规范（完整版）

> 本文档是家健镜随身版无障碍设计的完整规范，覆盖视觉、听觉、运动、认知四个维度的无障碍需求，以及具体的实现标准、测试方法和验收清单。面向设计师、前端开发者和测试人员，作为产品开发和验收的权威依据。

## 1. 设计理念

### 1.1 为什么无障碍优先

家健镜随身版的核心用户是老年人和慢病患者，其中相当比例存在不同程度的视力、听力、运动或认知障碍。无障碍不是「额外功能」，而是产品的基础能力：

- **视力障碍**：老花眼、白内障、青光眼、低视力、全盲
- **听力障碍**：老年性耳聋、耳鸣、全聋
- **运动障碍**：帕金森、关节炎、脑卒中后遗症、手抖
- **认知障碍**：轻度认知障碍、痴呆早期、学习障碍

无障碍设计同时改善所有用户的体验：大字号让阳光下阅读更清晰，高对比让强光下可见，语音播报让双手忙碌时可用。

### 1.2 设计原则

| 原则 | 说明 |
| --- | --- |
| 可感知 | 信息必须通过多种感官通道呈现（视觉+听觉+触觉） |
| 可操作 | 交互元素必须足够大、间距足够、支持多种输入方式 |
| 可理解 | 文案必须简洁明确，避免专业术语和歧义 |
| 健壮性 | 与辅助技术（读屏、放大、语音控制）兼容 |
| 诚实降级 | 无障碍功能不可用时如实提示，不冒充可用 |

### 1.3 合规标准

- **WCAG 2.1 AA**：Web 内容无障碍指南，所有页面需达到 AA 级
- **WCAG 2.1 AAA**：关键页面（今日、求助、登录）尽量达到 AAA 级
- **Android Accessibility**：与 TalkBack、放大手势、颜色校正兼容
- **GB/T 37668-2019**：信息技术 互联网内容无障碍可访问性技术要求

## 2. 视觉无障碍

### 2.1 字号系统

#### 2.1.1 三档字号

| 档位 | CSS 缩放 | 基准字号 | 适用场景 |
| --- | --- | --- | --- |
| 标准 | 1.0 | 16px | 年轻用户、视力正常 |
| 大 | 1.15 | 18.4px | 轻度老花、一般老年人 |
| 特大 | 1.35 | 21.6px | 中重度低视力、长辈模式默认 |

**实现：**

```css
:root { --font-scale: 1; }
[data-fontsize="large"] { --font-scale: 1.15; }
[data-fontsize="xlarge"] { --font-scale: 1.35; }

html { font-size: calc(16px * var(--font-scale)); }
body { font-size: 1rem; }
h1 { font-size: 1.5rem; }
h2 { font-size: 1.25rem; }
```

**约束：**
- 所有字号使用 `rem` 或 `em`，不使用固定 `px`
- 特大字号下不产生横向滚动
- 特大字号下按钮文字不截断
- 特大字号下表格可横向滚动或转为卡片布局

#### 2.1.2 系统字号跟随

应用尊重系统字号设置：
- Android：设置 → 显示 → 字体大小
- 检测 `window.matchMedia('(prefers-reduced-motion)')` 等系统偏好
- 系统字号最大档时，应用字号至少达到 1.35 倍

### 2.2 颜色与对比度

#### 2.2.1 对比度要求

| 元素 | WCAG AA | WCAG AAA | 本项目目标 |
| --- | --- | --- | --- |
| 正文文字 | 4.5:1 | 7:1 | 7:1 |
| 大文字（≥18pt 或 ≥14pt 粗体） | 3:1 | 4.5:1 | 4.5:1 |
| 图标/图形 | 3:1 | - | 3:1 |
| UI 组件边界 | 3:1 | - | 3:1 |

#### 2.2.2 色板对比度验证

浅色主题关键组合：

| 组合 | 前景 | 背景 | 对比度 | 等级 |
| --- | --- | --- | --- | --- |
| 正文 | #2c2c2c | #fffaf1 | 12.6:1 | AAA |
| 次要文字 | #5a5a5a | #fffaf1 | 7.2:1 | AAA |
| 弱化文字 | #8a8a8a | #fffaf1 | 4.1:1 | AA（大文字） |
| 主色按钮文字 | #ffffff | #2e7d32 | 4.7:1 | AA |
| 强调色文字 | #bf5a36 | #fffaf1 | 5.2:1 | AA |
| 严重风险 | #c62828 | #fffaf1 | 5.8:1 | AA |

深色主题关键组合：

| 组合 | 前景 | 背景 | 对比度 | 等级 |
| --- | --- | --- | --- | --- |
| 正文 | #e8f5e9 | #1a2e1f | 11.2:1 | AAA |
| 次要文字 | #a5d6a7 | #1a2e1f | 7.8:1 | AAA |
| 主色按钮文字 | #1b5e20 | #66bb6a | 4.2:1 | AA |

#### 2.2.3 高对比模式

高对比模式是无障碍的强制兜底，优先级高于深色模式：

```css
[data-contrast="high"] {
  --bg-paper: #ffffff;
  --surface: #ffffff;
  --text-primary: #000000;
  --text-secondary: #000000;
  --border: #000000;
  --border-strong: #000000;
  --shadow-paper: none;
  --shadow-elevated: none;
  --primary: #0000ff;    /* 纯蓝链接色 */
  --accent: #0000ff;
}

[data-contrast="high"] .card {
  border: 2px solid #000;
  background: #fff;
  border-radius: 0;     /* 去除圆角，边界更清晰 */
}

[data-contrast="high"] .glass {
  background: #fff;     /* 去除玻璃效果 */
  backdrop-filter: none;
}
```

**高对比模式行为：**
- 纯白实底 + 纯黑文字 + 纯黑描边
- 去除所有渐变、阴影、玻璃、模糊效果
- 按钮用 2px 黑边框区分
- 链接用纯蓝 + 下划线
- 焦点环用 3px 黑色虚线

### 2.3 不只靠颜色

所有状态、等级、分类必须使用「文字 + 图标 + 颜色」三重表达：

| 风险等级 | 颜色 | 图标 | 文字标签 | 形状 |
| --- | --- | --- | --- | --- |
| SEVERE 严重 | 红 #c62828 | ⛔ / 停止标志 | 「严重」 | 八边形 |
| HIGH 较高 | 橙 #e65100 | ⚠️ / 感叹号 | 「较高」 | 三角形 |
| INFO 一般 | 蓝 #1565c0 | ℹ️ / 信息 | 「一般」 | 圆形 |
| LOW 提示 | 灰 #616161 | 💡 / 灯泡 | 「提示」 | 方形 |

**实现示例：**

```html
<div class="risk-tag risk-severe" role="img" aria-label="严重风险">
  <svg class="risk-icon" aria-hidden="true">...</svg>
  <span class="risk-text">严重</span>
</div>
```

```css
.risk-tag {
  display: inline-flex;
  align-items: center;
  gap: 4px;
  padding: 4px 8px;
  border-radius: 4px;
  font-weight: 600;
}
.risk-severe {
  background: rgba(198, 40, 40, 0.1);
  color: #c62828;
  border: 1px solid #c62828;
}
```

### 2.4 焦点可见性

#### 2.4.1 焦点环

```css
:focus-visible {
  outline: 3px solid #1565c0;
  outline-offset: 2px;
  border-radius: 4px;
}

[data-contrast="high"] :focus-visible {
  outline: 3px dashed #000;
  outline-offset: 2px;
}

/* 鼠标点击时不显示焦点环，键盘导航时显示 */
:focus:not(:focus-visible) {
  outline: none;
}
```

#### 2.4.2 焦点管理

- 所有可交互元素可通过 Tab 键聚焦
- 焦点顺序与视觉顺序一致（DOM 顺序）
- 模态框打开时焦点陷阱在模态内
- 模态框关闭后焦点回到触发元素
- 路由切换后焦点移至主内容区（`<main tabindex="-1">`）
- 动态内容更新时，焦点不意外跳转

#### 2.4.3 跳过导航

页面顶部提供「跳转到主内容」链接，Tab 键第一个聚焦项：

```html
<a href="#main-content" class="skip-link">跳转到主内容</a>
<main id="main-content" tabindex="-1">...</main>
```

```css
.skip-link {
  position: absolute;
  top: -40px;
  left: 0;
  background: #000;
  color: #fff;
  padding: 8px 16px;
  z-index: 1000;
  transition: top 0.2s;
}
.skip-link:focus {
  top: 0;
}
```

### 2.5 放大与缩放

- 页面支持浏览器 200% 缩放，不产生横向滚动
- 支持 Android 放大手势（系统级放大）
- 重要内容不依赖 `hover` 显示（移动端无 hover）
- 图片提供 `alt` 文本，复杂图片提供长描述

## 3. 听觉无障碍

### 3.1 语音播报

#### 3.1.1 Web Speech API

使用浏览器内置的 Web Speech API 进行中文语音合成：

```typescript
function speak(text: string, opts?: { rate?: number; pitch?: number }) {
  if (!('speechSynthesis' in window)) {
    console.warn('当前设备不支持语音合成');
    return;
  }
  const utterance = new SpeechSynthesisUtterance(text);
  utterance.lang = 'zh-CN';
  utterance.rate = opts?.rate ?? 0.9;   // 稍慢，适合老年人
  utterance.pitch = opts?.pitch ?? 1.0;
  utterance.volume = 1.0;
  speechSynthesis.speak(utterance);
}
```

#### 3.1.2 播报场景

| 场景 | 播报内容 | 触发方式 |
| --- | --- | --- |
| 任务确认 | 「已确认，阿司匹林已服用」 | 操作后自动播报（长辈模式） |
| 风险提醒 | 「严重提醒：过敏风险」 | 风险出现时播报 |
| 页面导航 | 「今日页面」 | 切换页面时播报（可选） |
| 求助页 | 「点击大按钮拨打急救电话」 | 进入求助页时播报 |
| 错误提示 | 「网络连接失败，请重试」 | 错误时播报 |
| 手动播报 | 任意文本 | 用户点击「朗读」按钮 |

#### 3.1.3 播报控制

- 长辈模式默认开启自动播报
- 可在「我的 → 无障碍设置」中关闭
- 提供「停止播报」按钮
- 播报时显示视觉波形或「正在朗读」指示器
- 页面切换时停止当前播报
- 不播报敏感健康详情（求助页通知只说「有新提醒」）

### 3.2 重要信息的视觉替代

所有音频信息必须有视觉替代：
- 语音播报同时显示文字
- 视频提供字幕（P0 不做视频，但预留接口）
- 通知同时有横幅和声音
- 错误提示同时有图标和文字

### 3.3 助听器兼容

- Android 应用支持助听器直连（系统级，无需额外开发）
- 音频使用标准媒体通道，不占用通话通道
- 不使用超声波或人耳范围外的音频

## 4. 运动无障碍

### 4.1 触控目标

#### 4.1.1 最小尺寸

| 元素类型 | 标准模式 | 长辈模式 | WCAG 建议 |
| --- | --- | --- | --- |
| 主要按钮 | 48×48px | 60×60px | ≥44×44px |
| 底部导航项 | 56×48px | 64×56px | ≥48×48px |
| 图标按钮 | 44×44px | 56×56px | ≥44×44px |
| 文本链接 | ≥24px 高 | ≥32px 高 | - |
| 求助大按钮 | 120×120px | 160×160px | 远大于标准 |

**实现：**

```css
.button {
  min-height: 48px;
  min-width: 48px;
  padding: 12px 24px;
  border-radius: 12px;
}

[data-elder="true"] .button {
  min-height: 60px;
  min-width: 60px;
  padding: 16px 32px;
  font-size: 1.1rem;
}

.help-button {
  width: 140px;
  height: 140px;
  border-radius: 50%;
  font-size: 1.25rem;
  font-weight: 700;
}
```

#### 4.1.2 间距

- 相邻可点击元素间距 ≥ 8px（标准）/ 12px（长辈模式）
- 按钮之间不重叠
- 底部导航项之间有明确分隔
- 列表项点击区域包含整行，不只是文字

### 4.2 输入方式

- 所有操作可通过单指点击完成
- 支持双击放大（系统级）
- 不依赖多指手势（如双指缩放）作为唯一操作方式
- 长按操作提供替代按钮（如「更多」菜单）
- 滑动操作提供按钮替代（如「删除」按钮替代左滑删除）

### 4.3 防误触

- 危险操作（删除、撤权）需要二次确认
- 求助大按钮有确认弹窗，避免误触拨打
- 提交按钮点击后立即禁用，防止重复提交
- 表单提交前校验，减少往返
- 关键操作有触觉反馈（`navigator.vibrate`）

### 4.4 手抖适配

- 按钮足够大，减少精确点击需求
- 不使用 hover 触发的交互（移动端无 hover）
- 误触后可撤销（如任务确认后 5 秒内可撤销）
- 输入框提供清除按钮，方便修改

## 5. 认知无障碍

### 5.1 文案规范

#### 5.1.1 语言简洁

- 使用短句，每句不超过 20 字
- 避免专业术语，必要时加解释
- 使用主动语态
- 一次只说一件事
- 避免双否定和复杂从句

**示例：**

| 不推荐 | 推荐 |
| --- | --- |
| 「您所请求的资源由于权限策略的限制而无法被访问」 | 「您没有权限查看这个信息」 |
| 「请确认您是否真的想要执行此不可逆操作」 | 「确定删除吗？删除后无法恢复」 |
| 「该操作将导致当前会话令牌失效并需要重新进行身份验证」 | 「修改密码后需要重新登录」 |

#### 5.1.2 一致性

- 同一概念用同一词语（如始终用「确认」，不混用「确定」「好的」）
- 按钮文案与结果一致（「删除」按钮确实执行删除）
- 错误提示说明原因和解决方法
- 时间表述统一（「今天 8:00」而非「今早」）

#### 5.1.3 引导文案

- 新功能首次使用时有引导提示
- 复杂操作分步说明（「第 1 步：... 第 2 步：...」）
- 空状态有明确引导（「还没有药品，点击添加」）
- 加载状态有进度提示（「正在识别... 预计 10 秒」）

### 5.2 信息架构

- 底部导航不超过 5 项（长辈模式 4 项）
- 页面层级不超过 3 层
- 每个页面有明确标题
- 面包屑或返回按钮清晰
- 重要信息在首屏可见

### 5.3 错误恢复

- 错误提示说明发生了什么、为什么、怎么办
- 提供「重试」按钮
- 表单错误保留已输入内容
- 危险操作可撤销
- 数据丢失前有警告

### 5.4 记忆辅助

- 今日任务自动记录，不需记忆
- 服药历史可查
- 提醒自动触发，不需记忆时间
- 常用操作在首页直达
- 设置自动保存

## 6. 读屏兼容（TalkBack）

### 6.1 ARIA 规范

#### 6.1.1 语义化优先

优先使用原生 HTML 语义化标签，ARIA 作为补充：

| 功能 | 原生标签 | 不推荐 |
| --- | --- | --- |
| 按钮 | `<button>` | `<div onclick>` |
| 链接 | `<a href>` | `<span onclick>` |
| 列表 | `<ul><li>` | `<div>` 堆叠 |
| 表单 | `<label><input>` | 无 label 的输入框 |
| 进度 | `<progress>` | 纯 div |
| 对话框 | `<dialog>` 或 `role="dialog"` | 普通 div |

#### 6.1.2 必要的 ARIA

```html
<!-- 图标按钮 -->
<button aria-label="返回" class="icon-button">
  <svg aria-hidden="true">...</svg>
</button>

<!-- 状态标签 -->
<span class="risk-tag" role="img" aria-label="严重风险，过敏冲突">
  <svg aria-hidden="true">...</svg>
  严重
</span>

<!-- 动态内容 -->
<div aria-live="polite" class="toast" role="status">
  已确认服药
</div>

<!-- 错误提示 -->
<div role="alert" class="error-message">
  网络连接失败，请检查网络后重试
</div>

<!-- 模态框 -->
<div role="dialog" aria-modal="true" aria-labelledby="dialog-title">
  <h2 id="dialog-title">确认删除</h2>
  ...
</div>

<!-- 开关 -->
<button role="switch" aria-checked="true" aria-label="长辈模式">
  <span class="switch-track"></span>
</button>

<!-- 标签页 -->
<div role="tablist">
  <button role="tab" aria-selected="true" aria-controls="panel-today">今日</button>
  <button role="tab" aria-selected="false" aria-controls="panel-history">历史</button>
</div>
```

#### 6.1.3 aria-live 区域

| 场景 | aria-live | role | 说明 |
| --- | --- | --- | --- |
| 操作成功提示 | polite | status | 不打断当前朗读 |
| 错误提示 | assertive | alert | 立即打断朗读 |
| 风险出现 | assertive | alert | 立即提醒 |
| 加载进度 | polite | status | 后台播报 |
| 聊天新消息 | polite | status | 不打断 |

**注意：** 同一页面 aria-live 区域不超过 3 个，避免读屏混乱。

### 6.2 焦点与读屏顺序

- DOM 顺序与视觉顺序一致
- 装饰性元素 `aria-hidden="true"`
- 重复内容（如底部导航的图标和文字）只朗读一次
- 隐藏内容 `display: none` 或 `visibility: hidden`，不只是视觉隐藏
- 单页应用路由切换时，读屏朗读新页面标题

### 6.3 触控探索

- TalkBack 开启时，单指滑动聚焦元素，双击激活
- 所有可交互元素可被聚焦
- 聚焦元素有可见焦点环
- 列表项可整体聚焦，朗读完整信息
- 自定义控件（如开关、滑块）支持 TalkBack 操作

### 6.4 朗读内容设计

- 按钮朗读：动作 + 对象（「确认，按钮」）
- 风险朗读：等级 + 标题 + 摘要（「严重风险，过敏冲突，成员对青霉素过敏...」）
- 任务朗读：药品名 + 剂量 + 时间 + 状态（「阿司匹林，100毫克，早8点，待确认」）
- 时间朗读：完整日期时间（「2026年9月3日，下午2点30分」）
- 不朗读纯装饰性内容

## 7. 长辈模式

### 7.1 一键开启

长辈模式是无障碍组合的快捷开关，一键启用：

| 设置 | 长辈模式值 |
| --- | --- |
| 字号 | 特大（1.35x） |
| 主题 | 跟随系统（默认浅色） |
| 高对比 | 关闭（可单独开启） |
| 减少动效 | 关闭（可单独开启） |
| 语音播报 | 开启 |
| 底部导航 | 简化为 4 项（今日、拍药盒、求助、我的） |
| 触控目标 | 放大（≥60px） |
| 页面复杂度 | 简化（隐藏次要信息） |

### 7.2 简化导航

长辈模式底部导航只有 4 项：

| 顺序 | 页面 | 原因 |
| --- | --- | --- |
| 1 | 今日 | 最高频，确认任务 |
| 2 | 拍药盒 | 录入药品 |
| 3 | 求助 | 紧急情况，大按钮直达 |
| 4 | 我的 | 设置、数据来源 |

「家人」「提醒」「知识」「助手」入口移到「今日」页的快捷入口区域，或通过「我的」进入。

### 7.3 简化页面

- 今日页：只显示今日任务和风险，隐藏健康资讯和趋势图
- 拍药盒页：大按钮 + 简单步骤，隐藏技术细节
- 求助页：超大按钮 + 语音播报，无其他干扰
- 我的页：只保留常用设置（长辈模式开关、紧急联系人、数据来源）

### 7.4 触觉反馈

长辈模式下关键操作有触觉反馈：

```typescript
function vibrate(pattern: number | number[]) {
  if ('vibrate' in navigator) {
    navigator.vibrate(pattern);
  }
}

// 确认成功：短震
vibrate(50);

// 错误：两短震
vibrate([50, 100, 50]);

// 严重提醒：长震
vibrate(200);
```

## 8. 主题与外观

### 8.1 三档外观

| 模式 | 说明 | 适用场景 |
| --- | --- | --- |
| 浅色 | 暖纸背景 + 松绿主色 | 默认，室内光线 |
| 深色 | 深松绿背景 + 浅色文字 | 夜间、OLED 屏省电 |
| 跟随系统 | 自动切换 | 推荐 |

**实现：** 通过 `data-theme` 属性切换，CSS 变量驱动。

### 8.2 深色模式设计

深色模式不是简单的反色，而是重新设计的色板：

- 背景：深松绿 `#1a2e1f`（非纯黑，避免 OLED 吞没边界）
- 卡片：`rgba(30, 50, 35, 0.92)`（可分层）
- 主色：亮松绿 `#66bb6a`（在深底上可见）
- 强调色：亮陶土 `#ff8a65`
- 文字：`#e8f5e9`（近白，非纯白减少刺眼）
- 边框：`rgba(255, 255, 255, 0.1)`

### 8.3 系统偏好自动检测

```typescript
// 检测系统深色模式
const darkQuery = window.matchMedia('(prefers-color-scheme: dark)');
darkQuery.addEventListener('change', (e) => {
  if (themeSetting === 'system') {
    setTheme(e.matches ? 'dark' : 'light');
  }
});

// 检测系统减少动效
const reduceMotionQuery = window.matchMedia('(prefers-reduced-motion: reduce)');
reduceMotionQuery.addEventListener('change', (e) => {
  if (e.matches) {
    setReducedMotion(true);
  }
});
```

## 9. 动效与减少动效

### 9.1 动效设计原则

- 动效用于引导注意力，不为装饰
- 持续时间 200-300ms，不超过 500ms
- 使用 `ease-out` 缓动，自然减速
- 只动画 `transform` 和 `opacity`，保证 60fps
- 不使用闪烁、闪烁频率 > 3Hz 的动画（防癫痫）

### 9.2 减少动效模式

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}

[data-motion="reduced"] {
  --ambient-aurora-display: none;
  --ambient-firefly-display: none;
}

[data-motion="reduced"] .aurora-layer,
[data-motion="reduced"] .firefly-layer {
  display: none;
}

[data-motion="reduced"] .page-transition {
  animation: none;
}
```

**减少动效时停用：**
- 极光漂移背景
- 萤火粒子上升
- 页面切换过渡
- 卡片入场动画
- 数字滚动动画
- 彩带庆祝效果
- 加载旋转动画（改为静态进度条）

**保留：**
- 按钮按下反馈（颜色变化）
- 焦点环变化
- 必要的状态切换（如开关）

## 11. 常见无障碍错误

### 11.1 颜色对比度不足

**错误：** 灰色文字 `#999` 在白色背景上（对比度 2.8:1）

**正确：** 使用 `#666`（对比度 5.7:1）或更大字号

### 11.2 图标按钮无标签

**错误：** `<button><svg>...</svg></button>`

**正确：** `<button aria-label="关闭"><svg aria-hidden="true">...</svg></button>`

### 11.3 div 冒充按钮

**错误：** `<div onclick="...">确认</div>`

**正确：** `<button>确认</button>`

### 11.4 只靠颜色区分状态

**错误：** 红色圆点表示错误，绿色圆点表示正确

**正确：** 红色 + ✕ + 「错误」，绿色 + ✓ + 「正确」

### 11.5 焦点环被移除

**错误：** `*:focus { outline: none; }`

**正确：** `*:focus:not(:focus-visible) { outline: none; }`（只移除鼠标焦点，保留键盘焦点）

### 11.6 模态框无焦点管理

**错误：** 打开模态框后 Tab 可聚焦背景元素

**正确：** 焦点陷阱在模态框内，关闭后返回触发元素

### 11.7 自动播放音频

**错误：** 页面加载自动播放语音

**正确：** 用户主动触发或在长辈模式下由用户设置开启

### 11.8 超时无提示

**错误：** 会话过期后静默跳转登录

**正确：** 过期前提示「会话即将过期，点击续期」，过期后说明原因
