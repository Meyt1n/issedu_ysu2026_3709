# 移动端监控与可观测性指南

> 本文档是家健镜随身版的监控与可观测性指南，覆盖日志、指标、追踪、错误监控、性能监控、用户行为分析。面向移动端开发者和运维人员，作为线上问题排查和质量保障的权威依据。

## 1. 可观测性概述

### 1.1 三大支柱

| 支柱 | 说明 | 移动端实现 |
| --- | --- | --- |
| 日志 (Logs) | 离散事件记录 | console + 本地日志 + 上报 |
| 指标 (Metrics) | 聚合数值统计 | 性能指标、错误率、API 耗时 |
| 追踪 (Traces) | 请求链路追踪 | request_id 串联前后端 |

### 1.2 设计原则

1. **隐私优先**：不收集个人健康数据，不嵌入第三方分析 SDK
2. **最小化**：只收集排查问题必需的数据
3. **可关闭**：用户可在设置中关闭数据上报
4. **本地优先**：日志默认存本地，问题排查时手动导出
5. **家庭自部署**：上报目标为家庭服务器，不出公网

### 1.3 数据分类

| 类别 | 包含内容 | 是否上报 | 保留期限 |
| --- | --- | --- | --- |
| 错误日志 | 错误信息、堆栈、request_id | 可选上报 | 30 天 |
| 性能指标 | 页面加载时间、API 耗时 | 可选上报 | 30 天 |
| 操作日志 | 用户操作记录（不含内容） | 不上报 | 本地 7 天 |
| 健康数据 | 用药、血压等 | 不上报 | 不存储 |
| 设备信息 | 型号、系统版本、浏览器版本 | 可选上报 | 30 天 |

## 2. 日志系统

### 2.1 日志级别

| 级别 | 用途 | 示例 |
| --- | --- | --- |
| DEBUG | 开发调试 | 函数入参、中间状态 |
| INFO | 正常操作 | 页面加载、API 请求成功 |
| WARN | 异常但可恢复 | 重试、降级、缓存命中 |
| ERROR | 错误 | API 失败、异常捕获 |

### 2.2 日志格式

```typescript
interface LogEntry {
  timestamp: string;        // ISO 8601
  level: 'DEBUG' | 'INFO' | 'WARN' | 'ERROR';
  message: string;
  context?: {
    userId?: string;
    page?: string;
    requestId?: string;
    [key: string]: unknown;
  };
  error?: {
    name: string;
    message: string;
    stack?: string;
  };
}
```

### 2.3 日志实现

```typescript
// utils/logger.ts
class Logger {
  private buffer: LogEntry[] = []
  private maxBufferSize = 1000
  private reportEnabled = false

  constructor(private namespace: string) {}

  debug(message: string, context?: Record<string, unknown>) {
    this.log('DEBUG', message, context)
  }

  info(message: string, context?: Record<string, unknown>) {
    this.log('INFO', message, context)
  }

  warn(message: string, context?: Record<string, unknown>) {
    this.log('WARN', message, context)
  }

  error(message: string, error?: Error, context?: Record<string, unknown>) {
    this.log('ERROR', message, {
      ...context,
      error: error ? { name: error.name, message: error.message, stack: error.stack } : undefined,
    })
  }

  private log(level: LogLevel, message: string, context?: Record<string, unknown>) {
    const entry: LogEntry = {
      timestamp: new Date().toISOString(),
      level,
      message: `[${this.namespace}] ${message}`,
      context: {
        page: router.currentRoute.value.path,
        ...context,
      },
    }

    // 输出到控制台
    const consoleMethod = level === 'ERROR' ? console.error : level === 'WARN' ? console.warn : console.log
    consoleMethod(entry.message, entry.context)

    // 存入缓冲区
    this.buffer.push(entry)
    if (this.buffer.length > this.maxBufferSize) {
      this.buffer.shift()
    }

    // 上报（ERROR 级别立即上报）
    if (this.reportEnabled && level === 'ERROR') {
      this.report(entry)
    }
  }

  private async report(entry: LogEntry) {
    try {
      await fetch(`${apiBase}/api/v1/client-logs`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(entry),
      })
    } catch {
      // 上报失败不影响主流程
    }
  }

  export(): string {
    return JSON.stringify(this.buffer, null, 2)
  }

  clear() {
    this.buffer = []
  }
}

export const createLogger = (namespace: string) => new Logger(namespace)
```

### 2.4 日志使用规范

```typescript
// 好：有意义的日志
logger.info('任务确认成功', { taskId, status })
logger.error('API 请求失败', error, { path, requestId })

// 不好：无意义日志

```

### 2.5 敏感信息过滤

```typescript
const sanitize = (data: unknown): unknown => {
  if (typeof data !== 'object' || data === null) return data
  const result: Record<string, unknown> = {}
  for (const [key, value] of Object.entries(data)) {
    if (['password', 'token', 'health_data', 'medication'].includes(key.toLowerCase())) {
      result[key] = '[REDACTED]'
    } else {
      result[key] = sanitize(value)
    }
  }
  return result
}
```

## 3. 性能监控

### 3.1 核心指标

| 指标 | 说明 | 目标 | 测量方式 |
| --- | --- | --- | --- |
| FCP | First Contentful Paint | ≤1000ms | Performance API |
| LCP | Largest Contentful Paint | ≤1500ms | Performance API |
| FID | First Input Delay | ≤100ms | Performance API |
| CLS | Cumulative Layout Shift | ≤0.1 | Performance API |
| TTI | Time to Interactive | ≤1500ms | 自定义 |
| API 耗时 | 请求响应时间 | ≤1000ms (P95) | 拦截器 |
| 路由切换 | 页面切换时间 | ≤300ms | 路由守卫 |

### 3.2 Web Vitals 采集

```typescript
// utils/performance.ts
export function initPerformanceMonitoring() {
  // LCP
  new PerformanceObserver((list) => {
    const entries = list.getEntries()
    const lastEntry = entries[entries.length - 1]
    logger.info('LCP', { value: lastEntry.startTime })
    reportMetric('lcp', lastEntry.startTime)
  }).observe({ type: 'largest-contentful-paint', buffered: true })

  // FID
  new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
      const fid = entry.processingStart - entry.startTime
      logger.info('FID', { value: fid })
      reportMetric('fid', fid)
    }
  }).observe({ type: 'first-input', buffered: true })

  // CLS
  let cls = 0
  new PerformanceObserver((list) => {
    for (const entry of list.getEntries() as any) {
      if (!entry.hadRecentInput) {
        cls += entry.value
        logger.info('CLS', { value: cls })
        reportMetric('cls', cls)
      }
    }
  }).observe({ type: 'layout-shift', buffered: true })
}
```

### 3.3 API 性能监控

```typescript
// ApiClient 中
const request = async (path: string, options: RequestInit) => {
  const startTime = performance.now()
  const requestId = generateId()

  try {
    const response = await fetch(...)
    const duration = performance.now() - startTime

    logger.info('API 请求完成', { path, duration, status: response.status, requestId })
    reportMetric('api_duration', duration, { path })

    return response
  } catch (error) {
    const duration = performance.now() - startTime
    logger.error('API 请求失败', error as Error, { path, duration, requestId })
    reportMetric('api_error', 1, { path })
    throw error
  }
}
```

### 3.4 路由性能监控

```typescript
router.beforeEach((to, from, next) => {
```

## 4. 错误监控

### 4.1 全局错误捕获

```typescript
// main.ts
export function initErrorMonitoring() {
  // Vue 错误
  app.config.errorHandler = (error, instance, info) => {
    logger.error('Vue 错误', error as Error, { info })
    reportError(error as Error, { source: 'vue', info })
  }

  // 全局错误
  window.addEventListener('error', (event) => {
    logger.error('全局错误', new Error(event.message), {
      filename: event.filename,
      lineno: event.lineno,
      colno: event.colno,
    })
    reportError(new Error(event.message), { source: 'window' })
  })

  // 未捕获 Promise
  window.addEventListener('unhandledrejection', (event) => {
    const error = event.reason instanceof Error ? event.reason : new Error(String(event.reason))
    logger.error('未捕获 Promise', error)
    reportError(error, { source: 'unhandledrejection' })
  })
}
```

### 4.2 错误上报

```typescript
interface ErrorReport {
  timestamp: string
  message: string
  stack?: string
  source: string
  context: {
    userId?: string
    page: string
    appVersion: string
    userAgent: string
    screenSize: string
    networkType?: string
    [key: string]: unknown
  }
}

const reportError = async (error: Error, context: Record<string, unknown>) => {
  if (!settingsStore.errorReporting) return

  const report: ErrorReport = {
    timestamp: new Date().toISOString(),
    message: error.message,
    stack: error.stack,
    source: context.source as string,
    context: {
      page: router.currentRoute.value.path,
      appVersion: APP_VERSION,
      userAgent: navigator.userAgent,
      screenSize: `${window.innerWidth}x${window.innerHeight}`,
      ...context,
    },
  }

  try {
    await fetch(`${apiBase}/api/v1/client-errors`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(sanitize(report)),
    })
  } catch {
    // 上报失败静默
  }
}
```

### 4.3 错误聚合

```typescript
const generateErrorFingerprint = (error: Error) => {
  const stack = error.stack || ''
  // 取堆栈第一行作为指纹
  const firstLine = stack.split('
```

## 5. 请求追踪

### 5.1 Request ID

```typescript
// 生成唯一 request_id
const generateRequestId = () => {
  return `req_${Date.now()}_${Math.random().toString(36).substr(2, 9)}`
}

// ApiClient 中添加
const request = async (path: string, options: RequestInit) => {
  const requestId = generateRequestId()
  const headers = {
    ...options.headers,
    'X-Request-ID': requestId,
  }

  logger.info('请求发起', { path, requestId })

  try {
    const response = await fetch(path, { ...options, headers })
    logger.info('请求完成', { path, requestId, status: response.status })
    return response
  } catch (error) {
    logger.error('请求失败', error as Error, { path, requestId })
    throw error
  }
}
```

### 5.2 链路追踪

```
移动端 → API 网关 → 后端服务 → 数据库
  ↓         ↓           ↓          ↓
request_id 贯穿全链路，可通过 request_id 排查任意环节问题
```

## 8. 服务端监控对接

### 8.1 上报接口

```
POST /api/v1/client-logs
POST /api/v1/client-errors
POST /api/v1/client-metrics
POST /api/v1/client-events
```

### 8.2 上报策略

- 错误：立即上报
- 指标：批量上报（每 20 条或每 5 分钟）
- 事件：批量上报（每 20 条或每 5 分钟）
- 离线时缓存本地，上线后补发
- 上报失败不重试（避免雪崩）

### 8.3 服务端处理

- 接收并存储客户端上报
- 按错误指纹聚合
- 生成错误率、性能趋势报表
- 异常告警（错误率突增、P95 耗时超标）

## 9. 隐私与合规

### 9.1 用户控制

```
我的 → 隐私设置
  ├── 错误上报：[开/关]
  ├── 性能统计：[开/关]
  ├── 使用分析：[开/关]
  └── 导出本地日志：[按钮]
```

- 默认全部关闭
- 用户可随时开启/关闭
- 关闭后停止收集，已收集的数据可删除
- 首次使用时明确告知

### 9.2 数据最小化

- 不收集健康数据内容
- 不收集输入框内容
- 不收集用户 ID（错误上报可含匿名 ID）
- 不收集精确位置
- 不收集通讯录、相册等敏感信息

### 9.3 数据保留

- 本地日志：7 天自动清理
- 服务端上报：30 天自动清理
- 用户可手动清除本地数据
- 卸载应用清除所有本地数据

## 10. 告警与响应

### 10.1 告警规则

| 指标 | 阈值 | 级别 | 通知 |
| --- | --- | --- | --- |
| 错误率 | >5% (5 分钟) | P1 | 管理员通知 |
| API P95 耗时 | >3s (5 分钟) | P2 | 管理员通知 |
| 崩溃率 | >1% (1 小时) | P0 | 管理员通知 |
| 白屏率 | >2% (1 小时) | P1 | 管理员通知 |

### 10.2 响应流程

1. 告警触发
2. 管理员查看错误聚合
3. 定位问题（request_id 追踪）
4. 修复或回滚
5. 验证修复
6. 记录复盘
