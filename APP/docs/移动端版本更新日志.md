# 移动端版本更新日志

> 本文档记录家健镜随身版的版本更新历史，包括新增功能、改进、修复和已知问题。遵循语义化版本（Semantic Versioning）。

## 版本号规则

- **主版本号**：不兼容的 API 变更
- **次版本号**：向下兼容的功能性新增
- **修订号**：向下兼容的问题修正

格式：`MAJOR.MINOR.PATCH`（如 `1.2.3`）

---

## [1.0.0] - 2026-09-03

### 新增

- 今日任务页面：展示今日照护任务，支持确认/延期/跳过/记漏服
- 拍药盒识别：拍照/录像识别药品，支持视觉任务状态回查和取消
- 家人健康概览：查看被授权家庭成员的健康数据
- 风险提醒：按等级展示健康风险，支持已知晓回写
- 知识条目：浏览和检索健康知识库
- 语音助手：语音输入和文字对话，流式回复，证据面板
- 紧急求助：大按钮拨打急救电话，联系家人
- 我的与设置：无障碍设置、数据来源、账户安全、本地数据管理
- 登录注册：用户名密码登录，会话管理
- 环境行动卡：根据天气生成健康行动建议
- 长辈模式：大字号、大按钮、语音播报、精简界面
- 深色主题：森林夜深色模式
- 高对比模式：黑白强对比
- 减少动效：关闭装饰动画
- PWA 支持：添加到主屏幕，离线缓存静态资源
- Android APK：Capacitor 打包，支持安装到手机

### 改进

- 暖阳纸笺设计语言：暖纸背景、松绿主色、陶土强调
- 响应式布局：适配 320px-1280px 屏幕
- 折叠屏适配：外屏/内屏切换不丢失状态
- 性能优化：首屏 ≤1500ms（4G），路由切换 ≤300ms
- 无障碍：WCAG 2.1 AA 达标，TalkBack 兼容
- 安全：HTTPS 传输，会话内存存储，最小权限

### 修复

- 修复任务确认后进度环不更新的问题
- 修复语音识别 15 秒后不自动停止的问题
- 修复流式回复停止按钮无效的问题
- 修复高对比模式下部分文字不可见的问题
- 修复折叠屏切换后底部导航错位的问题

### 已知问题

- iOS Safari 语音识别支持不完整
- 部分低端设备深色模式下滚动帧率较低
- 视频识别在弱网下可能超时
- 演示模式下部分功能不可用

### 技术细节

- Vue 3.5 + TypeScript 5.7 + Vite 6
- Capacitor 8 打包 Android
- 构建产物：JS gzip ≤170 KiB，CSS gzip ≤30 KiB
- 测试覆盖率：单元测试 ≥70%
- 发布门禁：`npm run mobile:ready` 全部通过

## 升级指南

### 从 0.9.0 升级到 1.0.0

1. PWA 用户：打开应用自动更新，下次启动生效
2. APK 用户：下载新 APK 覆盖安装
3. 本地设置会保留
4. 如遇问题，清除应用数据后重新登录

### 从 0.8.0 升级到 1.0.0

1. 建议卸载旧版本后全新安装
2. 0.8.0 的本地设置不兼容，需要重新配置
3. 演示数据不会迁移
