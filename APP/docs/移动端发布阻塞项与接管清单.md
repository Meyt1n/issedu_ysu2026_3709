## 2. 接管步骤

### A. 受控环境

1. 用独立合成数据库部署服务端，不复用真实家庭数据。
2. 配置受控 HTTPS、CORS 和移动端允许的来源；不得使用开发代理或明文公网地址。
3. 记录服务端提交、API 版本、合成数据种子 SHA-256、APP 提交和 PWA shell 版本。
4. 在 `APP/` 执行 `npm run verify:linkage`，失败时保留错误和请求 ID，但不得上传原始健康正文。

### B. APK 与 Android

1. 安装 JDK 21–24、Android SDK 和目标平台，确认 `ANDROID_HOME`/`JAVA_HOME` 只存在于本机环境。
2. 运行 `npm run check`、`npm run test`、`npm run build`、`npm run android:sync`，再执行 `scripts/build-apk.ps1`。
3. 计算 APK SHA-256，记录版本、构建提交和工具链；APK、签名文件和 `local.properties` 不入库。
4. 在至少一台目标设备执行冷启动、切后台、断网/恢复、升级和回滚，并保存脱敏结果。

### C. 无障碍与辅助能力

1. 用真实 TalkBack 检查焦点顺序、可见焦点和触控目标；长辈模式目标不小于 58px。
2. 检查 TTS 不可用时的文字降级、减少动效、高对比、触觉反馈和求助拨号路径。
3. 在 320px 与 375px 宽度下检查底部导航、弹层按钮、错误文案和滚动区域。
4. 填写无障碍和语音证据模板，再运行对应校验器；缺设备元数据时保持 `BLOCKED`。

### D. 视觉生产边界

在固定数据集、模型、后端和人工网页复核均通过前，只允许把视觉能力描述为 `DEMO_ONLY` 或禁用入口。不得把演示识别结果写入正式健康状态、风险计算或药物计划。

候选发布失败时，停用受控环境配置并恢复上一份已验证的 APP 产物、PWA shell、API 版本和合成数据指纹。不得删除服务端授权、审计或任务记录来制造“回滚成功”。
