# 移动端 UI/UX 设计规范

> 本文档是家健镜随身版的 UI/UX 设计完整规范，覆盖设计语言、色彩系统、字体排版、组件设计、页面布局、交互模式、图标体系、动效设计、无障碍设计。面向设计师和前端开发者，作为设计和开发的权威依据。

## 1. 设计理念

### 1.1 设计原则

| 原则 | 说明 |
| --- | --- |
| 温暖可信 | 暖纸色调、圆润造型，营造家庭般的安全感 |
| 清晰易读 | 大字号、高对比、简洁布局，老年人友好 |
| 操作明确 | 按钮大、文案直白、反馈即时，减少认知负担 |
| 诚实透明 | 不冒充能力，降级有提示，数据来源可追溯 |
| 克制优雅 | 装饰适度，不喧宾夺主，内容优先 |

### 1.2 设计语言：暖阳纸笺

「暖阳纸笺」是产品的核心视觉语言，灵感来自阳光下的纸质笔记本：

- **暖纸背景**：米白色纸张质感，温暖不刺眼
- **松绿主色**：像松针一样沉稳有生命力，代表健康
- **陶土强调色**：温暖的橙棕色，用于关键操作和提醒
- **衬线标题**：类似手写笔记的标题字体，有温度
- **纸感卡片**：柔和阴影，像贴在纸上的便签
- **极光萤火**：低透明度装饰，像夜晚的微光，不干扰内容

### 1.3 目标用户

| 用户群 | 特征 | 设计重点 |
| --- | --- | --- |
| 老年人（60+） | 视力下降、动作变慢、数字技能弱 | 大字号、大按钮、简单操作、语音辅助 |
| 慢病患者 | 需长期管理、频繁用药 | 提醒清晰、记录方便、趋势可见 |
| 照护者（子女/护工） | 时间紧张、多任务 | 高效操作、授权管理、异常告警 |
| 家庭管理员 | 技术能力较强 | 完整功能、配置管理、审计查看 |

### 2.3 色彩使用规则

- 主色不超过页面面积的 30%
- 功能色只用于对应状态，不用于装饰
- 文字与背景对比度 ≥4.5:1（正文）
- 不使用颜色作为唯一的信息传递方式
- 深色主题下调整饱和度，避免过亮刺眼
- 高对比模式覆盖所有颜色，强制黑白

## 3. 字体排版

### 3.1 字体栈

```css
:root {
  --font-sans: -apple-system, BlinkMacSystemFont, 'Segoe UI',
    'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif;
  --font-serif: Georgia, 'Times New Roman', 'Songti SC', 'SimSun', serif;
  --font-mono: 'SF Mono', Consolas, 'Liberation Mono', Menlo, monospace;
}
```

- **正文**：无衬线字体（系统默认），清晰易读
- **标题**：衬线字体，有温度感，区分层级
- **代码/数据**：等宽字体，对齐美观

**不使用自定义 Web Font**：减少加载时间，避免字体闪烁，尊重系统字体设置。

### 3.2 字号系统

| 层级 | 标准 | 大 | 特大 | 用途 |
| --- | --- | --- | --- | --- |
| H1 页面标题 | 22px | 25px | 30px | 页面主标题 |
| H2 区块标题 | 18px | 21px | 24px | 卡片标题、区块标题 |
| H3 子标题 | 16px | 18px | 22px | 列表项标题 |
| Body 正文 | 16px | 18px | 22px | 正文、按钮文字 |
| Caption 辅助 | 14px | 16px | 18px | 次要信息、时间戳 |
| Small 小字 | 12px | 14px | 16px | 标签、说明 |

**行高：**
- 正文：1.6
- 标题：1.3
- 按钮：1.2
- 辅助文字：1.5

### 3.3 字重

| 字重 | 用途 |
| --- | --- |
| 400 Regular | 正文、辅助文字 |
| 500 Medium | 按钮、列表项标题 |
| 600 SemiBold | 卡片标题 |
| 700 Bold | 页面标题、重要数字 |

### 3.4 排版规则

- 段落首行不缩进，段间距 16px
- 行宽不超过 600px（阅读舒适度）
- 中英文之间留空格
- 数字使用等宽或 tabular-nums
- 时间格式统一：`YYYY-MM-DD HH:mm`
- 不使用斜体（中文斜体不美观）
- 长文本使用 `text-align: left`，不居中

## 4. 间距与布局

### 4.1 间距系统

| 名称 | 值 | 用途 |
| --- | --- | --- |
| xs | 4px | 图标与文字间距、紧凑元素内边距 |
| sm | 8px | 小元素间距、标签内边距 |
| md | 16px | 标准内边距、元素间距 |
| lg | 24px | 区块间距、卡片内边距 |
| xl | 32px | 页面区块间距 |
| xxl | 48px | 页面顶部/底部留白 |

### 4.2 页面布局

```
┌─────────────────────────┐
│  状态栏（安全区）         │
├─────────────────────────┤
│  页面标题（H1）          │
│  （可选：副标题/操作）    │
├─────────────────────────┤
│                         │
│  内容区域                │
│  （卡片、列表、表单）     │
│                         │
├─────────────────────────┤
│  底部导航（安全区）       │
└─────────────────────────┘
```

- 页面左右边距：16px（标准）/ 24px（平板）
- 内容最大宽度：600px（居中）
- 卡片间距：16px
- 页面底部留白：80px（避开底部导航）

### 4.3 卡片设计

```css
.card {
  background: var(--surface);
  border-radius: 16px;
  padding: 20px;
  box-shadow: var(--shadow-paper);
  border: 1px solid var(--border);
}
```

- 圆角：16px（大卡片）/ 12px（小卡片）/ 8px（标签、按钮）
- 内边距：20px（标准）/ 16px（紧凑）
- 阴影：柔和纸感阴影，不厚重
- 卡片可点击时：hover 轻微上浮（translateY(-2px)）

### 4.4 栅格系统

移动端使用单列布局，不使用复杂栅格：
- 手机竖屏：单列
- 手机横屏：单列，内容居中限宽
- 平板：单列居中，最大宽度 600px
- 不使用多列布局（避免老年人阅读困难）

## 5. 组件设计

### 5.1 按钮

#### 5.1.1 按钮类型

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 主按钮 | 松绿底白字，圆角 12px | 主要操作（确认、保存、提交） |
| 次按钮 | 白底松绿边框文字 | 次要操作（取消、返回） |
| 危险按钮 | 红底白字 | 删除、撤销授权 |
| 文字按钮 | 无背景无边框 | 低优先级操作（查看更多） |
| 图标按钮 | 48×48px，图标居中 | 工具栏操作 |
| 大按钮 | 60px 高，全宽 | 长辈模式、求助按钮 |

#### 5.1.2 按钮状态

| 状态 | 视觉 |
| --- | --- |
| Default | 正常样式 |
| Hover | 背景色加深 5%，轻微上浮 |
| Pressed | 背景色加深 10%，缩小 2% |
| Disabled | 透明度 50%，不可点击 |
| Loading | 显示加载动画，文字变「处理中...」 |

#### 5.1.3 按钮规范

- 最小高度：48px（标准）/ 60px（长辈模式）
- 最小宽度：80px
- 内边距：水平 24px，垂直 12px
- 字号：16px，字重 500
- 圆角：12px
- 同一操作区主按钮不超过 1 个
- 危险操作需要二次确认

### 5.2 输入框

```css
.input {
  height: 48px;
  padding: 0 16px;
  border: 1.5px solid var(--border-strong);
  border-radius: 12px;
  font-size: 16px;
  background: var(--surface);
}
.input:focus {
  border-color: var(--primary);
  box-shadow: 0 0 0 3px rgba(46, 125, 50, 0.15);
}
.input.error {
  border-color: var(--error);
}
```

- 高度：48px
- 边框：1.5px，聚焦时主色 + 外发光
- 标签：在输入框上方，字重 500
- 错误提示：在输入框下方，红色，含图标
- 占位符：文字弱色，不写示例值
- 密码框：显示/隐藏切换按钮

### 5.3 列表

#### 5.3.1 列表项

```
┌─────────────────────────────┐
│ [图标]  标题文字        >   │
│         辅助说明文字         │
├─────────────────────────────┤
│ [图标]  标题文字        >   │
│         辅助说明文字         │
```

- 列表项高度：最小 64px
- 左右内边距：16px
- 上下内边距：12px
- 分割线：左边距 72px（避开图标），1px 边框色
- 可点击列表项：右侧箭头图标，hover 背景变浅
- 列表项内容：主标题（16px 500）+ 辅助文字（14px 弱色）

#### 5.3.2 空状态

```
┌─────────────────────────────┐
│                             │
│        [插图/图标]          │
│                             │
│      暂无数据                │
│   点击下方按钮添加           │
│                             │
│      [ 添加按钮 ]            │
│                             │
└─────────────────────────────┘
```

- 插图：简洁线性图标，主色 30% 透明度
- 标题：18px 500，居中
- 说明：14px 弱色，居中
- 操作按钮：主按钮，居中

### 5.4 标签与徽章

| 类型 | 样式 | 用途 |
| --- | --- | --- |
| 风险标签 | 彩色背景 + 文字 + 图标 | 风险等级 |
| 状态标签 | 灰色/绿色背景 | 任务状态（待确认/已完成） |
| 演示标签 | 橙色边框文字 | 演示模式标识 |
| 数字徽章 | 红色圆形白字 | 未读数量 |

- 标签圆角：8px
- 标签内边距：4px 8px
- 标签字号：12px（标准）/ 14px（长辈模式）
- 风险标签必须含文字和图标，不只靠颜色

### 5.5 模态框

```
┌─────────────────────────┐
│  标题              [X]  │
├─────────────────────────┤
│                         │
│  内容区域                │
│                         │
├─────────────────────────┤
│      [取消]  [确认]      │
└─────────────────────────┘
```

- 宽度：90% 屏幕宽，最大 400px
- 圆角：16px
- 标题：18px 600，左对齐
- 关闭按钮：右上角，48×48px
- 内容：上下 20px
- 按钮区：右对齐，主按钮在右
- 背景遮罩：黑色 50% 透明度
- 打开时焦点陷阱，关闭后返回触发元素

### 5.6 底部导航

```
┌─────────────────────────────────────┐
│  [首页]  [拍药盒]  [提醒]  [我的]    │
│   图标    图标     图标    图标     │
│   文字    文字     文字    文字     │
└─────────────────────────────────────┘
```

- 高度：56px + 安全区
- 背景：白色 95% 透明度 + 顶部边框
- 每项：图标 24px + 文字 12px
- 选中态：主色图标 + 主色文字
- 未选中：弱色图标 + 弱色文字
- 长辈模式：4 项（今日、拍药盒、求助、我的），图标 28px，文字 14px

### 5.7 进度与加载

#### 5.7.1 骨架屏

- 灰色块（#e0e0e0）+ shimmer 动画
- 形状与实际内容一致（标题块、文字行、图片块）
- 减少动效模式下：静态灰色块，无动画
- 加载时间 >3 秒显示「加载中...」文字

#### 5.7.2 进度环

- 用于今日任务完成进度
- 环形进度，主色填充
- 中心显示百分比（24px 600）
- 下方显示「3/5 已完成」

#### 5.7.3 加载指示器

- 按钮内：旋转圆圈 + 「处理中...」
- 页面级：居中旋转圆圈
- 不使用全屏加载遮罩（除首次启动）

### 5.8 Toast 提示

- 位置：页面底部，底部导航上方
- 样式：深色背景 90% + 白色文字，圆角 8px
- 内边距：12px 20px
- 显示时间：2 秒（成功）/ 4 秒（错误）
- 成功：绿色图标 + 文字
- 错误：红色图标 + 文字
- 长辈模式：同时语音播报

## 7. 动效设计

### 7.1 动效原则

- **功能性**：动效引导注意力，反馈操作，不为装饰
- **快速**：200-300ms，不超过 500ms
- **自然**：ease-out 缓动，模拟物理
- **克制**：不滥用，关键路径才用
- **可关闭**：尊重系统「减少动效」设置

### 7.2 动效类型

| 类型 | 时长 | 缓动 | 用途 |
| --- | --- | --- | --- |
| 页面进入 | 250ms | ease-out | 新页面淡入上移 |
| 页面退出 | 200ms | ease-in | 旧页面淡出下移 |
| 按钮按下 | 100ms | ease | 缩小 2% |
| 卡片 hover | 200ms | ease-out | 上浮 2px + 阴影加深 |
| 模态框 | 250ms | ease-out | 缩放淡入 |
| Toast | 200ms | ease-out | 上移淡入 |
| 列表项 | 150ms | ease-out | 依次进入（交错 50ms） |
| 加载旋转 | 1000ms | linear | 无限循环 |

### 7.3 装饰动效

- **极光漂移**：3 个径向渐变，30s 周期，透明度 0.08
- **萤火上升**：8 个小圆点，15-25s 周期，透明度 0.12
- 仅在正常动效模式下显示
- 低端设备自动停用
- `pointer-events: none`，不拦截点击

### 7.4 减少动效模式

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

停用：页面切换、装饰动画、卡片 hover、数字滚动、彩带庆祝
保留：按钮按下颜色变化、焦点环变化

## 8. 页面设计规范

### 8.1 今日页

**布局：**
1. 顶部问候 + 日期
2. 进度环（今日任务完成度）
3. 今日任务列表（卡片式）
4. 待关注风险（横向滚动或列表）
5. 最近变化（时间线）
6. 健康资讯（可选，长辈模式隐藏）

**任务卡片：**

## 9. 交互模式

### 9.1 确认模式

- 危险操作（删除、撤权）：模态框二次确认
- 普通操作（确认任务）：直接执行 + Toast 反馈
- 可撤销操作（任务确认）：5 秒内可撤销 Toast

### 9.2 错误处理

- 输入错误：实时校验，输入框下方提示
- 网络错误：Toast + 重试按钮
- 权限错误：引导到授权说明
- 系统错误：错误页 + 反馈入口

### 9.3 加载模式

- 首次加载：骨架屏
- 操作中：按钮 loading + 禁用
- 下拉刷新：顶部加载指示器
- 分页加载：底部「加载更多」或无限滚动

### 9.4 空状态

- 无数据：插图 + 说明 + 添加按钮
- 搜索无结果：「未找到相关内容」+ 建议关键词
- 无权限：「未获授权」+ 联系管理员说明

## 10. 设计交付

### 10.1 设计稿规范

- 画板尺寸：375×812（iPhone X 基准）
- 包含：浅色、深色、高对比三种状态
- 标注：间距、字号、颜色、组件状态
- 导出：SVG 图标、PNG 插图（2x/3x）

### 10.2 开发交接

- 设计令牌（CSS 变量）与设计稿一致
- 组件在 Storybook（如有）中可预览
- 动效提供时长和缓动参数
- 无障碍标注（焦点顺序、aria-label）
