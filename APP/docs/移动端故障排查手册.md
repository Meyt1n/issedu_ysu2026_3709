# 移动端故障排查手册

> 本文档是家健镜随身版的故障排查完整手册，按症状分类，提供症状描述、可能原因、排查步骤、解决方案和预防措施。面向运维人员、开发者和技术支持，作为问题排查的权威依据。

## 1. 故障排查总览

### 1.1 排查流程

```
发现问题
  → 收集信息（症状、环境、复现步骤）
  → 确定范围（前端/后端/网络/设备）
  → 查看日志（前端控制台/后端日志/请求记录）
  → 复现问题（稳定复现最好）
  → 定位原因（二分法、对比法）
  → 实施修复
  → 验证修复
  → 记录归档
```

### 1.2 信息收集清单

排查前收集以下信息：

- [ ] 症状描述（什么不工作了）
- [ ] 复现步骤（怎么操作出现的）
- [ ] 发生频率（每次/偶尔/特定条件）
- [ ] 设备型号和 Android 版本
- [ ] APP 版本（PWA 或 APK，版本号）
- [ ] 数据模式（演示/联机）
- [ ] 网络环境（WiFi/4G/家庭局域网）
- [ ] 后端版本和状态
- [ ] 截图或录屏
- [ ] 错误提示文案

### 1.3 常用诊断工具

| 工具 | 用途 |
| --- | --- |
| Chrome DevTools | PWA 调试、控制台、网络、性能 |
| chrome://inspect | Android WebView 远程调试 |
| adb logcat | Android 系统日志 |
| 「我的 → 最近请求」 | 移动端请求记录 |
| 后端日志 | 服务端错误和请求详情 |
| curl | API 接口测试 |

## 2. 启动与安装问题

### 2.1 APK 安装失败

**症状：** 安装 APK 时提示「安装失败」或「解析包错误」

**可能原因：**

| 原因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| APK 损坏 | 检查文件大小和 SHA-256 | 重新下载或构建 |
| 签名冲突 | 已安装不同签名的同名应用 | 卸载旧版本后重装 |
| 版本降级 | 新版本 versionCode 低于已安装版 | 卸载旧版本或提高 versionCode |
| 存储空间不足 | 检查设备存储 | 清理存储空间 |
| 未知来源未允许 | 系统设置 | 允许安装未知来源应用 |
| minSdk 过高 | 设备 Android 版本低于 minSdk | 升级 Android 或降低 minSdk |
| CPU 架构不匹配 | APK 只含特定 ABI | 构建通用 APK 或对应 ABI |

**排查步骤：**

```bash
# 1. 检查 APK 是否完整
Get-FileHash app-debug.apk -Algorithm SHA256

# 2. 检查 APK 信息
aapt dump badging app-debug.apk | findstr "package version"

# 3. 查看安装错误详情
adb install -r app-debug.apk
# 错误码参考：
# INSTALL_FAILED_UPDATE_INCOMPATIBLE → 签名冲突
# INSTALL_FAILED_OLDER_SDK → minSdk 过高
# INSTALL_FAILED_INSUFFICIENT_STORAGE → 空间不足
```

### 2.2 应用启动白屏

**症状：** 打开应用后长时间白屏，无内容

**可能原因：**

| 原因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| JS 加载失败 | 控制台查看 404/网络错误 | 检查静态资源路径和服务器配置 |
| JS 运行时错误 | 控制台查看错误堆栈 | 修复代码错误 |
| Service Worker 缓存旧版本 | 清除站点数据 | 清除缓存或强制刷新 |
| 网络太慢 | Network 面板查看加载时间 | 优化产物体积或网络 |
| WebView 版本过低 | 检查 WebView 版本 | 升级 Android System WebView |

**排查步骤：**

1. PWA：打开 Chrome DevTools → Console，查看是否有红色错误
2. APK：连接电脑，chrome://inspect →  inspect WebView
3. 检查 Network 面板，确认 index.html 和 JS 文件加载成功
4. 清除站点数据：设置 → 应用 → 清除存储
5. 检查 `npm run build` 是否有警告

### 2.3 应用崩溃

**症状：** 打开应用或操作时突然闪退

**可能原因：**

| 原因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| WebView 崩溃 | adb logcat 查看 crash 日志 | 升级 WebView 或简化页面 |
| 内存溢出 | Android Profiler 查看内存 | 优化大图片和列表 |
| 原生插件错误 | logcat 查看插件异常 | 更新或替换插件 |
| 系统版本兼容 | 检查崩溃设备的 Android 版本 | 适配低版本系统 |

**排查步骤：**

```bash
# 查看崩溃日志
adb logcat -d | findstr "AndroidRuntime FATAL"

# 查看 WebView 相关日志
adb logcat -d | findstr "chromium WebView"

# 清除应用数据后重试
adb shell pm clear com.homecaretwin.companion
```

## 3. 网络与连接问题

### 3.1 无法连接服务器

**症状：** 联机模式下提示「无法连接到家庭服务器」

**可能原因：**

| 原因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| 服务器地址错误 | 检查「我的 → 数据来源」 | 输入正确的服务器地址 |
| 服务器未启动 | 后端健康检查 | 启动后端服务 |
| 网络不通 | ping 服务器 IP | 检查网络连接和防火墙 |
| 端口错误 | 检查端口号 | 使用正确端口（默认 8000/18800） |
| CORS 配置错误 | 控制台查看 CORS 错误 | 后端添加前端地址到 CORS_ORIGINS |
| HTTPS 证书错误 | 控制台查看证书错误 | 使用有效证书或允许局域网 HTTP（Debug） |
| 公网 HTTP 被拒 | APP 安全策略 | 使用 HTTPS 或私有 IP |

**排查步骤：**

```bash
# 1. 测试服务器是否可达
curl http://<server-ip>:<port>/health

# 2. 测试 API
curl http://<server-ip>:<port>/api/v1/meta/capabilities

# 3. 检查 CORS 头
curl -I -X OPTIONS http://<server-ip>:<port>/api/v1/health   -H "Origin: http://localhost:5173"   -H "Access-Control-Request-Method: GET"

# 4. 检查防火墙
sudo ufw status  # Linux
Test-NetConnection -ComputerName <ip> -Port <port>  # Windows
```

### 3.2 请求超时

**症状：** 操作后长时间无响应，提示「请求超时」

**可能原因：**

| 原因 | 排查方法 | 解决方案 |
| --- | --- | --- |
| 网络慢 | 测试网络延迟 | 切换网络或靠近路由器 |
| 服务器负载高 | 查看服务器 CPU/内存 | 优化查询或升级服务器 |
| 数据库慢 | 后端日志查看慢查询 | 添加索引或优化查询 |
| 视觉任务耗时 | 视觉 worker 负载 | 等待或取消重试 |
| 外部 API 超时 | 天气/LLM 服务慢 | 检查上游服务，增加超时 |

**排查步骤：**

1. 「我的 → 最近请求」查看具体哪个请求超时
2. 用 curl 直接测试该接口的响应时间
3. 后端日志查看请求处理时间和慢查询
4. 检查服务器资源使用（top/htop）

### 3.3 CORS 错误

**症状：** 控制台显示 `Access to fetch at ... has been blocked by CORS policy`

**原因：** 后端 `CORS_ORIGINS` 不包含前端地址

**解决方案：**

```bash
# 后端启动时设置
$env:CORS_ORIGINS = "http://localhost:5173,http://localhost:5175,capacitor://localhost,https://your-domain.com"
```

**注意：**
- PWA 地址是域名（如 https://homecare.example.com）
- APK 地址是 `capacitor://localhost`
- 开发环境是 `http://localhost:5173`
- 修改后重启后端

### 3.4 弱网下体验差

**症状：** 弱网环境下加载慢、操作无反馈

**排查与优化：**

| 现象 | 优化措施 |
| --- | --- |
| 空白加载 | 显示骨架屏 |
| 操作无反馈 | 按钮 loading 状态 + 禁用重复点击 |
| 超时无提示 | 15 秒超时 + 友好错误提示 |
| 图片加载慢 | 图片压缩 + 懒加载 |
| 列表卡顿 | 虚拟滚动 + 分页 |

## 4. 认证与授权问题

### 4.1 登录失败

**症状：** 输入用户名密码后提示「登录失败」

**可能原因：**

| 原因 | 提示文案 | 解决方案 |
| --- | --- | --- |
| 用户名不存在 | 「用户名或密码错误」 | 确认用户名或注册 |
| 密码错误 | 「用户名或密码错误」 | 重置密码（Owner 操作） |
| 账号被锁定 | 「账号已锁定，请 15 分钟后重试」 | 等待锁定解除 |
| 服务器不可用 | 「无法连接服务器」 | 检查网络和服务器 |
| 会话创建失败 | 「登录失败，请重试」 | 检查后端日志 |

**安全说明：** 不区分「用户名不存在」和「密码错误」，防止用户名枚举。

### 4.2 频繁被登出

**症状：** 使用过程中频繁跳转到登录页

**可能原因：**

| 原因 | 解决方案 |
| --- | --- |
| 会话过期（默认 1 小时） | 重新登录（设计如此） |
| 页面刷新 | 刷新后内存 token 丢失（设计如此） |
| 其他设备修改密码 | 当前设备会话被撤销 | 重新登录 |
| 后端重启 | 内存会话丢失 | 重新登录 |
| token 被篡改 | 安全机制 | 重新登录 |

### 4.3 看不到某些成员或数据

**症状：** 家人列表为空或缺少成员，健康数据不完整

**原因：** 授权范围限制

**排查：**

1. 确认当前用户角色（Owner / 照护者）
2. Owner 可看到全部成员和数据
3. 照护者只能看到被授权的成员和字段
4. 检查「我的 → 授权范围」（如有）
5. 联系家庭 Owner 确认授权配置

**API 层：** 未授权的成员/字段统一返回 404，不区分「不存在」和「无权限」。

### 4.4 修改密码后其他设备登出

**症状：** 修改密码后，其他设备上的会话失效

**说明：** 这是安全设计。修改密码后服务端撤销该用户的全部旧会话，只保留当前设备的新会话。

**解决：** 其他设备重新登录即可。

## 5. 功能问题

### 5.1 今日任务不显示

**症状：** 今日页没有任务列表

**可能原因：**

| 原因 | 排查 | 解决 |
| --- | --- | --- |
| 没有服药计划 | 检查是否添加了药品和计划 | 添加药品和服药计划 |
| 计划已全部完成 | 查看任务摘要 | 正常现象 |
| 计划日期不对 | 检查计划的开始日期和频率 | 修正计划配置 |
| 成员选择错误 | 检查当前选中的成员 | 切换到正确成员 |
| API 返回空 | 「最近请求」查看响应 | 检查后端数据 |
| 授权不足 | 照护者无该成员计划权限 | Owner 授权 |

### 5.2 任务确认没反应

**症状：** 点击「确认」按钮后无变化

**可能原因：**

| 原因 | 排查 | 解决 |
| --- | --- | --- |
| 按钮被禁用 | 检查按钮状态 | allowed_actions 不含 confirm |
| 网络请求中 | 按钮显示 loading | 等待请求完成 |
| 网络错误 | 「最近请求」查看错误 | 检查网络和服务器 |
| 幂等冲突 | 错误提示 409 | 刷新页面获取最新状态 |
| 服务端动作策略不允许 | 查看 plan-workbench 响应 | 服务端配置动作权限 |

### 5.3 拍药盒识别失败

**症状：** 拍照后识别结果为 UNKNOWN 或 FAILED

**可能原因：**

| 原因 | 排查 | 解决 |
| --- | --- | --- |
| 图片模糊 | 质量门控提示 | 重新拍摄，保持清晰 |
| 光线不足 | 质量门控提示 | 改善光线 |
| 药品不在主数据库 | 结果 UNKNOWN | 手动录入药品 |
| 视觉 worker 未启动 | 任务一直 QUEUED | 启动视觉 worker |
| OCR 识别错误 | 查看证据详情 | 人工修正候选 |
| 文件过大 | 上传失败 | 压缩图片或缩短视频 |
| 网络中断 | 上传失败 | 检查网络后重试 |

**排查步骤：**

1. 查看视觉任务状态（QUEUED/PROCESSING/FAILED）
2. 查看证据详情（OCR 文本、条码、包装类型）
3. 后端日志查看视觉 worker 输出
4. 确认 `vision-inference` 能力是否 available

### 5.4 风险提醒不出现

**症状：** 预期的风险没有出现在提醒列表

**可能原因：**

| 原因 | 排查 | 解决 |
| --- | --- | --- |
| 规则条件不满足 | 检查药品/过敏/库存数据 | 确认数据完整 |
| 风险被预算压制 | 查看 budget_status | INFO/LOW 级有每日预算 |
| 风险已确认 | 查看已确认列表 | 正常，不再显示 |
| 风险已过期 | 查看 valid_until | 正常，过期不显示 |
| 规则引擎未运行 | 检查 care_plan worker | 启动 worker |
| 授权不足 | 照护者无风险查看权限 | Owner 授权 |

### 5.5 语音助手不工作

**症状：** 点击麦克风无反应或识别失败

**可能原因：**

| 原因 | 排查 | 解决 |
| --- | --- | --- |
| 设备不支持 Web Speech API | 按钮置灰 | 使用文字输入 |
| 麦克风权限未授予 | 系统权限提示 | 授予麦克风权限 |
| 浏览器不支持 | 检查浏览器版本 | 使用 Chrome/Edge |
| 15 秒无输入 | 自动停止提示 | 重新点击说话 |
| 识别结果为空 | 提示未识别 | 说清楚一些或用文字 |
| 后端 LLM 未运行 | 助手返回降级 | 启动 Ollama 或接受降级 |
| 网络错误 | 提示网络失败 | 检查网络 |

### 5.6 知识检索无结果

**症状：** 搜索关键词后显示「无相关结果」

**可能原因：**

| 原因 | 排查 | 解决 |
| --- | --- | --- |
| 知识库为空 | 检查知识文档列表 | 导入知识文档 |
| 关键词不匹配 | 尝试其他关键词 | 使用更通用的词 |
| 文档未批准 | 状态为 pending | 管理员批准文档 |
| 授权不足 | 无该分类访问权限 | Owner 授权 |
| 向量索引未构建 | 后端日志 | 重建索引 |
| 能力不可用 | capabilities 检查 | 启动知识服务 |

## 6. 无障碍问题

### 6.1 TalkBack 朗读异常

**症状：** TalkBack 开启后，部分元素不朗读或朗读错误

**可能原因：**

| 原因 | 解决 |
| --- | --- |
| 图标按钮无 aria-label | 添加 aria-label |
| 装饰性内容未隐藏 | 添加 aria-hidden="true" |
| 动态内容无 aria-live | 添加 aria-live 区域 |
| 自定义控件无 role | 添加正确的 role |
| 焦点顺序混乱 | 调整 DOM 顺序 |
| 表单无 label | 添加 label for |

### 6.2 大字号下布局错乱

**症状：** 特大字号下文字溢出或横向滚动

**排查与修复：**

1. 检查是否使用了固定宽度（px）→ 改用 max-width
2. 检查长文本是否 `white-space: nowrap` → 允许换行
3. 检查按钮文字是否截断 → 增加按钮宽度或缩短文案
4. 检查表格是否溢出 → 横屏滚动或转卡片布局
5. 运行 `npm run audit:font-scale` 自动检测

### 6.3 高对比模式下看不清

**症状：** 高对比模式下部分内容不可见

**原因：** 使用了低对比度颜色或依赖颜色区分

**修复：**
- 高对比模式下强制黑白配色
- 所有状态添加文字和图标，不只靠颜色
- 边框使用纯黑色，2px 宽度
- 去除渐变和阴影，使用实色

### 6.4 减少动效后仍有动画

**症状：** 开启减少动效后，背景仍在动

**原因：** CSS 动画未被 `prefers-reduced-motion` 覆盖

**修复：**

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

[data-motion="reduced"] .aurora-layer,
[data-motion="reduced"] .firefly-layer {
  display: none;
}
```

## 7. 性能问题

### 7.1 启动慢

**症状：** 打开应用后很久才能操作

**排查：**

1. Lighthouse 测量 FCP、LCP、TTI
2. Network 面板查看资源加载时间
3. 检查 JS/CSS 体积
4. 低端设备模拟（4x CPU + Slow 3G）

**优化：**

- 代码分割，首屏只加载今日页
- 启用 gzip/brotli 压缩
- Service Worker 缓存 App Shell
- 减少第三方依赖
- 图片懒加载

### 7.2 滚动卡顿

**症状：** 列表滚动时掉帧

**排查：**

1. Chrome DevTools → Performance → 录制滚动
2. 查看是否有长任务（>50ms）
3. 查看是否触发重排（Layout 紫色区域）

**优化：**

- 列表虚拟滚动（>50 条）
- 列表项组件 memo 化
- 图片使用 `loading="lazy"`
- 避免在滚动回调中操作 DOM
- 只动画 transform/opacity

### 7.3 内存泄漏

**症状：** 使用时间越长越卡，最终崩溃

**排查：**

1. Chrome DevTools → Memory → 录制 heap snapshot
2. 多次路由切换后对比 heap 大小
3. 查看 Detached DOM tree

**常见泄漏点：**

- 定时器未清除（setInterval/setTimeout）
- 事件监听器未移除
- IntersectionObserver 未 disconnect
- AbortController 未 abort
- 全局状态累积不清理

**修复：** 组件 `onUnmounted` 中清理所有副作用。

### 7.4 低端设备发热

**症状：** 使用时设备明显发热

**原因：** 持续高 CPU/GPU 占用

**优化：**
- 低端设备自动停用装饰动画（极光、萤火）
- 减少同时运行的动画数量
- 视频抽帧频率降低
- 避免持续的 JS 计算

## 8. 数据问题

### 8.1 数据不同步

**症状：** 多端数据不一致

**原因：**

- 移动端不持久化数据，每次从服务端获取
- 刷新页面即可获取最新数据
- 如仍不一致，检查 outbox worker 是否积压

**排查：**

```bash
# 检查 outbox 状态
curl http://localhost:8000/api/v1/households/<id>/outbox

# 手动触发恢复
curl -X POST http://localhost:8000/api/v1/households/<id>/outbox/recover
```

### 8.2 演示数据和真实数据混淆

**症状：** 切换数据来源后显示错误数据

**解决：**

1. 切换数据来源时清除当前页面状态
2. 重新加载数据
3. 演示模式有明确「演示」标签
4. 联机模式显示服务器地址

### 8.3 本地设置丢失

**症状：** 无障碍设置、服务器地址丢失

**原因：** localStorage 被清除

**恢复：**
- 重新配置服务器地址
- 重新设置无障碍选项
- 这些设置仅存本机，清除后需重新配置

**预防：** 不要随意「清除站点数据」或「清除应用数据」。

## 9. PWA 问题

### 9.1 无法安装 PWA

**症状：** 浏览器不显示安装按钮

**条件：** PWA 可安装需满足：
- 有有效的 manifest.webmanifest
- 有 Service Worker 且已注册
- 通过 HTTPS 访问（localhost 除外）
- 不是已安装状态

**排查：**

1. Chrome DevTools → Application → Manifest，检查是否有效
2. Service Workers 检查是否已注册
3. 确认通过 HTTPS 访问
4. 检查 manifest 中是否有 name、icons（192px、512px）、start_url

### 9.2 离线不可用

**症状：** 断网后页面无法打开

**原因：**

- Service Worker 未注册或未激活
- App Shell 未缓存
- 首次访问未完成缓存

**排查：**

1. Chrome DevTools → Application → Service Workers
2. 检查 SW 状态（activated）
3. 检查 Cache Storage 是否有资源
4. 确认 SW 缓存策略包含 index.html 和 JS/CSS

### 9.3 更新不生效

**症状：** 发布新版本后，用户看到的还是旧版本

**原因：**

- Service Worker 缓存了旧版本
- 用户未确认更新提示
- 服务器缓存了旧的 sw.js

**解决：**

1. 用户点击「更新」提示后刷新
2. 服务器配置 sw.js 不缓存（`Cache-Control: no-cache`）
3. 紧急情况：用户清除站点数据

## 10. Android 特有问题

### 10.1 通知不显示

**症状：** 到了服药时间没有通知

**原因：**

| 原因 | 解决 |
| --- | --- |
| 通知权限未授予 | 系统设置 → 应用 → 通知 → 允许 |
| 电池优化限制后台 | 设置 → 电池 → 关闭优化 |
| 应用被划掉 | 锁定应用后台 |
| PWA 无后台通知 | PWA 不支持可靠后台通知，使用 APK |
| 计划提醒未配置 | 检查服务端计划提醒契约 |

### 10.2 安全区不适配

**症状：** 内容被状态栏或手势栏遮挡

**原因：**

- `env(safe-area-inset-*)` 未生效
- WebView 未开启边到边显示
- CSS 未使用安全区变量

**修复：**

```css
body {
  padding-top: env(safe-area-inset-top, 0);
  padding-bottom: env(safe-area-inset-bottom, 0);
}
```

确认 `MainActivity.java` 中调用了 `WindowCompat.setDecorFitsSystemWindows(window, false)`。

### 10.3 横屏后布局错乱

**症状：** 旋转手机后布局溢出或元素错位

**排查：**

1. 检查根容器 `max-width: 100vw`
2. 检查固定宽度元素
3. 检查底部导航高度
4. 运行 `npm run audit:responsive`

### 10.4 返回键退出应用

**症状：** 按返回键直接退出应用，而不是返回上一页

**原因：** Capacitor 默认行为，未处理返回键

**解决：** 可在 App.vue 中监听 backbutton 事件，实现路由返回。

## 11. 紧急恢复

### 11.1 应用完全不可用

**步骤：**

1. 确认后端服务状态（`curl /health`）
2. 确认数据库状态
3. 查看后端日志最近的错误
4. 重启后端服务
5. 如仍异常，回滚到上一版本
6. 通知用户暂时使用网页端

### 11.2 数据错误

**步骤：**

1. 停止写入（暂停服务或告知用户）
2. 备份当前数据库
3. 定位错误数据（事件溯源可追溯）
4. 追加补偿事件更正
5. 重放状态投影
6. 验证数据正确性
7. 恢复服务

### 11.3 安全事件

**步骤：**

1. 立即断开网络（防止数据泄露扩大）
2. 评估影响范围
3. 撤销可疑会话和授权
4. 更换密钥和密码
5. 保留日志证据
6. 通知受影响用户
7. 复盘并改进安全措施
