# 家健镜随身版 无障碍模式设计说明

> 状态：随本仓库 v0.1.0 交付；对应主仓库 NFR-07（可访问性）在移动端的延伸。
>
> 目标用户：老人与慢病成员（视力下降、手部精细操作困难、对复杂界面不熟悉）、以及在强光/嘈杂环境下使用手机的照护者。

## 1. 设计原则

1. **不只靠颜色**：所有等级、状态同时用文字 + 图标 + 颜色表达；色觉障碍用户不丢失信息（延续主仓库 NFR-07"状态不只依赖颜色"）。
2. **可组合**：长辈模式是一键预设；字号、对比度、语音、动效同时提供独立开关，互不锁死。
3. **本地保存**：全部设置写入 `localStorage`，不上传、不绑定账号。
4. **默认可用**：不开启任何设置时也满足基础可访问性（触控目标 ≥ 44px、焦点可见、语义化标签）。

## 2. 模式清单

| 设置 | 默认 | 行为 | 实现 |
|---|---|---|---|
| 长辈模式 | 关 | 一键：特大字号 + 语音播报开 + 底部导航简化为 4 个大入口（今日/拍药盒/求助/我的）+ 触控目标提升到 ≥60px | `html[data-elder='on']` + store 联动 |
| 外观 | 跟随系统 | 浅色 / 深色（森林夜配色）/ 跟随系统；auto 模式监听系统深浅色实时切换；状态栏 theme-color 同步 | `html[data-theme]`；`resolveTheme` + `matchMedia('(prefers-color-scheme: dark)')` 监听 |
| 字号 | 标准 | 标准 ×1 / 大 ×1.15 / 特大 ×1.32，全局 rem 缩放 | `html[data-font-scale]` 驱动 `--scale`，根字号 `calc(16px * var(--scale))` |
| 高对比度 | 关 | 纯白实底、文字近黑、描边加粗、焦点环加粗；玻璃/渐变/阴影/AI 背景装饰全部降级移除；优先级高于深色模式 | `html[data-contrast='high']` 覆盖全套颜色与材质变量（声明顺序在主题之后） |
| 语音播报 | 关 | 朗读今日安排摘要、风险卡内容、任务操作结果、识别阶段结果；页面切换自动打断 | Web Speech API（`speechSynthesis`，zh-CN，语速 0.95） |
| 减少动效 | 关 | 过渡/动画时长压到 0.01ms；JS 驱动的数字滚动与彩带庆祝直接跳过 | `html[data-motion='reduced']` + 系统 `prefers-reduced-motion`；`useCountUp` 与 `ConfettiBurst` 读取设置判断 |

受"减少动效"控制的动画清单：背景色斑漂移与 Ken Burns、英雄卡光斑呼吸、取景框扫描线与角标闪烁、列表交错入场、页面转场、Tab 图标弹跳、进度环光晕、趋势柱生长、数字滚动、彩带庆祝、SOS 脉冲。

长辈模式开关联动规则：开启时自动设字号=特大、语音播报=开；关闭时字号与语音恢复默认；高对比度与减少动效保留用户自己的选择（在设置页有文字说明）。

## 3. 工程机制

- 设置存于 `src/stores/accessibility.ts`，应用启动时在挂载前调用 `initAccessibility()`，避免首屏字号/对比度跳变；
- 所有模式通过 `<html>` 的 `data-*` 属性 + CSS 自定义属性生效，组件无需感知无障碍状态（`src/style.css`）；
- 语音封装在 `src/composables/useSpeech.ts`：`useSpeech()` 跟随"语音播报"开关；显式点按的"播报"按钮使用 `createSpeaker(() => true)`，尊重用户的即时意图；
- 语义化：`role="switch"` + `aria-checked` 开关、`role="alert"/"status"` 消息区、`aria-pressed` 筛选按钮、`aria-current="page"` 导航、`aria-expanded` 折叠面板、跳转链接（skip link）、图标一律 `aria-hidden` 并配文字。

## 4. 验收清单（人工）

- [ ] 长辈模式开启后：底部导航变为 4 个大入口，字号明显变大，切换时有语音确认；
- [ ] 特大字号下所有页面无文字截断、按钮不重叠（320px 宽度）；
- [ ] 高对比度下正文对比度 ≥ 7:1，焦点环清晰可见；
- [ ] 仅用键盘（或开关控件）可完成：确认任务、查看风险依据、切换设置；
- [ ] 关闭语音包的设备上，语音功能静默降级、界面提示检查系统"文字转语音"；
- [ ] 系统开启"减弱动态效果"时，应用动画自动消失（无需应用内设置）；
- [ ] 每个等级标签在灰度模式截图下仍可区分（文字可读）。

## 5. 已知限制

- 语音播报依赖设备系统的中文 TTS 语音包，部分安卓浏览器需要用户先与页面交互后才允许发声；
- 尚未针对屏幕阅读器（TalkBack/VoiceOver）做完整遍历验收，列入后续迭代；
- 高对比度目前为纯白底浅色方案且优先于深色模式，暂未提供"深色高对比"组合；
- 触觉反馈依赖 `navigator.vibrate`（iOS Safari 不支持，自动静默）。
