# MOB-147 受控发布环境与移动端依赖联调

## 1. 目标和安全边界

本流程用于建立**不含真实健康数据**的受控发布候选环境，验证 PWA 托管、Android WebView、移动端 API 契约与后端能力声明是否能够协同工作。它不是生产发布授权，也不替代正式认证、风险规则、模型发布或隐私审批。

受控环境只允许使用明确标为“演示”的合成家庭、成员、计划和风险数据。不得把真实服务器地址、访问令牌、Cookie、密码、私钥、APK 签名材料、真实设备标识、原始请求/响应正文或真实健康数据提交到仓库、Issue、PR、日志或测试报告。

## 2. 发布记录与指纹

从 [controlled-release-record.template.json](controlled-release-record.template.json) 复制一份到**未跟踪目录**，例如 `C:\temp\mob147-release-record.json`。模板故意不能通过校验，避免占位值被误认为受控环境证据。

运行：

```powershell
npm run verify:controlled-release -- --record C:\temp\mob147-release-record.json
```

校验器要求记录中同时包含：服务端和 APP Git 提交哈希、API 版本、PWA shell 版本、Android 版本、合成数据种子 SHA-256、设备信息和实际执行场景。输出的 `fingerprint` 是这些关键版本字段的 SHA-256，用于定位“旧 PWA shell + 新 API”或“旧 APK + 新种子”等混用问题。校验器会拒绝明文 HTTP、占位值、敏感字段和未标注为演示的种子。

## 3. 环境变量清单

以下值只能在 CI 机密变量或本地未提交 `.env` 中配置，绝不写入仓库：

| 变量 | 用途 | 要求 |
|---|---|---|
| `HOMECARE_API` | 开发代理的受控后端基地址 | 仅用于开发；受控发布候选必须记录 HTTPS 站点，不使用真实地址示例 |
| `VITE_ALLOW_DEV_ACTOR` | 本地演示身份开关 | 仅本地受控造数；发布构建必须关闭 |
| `DATABASE_URL` | 受控后端独立数据库 | 只指向合成数据实例；不得复用任何真实库 |
| `CORS_ORIGINS` | 受控 PWA 与 WebView 来源白名单 | 只包含受控来源；变更需重新记录 |
| `ANDROID_HOME` / `JAVA_HOME` | APK 构建工具链 | 本机路径，不提交 |
| 签名/认证机密 | 后端、CI、APK 签名 | 仅密钥管理系统或 CI secret；本流程不读取或记录值 |

## 4. 执行顺序

1. 在隔离数据库部署后端，运行合成数据种子；记录种子文件 SHA-256、服务端提交和 API 版本。
2. 配置受控 HTTPS PWA 托管与 CORS 白名单，禁止将开发代理、mock 或本机测试绕过当作发布成功。
3. 构建并审计移动端：`npm run check`、`npm run test`、`npm run audit:pwa`、`npm run audit:android-security`、`npm run android:sync`。需要 APK 时执行 `scripts/build-apk.ps1`，但 APK 和签名文件不得提交。
4. 在 PWA 与 Android WebView 上执行冷启动、切后台、断网/恢复、升级、回滚，以及登录、过期、授权过滤、任务写回、视觉任务、能力门控、求助和错误恢复。
5. 在未提交的发布记录中填写脱敏结果，运行校验器；将测试报告与已知限制记录在项目文档中。
6. 发布候选失败时，停用该受控环境配置，恢复上一份已验证 APP 产物及其对应的 API/PWA shell/种子指纹；不得让旧 shell 继续访问新 API。

## 5. 能力与错误验收

能力接口 `/api/v1/meta/capabilities` 只要缺失、超时或声明不可用，移动端入口必须禁用并显示限制。不能由 mock、开发代理或旧快照补出能力。

对 401、403、404、409、429、5xx 和带 `x-request-id` 的响应，验证错误文案可恢复、请求 ID 可用于支持排查，且 UI 不显示资源是否存在、内部栈、认证凭据或健康正文。网络离线时 PWA 只可回退到应用外壳，`/api` 与 `/health` 不得被 Service Worker 缓存。

## 6. 已知限制

本仓库只能提供配置、静态审计、记录格式与自动校验。受控 HTTPS 部署、后端功能实现、PWA 安装、Android 真机 WebView/Cookie/Bearer 行为、系统权限、升级与回滚演练必须由具备相应环境权限的维护者执行并留存脱敏证据。缺少任何依赖时发布状态必须为 `Blocked`。
