## 1 研发背景

家健镜 HomeCare Twin 移动端（随身版 HomeCare Twin Companion）是面向八周软件工程实训的本地优先家庭居家照护教学演示系统的移动端应用，以 H5 + Capacitor 安卓壳交付。它是主仓库（网页端 + FastAPI 后端）的"随身照护端"：老人与照护者用手机完成每天真正高频、低步骤的照护动作——确认服药任务、拍药盒录入、查看分级提醒、追问证据依据与一键求助；而授权管理、人工复核、健康图谱、家庭大屏与模型实验室等重度操作仍由网页端承担。

两端共用同一套术语、状态枚举与 API 契约；移动端拥有独立的视觉体系（暖奶油底 + 森林绿 + 蜜桃琥珀，渐变英雄卡、任务进度环、悬浮胶囊导航），按移动场景与适老审美设计。自 MOB-177 起，移动端在色相、层级与状态语义上与网页端对齐，但仍不复刻网页端的布局与组件结构。

V1.0 解决的是"移动端有哪些页面、做哪些事、不做哪些事"。V2.0 要解决的是三个更硬的问题：第一，把"功能已实现"推进到"证据可验收、演示可复现、风险可回滚"；第二，把演示模式下成立的交互，在正式鉴权、真实家庭服务器、真实 Android 设备与真实弱网条件下重新成立一次；第三，把移动端新增的助手、语音、联网搜索、知识浏览、通知提醒等能力纳入同一套隐私与拒答边界，不因为"在手机上更方便"而放宽任何一条硬约束。

### 1.1 项目目标

- 在手机端维持"今日任务确认、拍药盒可信录入、分级提醒查看、证据追问、紧急求助"的高频照护闭环，动作少、反馈诚实、状态可恢复。
- 以无障碍与长辈模式作为核心验收面：特大字号、语音播报、高对比、减少动效、TalkBack 读屏顺序与 ≥60px 触控目标贯穿每一个页面，并以 Android 真机记录签收，而非仅以代码存在签收。
- 以演示模式与家庭服务器联机模式支持分阶段验收；健康数据默认不出网，联机只连接家庭可信域。
- 把正式登录、会话过期、撤权与多家庭切换纳入移动端会话生命周期，任何权限变化都 fail-closed，不残留上一家庭数据。
- 让移动端助手成为"先证据、后解释"的窄口径入口：引用可核对、无证据可拒答、模型不可用时降级为结构化事实卡，音频与健康上下文不出家庭可信域。
- 通过 Capacitor 8 把同一套 Web 代码打包为可复现、可安装、可回滚的 Android 演示发布包，并以脱敏证据台账支撑发布结论。
- 为每一条需求建立"需求编号 → Story → Issue/PR → 自动化脚本 → 真机证据"的追踪链，使课程验收不依赖口头结论。

### 1.2 产品硬边界

| 边界 | 必须满足 | 禁止行为 |
|---|---|---|
| 本地隐私 | 家庭健康数据、图片、音频、对话与提醒内容默认不出网；联机仅连接家庭可信域；Service Worker 不缓存 `/api`、`/health` 与任何健康数据 | 依赖故障时把健康上下文转发云端；把健康正文写入日志、URL、分析上报或第三方 SDK |
| 视觉确认 | OCR、条码与主数据共同形成候选，人工确认后才写入正式状态；APP 只显示任务状态与证据摘要 | 以识别结果自动入库、显示假置信度或伪装确认成功 |
| 授权可见 | 只显示服务端已授权的成员与字段，未授权字段显示"未获授权"；授权范围、用途与到期时间明示 | 以空值伪装成没有数据；以亲属或照护者身份默认开放全部健康正文 |
| 风险规则 | 风险等级由服务端确定性规则决定，移动端只展示等级、证据与非医疗处置建议 | 在前端计算或改写风险等级；输出诊断、处方、停药、换药或剂量判断 |
| 助手回答 | 回答必须携带事实、规则、引用与可见范围；证据不足时澄清或拒答；模型不可用时降级为结构化卡片 | 让模型凭常识补答、伪造引用，或在本地依赖失败时改用云端模型 |
| 出网控制 | 出网只允许白名单适配器与显式勾选的受控联网搜索，且每次出网都有告知与范围说明 | 默认开启联网；在联网请求中携带成员、药品、疾病、过敏、报告或对话正文 |
| 通知内容 | 计划提醒使用本地通知，锁屏默认不展示药品名与成员姓名，只给最小提示与"打开查看" | 使用第三方推送服务；在锁屏或通知栏泄露健康信息 |
| 业务范围 | 只提供家庭居家照护教学流程 | 买药、问诊、挂号、保险、广告、佣金或健康消费导流 |

## 2 用户对象

### 2.1 用户角色

| 用户角色 | 主要目标 | 允许范围 | 明确限制 |
|---|---|---|---|
| 家庭成员（老人/慢病成员） | 在手机上确认自己的照护任务、拍药盒录入、查看提醒与求助 | 自己及明确授权的成员数据 | 不能读取其他家庭或未授权成员信息；不能在移动端修改药品、剂量与疗程 |
| 家庭 Owner | 在手机上处理本家庭任务与提醒，查看成员目录与授权摘要 | 由 `household.created_by` 标识的本家庭管理范围 | 授权的创建、修改与撤销仍在网页端完成；不能跨家庭访问 |
| 非 Owner 照护者 | 处理被委托成员的任务、计划与风险，必要时接收升级通知 | 授权成员、字段、动作、目的与有效期内的最小范围 | 亲属或照护者角色名称本身不产生访问权；撤权或过期后立即失去可见性 |
| 数据/知识管理员 | 在移动端只读查看已发布的知识条目，核对面向家庭的表述 | 已发布、已登记许可与版本的知识片段 | 不因管理资料而自动获得家庭健康正文；不能在移动端编辑知识与规则 |
| 模型/系统管理员 | 确认移动端与家庭服务器的能力探测、降级与版本链路正常 | 能力探测结果、请求日志摘要、版本与构建信息 | 管理员权限不转化为家庭成员数据权限；移动端不内置也不直连模型 |
| 测试/验收人员 | 执行演示模式与联机模式双验、真机矩阵、无障碍与发布门禁验收 | 合成数据、公开许可数据或明确授权的演示家庭数据 | 不能用真实未授权数据或截图替代可复现证据；不能以 mock 成功结论签收 |
| 发布维护者 | 裁决 `RUNTIME_RELEASE` 与 `FULL_VISION_PRODUCTION` 两条发布结论 | 构建产物哈希、回滚包、脱敏证据台账 | 任一门禁项缺证据即须写 `BLOCKED`；仅课堂或受控演示时只能写 `DEMO_ONLY` |

### 2.2 典型使用场景

| 场景 | 触发 | 用户价值 | 成功边界 |
|---|---|---|---|
| 早间服药确认 | 到达计划提醒时间，通知栏出现最小提示 | 老人一屏内完成确认，无需理解系统结构 | 确认写回服务端并返回回执；重复点击不产生重复事件 |
| 新增药品 | 成员拍摄药盒或录制短视频 | 减少药名、规格、批次与有效期的手工录入错误 | 多证据候选经人工确认后形成健康事件；APP 不显示自动入库结论 |
| 识别冲突 | OCR、条码、规格或包装证据不一致 | 让不确定性显式进入复核 | `CONFLICT` 不进入正式状态，修正保留 before/after 与原因 |
| 家庭协同 | 成员授权照护者查看摘要或处理提醒 | 照护者在必要范围内协助 | 撤权或过期立即拒绝，服务端执行字段过滤，移动端清理本地缓存 |
| 风险追问 | 用户对提醒不理解，点开风险依据或问助手 | 获得可核对的通俗解释与证据链 | 回答携带事实、规则、引用与版本；无证据时澄清或拒答 |
| 弱网操作 | 地铁、老旧路由器或厂商省电策略下操作 | 明确知道当前是加载中、失败还是离线 | 骨架屏与重试文案稳定；不闪现旧家庭缓存；读屏播报状态变化 |
| 紧急求助 | 老人发生跌倒、胸痛等紧急情况 | 两步内拨出急救或联系人电话 | 离线与未登录仍可用；二次确认防误触；不替代急救与问诊 |
| 连续未确认 | 任务连续多次未被确认 | 让家庭及时发现异常 | 先校验照护授权再升级；无授权或已撤权对象不接收通知 |
| 撤权与清理 | 用户撤回授权或要求清理本机数据 | 控制数据全生命周期 | 本机缓存、外壳缓存与草稿有可见的处置入口与结果 |
| 演示交付 | 课程演示或阶段验收 | 一套脚本可复现完整闭环 | 演示模式完整可体验；联机模式异常可解释、状态可恢复 |

### 3.2 网页端与移动端协同边界

| 能力 | 归属端 | 移动端行为 |
|---|---|---|
| 家庭与成员创建、授权创建与撤销 | 网页端 | 只读呈现授权范围、用途与到期时间，提供跳转说明 |
| 药盒候选的正式确认与修正 | 网页端 | 只创建视觉任务并安全交接，附带返回路径与隐私提示 |
| 健康图谱、家庭大屏、模型实验室 | 网页端 | 不实现，也不以聚合方式复制其展示 |
| 知识与规则的编辑、发布与回滚 | 网页端 | 只读浏览已发布条目 |
| 风险等级计算与告警预算 | 服务端规则引擎 | 只展示等级、证据、合并与预算结果 |
| 今日任务确认、延期、跳过 | 双端 | 移动端为主入口，写回同一套事件与幂等语义 |
| 提醒到达与照护升级 | 双端 | 移动端负责本地通知与升级触发前的授权校验展示 |
| 助手问答 | 双端 | 共享同一 API 契约与拒答边界，移动端不直连模型或向量库 |

移动端不得直连数据库、向量库或 Ollama，不在前端计算风险或伪造置信度。401/403/404/409/422、超时、离线、低置信与空态必须显式呈现，不能使用陈旧家庭数据填充。

### 3.3 非目标

- 不在移动端完成授权管理、人工复核、健康图谱、家庭大屏与模型实验室等重度操作。
- 不在移动端完成药盒候选的正式确认，不显示自动入库结论。
- 不做诊断、处方、停药、换药与剂量判断，不做购药、挂号、问诊、保险、广告与佣金导流。
- 不引入第三方推送服务、第三方分析 SDK 与云端模型回退。
- 不承诺识别任意药品，不在移动端建设医学本体或相互作用数据库。
- 不把刷脸作为强制身份入口，不做持续摄像头监控，不自动确认成员已经服药。
- 不承诺在所有厂商 ROM 上通知 100% 到达，只承诺记录真实结果与已知限制。
- iOS Capacitor 壳与深色高对比组合仍属 P2，当前 Android 优先。

## 4 术语定义

| 术语 | 释义 |
|---|---|
| 随身版 / 移动端 | 家健镜 HomeCare Twin 的移动端应用，H5 + Capacitor 安卓壳，定位随身照护端 |
| 家庭可信域 | 家庭局域网或机构内网中受控运行的 Web、API、数据库、文件、视觉/OCR、向量索引与本地模型环境，默认拒绝健康数据网络出口 |
| DataProvider | 隔离演示数据与家庭服务器联机数据的接口层，视图层不感知数据来源差异 |
| 演示模式 | 内置虚构家庭数据、不连服务器的默认模式，用于教学演示与交互验收 |
| 联机模式 | 调用主仓库 FastAPI 的家庭服务器模式，按身份与访问用途上下文请求 |
| 能力探测 | 移动端启动或切换数据源后向服务端查询可用能力，用于禁用不可用入口而非伪造功能 |
| 正式鉴权模式 | 使用真实登录与会话令牌的模式；与开发期身份头约定互斥，路由守卫按此模式决定是否跳转登录 |
| fail-closed | 权限、版本或依赖状态不确定时一律按拒绝处理，宁可不展示也不猜测展示 |
| 长辈模式 | 特大字号 + 语音播报 + 简化导航 + 更大触控目标的一键无障碍模式 |
| 高对比度 | 纯白实底 + 黑描边，去除玻璃、渐变、阴影与背景装饰，优先级高于深色模式 |
| 减少动效 | 停用背景漂移、扫描线、彩带、数字滚动等全部动画，并尊重系统 `prefers-reduced-motion` |
| 状态三重表达 | 任何等级或状态都同时以文字、图标与颜色表达，不只依赖颜色 |
| 四态 | 药盒候选状态 `MATCHED` / `CONFLICT` / `UNKNOWN` / `REVIEW`，均需人工确认 |
| 质量门控 | 图片或抽帧的质量检查（清晰度、曝光、反光、方向、透视），不通过只提示重拍原因 |
| 视觉任务 | 移动端上传后在服务端创建的识别任务，移动端只回查其状态与证据摘要 |
| 复核交接 | 移动端把视觉任务安全移交网页端人工复核中心的过程，含返回路径与隐私提示 |
| 安全时间窗 | 医嘱事实允许调整提醒时间的范围；越窗建议一律阻止 |
| 照护升级 | 连续未确认后按已有授权通知照护者的过程，先校验授权再通知 |
| 告警预算 | 对提示级与一般级告警进行合并、摘要与每日限量的机制，不压制较高与严重级别 |
| 已知晓回写 | 用户对风险卡标记"我已知晓"的写回动作；服务端未提供接口时界面如实提示 |
| 证据契约 | 助手回答或风险卡必须同时携带事实、规则、引用、确认状态、可见范围与版本 |
| 受控联网搜索 | 用户显式勾选后、经白名单与脱敏处理的一次性联网参考，不改变默认不出网策略 |
| 唤醒听写 | 通过唤醒词进入语音输入的交互；需显式启动麦克风，音频不上传、不落盘 |
| 自动朗读收口 | 助手回复的自动播报只在明确结束态触发，停顿、中断与用户停止时不播报半截内容 |
| 中断标记 | 流式回复被服务端取消或用户停止时的显式标记，不保留半截回答也不回退普通流 |
| 本地通知 | 由设备本地调度的提醒通知，不经第三方推送服务 |
| 私密通道 | 锁屏与通知栏默认不展示药品名与成员姓名的通知渠道配置 |
| PWA | 渐进式 Web 应用；Service Worker 只缓存应用外壳与静态资源，`/api`、`/health` 绝不缓存 |
| 外壳缓存 | 以固定前缀命名的应用外壳缓存；清理入口只清理该前缀，不触碰其他站点缓存 |
| 弱网夹具 | 仅内存、仅合成数据的本地受控服务，用于复核弱网列表状态，不是生产后端 |
| 性能预算 | 对产物体积、资源占用与低端设备模拟场景设定的阈值门禁 |
| 受控发布环境 | 用于验证移动端与依赖联调的受控运行时，含 HTTPS 夹具与运行手册 |
| 发布门禁 | 以 `RUNTIME_RELEASE` 与 `FULL_VISION_PRODUCTION` 两条独立结论裁决发布的矩阵机制 |
| 证据台账 | 记录每个门禁项的脱敏证据路径、执行日期、提交哈希、环境与回滚位置的清单 |
| MOB-xxx | 移动端 Story 编号，与主仓库 Issue 一一对应 |
| FR-Mxx | 本文档中的移动端功能需求编号 |
| NFR-xx | 主仓库非功能需求编号，移动端沿用同一套口径 |

## 5 业务流程说明

### 5.1 整体业务流程

```
打开 App
  ↓
判定数据模式（演示 / 家庭服务器联机）与鉴权模式（开发期身份头 / 正式登录）
  ↓
正式鉴权模式下未登录 → 跳转登录页（求助、我的、无障碍设置保持可达）
  ↓
后端能力探测 → 禁用不可用入口，不伪造功能
  ↓
今日照护：任务进度 + 趋势 + 待关注风险 + 最近变化 + 季节资讯 + 环境行动卡
  ↓
确认 / 延期 / 跳过任务，或拍药盒录入，或查看风险依据，或向助手追问
  ↓
写请求携带幂等键 → 服务端回执为准 → 三处（任务、趋势、时间线）刷新一致
  ↓
提醒到期 → 本地通知（私密通道）→ 未确认累积 → 校验授权后照护升级
  ↓
全部操作可在请求日志摘要与版本信息中定位，健康正文不进入日志
```

流程中移动端的模型输出只作为候选或语言解释；正式健康事实必须由用户或授权复核者在网页端确认；风险等级只能由服务端确定性规则生成；未授权字段显示"未获授权"而非空数据；依赖不可用时停在明确的加载、失败、离线、未授权或降级状态。

### 5.2 今日任务闭环流程

加载今日任务（由计划事实与最后动作事件推导）→ 展示进度环与统计 → 用户选择确认、延期或跳过 → 跳过必填原因、延期选择时长 → 携带幂等键写回对应事件 → 成功 Toast 与触觉反馈 → 任务、近 7 天趋势与最近变化时间线同步刷新 → 全部完成时播放彩带（减少动效下不播放）。

写回失败时保留用户输入并提供重试；重复点击不产生重复事件；同一幂等键的重复请求返回原结果；服务端返回冲突时展示冲突原因而不是覆盖本地状态。任务历史与服务端回执可在成员档案与请求日志摘要中回溯。

### 5.3 拍药盒与短视频录入流程

选择成员 → 选择拍摄、相册或短视频 → 校验文件类型、大小、像素与时长 → 短视频按策略抽帧 → 质量门控（清晰度、曝光、反光、方向、透视）→ 不通过只提示重拍原因，不进入识别 → 通过后上传并创建视觉任务 → 轮询任务状态并展示证据摘要 → 引导安全交接到网页端人工复核中心。

移动端不显示识别结果的自动入库结论，不显示置信度分值；任务完成或失败均给出明确状态与后续动作；上传过程中断网时保留任务引用并允许重试；相机或相册权限被拒绝时给出系统设置引导并保留手工录入路径。

### 5.4 会话、鉴权与多家庭切换流程

正式鉴权模式下：进入受保护路由 → 路由守卫检查会话状态 → 未认证或已失效则携带回跳地址跳转登录页 → 登录成功后恢复原目标页 → 会话过期或被撤权时清理内存与本机缓存中的家庭数据并回到安全状态。

多家庭场景下：选择家庭 → 记录当前家庭上下文 → 切换家庭时清空上一家庭的列表、详情、草稿与轮询任务 → 重新探测能力与授权范围。任何时刻都不允许两个家庭的数据同屏出现或残留。

刷脸登录为可选引导：能力不可用、样本不足或阈值未校准时按 fail-closed 处理，明确提示不可用并保留密码登录路径，不以刷脸结果替代授权校验。

### 5.5 助手问答与联网搜索流程

用户提问（键入或唤醒听写）→ 组装当前成员与访问用途上下文 → 优先请求流式接口并展示阶段状态 → 展示脱敏证据预览与引用（默认折叠，可展开）→ 校验后的文本进入回复气泡 → 自动朗读只在明确结束态触发。

普通流错误时回退非流式接口；服务端标记取消或用户主动停止时不回退、不保留半截回答，并显示中断标记。用户可显式勾选"本次使用脱敏联网参考"，勾选后仍只发送脱敏查询、显示出网告知与范围说明；未勾选时不产生任何出网请求。模型或检索不可用时返回结构化事实、规则与任务卡，并说明当前不可用原因。

### 5.6 风险提醒与依据展开流程

服务端确定性规则生成风险 → 移动端按四级（严重、较高、一般、提示）筛选展示 → 风险卡展示等级、涉及成员与摘要 → 展开或进入风险依据详情页 → 展示"为什么出现这条提醒 + 参与事实 + 规则编号与版本 + 非医疗处置建议" → 用户可标记"我已知晓"。

一般与提示级按成员、规则与时间窗合并，并受每日预算限制；较高与严重级不受普通预算压制，也不参与合并折叠。已知晓回写在服务端接口缺失时如实提示"当前版本不支持回写"，不伪装成功。风险相关文案不得出现"可以一起吃""必须停药"这类结论。

### 5.7 计划提醒、安全时间窗与照护升级流程

医嘱事实只读 → 提醒策略在安全时间窗内可调 → 到达提醒时间派发本地通知（私密通道，锁屏最小提示）→ 未确认则按策略再提醒 → 连续未确认达到阈值 → 校验照护授权是否有效 → 有效则通知授权照护者，无效或已撤权则不通知并记录原因。

移动端不得新增、停用、替换药物或改变剂量与频次；越过安全时间窗的调整建议一律阻止并说明原因；通知权限被拒绝或被厂商省电策略限制时，在应用内显示权限指引与已知限制，不假装提醒已送达。

### 5.8 环境行动卡与季节资讯流程

获取粗粒度天气输入（仅发送城市或区县编码）→ 结合成员主动授权标签生成低风险生活行动提示 → 同一事件有效期内只生成一次 → 天气失败时不生成新卡且不影响档案、事件、规则与任务。

季节健康资讯优先使用家庭服务器白名单结果，不可用时回退内置虚构季节日历，两种来源都必须标注来源与时间；缓存过期时显示过期提示与刷新入口，不静默展示旧内容；用户可携带标题与来源进入助手草稿，但不自动发送。

### 5.9 无障碍与紧急求助流程

进入"我的" → 一键开启长辈模式 → 全局套用特大字号、语音播报、简化底部导航与更大触控目标 → 可分别调整外观三档、字号三档、高对比与减少动效 → 语音自检页验证中文 TTS 与麦克风可用性 → 全部偏好只存本机。

求助流程：进入求助页（未登录、离线均可达）→ 展示急救号码与紧急联系人 → 超大按钮触发拨号 → 二次确认防误触 → 拨号能力不可用时展示号码与静态求助信息 → 可语音播报当前重要提醒。求助页不依赖联机数据，也不因会话失效而不可用。

### 5.10 构建、受控发布与回滚流程

`npm run check` 类型检查 → `npm run test` 单元测试 → `npm run build` 产物构建 → `npm run android:sync` 同步到 Android 工程 → Gradle 构建 APK → 记录产物 SHA-256、提交哈希与环境 → 在受控发布环境与 Android 真机执行矩阵验收 → 填写脱敏证据台账 → 维护者复核并裁决发布结论。

任一门禁项缺证据、依赖未满足或记录不一致时结论为 `BLOCKED`；仅课堂或受控演示时标 `DEMO_ONLY`，不得表述为家庭生产可用。发布后发现不一致时撤回候选版本、恢复上一份已验证产物与配置，并补充阻塞原因与新的脱敏证据索引。`local.properties`、构建产物、签名材料与真实设备标识不入库。

### 5.11 验收执行与证据归档流程

确定验收对象（需求编号 + Story）→ 冻结验收矩阵与用例清单 → 在演示模式执行一轮 → 在联机模式执行一轮 → 在 Android 真机执行需要真机的项 → 运行对应自动化脚本 → 收集脱敏截图、日志摘要与脚本输出 → 填写证据台账（证据路径、执行日期、提交哈希、环境、回滚位置）→ 维护者人工复核并复跑关键命令 → 回填第 13 章追踪矩阵与状态。

证据归档遵循三条约束：第一，不提交真实健康数据、令牌、Cookie、真实设备标识、APK 与签名材料；第二，截图必须脱敏且能看出系统版本、ROM 版本与相关设置项状态；第三，同一门禁项的多次执行保留最新一次与失败记录，失败记录不得删除。发现记录与实际行为不一致时，先把状态回退为待验收或阻塞，再补充新证据，不允许以"应该没问题"结论保留原状态。

## 6 需求规格说明

本章需求编号为 FR-M01～FR-M26。每条需求统一给出目标、角色、前置条件、输入、处理规则、输出、异常与降级、验收、证据要求与非目标；其中"验收"只描述可判定的条件，"证据要求"说明该条需求签收时必须能定位的材料。除特别说明外，所有需求共同遵守以下公共约束：

- 默认不出端：健康数据、图片、音频与对话不进入缓存、URL、日志、分析上报或第三方服务。
- 最小权限：所有读写都按服务端返回的授权范围执行，前端隐藏不构成授权。
- fail-closed：401/403/404/409/422、超时、低置信与权限变化一律按拒绝或降级处理，不展示陈旧或猜测内容。
- 双模验证：功能须在演示模式与家庭数据模式分别验证，关键路径有自动化或人工测试记录。
- 状态三重表达：所有状态与等级同时以文字、图标与颜色表达，且在减少动效与高对比下仍成立。
- 非医疗边界：不输出诊断、处方、停药、换药与剂量结论，不做健康消费导流。

### 7.2 页面状态矩阵

每个页面必须实现下表全部适用状态，且状态尺寸稳定、不发生跳变；状态之间的切换必须向读屏播报。

| 状态 | 界面要求 | 禁止行为 |
|---|---|---|
| 正常 | 内容完整，含来源与更新时间 | 用旧缓存冒充最新数据 |
| 加载 | 骨架屏或加载态占位，尺寸与最终内容接近 | 空白页面或无限旋转无说明 |
| 弱网慢速 | 保留骨架屏并提示"网络较慢"，提供重试 | 无提示长时间挂起 |
| 空 | 说明为什么为空以及下一步可做什么 | 用空态伪装未授权 |
| 错误 | 用户可理解的原因 + 可执行动作 + 请求标识 | 只显示错误码或堆栈 |
| 离线 | 明确标注离线与数据时间 | 展示可能过期的健康字段 |
| 未授权 | 显示"未获授权"，不暴露字段是否存在 | 显示空值或猜测值 |
| 会话失效 | 引导重新登录并保留回跳 | 静默失败或停留在旧数据 |
| 能力不可用 | 禁用入口并说明原因 | 保留入口但点击报错 |
| 低置信 | 明确标注需人工复核 | 显示为已确认或给出置信度分值 |
| 降级 | 说明当前处于降级模式与可用范围 | 用降级结果冒充完整结果 |
| 处理中 | 展示任务状态与可返回入口 | 阻塞用户直到完成 |

### 7.3 文案与交互规则

- 所有等级与状态同时使用文字、图标与颜色表达；高对比与减少动效下语义不丢失。
- 动作文案统一为"确认已服用""稍后提醒""本次跳过"，不使用"停药""改剂量""换药"等表述。
- 医疗相关页面显示教学演示边界；危险请求引导联系现有医生、药师或当地急救服务。
- 错误文案给出原因与下一步动作，并附可用于定位的请求标识，不出现原始错误码堆栈。
- 触控目标不小于 60px；主要流程在特大字号下仍可单手完成。
- 页面切换时停止上一页语音播报，并把读屏焦点移动到新页面主区域。
- 二次确认用于拨号、清理缓存、切换数据源与跳转外部页面等不可逆或跨边界动作。

## 8 性能需求

| 指标 | 移动端目标 | 测量约束 |
|---|---|---|
| 今日页首屏可用 | 演示与联机模式下可感知完成 | 加载态与空态明确，不闪现旧家庭缓存 |
| 任务写回反馈 | Toast 与触觉及时反馈 | 成功、失败与重试状态准确可区分 |
| 页面切换 | Hash 路由即时切换 | 切换时停止语音播报，避免串台 |
| 助手首字与阶段状态 | 流式阶段状态可见 | 中断与停止时不保留半截回答 |
| 列表弱网表现 | 骨架屏与重试文案稳定 | 六类弱网场景逐项记录 |
| 产物体积 | 不超过预算配置阈值 | 由预算脚本判定，超限即失败 |
| 低端设备模拟 | CPU 降频与慢速网络下核心流程可用 | 报告硬件、参数与场景标识 |
| 长驻资源 | 轮询、动画与语音在页面离开时释放 | 无残留定时器与未停止的播报 |
| 动效流畅度 | 数字滚动、进度环与彩带流畅 | 减少动效开关可全停 |
| APK 体积与启动 | 可安装、可启动 | debug 构建即可满足演示 |

数据库、后端 API 与并发预算由主仓库资源原型与阶段验收冻结；移动端不单独承诺毫秒级指标，没有测量证据时不写具体毫秒数值。所有性能结论必须附执行环境、样本量与冷热状态。

## 9 可靠性需求

| 故障或风险 | 要求行为 | 禁止行为 | 验收重点 |

| 重复写请求 | 幂等键防重复，返回原结果或明确冲突 | 重复创建健康事件 | 确认、延期、跳过重复点击回归 |
| 网络失败 | 明确错误提示与可重试，保留用户输入 | 伪装成功或闪现旧缓存 | 弱网与断网场景 |
| 服务不可达 | 联机入口显示服务不可用，演示模式不受影响 | 把未提供接口包装成可用 | 依赖故障场景 |
| 能力缺失 | 禁用对应入口并说明原因 | 保留入口点击后报错 | 能力探测回归 |
| 会话过期 | 引导重新登录并清理本地家庭数据 | 继续以旧会话展示数据 | 过期与登出场景 |
| 授权变化 | 立即拒绝并清理本地旧数据 | 继续展示旧家庭数据 | 撤权与过期场景 |
| 多家庭切换 | 清空上一家庭列表、详情、草稿与轮询 | 两个家庭数据同屏或残留 | 切换隔离回归 |
| 视觉能力离线 | 保留任务并允许手工录入 | 返回伪造候选或置信度 | 依赖故障场景 |
| 助手模型离线 | 展示结构化事实、规则与任务卡 | 让模型凭常识补答或转云端 | 模型不可用场景 |
| 语音不可用 | 静默降级为文字输入并给引导 | 阻塞核心操作或报错 | 无中文 TTS 与权限拒绝场景 |
| 震动不支持 | 静默降级 | 报错或反复请求 | 不支持震动设备 |
| 通知受限 | 应用内保留提醒清单并说明限制 | 假装提醒已送达 | 省电策略与权限拒绝场景 |
| 外壳缓存丢失 | 离线时显示安全回退提示 | 显示旧健康数据 | 缓存清理与恢复场景 |
| 天气失败 | 不生成新行动卡且不影响核心链 | 重复生成或上传健康详情 | 超时与无数据场景 |
| 构建或审计失败 | 阻断发布结论并记录原因 | 以 mock 成功或代码存在替代验证 | 门禁裁决回归 |

## 10 安全与隐私需求

| 控制域 | 要求 |
|---|---|
| 数据出端 | 健康数据、图片、音频、对话与提醒内容默认不出端；出网只允许白名单适配器与用户显式勾选的受控联网搜索，且请求内容脱敏 |
| 传输与地址 | 联机地址执行安全校验；明文 HTTP 仅允许家庭局域网地址，公网必须 HTTPS；地址不合规时禁止联机 |
| 身份与会话 | 不在本机存储明文凭据；会话令牌短期有效并支持刷新与登出；过期、登出与撤权时清理本地家庭数据；刷脸为可选且 fail-closed |
| 对象授权 | 所有成员资源以服务端返回的授权范围为准；前端隐藏不构成授权；未授权字段不暴露存在性 |
| 上传 | 校验类型、大小、像素与时长；短视频抽帧在本机完成；上传失败不残留可被复用的临时凭据 |
| 通知 | 只用本地通知；私密通道下锁屏与通知栏不展示药品名与成员姓名 |
| 语音与音频 | 麦克风需显式启动；音频只在本机处理，不上传、不落盘、不用于训练 |
| 本机存储 | 只存偏好、草稿与外壳缓存；健康数据不写入持久缓存；提供可见的清理入口与结果 |
| 日志与审计 | 只记录路径、方法、状态、耗时、请求标识与错误码；不记录健康正文、令牌、Cookie、提示词上下文与真实设备标识 |
| 第三方依赖 | 不接入第三方推送、分析与崩溃上报；依赖版本固定并纳入构建审计 |
| 系统能力 | 收紧系统自动备份与调试通道；权限按最小必要声明并在使用前请求 |
| 仓库卫生 | 真实健康数据、密钥、签名材料、模型权重、构建产物与 `local.properties` 不入库；隐私扫描作为构建门禁 |
| 事件响应 | 发现泄露、越权或危险回答时隔离入口或版本、保全最小审计、评估影响、回滚、修复并回归 |

## 11 可用性与可访问性需求

- 演示模式在完全离线、无服务端、无模型的条件下仍可完整体验核心流程，用于教学与交互验收。
- 正常、加载、弱网、空、错误、离线、未授权、会话失效、能力不可用、低置信、降级与处理中状态具有稳定尺寸与明确文案，不闪现其他家庭缓存。
- 风险、证据、确认与拒答不只依赖颜色；键盘与读屏可完成主要流程；交互控件有可读名称与焦点状态。
- 长辈模式下底部导航简化为今日、拍药盒、求助、我的四项，触控目标不小于 60px。
- 320px 宽度与特大字号组合下不出现截断、重叠与横向滚动；横屏与折叠屏展开态布局可用。
- 敏感字段被隐藏时只显示"未获授权"，不泄露该字段是否存在；错误响应提供请求标识与可执行重试动作。
- 所有医疗相关页面显示教学演示边界；危险请求引导联系现有医生、药师或当地急救服务。
- 语音、震动、通知、相机与网络任一能力不可用时静默降级并给引导，不阻塞核心操作。

### 12.4 模块职责与实现约束

需求实现必须落在既有分层内，不允许在视图层直接拼装请求或在组件内硬编码权限判断。

| 模块 | 职责 | 约束 |
|---|---|---|
| `src/api/` | 统一请求客户端、错误映射、鉴权头与请求日志摘要 | 所有网络请求经此出口；错误码统一映射；日志只记脱敏摘要 |
| `src/data/` | DataProvider 抽象与演示、HTTP 两套实现，以及标签与类型定义 | 视图层只依赖抽象接口；演示实现不得发起任何请求 |
| `src/stores/` | 会话、鉴权、无障碍、隐私、能力探测、本机数据与 PWA 状态 | 状态变更集中在此；权限相关状态以服务端返回为准 |
| `src/composables/` | 语音播报、语音输入、提示、视觉任务轮询、下拉刷新、数字滚动 | 长驻资源必须在卸载时释放；语音在路由切换时停止 |
| `src/notifications/` | 本地提醒调度、服务封装与平台适配 | 只用本地通知；渠道配置遵循私密通道策略 |
| `src/utils/` | 地址校验、上传与抽帧、电话与求助、触觉、助手回复与证据、资讯与联网搜索、引导步骤、无障碍辅助 | 纯函数优先并配单元测试；不在此层发起请求 |
| `src/components/` | 公共状态与展示组件 | 状态表达统一由公共组件承担，不在页面内重复实现 |
| `src/views/` | 页面编排与用户交互 | 只编排数据与组件，不实现权限判定与业务规则 |
| `src/router/` | 路由表、鉴权守卫与读屏焦点处理 | 守卫只在联机且正式鉴权模式下生效 |
| `src/buildInfo.ts` | 版本与提交标识注入 | 构建时注入，运行时只读，供"我的"页与错误定位使用 |
| `APP/scripts/` | 审计、预算、隐私扫描、证据校验与发布清单脚本 | 脚本输出作为门禁证据，不可手工编写或修改 |
| `APP/android/` | Capacitor Android 工程 | `local.properties`、产物与签名材料不入库 |

### 13.3 状态口径

状态只允许使用未开始、进行中、待验收、已验证、阻塞、不做六种取值。状态变化必须同时具备：需求编号、Issue 或 Story、提交或 PR、自动化测试结果、人工验收记录、环境与版本标识，以及必要的真机、部署或回滚证据。CI 通过、Issue 关闭、mock 成功或静态代码存在都不单独构成"已验证"。证据缺失时一律写"待验收"或"阻塞"，不得写"已完成"。

### 13.4 测试策略与用例分层

| 层次 | 覆盖对象 | 手段 | 通过条件 |
|---|---|---|---|
| 类型检查 | 全部 TypeScript 源码与组件模板 | `vue-tsc` | 零类型错误，不使用抑制注释绕过 |
| 单元测试 | 工具函数、Provider、Store、Composable、通知调度 | `vitest` + `happy-dom` | 关键分支（成功、失败、权限不足、降级）均有用例 |
| 契约与错误映射 | 请求客户端与错误码映射 | 单元测试 + 联机联调记录 | 401/403/404/409/422、超时与网络失败均有确定文案 |
| 状态矩阵 | 页面十二类状态 | 组件测试 + 人工走查 | 每个适用状态有稳定尺寸与明确文案 |
| 无障碍 | 长辈模式、字号、高对比、减少动效、读屏 | 响应式审计脚本 + 真机 TalkBack | 320px 特大字号不截断，触控目标达标，播报正确 |
| 弱网与降级 | 列表、助手、语音、通知、天气 | 弱网夹具 + 断网真机 | 六类弱网场景与各依赖失效路径均有记录 |
| 隐私 | 日志、缓存、出网、上传 | 隐私扫描脚本 + 请求内容核对 | 无健康正文、令牌与真实设备标识外泄 |
| 性能 | 产物体积与低端设备表现 | 预算脚本与低端模拟 | 无超限项，资源无残留 |
| 端到端与演示 | 核心闭环与连续演示 | 演示前置检查 + 连续演示脚本 | 一次跑通且异常态可解释 |
| 发布门禁 | 运行时矩阵全部项 | 证据台账 + 维护者复核 | 全部已验证且回滚演练完成 |

用例设计遵循三条原则：一是每条需求至少有一个"正常路径"与一个"被拒绝或降级路径"用例；二是涉及写操作的需求必须包含重复提交与冲突用例；三是涉及权限的需求必须包含撤权、过期与跨家庭用例。仅覆盖正常路径的用例集不构成验收通过。

## 14 发布门禁与波次计划

### 14.1 两条独立发布结论

| 结论 | 可声明范围 | 前置条件 |
|---|---|---|
| `RUNTIME_RELEASE` | 移动端 PWA 与 APK 可在受控运行时使用；视觉入口只消费获权、可追溯结果 | 运行时矩阵全部项为已验证，且回滚演练完成 |
| `FULL_VISION_PRODUCTION` | 可声明生产视觉闭环 | `RUNTIME_RELEASE` 已通过，且主仓库固定集、模型与后端隐私门禁均通过 |

任一项缺证据、依赖未满足或记录不一致时，结论必须写为 `BLOCKED`。仅用于课堂或受控演示时可标 `DEMO_ONLY`，不得表述为家庭生产可用或生产视觉闭环。视觉能力受限时必须同时满足：视觉结论写 `BLOCKED`、运行时结论写 `DEMO_ONLY` 或禁用视觉入口、界面说明视觉能力受限并保留安全网页复核交接、不伪造识别结果。

## 15 风险与依赖

| 编号 | 风险或依赖 | 影响 | 缓解措施 |
|---|---|---|---|
| RM-01 | 厂商 ROM 省电与自启限制导致本地通知静默丢失 | 用药提醒场景的安全问题 | 真机矩阵逐项记录、应用内权限指引、保留应用内提醒清单、明示已知限制 |
| RM-02 | 服务端接口或能力尚未提供（如已知晓回写） | 界面可能出现伪装成功 | 能力探测禁用入口、界面如实提示、不包装为可用 |
| RM-03 | 真机与设备持有人时间受限 | 真机签收滞后，发布结论卡在待验收 | 提前冻结矩阵模板与脚本、拆分为可分批签收的最小项 |
| RM-04 | 中文路径与 ADB 兼容问题影响构建与调试 | 构建不可复现 | 依赖路径检查开关、在运行手册记录已知限制与替代步骤 |
| RM-05 | 本地模型或检索不可用 | 助手无法回答 | 结构化事实与规则卡降级、明确不可用原因、禁止云端回退 |
| RM-06 | 弱网夹具被误当作生产后端 | 验收结论失真 | 夹具只用合成数据与内存、文档明确其非生产用途、不替代真机签收 |
| RM-07 | 视觉固定集与模型验收未通过 | 无法声明生产视觉闭环 | 视觉结论独立裁决、运行时结论按 `DEMO_ONLY` 处理、禁用或降级视觉入口 |
| RM-08 | 需求与实现口径漂移 | 文档与代码不一致 | 每次迭代回填追踪矩阵、状态只用六种取值、证据缺失即写待验收 |
