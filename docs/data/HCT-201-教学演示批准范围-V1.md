# HCT-201 教学演示批准范围 V1

> 生效日期：2026-08-24
> 批准人：项目负责人 Meyt1n
> 用途：HomeCare Twin 内部教学和本地 Demo
> 本文件是范围豁免记录，不是正式医疗数据发布证明。

## 1. 批准决定

项目负责人明确批准当前 HCT-201 候选用于**内部教学演示和本地实验训练**，并关闭本教学范围内的以下门禁：

- 作者授权证据的单独复核；
- 真实实体/采集会话分组复核；
- conflict 双证据要求；
- 删除传播记录；
- R3 复核。

机器可读的范围表达为：

```text
approval_status: APPROVED
approval_scope: INTERNAL_TEACHING_DEMO
formal_release_eligible: false
production_eligible: false
family_health_fact_eligible: false
```

这里的 `APPROVED` 只表示“项目负责人批准在内部教学范围使用”，不表示上述证据已经存在，也不表示通过正式 `approved_real_fixed_set` 门禁。

## 2. 允许使用的内容

- [固定药品集候选清单](HCT-201-固定药品集候选清单-20260824.md)中的 20 个 OCR 药品候选；
- 清单中的 2 个非纸盒 unknown 候选；
- 本地 YOLO/OCR/条码/字段结构化的演示训练和离线评估；
- 课堂中的数据血缘、候选融合、unknown 降级和人工确认流程演示。

冲突样本在本范围内不是必需项，因此当前 conflict 数量保持为 0；课堂展示冲突流程时必须使用明确标记的合成示例，不得把未知结果伪装成真实冲突。

## 3. 明确禁止

即使在教学批准范围内，也不得：

- 将模型或数据集发布到公开仓库、模型平台或第三方服务；
- 把候选识别结果写入家庭健康事实、用药计划、风险结论或正式报告；
- 对外宣称药品识别准确率、临床安全性或授权完整性；
- 将原始图像、权重、缓存、OCR 日志或个人信息提交到 Git、Issue、PR、Review Bot 或云端；
- 把本范围的 manifest 传给正式发布流程，或用它解除 HCT-202/HCT-203 的正式训练门禁。

前端和演示文案必须继续显示：`教学演示数据；识别结果仅为候选，需人工确认；不构成医疗建议。`

## 4. 与正式门禁的关系

正式门禁脚本继续保持 fail-closed：

- `scripts/hct201_formal_gate.py` 不因本豁免而通过；
- `scripts/hct201_fixed_set_gate.py` 不因本豁免而通过；
- HCT-201 正式状态仍为 `UNRELEASED`；
- 本文件只允许教学 Demo 使用，不改变正式训练、发布和生产状态。

## 5. 回滚

负责人可以撤销本范围批准。撤销后应立即：

1. 停止本地演示训练和推理服务；
2. 隔离或删除本范围产生的可控派生文件、缓存和导出物；
3. 将教学范围标记为 `REVOKED`；
4. 保留最小审计信息，不保留健康正文或个人信息。
