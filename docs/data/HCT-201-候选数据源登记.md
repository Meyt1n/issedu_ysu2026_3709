# HCT-201 候选数据源登记

> 登记日期：2026-08-08。本文只登记公开页面上的元信息和尽调结论，不下载、不提交任何图片、视频、药品标签正文或原始数据。
>
> `CANDIDATE` 不等于 `APPROVED`。任何候选必须完成下载来源固定、许可/隐私复核、脱敏、重复/泄漏检查和重新分组后，才能进入 `HCT-201-dataset-v1`。

## 1. 选择结论

当前首选候选是 **Mobile-Captured Drug Packs V3**：它最贴近家庭拍摄场景，页面明确给出 2,000 张药品包装图片、166 个包装、7 种设备、不同角度/光照和 CC BY 4.0。2026-08-08 通过 Mendeley 公开文件接口核验时，接口仅返回 1,000 个已完成 JPEG，累计 2,516,213,314 bytes，文件 SHA-256 无重复；这与页面的 2,000 张描述不一致，已记录为 `BLOCKED_COUNT_MISMATCH`，不能把该候选标为 `APPROVED`。它没有直接提供本项目所需的 YOLO 包装/字段区域或 OCR-first 字段契约，因此只作为图像来源候选，必须由本项目按 `annotation-spec-v1` 重新标注；包含手写内容的样本必须先做 PII 检查并可能隔离。

[AI-Hub 药品、化妆品包装 OCR 数据](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=633)可作为 OCR 预训练/对照候选：页面标注 50,000 对包装图像、4 点多边形/边界框 JSON，并说明覆盖产品名、剂量、有效期等包装信息。但页面要求申请和授权，且注明仅限韩国境内申请者，不能在许可确认前纳入 `APPROVED` 集合。

## 3. 许可证与隐私判断

CC BY 4.0 允许复制、改编和再分发，但要求署名、提供许可证链接并说明修改；Creative Commons 同时明确，许可证不一定覆盖隐私权、公开权或精神权利。因此即使页面显示 CC BY 4.0，也必须继续做：

- 下载时保存版本页、DOI/URL、下载时间、文件哈希和页面许可证快照；
- 检查手写、标签、背景、文件名和 EXIF 是否含姓名、联系方式、地址、处方号或其他个人信息；
- 对不能确认已脱敏或授权训练的样本标为 `QUARANTINED`，不进入训练、验证、测试或固定评估集；
- 保留来源署名和修改声明，不把源数据再上传 GitHub、Issue、PR、Relay Review Bot 或日志；
- 记录源数据删除/撤销机制。若源方无法支持撤销传播，只能作为隔离的研究参考，不进入可发布版本。

## 4. HCT-201 接纳门禁

候选只有同时满足下列条件，才能把 manifest 记录标为 `APPROVED`：

1. 页面许可证、版本和署名要求被保存，且没有额外禁止训练或再分发条款；
2. 下载制品哈希可复现，源文件和派生文件的关系可追踪；
3. PII/手写/EXIF/背景检查通过，不能确认的样本已隔离；
4. 按实体、包装对象、日期、设备和会话重新分组，近重复和相邻帧不跨集合；
5. 按 `HCT-201-标注规范-V1.md` 完成包装和关键区域标注，争议样本有第二人抽检；
6. 固定评估集、未知/非目标集、类别分布、偏差和删除传播证据齐全；
7. 项目负责人提交，R3 复核人确认，之后才允许 HCT-202/HCT-203 读取该版本。

- 若公开来源无法在交付窗口内完成核实，按[受控采集与授权登记模板](HCT-201-受控采集与授权登记模板.md)登记经明确授权的自采包装或明确标记的合成样本；这不是绕过许可门禁；
- 使用 `uv run python scripts/hct201_mendeley_inventory.py --output <可信域外报告路径>` 重新生成元数据报告；该脚本不保存签名下载 URL；
- 对 `SRC-ROBOFLOW-BLISTER-YEER-V1` 先核对总览/版本页数量差异，保存导出版本、下载时间、文件哈希和逐图来源；仅在许可、PII、重复、分组和人工抽检通过后，作为 `unknown` hard-negative 候选使用；
- `SRC-OPENIMAGES-V6-VALIDATION` 已取消，不再安排逐图复核或纳入后续版本；外部候选保持隔离，待按删除流程另行处置；
- 差异关闭后，才可从 Mendeley V3 页面下载到家庭可信域之外的隔离训练盘，仅保存元信息和哈希到项目登记；
- 不把下载文件放进仓库 `data/`、`models/`、`uploads/` 或 `artifacts/`，也不运行未经审计的图片到训练流程；
- 先抽样检查手写/EXIF/隐私，再决定是否进入 12–20 个 P0 包装范围；
- 若许可、隐私或标注成本不满足，立即将该候选标为 `QUARANTINED`，转为合成包装 + 明确同意自采的小规模数据，不降低安全门禁。

## 6. 元数据审计复现

```powershell
uv run python scripts/hct201_mendeley_inventory.py `
  --dataset-id bsmy5jjysy `
  --version 3 `
  --page-description-count 2000 `
  --output <可信域外报告路径>
```

脚本只请求官方公开文件接口并记录文件名、文件 ID、媒体类型、字节数、状态和 SHA-256；不会读取或保存媒体内容，也不会把短期签名 URL 写入报告。报告中的 `BLOCKED_COUNT_MISMATCH` 是当前 R3 阻断项，不能由本项目自行“按 1,000 张通过”。
