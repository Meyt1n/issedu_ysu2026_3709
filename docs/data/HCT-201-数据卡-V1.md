## 2. 预期用途

- 为 OpenCV 质量门控、OCR-first 字段管线和 YOLO11n 包装/条码区域辅助检测基线提供受控输入；
- 仅覆盖 P0 冻结的 12–20 个包装/非目标类别，不把 SKU 类别当成药品身份；
- 支持固定评估集、未知/非目标集和困难属性分析。

## 3. 禁止用途

- 不用于诊断、处方、停药、换药、剂量判断或临床性能声明；
- 不用于识别任意药品，不绕过 OCR、条码、包装特征、本地主数据和人工确认；YOLO 不作为整盒药品分类器或字段真值来源；
- 不把未经许可、未脱敏、未取得独立训练同意的样本用于训练或评测；
- 不上传云端，不提交公开仓库，不写入日志、截图、PR 或 Review Bot 请求。

## 4. 数据来源与许可门禁

每条 manifest 记录必须具有 `source_id`、`license`、`consent_status`、`deidentified`、`delete_ref` 和 `retention_until`。只接受：

1. 明确允许本项目用途的公开许可资料；
2. 有独立、可撤销训练同意的自采包装资料；
3. 不含真实个人信息的合成或非目标资料。

许可证、用途、训练同意、脱敏或删除责任任何一项缺失时，样本状态只能是 `QUARANTINED`，不得进入 `APPROVED` 集合。

## 5. 标注与划分

- 包装/条码区域、OCR 文本框、字段角色和困难属性以[标注规范](HCT-201-标注规范-V1.md)及[OCR 字段提取契约](HCT-201-OCR字段提取契约-V1.md)为准；
- train/validation/test/unknown 按 `group_key` 分组，实体、采集会话和相邻视频帧不得跨集合；
- `fixed_eval=true` 只能出现在 test/unknown，并在冻结后记录数量、分布和 manifest SHA-256；
- unknown 集保存拒识/非目标能力的证据，不得因为指标不理想而替换；
- 近重复样本按 `perceptual_hash` 审计，疑似重复必须隔离或记录处理决定。

## 6. 隐私与删除

采集前去除姓名、联系方式、地址、处方号、病历号、屏幕通知和可识别背景。删除/撤销必须传播到原始文件、manifest、派生裁剪、缓存、困难样本入口和可控备份；审计只保留样本 ID、版本、动作、时间和结果，不保留健康正文。

## 7. 偏差与已知缺口

在冻结前必须如实补齐：类别/包装面分布、拍摄设备、光照、反光、遮挡、模糊、背景、未知集比例、授权来源比例和标注抽检结果。当前不能据此宣称模型泛化到未覆盖 SKU、设备、地域或真实临床场景。

## 8. 质量门禁与证据

```powershell
uv run python scripts/hct201_dataset_audit.py --manifest <脱敏或合成 manifest> --strict

```

批准前必须归档许可完整性、PII/敏感字段扫描、精确/近重复、分组泄漏、类别/属性统计、固定集/未知集哈希和删除演练报告。任何 R3 阻断项未关闭时，数据状态保持 `UNRELEASED`。

## 9. 回滚

将数据集版本标记为 `REVOKED`，撤销训练入口，隔离/删除受影响派生制品，恢复上一批准 manifest；不得覆盖旧版本清单、哈希或报告。
