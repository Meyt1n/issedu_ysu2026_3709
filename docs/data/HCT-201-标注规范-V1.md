# HCT-201 标注规范 V1

> 仅定义包装/区域检测和数据治理边界，不标注药品诊断结论，也不把检测类别当作 SKU 身份。

## 1. 类别

P0 YOLO 辅助类别：

`medicine_box`、`medicine_bottle`、`blister_pack`、`barcode_region`、`health_report`、`metric_table`、`medical_advice_region`。

OCR 主链路另外记录文本框/多边形及原始转写，并可给文字框增加字段角色：`drug_name`、`specification`、`manufacturer`、`batch_number`、`expiry_date`。这些字段角色不是必须训练成 YOLO 类别。`drug_name_region`、`spec_region`、`expiry_region` 只能作为可选辅助预标注，不能替代 OCR 文本证据。

非目标/未知样本使用 `unknown_or_non_target` 登记，不强行归入已知类别。

## 2. 记录字段

每个样本/标注需要关联：`sample_id`、`annotation_version`、类别、包装面、来源裁剪/帧时间戳、遮挡、反光、模糊、目标占比、标注人、复核状态和争议说明。原图引用只能使用受控对象 ID，不记录本机绝对路径或个人信息。

## 3. 边界规则

- 框覆盖可见包装/字段区域，不根据文字内容推测框外区域；
- 多盒/多瓶分别标注，重叠时保留可见部分并记录遮挡；
- 反光、模糊或裁切导致边界无法确认时标记困难属性，不伪造精确框；
- 药名、规格、厂家、批号和有效期记录 OCR 文本区域及原始转写；条码区域只记录视觉位置，实际码值由专用解码器产生；任何区域或文本都不得推断真实药品身份；
- 报告/医嘱只标注界面区域，禁止把其内容复制到标注说明。

## 4. 抽检与争议

首轮标注完成后按类别、包装面和困难属性分层抽检；争议样本进入 `REVIEW`，由第二位复核人决定保留、修正或隔离。不得删除失败样本以改善指标；保留失败类型和处理原因。

## 5. 版本与回滚

标注规范变更必须递增版本并重跑受影响集合审计。训练登记必须绑定代码 SHA、数据版本、标注版本、划分版本和 manifest 哈希；回滚时恢复上一批准组合，不覆盖历史标注。
