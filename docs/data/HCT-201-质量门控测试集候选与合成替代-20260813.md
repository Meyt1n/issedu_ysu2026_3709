# HCT-201 质量门控测试集候选与合成替代（2026-08-13）

> 背景：`HCT-201-dataset-v1.2` 的 147 张候选 test 图全部为摄影棚白底拍摄，在家庭场景质量门控阈值（`opencv-quality-demo-v1`）下 100% 触发 `GLARE`（58 张另触发 `TOO_BRIGHT`），无法用于门控下游链路（适配器、字段抽取、融合）的联调与演示。本文登记替代来源的尽调结论与当前可用的合成替代集。
>
> 本文只登记元信息与尽调结论；除合成集外不下载、不提交任何图片。`CANDIDATE` 不等于 `APPROVED`；任何外部候选进入正式评估集前仍须完成 [候选数据源登记](HCT-201-候选数据源登记.md) 第 4 节的全部接纳门禁。

## 3. 建议顺序

1. 立即：合成集 v1 承担门控回归与适配器联调（已可用）。
2. 短期：负责人浏览器手动下载 `SRC-MENDELEY-BJY2SVVMN8-1` 整包至隔离目录，运行解包核数 + 门控通过率抽测 + 手写 PII 复核；通过后按接纳门禁申请 `APPROVED` 评估子集。
3. 并行：真实家庭自采样本按[受控采集与授权登记模板](HCT-201-受控采集与授权登记模板.md)补充，这仍是最贴近产品的评估来源。
4. 门控阈值本身的校准（`GLARE`/`TOO_BRIGHT` 对白底的敏感性）应在获得批准的真实家庭样本后再议，不为迁就棚拍数据放宽家庭场景阈值。
