## 数据来源与证据

- 标签媒体来自 [DailyMed SPL Web Services](https://dailymed.nlm.nih.gov/dailymed/app-support-web-services.cfm) 的固定 `setid` 和 `media` 版本；每个文件保存 URL、发布日期和 SHA-256。
- 产品和包装元数据来自 [openFDA NDC API](https://open.fda.gov/apis/drug/ndc/)；openFDA 的数据许可/免责声明见 [openFDA license](https://open.fda.gov/license/)。
- DailyMed/NLM 的版权政策要求使用者自行确认非政府贡献内容的权利；因此审批记录将原始媒体限定为本机内部使用，禁止把图片、OCR 原文、条码和缓存提交仓库或第三方服务。

## 实际识别结果摘要

本次运行使用本机 Tesseract 5.3.4 和 OpenCV `BarcodeDetector`。报告记录了原始 OCR/条码的引用和哈希，失败样本只输出字段名、状态、置信度和证据引用。

当前报告指标为：

- overall field accuracy：`0.6250`；
- barcode field accuracy：`0.8889`；
- drug name field accuracy：`0.6923`；
- manufacturer/specification field accuracy：`0.5000`；
- status accuracy：`0.7674`；
- failure count：`25`。

因此保持 `BLOCK_OCR_BARCODE_MASTER_DATA`，不能把真实结果改写成通过。下一轮应使用授权的包装实拍、人工复核和固定阈值重新采集，而不是调低门槛或手工修正 OCR。
