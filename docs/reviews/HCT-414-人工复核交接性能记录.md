## 目的与边界

本记录验证视觉任务完成后，证据提交能否通过真实 FastAPI 路由创建成员范围内的唯一人工复核任务，随后融合路由能否复用该任务并补齐融合上下文。验证同时检查：

1. 每个视觉任务只产生一条 `ReviewTask`；
2. 证据提交与融合返回的复核任务标识保持一致，版本仍连续；
3. 复核尚未由人确认时，不写入 `HealthEvent`；
4. 延迟、进程 RSS 和夹具哈希可被再次核对。

探针使用真实 API 路由和 SQLAlchemy ORM，但数据库是进程内临时 SQLite，视频、主数据和 OCR/条码证据全部为合成夹具。它不代表生产 MySQL、队列、网络、多主机 worker 或真实 OCR 推理的容量，也不提供 HCT-201 固定集准确率结论。

## 测量方法

```text
uv run python scripts/hct414_review_handoff_perf.py --samples 10 --warmup 1
uv run pytest tests/unit/test_hct414_review_handoff_perf.py
uv run ruff check scripts/hct414_review_handoff_perf.py tests/unit/test_hct414_review_handoff_perf.py
```

每个样本先通过 `/vision-quality/check` 和 `/vision-tasks` 建立视频任务，再依次调用：

- `POST /api/v1/vision-tasks/{task_id}/evidence`：校验适配器回执、保存证据、完成视觉任务，并创建占位复核任务；
- `POST /api/v1/vision-tasks/{task_id}/fusion`：复用同一复核行，写入候选、融合状态和版本上下文，不重复创建任务。

预热样本不计入延迟统计，但计入数据库一致性断言。探针输入有界，夹具在临时目录中生成并在进程结束时删除。

## 结果（2026-08-28）

使用 `--samples 10 --warmup 1` 生成了 `artifacts/hct414-review-handoff-perf.json`；报告中的 `commit_sha`、机器和夹具哈希可用于复核本次运行。验收结果如下：

| 阶段 | 接口 | 指标 |
|---|---|---|
| 证据交接 | `POST .../evidence` | 10 个样本；P50 **8.904 ms**，P95 **9.246 ms**，Max **9.246 ms** |
| 融合复核交接 | `POST .../fusion` | 10 个样本；P50 **6.690 ms**，P95 **33.593 ms**，Max **33.593 ms** |
| 数据库一致性 | SQLite `ReviewTask` | 预热 1 + 样本 10 = **11** 行，全部 `PENDING_REVIEW`，版本均为 **1** |
| 幂等重放 | 重复调用 `POST .../fusion` | **11/11** 次返回同一 `review_task_id` |
| 副作用保护 | SQLite `HealthEvent` | 人工确认前 **0** 条 |

最差交接 P95 为 **33.593 ms**，在 **2000 ms** 预算内；报告还固定声明 `synthetic-only`、`fixtures_persisted=false` 和 `DEMO_ONLY`，避免把合成证据或临时 SQLite 结果写成生产发布结论。

## Given / When / Then

- Given 一个带有效质量凭证和适配器回执的视频任务；When 提交证据；Then 任务完成并创建一条 `PENDING_REVIEW` 复核任务。
- Given 已由证据路由创建复核任务；When 再调用融合路由；Then 返回相同 `review_task_id`，填充融合上下文，不新增第二条复核任务。
- Given 复核任务尚未确认；When 查询临时数据库；Then `HealthEvent` 数量为 0，复核版本仍为初始版本 `1`。
- Given 样本数或预热数越界；When 启动探针；Then 立即拒绝参数，不创建无限负载。

## 未覆盖与发布阻断

- **OCR 推理未覆盖**：探针注入合成 OCR token；缺少 `paddleocr` 时不得把降级路径写成 OCR P95。
- **人工确认后的写入未覆盖**：本记录只验证确认前的安全边界；确认、修正、跳过及健康事件审计仍需独立回归。
- **生产容量未覆盖**：临时 SQLite 不等价于 MySQL、连接池、队列、网络或多主机 worker。
- **HCT-201 未完成**：授权固定集、正式模型/主数据发布门禁仍是发布前置。
- **Android 真机链路未完成**：真实文件选择器 MIME、端到端上传、HEVC 样本过服务端抽帧仍需真机证据。

因此本记录只把 #246 的“人工复核交接 API + DB 性能”推进为可复核的合成验证，不关闭父 Issue，也不改变 `DEMO_ONLY`。
