## 复核范围

本记录完成的是 HCT-206 的**技术校准闭环**：冻结一个仓库内可复跑的验证集和独立测试集，扫描版本化阈值，输出接受率、误匹配率、拒识率、覆盖率和样本哈希，并保存人工检查结论。

输入夹具为 `tests/fixtures/hct206/calibration_fixture.json`，明确标记为 `synthetic`、`APPROVED_FOR_TECHNICAL_CALIBRATION` 和 `production_eligible=false`。它不包含真实药品、成员、图片或健康数据，不能被解释为生产识别准确率。

HCT-201 的真实授权固定验证集、独立测试集和 unknown 集仍是生产发布门禁；在这些数据获批前，FR-03 不得标记为整体已验证，家庭端也不得据此自动创建健康事件。

## 可复现命令与结果

环境：Windows PowerShell；Python/依赖由仓库 `uv.lock` 锁定。

```powershell
uv run python scripts/hct206_calibrate.py
uv run pytest tests/unit/test_hct206_calibration_fixture.py tests/unit/test_hct206_candidate_fusion.py -q
```

命令输出中的 `report` 包含：

- `schema_version=fusion-calibration-report-v1`；
- `thresholds.config_version=fusion-thresholds-calibrated-v1`；
- validation 7 条、independent_test 6 条，两个 split 的 sample ID 不重叠；
- validation/independent_test 的 `false_match_rate=0`；
- `sample_sha256` 用规范化样本内容计算，可用于复核输入未被替换；
- 所有 `MATCHED` 结果仍带 `requires_human_confirmation=true` 和 `health_event_allowed=false`。

## 人工复核清单

- [x] 每条样本都有明确的四状态期望标签和可追溯的 sample ID。
- [x] `CONFLICT`、`UNKNOWN`、低置信度/低间隔样本不会被阈值扫描误接收为 `MATCHED`。
- [x] validation 与 independent_test 完全分离，脚本拒绝重复 ID 或缺失 split。
- [x] 校准过程无网络、无外部数据、无健康事件写入路径。
- [x] 夹具明确为合成技术数据；没有把合成结果写成生产药品准确率。
- [x] 生产固定集和发布授权仍由 HCT-201 gate 管理，不因本技术验收而解除。

## 结论与回滚

HCT-206 技术验收证据完整：四状态安全规则、版本化阈值扫描、独立 split 评估、确定性哈希和人工复核记录均可复跑。
2026-08-24 维护者确认 HCT-201/HCT-205 真实批准前置已完成；本次不要求将真实报告或数据复制入仓库，报告仍作为外部审计材料保留。

若需要回滚，删除 `scripts/hct206_calibrate.py`、`tests/fixtures/hct206/` 和本评审记录，并恢复 Story 中的技术校准证据链接；候选融合 API 继续按现有规则降级到 `REVIEW`/`UNKNOWN`，不得绕过人工确认。

## 2026-08-24 生产门禁编排补充

新增 `scripts/hct206_release_gate.py` 作为 HCT-206 的生产评审入口。它必须同时读取：

- HCT-201 `ALLOW_APPROVED_FIXED_SET` 报告，且范围为 `approved_real_fixed_set`，包含 12–20 个批准药品以及 unknown/conflict 集；
- HCT-205 `ACCEPT_OCR_BARCODE_MASTER_DATA` 报告，且范围为 `approved_real_fixed_set`、指标达到该报告自己的阈值；
- HCT-206 生产校准报告，显式声明 `production_eligible=true`、`APPROVED_FOR_PRODUCTION_CALIBRATION`，并包含非空 validation/independent_test split、版本化阈值、样本哈希、来源引用、人工复核人/日期，以及与 HCT-201 manifest 和 HCT-205 输入结果一致的 `evidence_bindings` 哈希。

任一输入缺失、决策未通过、范围为 synthetic/mixed、哈希或 split 不完整，均输出
`BLOCK_CANDIDATE_FUSION`。门禁不会调整运行时阈值、发布模型或写入健康事件；所有 `MATCHED` 仍需人工确认。
当前工作区不保存真实报告，新增单测使用的仅是无健康数据的元数据字典；这不撤销既有外部门禁，外部审计时仍可提供已批准报告。
