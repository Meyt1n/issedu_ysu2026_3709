## 验收范围

本 Story 收口的是 React 教学演示页面，不是生产 API、认证、权限、模型调用或健康事件功能。页面使用仓库内本地图片与合成内容，所有页面顶部显示“教学演示”免责声明；模型实验室明确标记候选模型为 `EXPERIMENTAL_UNRELEASED`，证据详情明确标记为合成示例和非实时生成。

## 可复现检查

在 `src/web/react` 目录执行：

```powershell
npm.cmd ci
npm.cmd run verify
npm.cmd run build
```

结果：

- `npm.cmd run verify` 通过：检查 24 个 React/CSS/TSX 源文件；未发现 `http(s)://`、`fetch(`、`axios` 或 `XMLHttpRequest`；核心页面入口和演示边界文案均存在。
- `npm.cmd run build` 通过：Vite 生产构建成功，资源全部从 `src/assets` 打包。
