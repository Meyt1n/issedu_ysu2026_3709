# HCT-494 人脸阈值标定任务关闭记录

- Issue: #562

- Status: Superseded

## Closing Decision

HCT-494 originally required calibrating local face-login thresholds on the
demonstration machine. It is closed as superseded, not as a completed
biometric calibration. ADR-0008 and merged PR #619 (HCT-498) make formal Web
authentication account-password only. The Web welcome page no longer exposes
face login, so a face-login threshold cannot be a release or acceptance gate
for the current product entry point.

The retained face credential APIs and historical credentials are limited to
controlled experiments and compatibility. This record does not claim a
production biometric result.

## Evidence And Boundary

1. PR #619 was merged on 2026-08-31. ADR-0008 states that face recognition is
   retained as a historical experimental capability, not a formal Web identity
   entry point.
2. The maintainer reported the applicable tests passed. The available
   HCT-493 evidence records 9 passing model-loading and error-contract tests;
   those tests verify Unicode-path model loading and error redaction only and
   are not presented as threshold-calibration evidence.
3. No real-person images, embeddings, samples, PINs, tokens, camera recordings,
   lighting records, or raw similarity scores are stored in this repository.

## Calibration Result

No HCT-494 threshold was applied. No `.env` threshold setting was changed, and
there is no fabricated ROC, false-accept, false-reject, lighting, or
before-and-after statistic in this record.

If a later approved decision restores face recognition as a formal identity
entry point, create a new issue and perform a fresh on-device calibration with
authorized participants. Store only aggregate, de-identified statistics in the
repository and provide the recommended values, rollback defaults, failure-bucket
distribution, and environment notes at that time.

## Rollback

This change is documentation only. Reopen or replace Issue #562 if the formal
Web authentication decision changes; restoring face login requires a new
calibration run before it is enabled.
