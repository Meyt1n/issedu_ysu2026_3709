以下步骤必须在正式环境或获批演示机执行，并由维护者复核：

1. 确认 `HEALTH_NEWS_ADAPTER=enabled`，且 `HEALTH_NEWS_ALLOWED_DOMAINS` 仅含已批准 HTTPS 主机；不在记录中粘贴密钥或完整环境文件。
2. 使用锁定项目依赖先运行离线预检：

   ```bash
   uv run python scripts/hct445_health_news_preflight.py
   ```

3. 离线预检通过后，在受控出口窗口执行一次实时预检：

   ```bash
   uv run python scripts/hct445_health_news_preflight.py --live
   ```

4. 仅落盘以下脱敏字段：执行时间（含时区）、环境标识、脚本版本/提交 SHA、适配器状态、白名单域名数量、来源 ID、HTTP 状态码、响应字节数、退出码和结果。不得保存响应正文、请求头、令牌、IP、用户或家庭健康数据。

## 5. 回滚说明

若实时预检失败、来源内容不符合要求或维护者不批准出口：

1. 将 `HEALTH_NEWS_ADAPTER` 设为 `local`，使健康资讯立即回到仅本地季节提醒模式；该模式不需要远程出口。
2. 移除或恢复本次发布涉及的 `HEALTH_NEWS_ALLOWED_DOMAINS` 变更，保留默认拒绝出口策略。
3. 不清除缓存、不修改用户健康数据；仅记录脱敏故障摘要和回滚时间。
4. 若问题来自应用版本，回退至上一已批准版本，再用本地模式验证 `/api/v1/health-news` 可返回 `local_only` 结果。
