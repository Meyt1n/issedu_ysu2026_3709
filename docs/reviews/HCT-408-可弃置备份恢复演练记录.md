## 关闭的缺口

此前 HCT-408 备份只写 `file_manifest.json`（哈希清单），恢复脚本只校验现有
`FILE_ROOT` 是否仍匹配，**无法在文件被破坏后真正恢复内容**。本增量补齐：

1. `scripts/hct408_file_archive.py`：创建/解包 `files.tar.gz`（路径安全、哈希复核）
2. `backup.sh` / `backup.ps1`：备份时归档 FILE_ROOT
3. `restore.sh` / `restore.ps1`：恢复前先解包归档，再跑校验
4. `hct408_validate_backup.py`：清单非空时强制要求可恢复归档（fail-closed）
5. 可弃置演练：播种 → 备份 → 校验 → 销毁 FILE_ROOT → 恢复 → 哈希一致
