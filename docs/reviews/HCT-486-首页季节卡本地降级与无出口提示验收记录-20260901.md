## 1. 结论

成员前台首页季节卡在「无出口 / 本地降级」各状态下提示正确：每一种状态都明确说明当前未联网抓取、已降级为本地季节提醒，并给出降级原因；任何状态都不显示「已更新」状态、抓取时间或白名单来源等可能被误解为联网成功的信息。与 HCT-444 的助手跳转和 HCT-445 的降级语义保持一致。

## 2. 验收环境与方法

- 本机路径 B（`scripts/start.ps1` 等价命令）：FastAPI + SQLite（`homecare-dev.sqlite3`，迁移至 `0025_hct497`）+ `npm run dev:web:member`（成员前台 5173）。
- 登录账号：`demo-child` / 教学默认密码（`seed_formal_demo_health.py` 播种的合成演示家庭，全部为虚构数据）。
- 通过重启 API 并设置 `HEALTH_NEWS_ADAPTER` 依次进入 `local`（默认）、`enabled` + 空白名单、`disabled` 三种模式；再在已登录状态下停止 API 并点击卡片「刷新」验证请求失败提示。
- 全程未配置真实白名单域名、未发生任何真实外网出站请求；`egress_blocked` / `stale` 状态需要真实白名单抓取才能触发，见第 5 节说明。
- 截图仅截取健康资讯卡片或助手页面本身，不含其他家庭健康数据。

- HCT-444（首页季节健康新闻与助手跳转）：季节卡常驻成员首页，点击条目写入种子问题并跳转 `assistant`，截图 `assistant_jump.png` 验证通过；不编造疫情病毒名或病例数的文案保留。
