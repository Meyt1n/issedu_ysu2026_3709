当前维护者在本任务中明确批准：HCT-203 YOLO11n 药盒辅助定位候选可以不等待以下三项前置材料，
直接进入“仅辅助发布”流程：

- 真实批准固定集；
- 正式外置权重现场校验；
- 单独人工 R3 记录。

该批准由 [HCT-203-maintainer-waiver.json](HCT-203-maintainer-waiver.json) 记录，并通过
`scripts/hct203_maintainer_waiver.py` 校验。它不是正式固定集验收，也不是独立 R3 复核，
不会把当前候选的两例 hard-negative 误检改成通过。

- `PUBLISHED_AUXILIARY_ONLY`；
- 默认不启用家庭运行时；
- 只提出药盒/裁剪区域，不识别药品、不覆盖 OCR/条码、不写入健康事实；
- 必须人工确认，保留 `vision_model_version=unavailable` 降级；
- 仍要求现有模型绑定回滚契约和回滚测试。

历史实验登记 `HCT-203-yolo11n-experimental-v1.3.json` 不改写，原始指标、候选 test 集、
两例 hard-negative 误检和部分复现限制继续保留。
