## 4. `gh issue` 403 盲区说明

在本仓库环境中，agent 的 GitHub 集成 token 对 Issues API 无读权限：

```text
$ gh issue list
GraphQL: Resource not accessible by integration (repository.issues)
```

影响与处理：

- **无法枚举 open/closed Issue**，无法核对 Issue 标签、里程碑与 assignee；本文所有 Issue 编号（如 #480、#477、#475、#310、#71、#234）均来自 PR 正文、矩阵与流程文档的引用，不是实时查询结果。
- **agent 也无法创建 Issue**（矩阵多行已记录同样限制），因此下一期所有 Issue 由维护者按 [Story卡片集](Story卡片集-HCT-5xx与NEXT.md) 的可粘贴正文手工创建。
- 若希望消除盲区，需仓库管理员为集成授予 issues 读权限；否则请将本节视为长期约束。
