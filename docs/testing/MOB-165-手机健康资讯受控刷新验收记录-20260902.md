# MOB-165 手机健康资讯受控刷新验收记录

## 目的

为 Issue [#520](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/520) 提供不依赖外部资讯源的可复跑边界证据。记录只使用虚构数据，不能替代真实 TTL、生产 provider 或发布门禁签收。

## 受控输入

夹具：`APP/scripts/mob171-weak-network-fixture.mjs`。

```powershell
cd APP
node scripts/mob171-weak-network-fixture.mjs --host 127.0.0.1 --port 8000 --mode news-stale
# 需要切换失败态时：
Invoke-RestMethod http://127.0.0.1:8000/__control -Method Post `
  -ContentType 'application/json' -Body '{"mode":"news-error"}'
```

`news-stale` 返回 `cache_status: stale`、明确的 `fetched_at` 和一条虚构白名单资讯；`news-error` 返回 HTTP 503、错误码 `HEALTH_NEWS_UNAVAILABLE` 和 `request_id`。夹具默认只监听回环地址，不写磁盘，不访问外部站点。

| 场景 | 预期 | 代码/输入证据 | 状态 |

| 过期缓存 | 告警使用 `role=alert`，显示缓存时间，刷新入口突出 | `HealthNewsPanel.vue` + `presentHealthNewsFreshness()` + `news-stale` | 已覆盖，可复跑 |

## 边界

- 本记录不声称真实缓存已超过后端 TTL；真实 `health_news_cache_ttl_seconds`/`stale_ttl_seconds` 需要受控服务端联调。
- Android/PWA 的 TalkBack、长辈模式、特大字号、安装态和生产 provider 仍由 MOB-148（#234）发布门禁签收。
- 夹具使用完毕后应停止进程，避免在局域网长期暴露测试端口。
