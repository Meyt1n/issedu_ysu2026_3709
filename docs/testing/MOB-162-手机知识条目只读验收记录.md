# MOB-162 手机知识条目只读验收记录

> 对应 Issue [#517](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/517)。本记录只登记可复跑的自动化和设备事实，不把演示数据或浏览器模拟写成生产联调结论。

## 验收范围

- 「我的」页进入知识条目只读列表；列表只显示服务端已批准且当前身份可见的条目。
- 条目详情展示来源、许可、批准状态、索引版本、生效区间和正文分块；未批准条目不渲染正文。
- 助手引用跳转到条目详情并定位引用分块；索引版本变化时显示告警。
- 长正文支持逐块收起/展开、全部收起/展开和回到顶部；所有控制均为键盘、读屏可访问的按钮。
- 移动端没有新增、编辑、删除、抓取、审核或晋升知识的写入路径。

## 自动化证据（2026-08-31）

在 `APP/` 目录执行：

```powershell
npm run check
npm run test -- --reporter=dot
npm run build
npm run privacy:scan
git diff --check
```

结果：`vue-tsc` 通过；38 个测试文件、351 项测试通过；Vite 构建通过；隐私扫描通过；差异空白检查通过。

另以 Playwright 在 390×844 视口对演示条目执行一次页面烟测：

1. 详情页加载 3 个正文分块。
2. 点击「全部折叠」后正文节点数为 0。
3. 展开第 1 段后正文节点数为 1。
4. 点击「全部展开」后正文节点数恢复为 3。
5. 滚动后「回到知识条目顶部」出现，点击后 `scrollY` 回到 0。

演示 Provider 的 `staging` 条目仍不会出现在列表；直接请求未批准条目只返回元信息，正文数组为空。HTTP Provider 的 403/404/服务不可用路径继续复用统一错误呈现，不在客户端猜测资源是否存在。

## 荣耀真机烟测（2026-08-31）

设备：荣耀 AAP-AN00，Android 16，屏幕 1272×2800，USB ADB 枚举需设置 `ADB_LIBUSB=1`。

- 从「我的」页进入「阅读助手用到的知识条目（只读）」入口成功。
- 演示模式列表只显示「家庭用药记录基础须知（演示）」一条，未批准演示草稿未出现在列表。
- 打开详情后可读到「已批准」、来源、许可、索引版本、生效时间和 3 个正文分块；底部固定导航不影响页面继续滚动。
- 测试后设备连接、数据模式和应用无障碍偏好保持原状。

这次真机烟测使用的是已安装的既有 Debug APK（构建提交 `64f8ec5`），用于确认合并主线的只读入口与详情链路；本 PR 新增的分块控制和回到顶部已由上面的 PWA 烟测覆盖。由于当前工作机只有 Java 24，没有 Gradle 要求的 Java 21，无法在本机重建包含本 PR 增量的 APK；维护者重建候选包后应按本记录复跑真机控制项。
