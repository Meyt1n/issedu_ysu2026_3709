# MOB-162 手机知识条目只读验收记录

> 对应 Issue [#517](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/517)。功能验收已完成；本记录只登记可复跑的自动化和设备事实，生产发布门禁另由 #234 裁决。

## 验收范围

- 「我的」页进入知识条目只读列表；列表只显示服务端已批准且当前身份可见的条目。
- 条目详情展示来源、许可、批准状态、索引版本、生效区间和正文分块；未批准条目不渲染正文。
- 助手引用跳转到条目详情并定位引用分块；索引版本变化时显示告警。
- 长正文支持逐块收起/展开、全部收起/展开和回到顶部；所有控制均为键盘、读屏可访问的按钮。
- 移动端没有新增、编辑、删除、抓取、审核或晋升知识的写入路径。

结果：`vue-tsc` 通过；38 个测试文件、351 项测试通过；Vite 构建通过；隐私扫描通过；差异空白检查通过。

另以 Playwright 在 390×844 视口对演示条目执行一次页面烟测：

1. 详情页加载 3 个正文分块。
2. 点击「全部折叠」后正文节点数为 0。
3. 展开第 1 段后正文节点数为 1。
4. 点击「全部展开」后正文节点数恢复为 3。
5. 滚动后「回到知识条目顶部」出现，点击后 `scrollY` 回到 0。

演示 Provider 的 `staging` 条目仍不会出现在列表；直接请求未批准条目只返回元信息，正文数组为空。HTTP Provider 的 403/404/服务不可用路径继续复用统一错误呈现，不在客户端猜测资源是否存在。

## 当前分支补充验收（2026-09-01）

- 已批准详情：3 个正文分块、来源/许可/索引版本/生效时间可见；带 `chunk=demo-chunk-2` 的引用自动定位并保留展开，`.chunk-item.cited` 的计算背景非透明。
- 未批准详情：`demo-doc-staging-draft` 显示不可查看，正文节点数为 0；没有表单、输入框或可编辑节点，符合只读边界。
- 版本保护：带错误 `version` 时出现 `role="alert"` 版本不一致告警；按钮具有 `aria-expanded` 和 `aria-controls`，页面根宽度与滚动宽度均为 363 CSS px。
- 服务端权限：后端 3 条知识权限回归全部通过；未授权详情按安全契约返回 404，列表过滤掉私有/内部条目，客户端错误呈现不泄露资源存在性。
