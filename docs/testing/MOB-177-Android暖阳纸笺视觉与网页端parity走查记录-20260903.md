### 1.2 深色与高对比模式

| 模式 | 检查项 | 结果 |
| --- | --- | --- |
| 深色（森林夜） | 背景为可分层深松绿，非纯黑；卡片边界可见 | 通过 |

| 高对比 | 纯白实底 + 黑描边，玻璃/渐变/阴影自动去除 | 通过 |
| 高对比 | 优先级高于深色模式，切换时实时生效 | 通过 |
| 减少动效 | `data-motion="reduced"`，极光与萤火层 `display:none` | 通过 |

高对比模式下所有等级/状态仍保持「文字 + 图标 + 颜色」三重表达，未因去除装饰而丢失语义。

### 1.3 极光与萤火装饰层

- 正常动效下，`App.vue` 渲染 3 个极光节点与 8 个萤火粒子节点，动画名称为 `ambient-aurora-drift` 与 `ambient-firefly-rise`。
- 装饰层 `pointer-events: none`，不拦截点击；透明度低于 0.15，不遮挡正文。
- 开启系统「减少动态效果」后，两层均为 `display:none`，页面切换无过渡动画。
- 装饰层全部为 CSS 绘制，不产生额外网络请求，不加载外部图片或字体。
