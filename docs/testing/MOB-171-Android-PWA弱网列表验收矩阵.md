## 签收规则

- Android 与 PWA 必须在同一受控后端和合成数据种子上分别完成；设备、WebView、浏览器、API/错误契约或构建标识变化后须重签。
- 记录弱网注入方式（受控 HTTPS、连接超时、服务端慢、部分失败、断网恢复）和请求次数；不得提交公网地址、完整请求/响应、token、真实姓名或健康正文。
- 骨架卡只代表布局占位，不能包含演示数据；“确实没有数据”和“加载失败”必须有不同文案与状态角色。
- 减少动效开启时不得有扫光、闪烁或位移动画；TalkBack 必须能播报加载→失败→成功的每次状态变化。
- 只有全部用例为 `通过`、隐私检查通过、附件路径与 SHA-256 可复核，才可把「真机验收结论」改为「真机验收结论：通过」。
