## 真机步骤与结果

1. 从应用进入「随身助手」，确认演示模式提示为“不调用家庭服务器”，联网参考开关保持关闭。
2. 在问题草稿输入不含个人信息的 `hello` 并点按「发送」。回答显示“降级说明：demo_mode”，依据区默认收起，摘要显示“查看依据 · 回答已降级”。**通过**：没有把依据正文直接堆在回答下方。
3. 点按“查看依据”。`details.open` 从 `false` 变为 `true`，展开内容显示“本次回答没有可引用的知识文档；当前为受控降级（demo_mode），请勿把回答当作已核验的医疗建议。”，引用卡片数量为 0。**通过**：无 citation 时不伪造来源、版本或条目链接。
4. 使用 CDP 读取页面布局：列表和详情根节点的 CSS 宽度均为 363，`document.documentElement.scrollWidth` 为 363，与视口一致；未发现横向溢出。
5. 将展开态滚动到依据区并保存脱敏截图：[MOB-175-Android演示无引用展开-20260902.png](MOB-175-Android演示无引用展开-20260902.png)。SHA-256：`A1FAF6227DD64F30E3E9111961FCCD4E92ED412120F448E41C19042462B679DE`。
