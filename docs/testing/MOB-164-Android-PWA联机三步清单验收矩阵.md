## 签收规则

- Android 与 PWA 必须记录构建标识、设备/浏览器版本、会话形态和同一份合成数据种子；版本、地址校验规则或家庭契约变化后须重签。
- 只使用虚构成员别名和家庭名。截图不得出现真实姓名、token、完整请求/响应、服务端内部异常、真实健康正文或设备唯一标识。
- 清单只读消费已有会话与能力探测状态，不改变授权判定，不自动发现服务器，不进入管理后台。多家庭未显式选择时必须证明没有成员/事件请求。
- 特大字号、TalkBack 与系统减少动效需要设备持有人记录实际朗读顺序、焦点移动、换行和静态占位；模拟器或普通浏览器截图不能替代。
- 只有全部用例为 `通过`、隐私检查通过、附件路径与 SHA-256 可复核，才可把「真机验收结论」改为「真机验收结论：通过」。
