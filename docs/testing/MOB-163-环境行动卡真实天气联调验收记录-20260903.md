## 验收条件回顾

1. Given 已授权成员，When 请求环境行动卡，Then 返回该成员所在城市的天气和行动卡。
2. Given 未授权成员，When 请求，Then 返回 403 或空列表，不泄露天气数据。
3. Given 城市编码无效，When 请求，Then 返回参数错误，不调用上游 API。
4. Given 上游 API 超时，Then 返回降级响应，使用旧缓存（如有）。
5. Given 上游 API 返回错误，Then 记录错误，返回降级响应。
6. Given 频繁请求，Then 触发限速，使用缓存。
7. Given 相同城市重复请求，Then 去重，不重复调用上游。
8. Given 行动卡有效期过期，Then 不再展示。
9. Given 移动端，Then 只发送城市编码，不发送精确坐标。
10. Given 天气数据，Then 行动卡内容与天气条件匹配（高温→药品储存提醒，低温→血压提醒等）。
