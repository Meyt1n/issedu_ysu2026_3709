- 使用同一台 Android 真机上的 APK（或受控 PWA WebView）完成；APK / WebView / 系统 TTS / 网络环境变化后须重签。

- 仅当全部用例为通过且证据附件可复核时，才将下方「真机验收结论」改为「真机验收结论：通过」，并执行 `node APP/scripts/verify-android-voice-evidence.mjs <本文件路径>`。

- 明确接受：麦克风仍需一次用户手势；不验收后台常驻唤醒；不验收自建云 ASR/TTS。
