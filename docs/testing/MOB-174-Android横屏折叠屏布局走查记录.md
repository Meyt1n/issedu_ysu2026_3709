## 2. 自动证据

在 `APP/` 执行：

```powershell
npm run audit:responsive
npm run check
npm run test
npm run build
```

预检应确认：

1. `html/body/#app` 与 `.screen` 有可收缩宽度边界，页面不声明 `100vw` 制造横向滚动。
2. 横屏、低高度横屏和 `horizontal-viewport-segments: 2` 折叠屏规则存在。
3. `.screen`、卡片、英雄区、横屏子项允许 `min-width: 0`，长文字可换行。
4. 内容底部留白和底部导航使用安全区变量；横屏短屏只缩短留白，不缩小长辈模式触控目标。
5. Service Worker、API、权限和会话测试未被布局任务改变。

自动检查通过只代表响应式契约存在，不能代替设备截图或状态保持签收。

## 5. 重点验收步骤

1. 在 Today 页面滚动到任务列表中段，旋转到横屏，再旋回竖屏；确认滚动位置、当前任务和展开的历史区域没有被重置。
2. 在助手输入框写入一段不含个人信息的教学问题，折叠/展开设备；确认草稿、当前会话和发送状态保持，不产生重复请求。
3. 在拍药盒页选择仓库内的合成图片但不提交真实文件，旋转设备；确认上传草稿仍在，未出现第二次提交或误写入健康档案。
4. 打开长辈模式和特大字号，逐页检查文字不重叠、不截断，按钮仍至少保持既有 `--tap` 触控尺寸，底部导航不遮挡正文。
5. 从折叠外屏展开到内屏、再折回外屏，检查安全区、刘海/挖孔边距和卡片左右边界；确认页面无横向滚动条或被铰链裁切的内容。
6. 开启减少动效与高对比模式重复第 1～5 步；确认布局修复没有依赖动画、颜色或玻璃背景才能阅读。
