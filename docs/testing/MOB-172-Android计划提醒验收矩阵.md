## 签收规则

- 使用同一台 Android 真机上的同一 APK 完成全部用例；APK、WebView、系统通知设置或 ROM 变化后须重签。
- 只使用虚构演示计划与成员；截图不得出现真实姓名、药品名、剂量、健康正文、电话号码、token、完整服务器响应或设备唯一标识。
- 每个用例都必须记录实际结果：`通过`、`未到达` 或 `不适用`，并在备注中写明触发时间、系统设置与原因；不得用“待验收”代替结果。
- 只有全部用例、隐私专项和附件都可复核时，才将「真机验收结论」改为「真机验收结论：通过」，再运行证据门禁脚本。
- 任一隐私专项未通过、结果缺失或截图含敏感信息 → 结论保持「待验收」或「不通过」，Issue 保持打开。
- 国内 ROM 的电池优化、自启动和勿扰策略允许记录“未到达”，但必须保留设置项、时间与用户侧补救指引；不得宣称通知已送达。
