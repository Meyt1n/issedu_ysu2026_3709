## 本轮修复

真机测试发现 Vue `ref` 数组会把流式气泡包装为响应式代理：旧逻辑一方面用对象身份比较，另一方面继续修改压入数组前的普通对象，导致收尾分支不命中且 token 不能及时刷新，气泡会卡在“正在生成”。`APP/src/views/AssistantView.vue` 现按数组索引和 `replyStatus === 'streaming'` 判断当前条目，并从响应式数组取回条目后写入 token；同时区分无正文时的停止/结束提示，生成中的“结束回复”按钮不再依赖首个 token 已到达。
