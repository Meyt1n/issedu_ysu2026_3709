## Smoke 测试步骤与结果

1. 启动应用并进入“今日”页，页面显示“计划提醒”状态为“已按服务端计划安排本地提醒”。
2. 通过应用 WebView 的 `LocalNotifications` 原生桥安排一条 25 秒后的虚构测试提醒，使用生产相同的 `hct_reminder` 通道、脱敏标题/正文和 `allowWhileIdle`。
3. 将应用置于后台，等待触发；系统通知历史出现一条 `com.homecaretwin.companion` 通知，ID 为本次临时测试 ID `190901`。
4. 展开系统通知栏，实际可读到：标题“家健镜提醒”，正文“请打开应用查看今日安排。”；点击该通知后恢复到 `com.homecaretwin.companion/.MainActivity`，应用回到“今日”页。
