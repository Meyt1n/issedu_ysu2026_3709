## 签收规则

- Android 与 PWA 必须在同一受控后端、同一 API/契约版本和同一合成数据种子上分别完成；APK、WebView、浏览器、服务端提交或规则配置变化后须重签。
- 只使用虚构成员别名和城市/区县编码。截图不得出现真实姓名、精确经纬度、完整请求/响应、token、公网服务器地址或设备唯一标识。
- 记录服务端实际返回的来源、生成时间、有效期、规则/配置版本和降级原因；旧缓存必须显示缓存时间，不能写成实时天气。
- “未授权”“城市编码缺失”“访问目的不匹配”必须证明没有发起天气推断请求；失败/限速/超时必须证明页面保持 fail-closed，不自行猜测天气或行动。
- 只有全部用例为 `通过`、附件路径与 SHA-256 可复核、隐私检查通过，才可把「真机验收结论」改为「真机验收结论：通过」。
