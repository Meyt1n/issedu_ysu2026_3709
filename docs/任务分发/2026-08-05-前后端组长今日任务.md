## 6. 分支、提交和交付流程

每位组长从最新 GitHub master 创建自己的任务分支：

    git switch master
    git pull --rebase origin master
    git switch -c feature/<姓名>-<任务简述>

提交前执行：

    git status --short
    git diff --check

只暂存本任务文件，禁止使用 git add .。完成后推送分支，创建 PR 到 GitHub master，等待 CI 和第二人复核。禁止直接修改共享 master，禁止直接向内部仓库 master 提交。
