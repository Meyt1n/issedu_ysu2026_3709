## 3. 页面实施设计

### 3.1 家庭与成员页面

#### 入口与角色

- 入口：家庭总览 -> 家庭与成员。
- 家庭管理员：查看家庭、查看成员、创建成员。
- 普通成员或照护者：只能查看 API 返回的可见成员，不因家庭关系自动获得全部健康信息。

#### 页面流程

```text
进入页面 -> 获取家庭上下文 -> 获取成员列表
        -> 查看角色和可见范围 -> 管理员创建成员
```

#### 字段映射

| 页面区域 | API 字段 |
|---|---|
| 家庭名称 | `household.name` |
| 家庭标识 | `household.id` |
| 创建者 | `household.created_by` |
| 创建时间 | `household.created_at` |
| 成员名称 | `member.display_name` |
| 成员角色 | `member.role` |
| 成员身份关联 | `member.actor_id`，无权限时不展示额外身份信息 |
| 成员创建时间 | `member.created_at` |

#### 状态

- 加载：显示家庭和成员骨架屏。
- 空数据：显示“尚无成员，可添加家庭成员”。
- 成功：显示成员卡片和当前操作者可见范围。
- 未登录：`401`，引导进入开发环境身份入口；不实现生产登录。
- 无权限：`403`，显示“当前操作者无权查看此家庭”。
- 不存在：`404`，返回家庭列表或上级页面。
- 校验错误：`422`，在成员表单字段旁显示原因。
- 依赖不可用：显示 API/数据库不可用，不展示假成员数据。

### 3.2 授权配置页面

#### 入口与角色

- 入口：家庭与成员 -> 授权配置。
- 只有家庭管理员可以创建和撤销授权。
- 授权照护者只能查看服务端返回的自身授权范围，不能编辑或撤销授权。

#### 页面流程

```text
选择被授权人
 -> 选择成员
 -> 选择数据字段
 -> 选择动作和目的
 -> 设置到期时间
 -> 提交授权
 -> 刷新授权状态和可见范围
```

#### 请求与响应映射

| 页面字段 | API 字段 | 规则 |
|---|---|---|
| 被授权成员 | `member_id` | 必须属于当前家庭 |
| 被授权操作者 | `grantee_actor_id` | 不使用家庭关系推断权限 |
| 数据字段 | `data_fields[]` | 从后端允许字段清单选择 |
| 动作 | `actions[]` | 当前基线为 `READ_EVENTS`、`WRITE_EVENTS` |
| 使用目的 | `purpose` | 必填，长度由 API 校验 |
| 到期时间 | `valid_until` | 必须是含时区时间且晚于当前时间 |
| 生效时间 | `valid_from` | 只读展示 |
| 撤权时间 | `revoked_at` | 非空即显示“已撤权” |

#### 授权状态

| 状态 | 前端展示 | 服务端依据 |
|---|---|---|
| 生效中 | 可见范围、动作、目的、到期时间 | 当前时间在有效期内且未撤权 |
| 即将到期 | 到期提醒，不自动延长 | `valid_until` |
| 已过期 | “已过期”，禁止继续访问 | 当前时间不在有效期内 |
| 已撤权 | “已撤权”，显示撤权时间 | `revoked_at` |
| 创建失败 | 保留表单并显示错误 | `401/403/404/422` |

撤权必须二次确认。撤权成功后，前端重新请求受保护资源；收到 `403` 或 `CONSENT_REVOKED` 时立即清空旧数据，不能继续展示缓存内容。

### 3.3 健康事件录入与事件时间线页面

#### 入口与角色

- 入口：成员健康档案 -> 事件时间线 -> 手工录入。
- 成员本人、管理员或拥有 `WRITE_EVENTS` 的授权照护者可以提交事件。
- 查看事件需要服务端授予 `READ_EVENTS` 和对应字段权限。

#### 页面流程

```text
选择成员 -> 读取状态和事件列表
        -> 填写手工事件 -> 提交 CONFIRMED 事件
        -> 刷新事件时间线和成员状态投影
```

#### 请求字段

```json
{
  "member_id": "...",
  "event_type": "...",
  "source": "MANUAL",
  "confirmation_status": "CONFIRMED",
  "payload": {},
  "evidence": {}
}
```

#### 展示字段

| 页面区域 | API 字段 |
|---|---|
| 事件类型 | `event_type` |
| 来源 | `source` |
| 确认状态 | `confirmation_status` |
| 事件内容 | `payload`，必须经过 API 字段过滤 |
| 证据 | `evidence` |
| 操作者 | `created_by` |
| 确认人 | `confirmed_by` |
| 发生/创建时间 | `created_at` |
| 当前投影 | `state` |
| 最近事件 | `last_event_id` |
| 投影更新时间 | `updated_at` |

事件是追加写入，不提供原地编辑按钮。后续更正使用补偿事件，并保留原事件、操作者、证据和时间。

#### 状态

- 加载：分别显示事件列表和状态投影加载状态。
- 空数据：显示“尚无已确认健康事件，可手工录入一条事实”。
- 成功：按时间展示事件，并显示确认人、证据和投影更新时间。
- 未授权读取：清空已有敏感内容，显示 `403` 或 `CONSENT_REVOKED`。
- 未授权写入：禁止提交并显示服务端错误。
- 成员/家庭不存在：显示 `404`，不显示可能存在的隐私内容。
- 表单无效或非确认事件：显示 `422`，不进入时间线。
- API/数据库不可用：显示“当前无法保存或读取，请稍后重试”，不伪造成功结果。

## 4. API 依赖与契约缺口

### 4.1 当前代码已有接口

- `POST /api/v1/households`
- `POST /api/v1/households/{household_id}/members`
- `POST /api/v1/households/{household_id}/authorizations`
- `POST /api/v1/households/{household_id}/authorizations/{authorization_id}/revoke`
- `POST /api/v1/households/{household_id}/events`
- `GET /api/v1/households/{household_id}/events`
- `GET /api/v1/households/{household_id}/members/{member_id}/state`

### 4.2 前端实现前必须补齐或确认

1. 获取当前操作者可访问的家庭列表和当前家庭上下文。
2. 获取家庭成员列表。
3. 获取家庭授权列表和历史授权。
4. 获取当前操作者对成员的字段级可见范围和可执行动作。
5. 统一错误响应：`error.code`、`message`、`details`、`request_id`。
6. 明确 `401`、`403`、`CONSENT_REVOKED`、`404`、`422` 和依赖不可用的映射。
7. 明确事件 `payload` 和 `evidence` 的字段过滤规则，禁止仅由前端隐藏敏感字段。
8. 确认列表分页、排序、`request_id` 和写操作幂等语义。
9. 确认 `X-Actor-Id` 仅限开发环境，生产环境不得作为认证方案。
10. 当前任务单标注基线为 `a18feb0`，仓库实际 HEAD 为后续合并提交 `8f86d16`，需项目负责人确认。

在上述契约冻结前，前端不得使用 Mock、固定响应或截图证明页面功能完成。

## 5. 授权与事件状态流转

### 5.1 授权

```text
草稿 -> 提交校验 -> 生效中 -> 已过期
                         \-> 已撤权
```

创建和撤权均由服务端鉴权、校验并记录审计。前端只负责输入校验、确认交互和结果展示。

### 5.2 健康事件

```text
手工填写 -> 服务端校验 -> CONFIRMED -> health_event 追加
                                   -> outbox 创建
                                   -> member_state_projection 更新
```

当前 Story 不接受未确认识别结果，也不实现视觉识别状态流转。

## 7. 验收条件

### Given / When / Then

- Given 管理员进入家庭页面；When 家庭和成员接口成功；Then 页面展示成员角色、时间和可见范围。
- Given 家庭无成员；When 成员列表返回空数组；Then 页面展示下一步操作，不展示假数据。
- Given 管理员提交完整授权；When 到期时间有效；Then 页面展示生效中的字段、动作、目的和期限。
- Given 授权已撤回；When 照护者重新读取事件；Then API 拒绝访问，页面清理旧敏感数据。
- Given 操作者没有成员字段授权；When 请求成员状态或事件；Then 页面不展示被拒资源内容。
- Given 操作者提交 `CONFIRMED` 手工事件；When API 返回成功；Then 页面展示事件、证据、确认人和状态投影。
- Given 操作者提交非确认事件或空 payload；When API 校验失败；Then 页面展示错误，事件不进入正式时间线。
- Given 跨家庭访问或成员不存在；When API 返回错误；Then 页面不泄露资源是否存在的额外敏感信息。

### 测试与证据

- 设计阶段：检查字段映射、状态清单、文案边界和 API 缺口。
- 前端实现阶段：TypeScript 类型检查、构建检查、API 契约测试和 Playwright E2E。
- 必测场景：正常、空数据、加载、错误、未登录、越权、过期、撤权、跨家庭、依赖不可用。
- 测试数据仅使用合成家庭、合成成员和合成事件。
- 只有代码、自动测试、人工验收、环境版本和演示证据齐全后，才能将 Story 标记为“已验证”。
