# 教学用脱敏说明书摘要（示例）

> **状态：** 合成教学样例（synthetic-demo），非真实批准说明书全文。  
> **许可意图：** internal-demo / 教学引用。  
> **禁止：** 诊断、处方、停药、换药、剂量判断；买药/问诊/广告导流。

## 1. 摘要元数据（入库前必填）

| 字段 | 示例值 |
|---|---|
| 通用名（示意） | 示例解热镇痛片（虚构） |
| 摘要版本 | sample-insert-v1 |
| 来源类型 | 教学改写摘要（非官方原文粘贴） |
| 审核人 / 日期 | （由知识管理员填写） |
| 权限域 | internal 教学；或指定 household_ids |
| 删除责任 | 知识管理员；家庭私有摘要随撤权/删除传播 |

## 2. 可引用的教学摘要（非用法用量医嘱）

- 本摘要仅说明「包装上通常可见的信息类别」：通用名/商品名、规格、厂家、批号、有效期、储存条件提示。
- 具体是否适合某位成员使用、如何服用、能否与其它药品同用，**必须**由医生或药师结合完整医嘱判断；本系统不得据此给出剂量或联用结论。
- 若包装文字与条码主数据冲突，按产品多证据规则进入 `CONFLICT` / `REVIEW`，由人工核对原包装。

## 3. 储存与过期（口径级）

- 按包装标注的避光 / 阴凉 / 冷藏等条件存放；不确定时咨询药师，不由助手臆测。
- 过期或性状异常（变色、异味、结块）应移出常用区并走回收渠道；本摘要不判断「能不能继续吃」。

## 4. FAQ（教学问答）

**Q: 为什么这里没有「一次几片」？**  
A: 剂量属于处方/医嘱范畴，演示知识与脱敏摘要均禁止给出个体化用法用量。

**Q: 可以把厂家 PDF 直接放进仓库吗？**  
A: 不可以。应在获批许可后提取脱敏摘要，登记来源与哈希，用正式清单入库；不要把 PDF 丢进 `docs/demo`。
