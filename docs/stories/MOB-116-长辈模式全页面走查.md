## 用户价值与范围

确保长辈模式不是只在设置页生效，而是覆盖今日、拍药盒、家庭成员、成员档案、提醒、风险依据、求助、我的和无障碍设置九个页面。走查关注 320px 窄屏、标准字号与特大字号下的文字换行、页面宽度、底部主导航、触控目标和播报降级浮层；不新增业务能力，不改变 API、授权、健康事实或医疗边界。

## Given / When / Then

- Given 320px 视口和标准字号，When 依次打开九个页面，Then 页面和交互控件不产生横向溢出，基础触控目标不低于 44px。
- Given 320px 视口和长辈模式（特大字号），When 依次打开九个页面，Then 无文字截断、卡片/按钮重叠，交互控件不低于 58px，底部导航保持今日/拍药盒/求助/我的四个入口。
- Given 语音播报不可用或正在播报，When 出现文字引导/播报浮层，Then 浮层位于底部导航上方，不遮挡导航入口，且可以继续使用页面核心操作。
- Given 风险依据或事件摘要包含较长标识，When 在 320px 窄屏查看，Then 标识在卡片内换行，不撑大页面导致横向滚动。

## 九页面走查记录

执行环境：本地 Vite 演示模式；浏览器视口 `320×800`；演示数据为仓库内置虚构数据。DOM 走查逐页检查 `document/body.scrollWidth`、交互元素边界、导航入口和浮层与导航的垂直间距。

| 页面 | 路由 | 标准字号 | 长辈模式/特大字号 | 结果 |
|---|---|---|---|---|
| 今日 | `/` | 无横向溢出，控件 ≥44px | 无横向溢出，控件 ≥58px，四入口导航 | 通过 |
| 拍药盒 | `/scan` | 无横向溢出，控件 ≥44px | 无横向溢出，控件 ≥58px，四入口导航 | 通过 |
| 家人 | `/family` | 无横向溢出，控件 ≥44px | 无横向溢出，控件 ≥58px，四入口导航 | 通过 |
| 成员档案 | `/family/:memberId` | 无横向溢出，控件 ≥44px | 无横向溢出，控件 ≥58px，四入口导航 | 通过 |
| 提醒 | `/alerts` | 筛选控件 ≥44px | 筛选控件 ≥58px | 通过 |
| 风险依据 | `/alerts/:memberId/:ruleId` | 长标识可换行，无横向溢出 | 长标识可换行，无横向溢出 | 通过 |
| 求助 | `/help` | 求助/播报入口 ≥44px | 求助/播报入口 ≥58px | 通过 |
| 我的 | `/me` | 设置、表单控件 ≥44px | 设置、表单控件 ≥58px | 通过 |
| 无障碍设置 | `/me/accessibility` | 开关/分段选项 ≥44px | 开关/分段选项 ≥58px | 通过 |

底部导航在长辈模式下保持四个大入口；语音提示和停止播报浮层与导航保留间距。标准模式保留五个入口（今日/拍药盒/家人/提醒/我的）。
