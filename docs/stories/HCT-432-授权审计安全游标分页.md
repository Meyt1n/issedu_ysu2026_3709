## 1. 用户价值与目标

授权审计是排查越权访问和复盘请求链路的最小证明。现有列表接口一次性返回家庭全部审计记录，记录增多后会产生无界响应，也无法按 HCT-431 写入的 `request_id` 快速定位一次请求。此切片新增 Owner 专用的有界游标查询接口，让后台可以稳定翻页并按请求追踪审计记录。

## 2. 范围与非目标

本切片实现：

1. 新增 `GET /api/v1/households/{household_id}/authorization-audits/page`；
2. 使用 `limit`（1 至 100）控制响应上限，按 `created_at`、`id` 稳定排序；
3. 使用 HMAC 签名的不透明游标，游标绑定家庭和 `request_id` 过滤条件；
4. 支持 `request_id` 精确过滤，便于从请求追踪 ID 回查授权审计；
5. 保持既有 `/authorization-audits` 列表接口兼容；
6. 覆盖分页连续性、过滤条件、游标篡改、跨范围和非 Owner 场景。

不做：

- 不改变授权结论、审计写入字段、审计保留策略或 Owner 查询权限；
- 不返回健康正文、证据或状态快照；
- 不新增数据库迁移、前端页面或外部网络出口；
- 不把游标内容当作客户端可信输入，服务端始终重新校验家庭和过滤范围。

## 3. Given / When / Then 验收

- Given Owner 请求第一页并设置 `limit=2`；When 家庭存在多条审计；Then 响应最多返回 2 条并提供 `next_cursor`、`has_more`。
- Given 使用上一页返回的游标；When 请求下一页；Then 结果按稳定顺序连续返回，不重复、不遗漏。
- Given 携带 `request_id`；When 请求分页接口；Then 只返回完全匹配该请求 ID 的审计记录，游标只能用于同一过滤条件。
- Given 修改游标签名、替换家庭或跨过滤条件复用游标；When 服务端解码；Then 返回 `422 AUDIT_CURSOR_INVALID`，不泄露审计内容。
- Given 非 Owner 或跨家庭请求；When 查询分页审计；Then 保持 `404 RESOURCE_NOT_FOUND` 语义。
- Given `limit` 小于 1 或大于 100；When 请求接口；Then 返回校验错误，不执行无界查询。
