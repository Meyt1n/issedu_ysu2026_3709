## 范围

- 默认 `HEALTH_NEWS_ADAPTER=local`：仅本地日历季节卡（HCT-444），零出口。
- `HEALTH_NEWS_ADAPTER=enabled` 时：仅 HTTPS + `HEALTH_NEWS_ALLOWED_DOMAINS` 白名单主机可抓取；内置 WHO / 卫健委 / 疾控等源配置，域名未进白名单则跳过该源。
- 支持 RSS/Atom 与受控 HTML 列表页解析；文章链接必须与源同域（或显式允许的 https 白名单域）。
- 进程内 fresh/stale 缓存、限速、有限重试；失败或无缓存时合并本地季节卡并标注 `degraded_reason`。
- 卡片字段：标题、摘要、来源名、来源 URL、发布时间（若有）、抓取时间、`chat_prompt`（确定性模板，不经 LLM 编造）。
- 不做：LLM 生成新闻正文；不外发任何家庭/成员/健康字段；不导流购药问诊；不把资讯写入健康事件。

## Given / When / Then

- Given 适配器为 local；When 请求 `/health-news`；Then 仅返回季节卡，`status=local_only`，无 HTTP 出站。
- Given 适配器 enabled 但白名单为空；When 请求；Then `status=unconfigured`，仍返回季节卡，无出站。
- Given 白名单含示例源且提供方返回合法 RSS/HTML；When 请求；Then `status=ok`，条目带来源名/URL/fetched_at，且不包含家庭字段。
- Given 缓存仍在 TTL 内；When 再次请求；Then `cache_status=fresh`，不重复出站。
- Given 提供方超时且有旧缓存；When 请求；Then `status=stale`，展示旧远程卡 + 可选季节补齐。
- Given 提供方失败且无缓存；When 请求；Then 季节卡降级，`degraded_reason` 明确，不伪造远程来源。
- Given 远程标题含导流话术（购药/在线问诊）；When 过滤；Then 丢弃该条。
