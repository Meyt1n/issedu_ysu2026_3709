## 用户价值

服务端已按 ADR-0007 落地受控开放联网与 `egress_mode`、三档出网上下文，网页端有对应开关，移动端还没有。补一个显式的联网搜索开关，并在开关旁把「什么会出网、什么不会」讲清楚，默认关闭、fail-closed。

## 范围

- 助手页新增联网搜索开关，默认关闭；服务端未声明联网能力时开关禁用并说明原因。
- 开关旁的隐私说明：出网的是问题文本与检索关键词，不出网的是成员姓名、健康事件与位置。
- 回复里标注本轮是否使用了联网结果，以及来源域名。
- 服务端拒绝出网（策略关闭、限速、超时）时的可恢复文案。

## 非目标

- 不在 APP 内直连任何搜索服务；出网一律由家庭服务器按白名单执行。
- 不改服务端 `egress_mode`、白名单与三档上下文策略（属 HCT-430/ADR-0007）。
- 不提供「记住并默认开启」这类降低知情度的便捷项。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 首次进入助手，When 查看联网开关，Then 处于关闭态，并可展开阅读出网范围说明。
2. Given 用户显式打开开关并提问，When 服务端使用了联网结果，Then 回复中标注联网已启用与来源域名。
3. Given 服务端未声明联网能力或策略为关闭，When 查看开关，Then 开关禁用并说明「当前部署未开放联网搜索」，不静默降级成本地检索却声称联网。
4. Given 联网被限速、超时或上游失败，When 提问，Then 显示可恢复错误并给出仅用本地知识重试的入口。
5. Given TalkBack 与长辈模式，When 操作开关，Then 开关状态、说明文本与禁用原因均可朗读。

## 安全、隐私与回滚

- 默认关闭且每次会话不继承上次开启状态之外的任何隐式授权。
- 任何情况下不把成员姓名、健康事件正文、位置或家庭标识发往搜索链路。
- 不出现买药、问诊、广告或佣金导流入口（产品硬边界）。
- 回滚：隐藏联网开关入口并强制本地检索，助手其余功能不受影响。
