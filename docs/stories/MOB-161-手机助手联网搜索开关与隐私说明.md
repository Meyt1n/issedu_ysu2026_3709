## 用户价值

服务端已按 ADR-0007 落地受控开放联网与 `egress_mode`、三档出网上下文，网页端有对应开关，移动端还没有。补一个显式的联网搜索开关，并在开关旁把「什么会出网、什么不会」讲清楚，默认关闭、fail-closed。

## 范围

- 助手页新增联网搜索开关，默认关闭；服务端未声明联网能力时开关禁用并说明原因。
- 开关旁的隐私说明：出网的是问题文本与检索关键词，不出网的是成员姓名、健康事件与位置。
- 回复里标注本轮是否使用了联网结果，以及来源域名。
- 服务端拒绝出网（策略关闭、限速、超时）时的可恢复文案。

## 非目标

- 不在 APP 内直连任何搜索服务；出网一律由家庭服务器按白名单执行。
- 不改服务端 `egress_mode`、白名单与三档上下文策略（属 HCT-430/ADR-0007）。
- 不提供「记住并默认开启」这类降低知情度的便捷项。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 首次进入助手，When 查看联网开关，Then 处于关闭态，并可展开阅读出网范围说明。
2. Given 用户显式打开开关并提问，When 服务端使用了联网结果，Then 回复中标注联网已启用与来源域名。
3. Given 服务端未声明联网能力或策略为关闭，When 查看开关，Then 开关禁用并说明「当前部署未开放联网搜索」，不静默降级成本地检索却声称联网。
4. Given 联网被限速、超时或上游失败，When 提问，Then 显示可恢复错误并给出仅用本地知识重试的入口。
5. Given TalkBack 与长辈模式，When 操作开关，Then 开关状态、说明文本与禁用原因均可朗读。

## 安全、隐私与回滚

- 默认关闭且每次会话不继承上次开启状态之外的任何隐式授权。
- 任何情况下不把成员姓名、健康事件正文、位置或家庭标识发往搜索链路。
- 不出现买药、问诊、广告或佣金导流入口（产品硬边界）。
- 回滚：隐藏联网开关入口并强制本地检索，助手其余功能不受影响。

## 实现与验证证据

- 新增 `APP/src/utils/networkSearch.ts`，把三处与安全相关的判定从视图里抽出来单测：`networkSearchDisabledReason()`（fail-closed 判定）、`resolveNetworkSearchForTurn()`（单轮是否出网）、`collectExternalDomains()`（来源域名展示）。
- 能力门禁（验收 3）：`AssistantView.vue` 接入 `useCapabilities()`，只有服务端声明 `external-web` 才允许打开开关。**能力探测未完成也按不可用处理**，不乐观放行；禁用时给出「当前部署未开放联网搜索。」或「能力探测尚未完成…」并说明助手只用本地知识，不静默降级却声称联网。
- 双重闸门（安全边界「默认关闭且不继承隐式授权」）：`allowNetworkSearch` 默认 `false`；`watch(networkSearchAvailable)` 在能力变为不可用时立刻把开关关掉；发请求时再经 `resolveNetworkSearchForTurn()` 判定一次，开关状态残留为开也不会出网。
- 出网范围说明（验收 1）：开关旁新增默认折叠的 `<details>`「出网范围说明」，逐条列出会出网的内容（服务端判定需要外部参考的检索词）与不会出网的内容（成员姓名、健康事件正文、用药记录、位置、家庭标识），并声明联网结果需人工确认、不构成诊断或剂量建议。
- 来源域名标注（验收 2）：`ChatEntry` 增加 `externalDomains`，流式 `onExternalSources` 与最终回复都只取服务端返回的 `domain` 字段（去重、限 8 个、不展示完整 URL、不本地推断）；气泡文案改为「已启用联网参考 · 需人工确认，不作诊断 · 来源域名：…」，服务端没返回域名时明确写「服务端未返回来源域名」。
- 本地重试入口（验收 4）：`send()` 增加 `{ localOnly }` 选项；联网轮次失败时记下原问题并展示「仅用本地知识重试」按钮，该轮强制不出网，且**不改开关状态**，避免用户为拿到回答而永久关闭开关。
- 服务端降级回传（验收 4）：新增 `networkSearchFailureMessage()`，识别 `web_search` 节点的 `RATE_LIMITED`、`SEARCH_FAILED`、`DEPLOYMENT_DISABLED` 与 `EGRESS_BLOCKED` 降级 trace；即使 HTTP 请求成功并返回本地回答，也会显示可恢复提示并保留「仅用本地知识重试」入口，不把服务端降级误报成联网成功。
- 可访问性（验收 5）：开关禁用时通过 `aria-describedby` 关联禁用原因段落（`role="status"`），说明区用原生 `<details>`/`<summary>` 保证展开态可朗读，触控目标保持 `var(--tap)`，焦点可见样式与页面其它控件一致。
- 入口一致性修复：演示模式也显示同一组联网开关和「出网范围说明」，开关保持禁用并明确说明不会出网；联机模式继续由 `external-web` 能力门禁控制，避免首次进入时因隐藏入口而无法确认默认关闭状态。
- 2026-08-29 真机复核：荣耀 AAP-AN00（Android 16、系统 WebView 138.0.7204.179）通过 USB `adb reverse` 打开当前 Vite 构建；演示模式可见默认关闭且禁用的「允许本次脱敏联网参考」开关，展开后可读到「演示模式不会出网」及出网/不出网边界说明。该证据仅覆盖入口与文案可见性，不替代联机限速、超时、上游失败和 TalkBack/长辈模式签收。
- 2026-08-31 原生 APK 复核：荣耀 AAP-AN00（Android 16、系统 WebView 138.0.7204.179、1272×2800）安装提交 `0034eb2` 的 debug APK 后进入助手页；UIAutomator 证实「允许本次脱敏联网参考」默认关闭且禁用，禁用原因可读，展开「出网范围说明」后可读到会/不会出网、默认关闭和人工确认边界。该证据覆盖原生入口与文案可见性。
- 2026-08-31 长辈模式复核：开启「长辈模式」后重复进入助手页，联网开关仍保持关闭且禁用，禁用原因与出网说明保持同一语义；设备不支持语音播报时出现预期的文字提示「此设备暂不支持语音播报，请继续阅读屏幕文字。」。复核结束后已关闭长辈模式并恢复标准字号、导航与应用设置。

## 受控联机待补证据

- 验收 2 的域名标注依赖服务端在 `external_sources` 里返回 `domain`；只做了客户端映射与降级文案的自动验证，真实联网链路下的域名内容需在联机环境实测。
- 验收 4 已覆盖 HTTP 失败和服务端 `web_search` 降级 trace 的本地重试决策；真实限速（429）、超时与上游失败三种联网链路仍需在联机环境分别走一遍，以确认后端实际返回的 trace/错误码与提示一致。
- 验收 5 的 TalkBack 朗读顺序仍需在发布门禁设备上由维护者签收；本 Story 已覆盖 Android 真机的语义节点、长辈模式和设备无语音能力时的文字降级。
- 上述三项受控联机证据属于家庭服务器/provider 环境的发布门禁，不改变移动端 fail-closed 默认关闭与本地重试实现；联机环境未提供时不得用演示模式结果替代。
