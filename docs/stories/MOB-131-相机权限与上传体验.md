## 用户价值

照护者在拍摄药盒或从相册选择图片时，能够知道下一步可做什么、哪些文件不会被上传，以及失败后怎样安全地重试。页面只生成识别候选和人工复核任务，不提供诊断、处方、停药、换药或剂量判断。

## 范围

- 提供带 `capture="environment"` 的相机优先文件入口，以及相册/文件选择回退。
- 检测浏览器没有 `mediaDevices.getUserMedia` 的场景，明确提示用户仍可从相册或文件选择图片。
- 在质量检查或上传请求之前，本地拒绝非图片、空文件和大于 10 MiB 的图片。
- 识别请求失败时保留已通过质量检查的同一文件；“开始识别”按钮可再次提交，避免用户重复选择文件。
- 支持在没有请求进行时清除本地选择、预览 URL、质量结果和候选结果。
- 提供单元测试覆盖本地校验边界。

## 非目标与已知限制

- 当前 `DataProvider.recognizeMedicine(file, memberId)` 没有 `AbortSignal`、上传进度或幂等键参数；本 Story 不伪造网络中取消、上传百分比或“已创建任务”。
- 在请求已发出后，页面仅禁用重复选择；无法取消未知服务端状态的请求。需要后续扩展 Provider/API 合同后才能实现真实取消、可恢复进度与端到端幂等。
- Android 相机权限行为依赖系统版本、WebView 与设备策略，尚未用真机验证前不得标记为完成。
- 图片、健康数据、接口响应和识别候选均不写入本地缓存、日志或通知。

## Given / When / Then

### 正常路径

1. Given 已选择家庭成员、视觉任务能力可用且相机可用，When 用户拍摄一张不超过 10 MiB 的图片，Then 页面只在本地创建预览并发起质量检查；质量通过后才允许开始识别。
2. Given 当前设备不能直接使用相机，When 页面加载，Then 页面说明可从相册或文件选择图片，不将此状态描述为上传成功。
3. Given 用户从相册选择有效图片且质量通过，When 点击“开始识别”，Then 仅调用既有视觉识别 Provider；成功结果继续进入人工复核流程。

### 边界与失败路径

1. Given 用户选择 PDF、文本等非图片，When 选择事件触发，Then 本地提示格式不支持，不创建预览、不发起质量检查也不上传。
2. Given 用户选择零字节图片，When 选择事件触发，Then 本地拒绝，提示重新拍摄或从相册选择。
3. Given 用户选择超过 10 MiB 的图片，When 选择事件触发，Then 本地拒绝并说明未上传。
4. Given 图片质量已经通过但识别请求弱网失败，When Provider 返回异常，Then 页面回到质量结果，保留原图片，并说明未确认创建视觉任务；用户可直接重试。
5. Given 用户尚未发起请求，When 点击“取消本次选择”，Then 仅清理本地预览和本地状态，并明确未上传、未创建视觉任务。
6. Given 质量检查或识别正在进行，When 用户尝试再次选择图片，Then 入口被禁用，避免并发重复请求。

### 未授权和能力不可用

1. Given 实时模式未完成能力探测，When 用户打开页面，Then 拍摄与相册入口禁用，提示先检测连接。
2. Given 实时模式服务端未声明视觉任务能力，When 用户打开页面，Then 拍摄与相册入口禁用，不将不可用接口包装为可用功能。
3. Given Android 用户拒绝或系统限制相机，When 原生/WebView 无法提供相机，Then 应能使用相册/文件入口；真机行为需按下方清单验收。
