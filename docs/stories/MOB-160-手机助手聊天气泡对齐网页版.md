## 用户价值

网页端助手已完成气泡与对话流视觉打磨（HCT-452、HCT-460），移动端助手仍是早期样式，两端观感不一致，长会话下可读性明显更差。把移动端对话流对齐到网页版的气泡、间距、时间戳与分组规则。

## 范围

- 用户/助手气泡的圆角、留白、最大宽度、左右对齐与连续消息分组。
- 时间戳与状态行（发送中、失败、已停止）的位置与文案。
- 长文本、代码块、列表、引用块在窄屏下的换行与横向溢出处理。
- 三主题（默认/高对比/长辈）与三字号下的对比度与行高校验。

## 非目标

- 不改助手的回答内容、路由、工具调用或安全策略。
- 不引入新的动画库或第三方 UI 依赖。
- 不改网页端样式（属 HCT-452/HCT-460）。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 一轮多消息会话，When 查看对话流，Then 气泡分组、间距与时间戳规则与网页端一致。
2. Given 助手返回长文本、列表或代码块，When 在 320px 窄屏查看，Then 不出现横向滚动或文字被裁切。
3. Given 高对比主题与特大字号，When 查看气泡，Then 前景/背景对比度满足 WCAG 2.1 AA，行高不导致重叠。
4. Given 减少动效开启，When 新消息插入，Then 不播放位移或淡入动画。
5. Given TalkBack 开启，When 逐条浏览消息，Then 每条能读出「谁说的 + 内容 + 时间」，不重复朗读装饰元素。

## 安全、隐私与回滚

- 纯前端呈现改动，不触碰助手请求与安全边界。
- 不得为了观感降低对比度或缩小触控区。
- 回滚：revert 本 PR 回到既有样式，功能不受影响。
