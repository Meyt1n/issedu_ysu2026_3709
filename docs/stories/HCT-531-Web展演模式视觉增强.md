# HCT-531：Web 展演模式视觉增强

## 1. 范围

- FR/NFR：FR-09（家庭/模型大屏展示）、NFR-02（不展示敏感正文）、NFR-04（基础档可降级）、NFR-07（可访问与可理解）。
- 关联：本地前端展示层；Issue 需由维护者创建后回填。
- 目标：在不增加医疗业务判断、不写入健康事实、不改变权限边界的前提下，为 Web 演示补充一组可关闭的视觉展演层。当前增量覆盖健康脉络星图、数字孪生脉搏仪表盘、时光隧道，以及水晶球、事件瀑布、矩阵雨、成就提示和氛围呼吸边框。
- 本轮视觉升级：使用 ImageGen 生成项目内静态主视觉资产，替换原先由 CSS/Canvas 手工绘制的空间、材质、光效和主体形状；实时数据仍由 DOM/Canvas 前景层叠加。

## 2. 验收条件

### 第一批视觉层

- 进入展演模式后的首次会话播放「INITIALIZING HOMECARE TWIN」启动仪式；可跳过，且通过 `sessionStorage` 保证本次浏览会话只播放一次，退出展演模式时不遮挡普通页面。
- 展演模式右下角 AI 守护机器人只执行页面跳转到助手，不代替真实助手回答；加载、扫描、助手、待复核和离线状态来自现有会话/路由状态，普通模式不渲染该装饰层。
- 扫描雷达跟随现有视觉任务的 queued/running/succeeded/failed/timeout 状态；没有结果时不得显示为已完成复核。
- 大屏指标、成员摘要和面板使用轻量玻璃卡片与倾斜效果；支持 `prefers-reduced-motion` 降级。

### 第二批视觉层

- 展演模式可通过主题菜单、命令面板或 `Ctrl/Cmd + Shift + H` 开关；开关只保存在当前页面会话，不写后端。
- 关闭展演模式后，家庭大屏恢复原有 `bs-tile`、`bs-panel`、成员卡片、布局宽度和主题配色，不保留 ImageGen 背景、边框、倾斜或深色变量。
- 数据瀑布只绘制成员数、待复核数、当前路由等聚合信号，不绘制健康正文、姓名、药品或模型输出。
- 时间回溯只回放现有近七日 `week_series` 的已确认事件数量，不改变当前家庭状态。
- 家庭沙盘只展示成员、已确认计划摘要、待复核数和严重信号数；全息控制台只执行已有页面导航。
- 展演模式下的弹层、快捷键和时间滑块可由键盘操作；移动窄屏和减少动效状态不阻塞核心页面。

### 本次扩展

- 健康脉络星图复用现有关系图谱 API；成员/药品/计划/过敏/关注项节点在 Canvas 中缓慢公转，悬停或选中时显示核心连线与授权详情，严重信号只触发视觉脉冲。
- 数字孪生心跳仪表盘使用今日事件、待复核数和本地运行状态生成视觉脉搏线；环形指标表示「计划已载入」而非虚构的服药完成率，链路百分比只按实际在线组件计算。
- TemporalReplayPanel 增加全屏时光隧道，支持正向穿梭、反向倒带和时间轴拖动；仅显示 `week_series` 数量与日期标签。
- ScanRadarOverlay 增加 OCR / BARCODE / YOLO 全息层，仍只展示现有视觉任务状态，不生成新的识别结果。
- 水晶球、事件瀑布、矩阵雨、守护精灵尾迹、成就提示和氛围呼吸边框均为装饰层；矩阵雨只使用 `LOCAL/EVENT/TASK/REVIEW/SYNC/READY` 等非健康正文 token。

### ImageGen 主视觉资产

- 资产统一落在 `src/web/public/showcase/`，包括启动仪式、星图空间、脉搏 HUD、时光隧道、扫描投影、水晶球、守护机器人、事件瀑布、矩阵纹理、成就爆发、氛围边框、家庭沙盘、玻璃卡片和全息控制台。
- 当前展演主题为「自然照护图鉴」：ImageGen 素材统一采用米白纸张、亚麻、鼠尾草绿、陶土橙、手绘植物和手工陶瓷质感；明确移除霓虹蓝、塑料玻璃、金属边框和赛博控制台语汇。该主题只覆盖展演模式，普通大屏继续使用原有视觉。
- 普通页面在默认「暖阳纸笺」主题下复用低透明度的植物标本背景、自然纸张纹理和局部图谱衬底；家庭大屏、其他主题和业务数据层不复用这组点缀。
- 生成图只承担展示层的空间、材质和光效；事件数量、任务状态、节点标签、当前日期和可访问控件仍使用现有已授权数据，不把静态画面当成健康事实。
- 资源不含姓名、药品正文、模型输出或可识别健康结论；扫描、星图和时间回溯的交互仍遵循原有人工确认与聚合边界。

## 3. 实现边界

- 仅修改 Web Vue 组件、共享展演状态、样式和前端测试；不修改 API、数据库、权限、健康事件、视觉任务状态机或模型配置。
- 所有文案明确「展示/聚合/候选」边界，不把视觉动画描述为诊断、处方或用药决策。
- 不新增第三方 3D/Canvas 运行时；空间主体与装饰光效使用项目内 ImageGen PNG，星图仅保留 Canvas 作为实时节点前景层，沙盘使用生成图与 DOM 热区叠加。

## 4. 回滚与风险

- 回滚：移除 `src/web/src/components/showcase/`、`src/web/src/ui/showcase.ts` 及其 App/大屏/扫描/命令面板接入和样式增量；不需要迁移或数据恢复。
- 主要风险是低性能设备上的动画开销和展示层遮挡交互；通过减少动效、Canvas 不参与命中测试、可关闭展演模式和原有页面保留进行缓解。
- 该 Story 不证明真实视觉识别、AI 推理、健康风险判断或隐私 R3 验收已经完成。
