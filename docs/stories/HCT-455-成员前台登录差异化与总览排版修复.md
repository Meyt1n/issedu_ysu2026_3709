## 1. Story

用户按四张截图报告：①从管理后台点「回成员前台」后，落地页和后台登录长得几乎一样，感觉不是「每个人自己的前台」；②总览「家庭环境」卡里的生活建议被挤成一字一行的竖排；③「04 家庭成员状态」被压成一条只剩标题的白条，且它下面又出现「01 近期变化」，编号乱序；④管理后台侧栏出现可见滚动条。本 Story 逐图修复，并让成员前台登录页与管理后台登录页在品牌、凭据默认值、主按钮与左栏文案上明显不同。

## 2. 方案

### 图一 成员前台登录差异化（`portalEntry.ts` + `WelcomeView.vue` + `style.css`）

- 品牌模型扩展（`PortalEntryBranding`）：新增表单身份说明 `formIdentityHint`、左栏承诺胶囊 `chips`、主按钮文案 `ctaLabel`、`passwordBehindOtherWays`。
- 成员前台：徽标「成员前台 · 每位家人自己的健康日常」、标语「我的健康日常，刷脸就能进」、表单顶签「成员前台 · 个人身份」、松木绿顶边；凭据 tab 只保留人脸识别 / 家庭 PIN，账号密码收进「其他方式：用账号密码登录」次级链接；主按钮「进入我的前台」。
- 管理后台：保持「家庭管理后台」全家管理品牌，新增顶签「管理后台 · 全家管理」、陶土色顶边与管理向左栏胶囊；主按钮改为「进入管理后台」；账号密码仍为默认 tab。
- 跨端链接（含入口冲突指引）统一带 `?portal=member|admin` 显式覆盖：目标端口即使没有注入入口模式（配置不全的部署），落地页也按目标品牌渲染。
- 登录后落点不变：成员账号进 `member-home`（HCT-439 成员导航），管理员进 `overview`；入口/账号不匹配仍走 HCT-453 登出 + 跨端指引，未削弱。
- auto 模式（裸 `npm run dev:web` 单入口）完全保持原文案与行为，既有 e2e 不迁移。

### 图二 天气建议竖排（`style.css`）

`.weather-action-body` 原为不换行 flex（读数 218px + 指标 250px 固定），仪表盘两栏布局下建议列仅剩几十像素，中文被挤成一字一行。改为默认 `flex-wrap: wrap`，建议列 `flex: 1 1 260px; min-width: min(100%, 260px)`——放不下就整行换行，绝不压缩成竖排；补 `writing-mode: horizontal-tb` 防御与 1.65 行高。

### 图三 家庭成员状态白条与编号乱序（`OverviewView.vue`）

- 根因：`.view-container` 是定高 grid，成员状态卡是其直接子项且 `overflow: hidden`，按 CSS Grid 规范其自动最小尺寸被清零，视口不够高时整行被压到只剩标题（复现实测整卡仅 46px）。改 `overflow: visible` 恢复 min-content 参与行高计算，成员格子（姓名/角色/状态签/事件数）完整渲染。
- 「近期变化」分区编号由 01 改为 05：总览编号沿阅读顺序 01 待确认事项 → 02 今日用药 → 03 最近识别的药品 → 04 家庭成员状态 → 05 近期变化，严格递增，不再出现「04 下面还有 01」。

### 图四 侧栏滚动条（`style.css`）

- 常规压缩：侧栏 gap/padding、分组标题间距、导航项 padding 各收紧，1052px → 常规视口一屏内。
- 矮视口紧凑档 `@media (max-height: 930px) and (min-width: 861px)`：1280×800 / 1440×900 下五组导航 + 品牌 + 页脚（隐私说明与收起按钮保留）全部收进 100dvh，实测 1280×800 下 scrollHeight=clientHeight=800。
- 兜底：`scrollbar-width: none` + `::-webkit-scrollbar { display: none }`，极矮窗口即使溢出也不渲染可见滚动条，键盘/滚轮滚动仍可用。

- 不改 `src/web/react` 与 `APP/`；不宣称 P0 关闭。

## 5. 验收标准（Given/When/Then）

1. Given 成员前台入口（5173 member 模式 / 8080 / `?portal=member`），When 打开欢迎页，Then 显示「我的健康日常」个人前台品牌、顶签「成员前台 · 个人身份」、凭据 tab 只有人脸/家庭 PIN、密码在「其他方式」里、主按钮「进入我的前台」。
2. Given 管理后台入口，When 打开欢迎页，Then 显示「家庭管理后台」品牌、顶签「管理后台 · 全家管理」、账号密码为默认 tab、主按钮「进入管理后台」；两页标语/徽标/主按钮互不出现。
3. Given 任一入口的跨端链接（含入口冲突指引），When 检查 href，Then 指向对端端口且带 `?portal=member|admin`。
4. Given 成员账号在成员前台登录成功，Then 落在 `member-home` 且侧栏只有成员导航；管理员在管理后台登录成功落在 `overview`；入口/账号不匹配仍登出并给跨端指引（HCT-453 不削弱）。
5. Given 管理员总览且天气返回一条生活建议，When 1280×800 渲染，Then 建议卡横排（宽>240px、高<120px），无一字一行竖排。
6. Given 两位成员，When 渲染「04 家庭成员状态」，Then 每位成员的姓名、角色、状态签、事件数完整可见，卡片不再是白条；分区编号按 01→05 递增。
7. Given 管理后台 1280×800，When 渲染侧栏，Then 五组导航 + 隐私说明 + 收起按钮收进一屏（scrollHeight ≤ clientHeight）且 `scrollbar-width: none`。

## 8. 已知限制

- 双端差异化只作用于 member/admin 入口模式；auto 单入口保持旧欢迎页。
- 侧栏紧凑档按 1280×800 / 1440×900 校准；更矮或系统缩放更大的窗口由隐藏滚动条兜底（仍可键盘/滚轮滚动）。
- 成员前台「其他方式」仍可用账号密码登录（注册入口保留），供管理员排障或无摄像头设备使用；入口锁行为不变。
