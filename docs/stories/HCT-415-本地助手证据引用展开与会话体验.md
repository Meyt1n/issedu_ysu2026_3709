# HCT-415：本地助手证据引用展开与会话体验

## 1. Story

作为家庭照护者，我希望看清助手回答引用了哪些本地文档，并能在当前标签页恢复或清空短期对话，从而区分“有证据的解释”和受控降级回复。

## 2. 需求与边界

- 关联 Issue：[#252](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/252)
- 关联 FR：FR-08 本地证据型助手
- 关联 NFR：NFR-01 安全、NFR-02 隐私、NFR-03 可追溯、NFR-04 可用性、NFR-07 可理解
- 风险等级：R2；引用展示和浏览器会话缓存不能扩大授权范围。
- 服务端只返回本次工具调用实际核验过的 `document_id`、`version`、`chunk_id`，以及允许展示的标题、片段和定位；前端不自行拼接或猜测引用。
- 会话只保存在当前浏览器标签页的 `sessionStorage`，按开发身份、家庭和成员隔离；不上传、不写入 API、日志或模型上下文之外的服务端存储，退出或清空时删除。
- 追问建议只填入输入框，用户点击发送后才进入原有聊天 API。
- 不展示完整思考链，不在前端直接调用 Ollama、数据库或向量库。

## 3. 验收条件

1. 有服务端引用时，展开项显示文档标题、版本、片段 ID、可用正文和定位；缺少正文时明确说明未返回正文。
2. 无证据、知识库不可用、模型不可用、请求失败、越权和引用校验失败分别显示可理解的降级原因，不把降级文本标成模型结论。
3. 刷新当前视图时只恢复当前身份/家庭/成员的短期会话；切换范围不会显示上一个范围的对话；点击清空会话后立即删除。
4. 点击初始问题或回答下的追问建议只填入草稿并聚焦输入框，不自动提交。
5. 前端类型检查、单元测试、生产构建和页面人工验收通过；离线、空数据和不支持语音能力时文字对话仍可用。

## 4. 实现与证据

- `src/web/src/assistant/chatSession.ts`：当前标签页会话隔离、限长、恢复和清理。
- `src/web/src/views/AssistantView.vue`：引用展开、依据状态、降级说明、清空会话和追问草稿交互。
- `src/api/app/schemas.py`、`src/api/app/tool_call.py`：引用展示字段沿用服务端已授权检索结果，不新增未经核验来源。
- `src/web/src/assistant/chatSession.test.ts`：范围隔离、清理和异常数据边界测试。

## 5. 回滚

回滚本 Story 的前端辅助模块、助手页面和引用字段即可恢复原有文字聊天；不修改健康事实、知识文档、授权、规则或模型。
