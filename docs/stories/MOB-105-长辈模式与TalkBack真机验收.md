## 用户价值

把无障碍从"代码层实现"推进到"可复现的真机验收"，确保长辈模式下字号放大不遮挡、点击目标够大、状态不靠颜色、语音可停可断。

## 范围

- 九个页面特大字号、高对比、减少动效、语音和键盘焦点的全页面走查（320px 宽度、标准/大/特大字号）；
- TalkBack 遍历记录：页面标题、按钮名称、焦点顺序、展开状态和动态提示可理解；
- 状态的三重表达（文字 + 图标 + 颜色）回归；
- 语音播报降级（无中文 TTS、首次交互限制、手动播报）验证。

## 非目标

- iOS VoiceOver 完整验收（当前 Android 优先，属 P2）；
- 新增业务功能（本 story 只做无障碍验收与缺陷修复）。

## Given / When / Then

- Given 长辈模式 + 特大字号；When 在 320px 宽度浏览九个页面；Then 无截断、重叠或不可点击区域，主导航保持四个大入口。
- Given 高对比模式开启；When 查看任一状态；Then 状态同时用文字、图标、颜色表达，不依赖颜色。
- Given 减少动效开启或系统 prefers-reduced-motion；When 触发动画；Then 全部动画停用。
- Given 无中文 TTS 或语音不可用；When 触发播报；Then 静默降级并给出引导，不阻塞核心操作。

## 测试

- 长辈模式全页面走查记录
- TalkBack 遍历记录
- 三重表达与高对比/减少动效回归
- 语音播报降级
