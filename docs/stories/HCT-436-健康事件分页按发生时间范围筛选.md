## 1. 用户价值与目标

家庭事件会持续累积，时间线查询需要能够限定业务关注的发生时间窗口。HCT-436 在 HCT-419、HCT-435 的授权安全分页、成员、事件类型和确认状态筛选之上增加 `occurred_from`、`occurred_until`，让 Owner 或有效照护者只读取指定时间范围内的事件。

## 2. 范围与非目标

本切片实现：

1. 事件分页支持开始和结束发生时间筛选，边界包含在查询范围内；
2. 下一页游标绑定家庭、成员、事件类型、确认状态和时间范围；
3. 时间范围变化、游标篡改或跨成员复用时拒绝继续翻页；
4. 开始时间晚于结束时间时返回明确的 `EVENT_TIME_RANGE_INVALID`；
5. 补充时间范围命中、游标范围、非法范围和授权边界契约测试。

不做：

- 不改变事件追加、确认、更正、投影或风险规则；
- 不把 `payload`、`evidence` 或健康正文写入游标；
- 不新增数据库字段、迁移或新的授权能力。

## 3. Given / When / Then 验收

- Given 请求者拥有成员 `READ_EVENTS`；When 指定 `occurred_from` 与 `occurred_until`；Then 只返回发生时间在闭区间内的事件。
- Given 第一页返回游标；When 家庭、成员、已有筛选和时间范围保持一致；Then 下一页不重复且仍在同一时间窗口。
- Given 任一时间边界改变、游标被篡改或跨成员复用；When 继续分页；Then 返回 `422 EVENT_CURSOR_INVALID`。
- Given 开始时间晚于结束时间；When 请求分页；Then 返回 `422 EVENT_TIME_RANGE_INVALID`。
- Given 读取授权已撤销；When 携带时间筛选查询；Then 返回 `404 RESOURCE_NOT_FOUND`。
