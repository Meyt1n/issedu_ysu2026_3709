# HCT-423 家庭六位 PIN 身份登录

- 父任务：[ #278](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/278)
- 状态：进行中
- 范围：桌面网页和本地 API；不包含移动端和人脸识别

## 用户故事

作为家庭成员，我希望选择家庭和身份后输入六位数字 PIN 登录，以便在家庭网页中查看自己被授权的健康空间。

## 验收标准

1. PIN 只能是六位数字，并按家庭 ID 与身份 ID 绑定。
2. PIN 只保存 bcrypt 哈希，接口响应、日志和浏览器持久化存储不包含明文 PIN。
3. 服务端验证身份确实属于所选家庭；跨家庭或不存在身份统一返回 `401 AUTH_FAILED`。
4. PIN 登录成功后签发与账号密码登录一致的 Bearer 会话，现有会话过期、401 清理和登出流程继续生效。
5. 同一家庭身份连续失败达到 5 次后进入现有限流窗口，返回 `429`，不泄露账号是否存在。
6. 桌面网页提供家庭 ID、身份 ID 和 PIN 输入入口，并在失败、锁定和成功状态下给出可理解的反馈。

## API 契约

- `POST /api/v1/auth/pin`：已认证身份为自己配置或替换家庭 PIN。
- `POST /api/v1/auth/pin-login`：提交 `{ household_id, actor_id, pin }`，返回 `AuthSessionRead` 和 `household_id`。

## 非目标

- 不实现人脸采集、活体检测、特征模板或摄像头权限。
- 不实现移动端页面或跨设备持久登录。
- 进程内存存储仅用于当前本地 API 原型；生产持久化、密钥轮换和分布式限流留给后续安全 Story。

## 测试与回滚

- 集成测试覆盖成功登录、家庭边界、统一失败响应和失败限流。
- 前端 API 契约测试覆盖 PIN 请求体和 Bearer 配置请求。
- 回滚时移除本 Story 的 PIN 路由、内存哈希、前端入口、测试和文档；账号密码登录与既有会话契约保持不变。
