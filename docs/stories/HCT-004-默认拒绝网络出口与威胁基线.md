# HCT-004：建立默认拒绝网络出口、威胁基线和无导流门禁

- 需求：NFR-01、NFR-02、NFR-04
- 状态：进行中
- 负责人：Shen-huang-123
- 复核人：待项目组指定，不得由实现者独立验收
- 风险：R3；涉及网络出口、威胁模型和密钥安全，失败将导致健康数据泄露或合规门禁缺失
- 依赖：HCT-001、HCT-003
- 允许修改：`src/api/app/config.py`、`src/api/app/`（新增适配器与中间件）、`src/web/src/`（前端出口调用点）、`tests/`、`.github/workflows/ci.yml`、`.gitleaks.toml`、`.pre-commit-config.yaml`、`docs/threat-model/`

## 用户价值

让"健康数据不出网"和"无购药、问诊、广告跳转"从产品承诺变为可验证的架构门禁和自动化测试——任何违反默认拒绝出口、日志泄露密钥或引入导流入口的变更都会被 CI 拦截。

## 范围与非目标

**范围：**
- STRIDE 威胁建模，覆盖提权、吊销、文件泄露、提示注入、依赖劫持、密钥泄露、备份安全
- 网络层默认拒绝出口策略，仅放行天气服务白名单
- 天气适配器请求体约束为城市/区划代码，拒绝含健康字段的外发请求
- 日志、错误、审计和 CI 输出的密钥与健康内容脱敏
- 前后端及依赖的无导流关键词扫描，纳入 CI 门禁与 pre-commit hook

**明确不做：**
- 不引入云端 LLM 回退
- 不向天气服务发送会员、健康、报告、图像、向量或对话内容
- 不替代真实认证（REAL_AUTH_REQUIRED 保持不变）
- 不修改现有业务路由的授权逻辑

## Given / When / Then

- Given 系统启动且天气适配器启用；When 后端尝试向非白名单域名发起 HTTP 请求；Then 请求被出口守卫拦截并返回 `EGRESS_BLOCKED`，记录审计日志（不含敏感正文）。
- Given 天气适配器已配置白名单；When 请求体包含成员 ID、疾病名称、药品名称或健康事件载荷；Then 适配器拒绝发送，返回 `EGRESS_CONTENT_REJECTED`。
- Given 任意代码路径输出日志或错误响应；When 输出内容匹配密钥模式（API key、token、password）或健康字段模式（report_body、ocr_text）；Then 脱敏层替换为 `<REDACTED>`，原始内容不落盘。
- Given 前后端源码或 `package.json`/`pyproject.toml` 依赖；When 关键词扫描命中购药、问诊、广告、佣金、跳转/redirect 模式；Then CI 和 pre-commit 均失败，阻止合入。
- Given CI 运行；When Secret Scan（gitleaks）、出口拦截测试、脱敏测试或无导流回归任一失败；Then PR 不得被视为可合并。

## 测试与证据

- `uv run pytest tests/ -k "egress"` — 出口拦截与天气白名单测试
- `uv run pytest tests/ -k "log_mask or secret_scan"` — 日志脱敏与密钥扫描测试
- `uv run pytest tests/ -k "no_redirect"` — 无导流关键词回归
- `.github/workflows/ci.yml` 中 secret-scan job 已存在，需补充门禁规则配置
- `gitleaks detect -v` 本地通过
- 一次威胁建模评审记录（docs/threat-model/STRIDE-v1.md）
- PR 描述附命令、环境、结果和截图

## 部署与回滚

部署随 CI 合入 master 后自动生效（门禁规则和中间件在启动时加载）。回滚步骤：
1. 关闭所有外部适配器（`WEATHER_ADAPTER=disabled`）
2. 恢复 `.env.example` 中 `WEATHER_ADAPTER=disabled`
3. 回滚威胁模型与白名单配置至上一版本
4. 本地核心功能（家庭、成员、事件、授权）不受影响

出口守卫和脱敏中间件设计为 fail-closed：配置缺失或白名单为空时默认拒绝所有出口。
