## 缺陷复现与根因

用户在「演示造数与课堂剧本」页点击「补种 / 重置演示健康数据」后看到红条「本地 API 服务不可用，本次没有改变任何数据。」。复现与排查结论（2026-08-25，本地 SQLite + uvicorn + Vite dev）：

1. 后端本身可用：`POST /api/v1/demo/formal-health-seed`（`demo-parent`）首跑 200 / 0.35s、幂等重跑 200 / 0.01s；非 demo 身份 403 `DEMO_SEED_FORBIDDEN`；`GET /api/v1/demo/classroom-scenarios` 200。种子逻辑无挂起，代理配置（Vite `HCT_API_PROXY`→127.0.0.1:8000、Nginx `/api/`→api:8000）正确。
2. 该文案只在 `ApiClientError.code === 'DEPENDENCY_UNAVAILABLE'`（fetch 抛错或超时，status 0）时出现，即浏览器层面确实拿不到任何 HTTP 响应（API/整栈中途停止、断网、隧道断开、请求超过 15s 默认超时）。
3. 但页面存在四类归因/引导缺陷，会让用户在多种非「断网」场景下也得不到正确信息：
   - `loadScenarios()` 失败把错误写进 `seedError`，剧本加载失败被显示在「造数」卡片的红条里，未点补种也会出现；
   - 标准 dev 场景「API 未启动」时 Vite 代理返回 **500 空响应体**（实测 `connect ECONNREFUSED`），Nginx 场景返回 502，二者都不会命中 `DEPENDENCY_UNAVAILABLE`，而是落入兜底文案「请求未能完成…」，既不说明 API 未启动也不给操作指引；
   - `pushToast(text, kind)` 参数顺序与 `store.ts` 的 `pushToast(kind, text)` 相反，失败 toast 只显示「error」、成功只显示「success」（`check:web` 为纯 `tsc`，不检查 `.vue`，因此未被拦截）；
   - 非 demo 身份 403 只显示通用「当前账号没有执行此操作的权限。」，没有引导改用 `demo-parent`。

## 修复内容

1. **错误分层（client.ts）**：新增网关不可用识别——502/504，以及 500/503 且响应体为空（Vite dev 代理对 ECONNREFUSED 的实测行为）归类为 `DEPENDENCY_UNAVAILABLE`；带响应体的真实后端 5xx（FastAPI 崩溃文本、JSON 业务信封）保持原分类。
2. **可操作文案（store.ts）**：`DEPENDENCY_UNAVAILABLE` 文案保留原句「本地 API 服务不可用，本次没有改变任何数据。」并追加「请确认 API 已在 8000 端口运行（本地进程 scripts/start api，或 Docker Compose 的 api 服务处于 healthy）后重试。」；既有 abort 断言按子串匹配不受影响。
3. **页面分离（DemoLabView.vue）**：剧本加载错误独立为 `scenarioError`，显示在剧本卡片并带「重新加载剧本」按钮；造数红条只反映补种结果；补种成功后自动重试剧本加载。
4. **身份引导（ui/demoLab.ts）**：403 `DEMO_SEED_FORBIDDEN` 显示「请改用 demo-parent（或其它 demo- / test- 前缀）演示身份登录后重试。API 服务本身工作正常…」。
5. **超时余量（client.ts）**：`seedFormalDemoHealth` 默认超时 30s（`DEMO_SEED_TIMEOUT_MS`，可被调用方覆盖）；种子使用固定幂等键，超时重试安全。
6. **toast 修复**：`DemoLabView.vue` 三处与 `RisksView.vue` 一处的 `pushToast` 参数顺序纠正。

## Given/When/Then 验收

- Given API 未启动（dev 代理 500 空体 / Nginx 502），When 点击补种或加载剧本，Then 显示「本地 API 服务不可用…请确认 API 已在 8000 端口运行…」而非笼统兜底文案。
- Given 非 demo/test 身份，When 点击补种，Then 显示改用 `demo-parent` 的引导且不称 API 不可用；后端仍 403。
- Given 剧本加载失败但未点补种，When 打开页面，Then 红条出现在剧本卡片（含重试按钮），造数卡片无红条。
- Given `demo-parent` 与运行中的 API，When 点击补种，Then 200、toast 显示「已补种虚构演示数据（幂等）」、报告展示 `events_touched`。
- Given 真断网 / 请求挂起超时，Then 仍归类 `DEPENDENCY_UNAVAILABLE`（status 0），既有 `route.abort` E2E 用例继续通过。
