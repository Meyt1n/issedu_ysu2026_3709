## 1. 用户价值与目标

为 HCT-202 质量门控、HCT-203 YOLO 辅助定位基线和后续 OCR 字段管线提供来源、许可、标注和分组划分均可追溯的数据输入。数据集只服务于受控的教学演示，不能被解释为任意药品识别能力或医学结论。

本 Story 的目标是交付一个可审计的 `HCT-201-dataset-v1` 数据集登记与验证闭环：每个样本有来源和用途许可，训练/验证/测试按实体或会话分组，固定集与未知集冻结并有哈希，撤销或删除能够定位到派生制品。

## 2. 范围

- 冻结 P0 的 12–20 个药品包装/非目标类别范围，以及包装对象、条码区域和 OCR 文本/字段角色的标注边界；
- 建立样本登记字段：来源、用途、许可/独立训练同意、脱敏状态、采集实体/日期/设备/会话、保存位置、保留期、删除责任人和数据版本；
- 建立标注规范、困难属性、未知/非目标样本、抽检和标注争议处理规则；
- 生成按实体/日期/设备/视频会话分组的 train/validation/test 划分，禁止相邻视频帧跨集合；
- 冻结固定评估集与未知/非目标集，记录数量、分布、访问范围和 manifest 哈希；
- 运行许可完整性、重复/近重复、PII/敏感信息和分组泄漏检查，保存可定位报告；
- 形成数据卡、删除/撤销传播记录和下一任务 HCT-202/HCT-203/后续 OCR 字段 Story 的交接说明。

## 3. 明确不做

- 不采集、提交或发送真实患者/家庭健康数据、处方/报告原图、可识别视频或未脱敏个人信息；
- 不使用网络爬取的未知许可药品图片，不把业务使用同意自动当作训练同意；
- 不在仓库提交原始图片、视频、数据集、模型权重、向量索引或含个人路径的日志；
- 不在本 Story 训练 YOLO、实现 OCR/条码或完成药品身份确认；这些属于 HCT-202/HCT-203 及后续 OCR 字段 Story；
- 不以数据集分布或标注存在宣称视觉模型已完成、可识别任意药品或可用于医疗决策。

## 4. 输入、输出与异常

### 输入

- HCT-002 的数据字典、许可/独立训练同意、脱敏、删除传播和分组划分规范；
- 仅限合成、公开许可或明确授权自采的数据元信息；如许可证据缺失，样本状态必须为 `QUARANTINED`；
- 版本化的标注类别、困难属性、数据集 manifest 和审计命令。

### 输出

- `HCT-201-dataset-v1` 的数据卡、标注规范、manifest/哈希、分组统计、泄漏检查和删除演练记录；
- `APPROVED`、`QUARANTINED`、`REVOKED` 三类样本/版本状态及对训练入口的明确约束；
- 给 HCT-202/HCT-203 的数据版本、访问方式、固定集/未知集边界和已知偏差交接记录。

### 异常处理

- 许可、独立训练同意、脱敏或来源字段缺失：隔离样本，禁止进入任何训练/评测集合；
- PII 扫描、重复/近重复或分组泄漏失败：数据集版本不得批准，修复 manifest 后重新运行全量检查；
- 删除/撤销无法传播到派生 manifest、缓存或备份：冻结数据集版本和训练入口，记录 R3 blocker；
- 固定集样本不足或类别不平衡：如实记录范围缩小和指标限制，不通过换集、删失败样本或降低门槛掩盖。

## 5. Given / When / Then 验收

- [ ] Given 每个样本均有来源、用途许可、独立训练同意和删除责任人，When 运行许可完整性审计，Then 缺项样本为 `QUARANTINED` 且不会进入训练集；
- [ ] Given 标注规范已冻结，When 对类别、包装面、关键区域、遮挡、反光、模糊和困难属性抽检，Then 结果可复核且争议有处理记录；
- [ ] Given 样本带有实体/日期/设备/会话分组键，When 生成 train/validation/test，Then 无相邻视频帧或同一分组跨集合，泄漏检查返回通过；
- [ ] Given 固定评估集和未知/非目标集已冻结，When 校验 manifest，Then 数量、分布、访问权限和哈希可复现；
- [ ] Given 发生撤销或删除，When 执行删除传播演练，Then 主清单、派生清单、缓存、困难样本入口和可控备份均被隔离/删除，并仅保留最小审计证明；
- [ ] Given 交付给 HCT-202/HCT-203，When 读取数据卡和交接记录，Then 下游能明确知道适用范围、偏差、禁止用途、版本和回滚入口。

## 9. 风险与人工复核

- 数据许可、撤销和删除传播是 R3 发布阻断项；没有证据不得进入训练或评测；
- Mendeley V3 页面声明 2,000 张、公开接口返回 1,000 个文件的数量冲突是当前 R3 阻断项；必须向来源方核实或更换来源，不能按较小返回值默认为完整数据集；
- 同一实体/视频会话泄漏会使 CV 指标失真，必须由负责人和复核人共同检查分组算法和统计；
- 类别不平衡、合成样本偏差、包装反光/遮挡与未知集不足必须进入数据卡，不得只报告最优指标；
- 数据卡、manifest 哈希、分组统计和删除演练由负责人提交，`Shen-huang-123` 在 PR 中完成跨角色 R3 复核；
- 训练模型只能作为视觉候选证据，不能绕过 OCR、条码、包装特征和人工确认。

## 10. 回滚与完成定义

回滚时将 `HCT-201-dataset-v1` 标记为不可用，撤销训练入口，恢复上一批准数据清单；对撤销样本删除或隔离所有可控派生制品，并保留最小审计证明。不得覆盖旧版本 manifest 或报告。

只有数据卡、标注规范、许可/同意、分组划分、固定/未知集、哈希、审计、删除演练、交接记录、测试和 PR 复核全部具备可定位证据，且 Issue 验收项全部成立后，才能将本 Story 从“进行中”更新为“待验收”；合并后再由维护者完成最终人工复核并进入“已验证”。
