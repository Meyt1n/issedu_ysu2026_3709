## 2. 验收条件

- 扫描雷达继续跟随现有视觉任务的 queued/running/succeeded/failed/timeout 状态（`radarStageFor` 未改动）；分析完成只进入「等待人工复核」，不显示「识别成功」；review 态出现四角锁定框，error 态使用 rose 提示。
- 扫描雷达不再引用 `/showcase/holographic-scan-stage.png`、OCR/BARCODE/YOLO 全息栈；普通页面在暖阳纸笺主题下为温暖纸感视觉。
- 健康月历只统计「事件 / 用药 / 识别」三类数量与类别标签，不读取事件 payload、药品正文或模型输出；日期摘要有 `aria-live` 文本；月格有独立 aria-label；翻月与「回到今天」可键盘操作。
- 月历数据全部来自首页已加载的 `listMemberTimeline`、`getPlanWorkbench`、`listReviewTasks` 结果，不新增 API 调用；成员选择器切换后跟随刷新。
- 启动仪式不再请求 `/boot/warm-ceremony.jpg`（该目录已删除，原先必然 404）；阶段点亮、进度条与 Esc 跳过行为不变。
- 守护光球在 idle/assistant 态有 3px 缓慢漂浮，loading/scanning/attention 态不漂浮；状态色变化有约 400ms 过渡；`prefers-reduced-motion` 下全部动画停用（沿用全局降级规则）。
- `src/web/src/ui/visuals.ts`（全部指向已删除的图片目录）与仓库根目录 7 个互相矛盾的过时过程文档（`VISUAL_REFACTOR_README.md` 等）以及服务于旧方案的 `scripts/verify_visual_refactor.sh` 已删除；`src/web/public/showcase/` 中仅剩的未引用资产不在本 Story 处理范围。

## 3. 实现边界

- 仅修改 Web Vue 组件、样式、overview 纯逻辑模块、前端测试与文档；不修改 API、数据库、权限、视觉任务状态机或模型配置。
- 月历聚合为纯函数（`healthCalendar.ts`），非法时间戳只跳过该条，不阻塞页面。
