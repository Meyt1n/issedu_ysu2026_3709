## 用户价值

本地家庭账号有可靠的密码认证、会话管理和高风险操作的二次确认——不依赖云端服务，所有尝试可审计。

## 范围与非目标

**范围：**
- bcrypt 密码哈希 + salt
- 统一登录失败提示（防账号枚举）
- 速率限制与临时锁定
- 短生命周期会话，支持登出/撤消
- PIN/QR 二次确认（短期、绑定动作+会话、单次、重放拒绝）
- QR 不含健康内容、长期密钥或可直接枚举的成员 ID
- 脱敏审计日志

**明确不做：**
- 云端身份服务（OAuth/OIDC）
- QR 作为长期凭证或健康数据载体

## Given / When / Then

- Given 用户输入错误密码多次；When 超过速率限制；Then 临时锁定，统一返回 `AUTH_FAILED`。
- Given 已登录会话；When 执行高风险操作（授权、删除）；Then 要求 PIN/QR 二次确认。
- Given PIN 已使用一次；When 重复提交同一 PIN；Then 拒绝并记录 `PIN_REPLAY`。

## 测试与证据

- 正确/错误密码、暴力破解、锁定恢复
- 会话过期/登出/撤消
- PIN 过期和重放拒绝
- 高风险 API 拒绝缺失/已用 challenge
- PR 描述附命令、环境、结果

## 部署与回滚

部署：bcrypt 依赖随 PR 合入。回滚：禁用 PIN/QR 入口，回退密码重认证，撤销未用 challenge 和活跃会话。
