# HCT-417 Web 正式登录与会话生命周期

## 1. Story

作为家庭成员，我希望网页端通过正式账号建立和撤销会话，以便在家庭切换、会话过期或授权撤销后，不继续看到旧成员和旧健康数据。

## 2. 需求与边界

- 关联 Issue：[#258](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/258)
- 依赖：HCT-107/#47 本地鉴权基线、MOB-133/#219 正式鉴权契约；本 Story 负责网页端适配，不替代后端部署级鉴权审计。
- 关联 FR：FR-01 家庭与成员、FR-08 本地证据型助手
- 关联 NFR：NFR-01 本地优先与权限边界、NFR-03 全链版本与审计、NFR-04 基础档降级可用
- 风险等级：R2（会话和身份边界）；正式部署前的持久化会话、密钥轮换、CSRF/同源策略仍是 R3 发布阻断项。
- 注册、登录、登出使用 JSON；密码不进入 URL、持久化缓存、健康事件或业务日志。
- 正式会话令牌只放在当前页面内存；Bearer 认证优先于开发用 `X-Actor-Id`。生产环境不能依赖开发身份头。

## 3. 验收条件

1. 网页可以在“正式账号登录”模式下注册或登录，登录成功后保存最小会话信息、加载家庭列表，并使用 `Authorization: Bearer` 请求业务 API。
2. 登出、会话过期、令牌撤销或任一受保护请求返回 `401` 时，清理家庭、成员、选中成员、健康摘要和本地临时会话状态，回到登录入口并显示明确原因。
3. 家庭切换继续清除旧成员和旧健康数据；前端隐藏不是权限控制，后端仍以 Bearer 身份和成员授权校验每次请求。
4. 开发演示入口明确标注为非生产模式；无效/缺失/非 Bearer 的 `Authorization` 不得回退到 `X-Actor-Id`。
5. 回归测试覆盖 JSON 载荷不泄露密码、Bearer 优先级、登出撤销、401 清理和正式/开发入口切换；测试只使用合成账号和数据。

## 4. 实现与证据

- 后端：`src/api/app/routes.py`、`src/api/app/security.py`、`src/api/app/schemas.py`。
- 前端：`src/web/src/api/client.ts`、`src/web/src/api/types.ts`、`src/web/src/store.ts`、`src/web/src/views/WelcomeView.vue`。
- 定向测试：`tests/integration/test_hct417_web_session.py`、`src/web/src/api/client.test.ts`，并补充浏览器路径测试。
- 已知限制：当前账号和会话仍为进程内存实现，服务重启会清空账号/会话；这只能用于本地演示，正式部署需接入持久化会话和审计方案。

## 5. 回滚

回滚本 PR 后，网页恢复到开发身份头入口，已有家庭、成员、事件、助手和视觉接口不改变；若正式会话的后端契约尚未部署，发布时应关闭“正式账号登录”入口而不是让前端静默回退到旧身份。
