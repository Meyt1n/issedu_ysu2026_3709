## 用户价值

让每一条药品图像、视频、文档和训练样本从采集到删除都有据可查——授权可追溯、划分可复现、删除可传播，杜绝数据泄露风险。

## 范围与非目标

**范围：**
- 数据卡模板（来源、用途、许可、敏感度、存储位置、留存期、删除负责人）
- 数据字典（现有六表字段的敏感度分级与脱敏规则）
- 标注规范（类别、属性、困难样本、冲突仲裁、两人抽检）
- 训练许可独立授权机制（可撤回，不自动继承业务授权）
- 按实体/日期/设备/会话的分组划分规则，禁止相邻视频帧跨集
- 删除传播规则（主库→文件→索引→缓存→困难样本池→可控备份，保留最低审计凭证）

**明确不做：**
- 不收集真实患者隐私数据
- 业务使用许可不得自动视为训练许可
- 不修改现有业务路由的授权逻辑

## Given / When / Then

- Given 标注人员提交一批药品图像标注；When 标注数据未附许可来源和训练同意；Then 数据不得进入训练集，标注平台拒绝入库。
- Given 视频采集会话包含连续帧；When 执行训练/验证/测试划分；Then 同一会话的所有帧落入同一集合，不存在跨集合泄露。
- Given 用户请求删除某成员数据；When 执行删除操作；Then 主库记录、关联文件、向量索引、缓存、困难样本和可控备份均在规定时间内清除，仅保留脱敏审计记录。
- Given 数据卡模板已发布；When 新数据类型接入；Then 必须填写完整数据卡并通过许可评审方可入库。

## 测试与证据

- 合成样本数据卡与许可评审记录（至少 3 个数据类型）
- 划分泄露检查脚本：按哈希和统计量验证无跨集重叠
- 删除传播桌面推演记录（表→文件→索引→缓存→样本池→备份）
- PR 描述附命令、环境、结果和链接

## 部署与回滚

数据规范文档和脚本随 PR 合入 master 生效。回滚步骤：
1. 隔离/禁用不合规数据版本
2. 撤销训练许可引用
3. 恢复上一版批准的数据卡和划分清单
