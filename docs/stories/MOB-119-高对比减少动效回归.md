## 用户价值与范围

验证三种外观（浅色/深色/跟随系统）、三档字号（标准/大/特大）、高对比度和减少动效可以自由组合；高对比下状态仍有文字、图标和边框/颜色三重表达，减少动效可以覆盖全局 CSS 动画、页面转场、数字滚动、图表生长、取景框扫描和彩带等新增动效。本 Story 不新增业务功能，不改变 API、授权、健康事实或医疗边界。

## Given / When / Then

- Given 浅色、深色或跟随系统，When 切换三档字号，Then 页面保留可读文本、布局不产生横向溢出，设置写入本机。
- Given 高对比度开启，When 查看今日、提醒、风险、任务和识别状态，Then 状态不只依赖颜色，正文/边框/焦点清晰可辨，玻璃材质和阴影降级为实色/描边。
- Given 减少动效开启，When 浏览页面或触发任务完成、图表、扫描和页面切换，Then CSS 动画/过渡时长压到约 `0.01ms`，数字滚动和彩带不执行。
- Given 高对比度与减少动效同时开启，When 切换任意外观和字号，Then 两组设置互不覆盖且页面仍可操作。

## 组合回归矩阵

| 外观 | 字号 | 高对比 | 减少动效 | 结果 |
|---|---|---|---|---|
| 浅色 | 标准/大/特大 | 开/关 | 开 | 通过：无横向溢出，状态标签存在 |
| 深色 | 标准/大/特大 | 开/关 | 开 | 通过：高对比优先显示纯白实底 |
| 跟随系统 | 标准/大/特大 | 开/关 | 开 | 通过：本地系统浅色解析为浅色，设置不丢失 |

浏览器复核还覆盖了高对比 + 特大字号 + 减少动效 + 三种外观的组合：高对比卡片为白底 2px 黑边；提醒筛选与等级标签保留文字；动画计算时长为 `1e-05s`（约 0.01ms）；页面 `body/document.scrollWidth` 未超过可视宽度。

## 状态三重表达检查

- 风险等级：`LevelTag` 输出“严重/较高/一般/提示”等文字，并保留图标、描边和等级色；高对比下标签为白底黑描边。
- 任务/识别结果：任务卡、质量检查和候选状态同时使用文字、图标和边缘/标签样式；失败和未达标状态有明确中文文案。
- 趋势与时间线：趋势图提供完整 `aria-label` 摘要，时间线用文字状态和节点/边框表达，不以颜色作为唯一信息。
- 加载/错误/成功：统一 `notice` 文案、图标和描边；高对比下去除阴影和玻璃材质。
