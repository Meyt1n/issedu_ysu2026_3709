## 用户价值与范围

让 TalkBack 用户在九个移动端页面中理解页面标题、按钮名称、焦点顺序、展开状态与动态提示。本 Story 只补齐无障碍语义、焦点管理和验收证据，不新增业务功能，不改变 API、授权、健康规则或医疗边界。

## Given / When / Then

- Given 用户从主导航或页内链接进入新路由，When 页面完成渲染，Then 焦点进入带页面名称的主区域，TalkBack 可理解当前页面。
- Given 用户点按任务卡“稍后”或“跳过”，When 面板展开，Then 控件播报展开状态且焦点进入对应区域；跳过校验失败时错误与输入关联。
- Given 拍药盒流程进入新阶段或产生结果，When 状态变化，Then 当前步骤、质量结果、识别候选和人工复核提示可被辅助技术感知。
- Given 页面出现 Toast，When TalkBack 聚焦提示，Then 可理解提示内容及“点按关闭”的操作。
