# HCT-489：网页扫描页失败可重试与人话提示

- Issue：[ #554 ](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/554)
- 绑定：FR-03、NFR-04、NFR-07
- 前置：HCT-416 Web 视觉扫描与人工复核闭环
- 状态：实现完成，待 PR/CI 与维护者人工验收
- 风险：R2；重试只重新处理原任务，不绕过质量门控、人工确认或健康记录边界

## 目标

让家庭成员在网页扫描失败或超时时，能看懂发生了什么、知道下一步怎么做，并在原页面安全地重新处理。失败提示不能要求用户理解 worker、模型路径或内部错误码；重试必须保留原图片、成员和任务上下文，避免重复创建任务。

## 实现范围

- `src/web/src/vision/visionReasons.ts` 集中维护图片读取、预处理、视频限制、识别服务不可用、超时和 worker 失败等家庭可见文案。
- `ScanView.vue` 将结构化失败转换为标题、原因和下一步建议；仅在服务端标记 `retryable` 时显示“重新处理”，并保留原任务编号用于排查。
- 失败/超时的兜底提示明确说明健康记录没有被修改，建议补拍完整、清晰的药盒正面；内部异常消息和本机路径不展示给家庭成员。
- `POST /api/v1/vision-tasks/{task_id}/retry` 继续复用既有原地重处理契约：任务 ID、文件、成员范围和复核上下文不变，不创建第二个任务。

## 验收条件

- 失败任务展示易懂的原因和下一步；不显示 `MODEL_*`、worker、模型路径或原始堆栈。
- 可重试失败显示重新处理按钮，点击后回到队列；重复操作不会产生第二个任务。
- 超时和不可用状态明确告知健康记录未修改，并提供补拍或联系家人检查本地服务的建议。
- 重试成功后仍须进入候选和人工复核，不能自动写入健康记录。

## 验证命令

```text
npm run check:web
npm run test:web
npm run test:e2e:web -- tests/browser/hct416-vision-review.spec.ts
npm run build:web
git diff --check
```

浏览器证据位于 `tests/browser/hct416-vision-review.spec.ts`：失败任务的人话提示、原地重试，以及重试后不重复创建任务均由合成 API 验证。

## 非目标与回滚

本切片不改变服务端错误码、重试资格、识别算法或人工复核规则，也不把候选结果升级为健康事实。回滚时可移除前端文案映射和展示调整，保留既有结构化错误与原地重试 API。
