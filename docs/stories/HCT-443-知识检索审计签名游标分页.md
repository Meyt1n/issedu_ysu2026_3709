# HCT-443 知识检索审计签名游标分页

- Issue：[#419](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/419)
- 关联需求：FR-08、NFR-01、NFR-02、NFR-03
- 负责角色：后端组
- 风险：R2
- 状态：实现中（待 PR、CI 和维护者复核）

## 用户故事

作为家庭照护系统维护者，我希望能够按家庭或成员范围稳定翻阅知识检索审计摘要，并且游标不能被篡改或跨操作者复用，从而在审计记录增长后仍保持可追溯性和隐私边界。

## 验收标准

- [x] 新增 `/api/v1/knowledge/query-audit/page`，支持 `limit`、`cursor`、`household_id` 和 `member_id`。
- [x] 游标使用服务端签名，并绑定 actor 与过滤条件；篡改、换 actor 或换过滤条件复用时返回 `KNOWLEDGE_AUDIT_CURSOR_INVALID`。
- [x] 分页按创建时间和审计 ID 稳定排序，不重复、不遗漏，并限制单页最多 100 条。
- [x] 分页响应只返回 HCT-442 的摘要、长度、范围、计数和时间，不返回查询原文、chunk ID 或知识正文。
- [x] 原有 `/knowledge/query-audit` 兼容接口、检索权限和降级语义保持不变。

## 实现与证据

1. 新增知识审计专用 HMAC 游标模块，游标只编码 actor、过滤范围和排序键。
2. 新增 actor-scoped 分页 API，按时间倒序返回最新审计，并使用 `limit + 1` 判断是否还有下一页。
3. 补充游标单元测试和分页契约测试，覆盖重复、过滤、跨 actor、篡改和上限校验。

## 回滚

分页接口为新增能力，回滚应用代码即可移除入口；HCT-442 的隐私摘要字段和历史脱敏迁移不受影响。
