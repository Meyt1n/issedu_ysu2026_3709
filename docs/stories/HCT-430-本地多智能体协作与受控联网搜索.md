# HCT-430：本地多智能体协作与受控联网搜索

## 任务元数据

- FR/NFR：FR-08、NFR-01、NFR-02、NFR-03、NFR-04、NFR-07
- 风险等级：R3（网络出口、健康数据边界、模型提示注入）
- 前置依赖：HCT-004、HCT-403、HCT-415
- Issue：#310
- 当前状态：已实现，待 PR 合并、维护者 R3 复核和真实环境演示验收

## 目标

为本地健康助手提供类似工作流智能体的协作体验，但不引入云端智能体或云端大模型。一次请求由本地 API 编排以下节点：

1. 本地路由智能体：确定问题类型和执行路径；
2. 本地数据库智能体：只能调用 HCT-403 已批准的授权只读工具；
3. 本地知识智能体：检索已审核的本地知识文档并绑定可核验片段；
4. 受控联网搜索智能体：仅在部署开关和本次请求两个条件同时满足时运行；
5. 本地综合智能体：通过回环地址的 Ollama 使用上述结果生成结构化回答。

“所有智能体本地运行”具体指编排、工具权限、数据库访问和 Ollama 推理均在本机 API/本机 Ollama 完成。联网搜索不是云端智能体：它是本机发起的受控外部工具请求，默认关闭，且外部结果不属于本地审核证据。

## 安全边界

- Ollama 地址必须是 `localhost`、`127.0.0.1` 或 `::1`；非回环模型地址直接降级，不允许把健康上下文发送到云端模型。
- 数据库智能体不生成 SQL，不接收模型自定义工具；只复用 `execute_whitelisted_tool`，再次校验 actor、家庭、成员、访问目的和只读范围。
- 联网搜索只接收脱敏后的用户问题；不得发送 actor/household/member ID、成员姓名、健康事件、家庭事实、药品扫描图片、OCR、报告、向量、对话上下文或数据库返回值。
- 联网搜索必须由 `AGENT_WEB_SEARCH_ENABLED=true` 和请求体 `allow_network_search=true` 双重开启；HTTPS 地址还必须命中 `AGENT_WEB_SEARCH_ALLOWED_DOMAINS`。
- 外部结果单独放在 `external_sources`，不能写入本地 `sources`/`citations`；用药安全问题即使有外部搜索结果，也仍要求本地审核知识片段，否则返回 `EVIDENCE_REQUIRED`。
- 搜索失败只影响联网搜索节点，不阻断本地数据库、知识和规则链路；模型失败、引用伪造、危险输出和非本地模型地址继续走结构化降级。
- 搜索结果页面只作为外部参考展示，不能提供购药、问诊导流或临床结论。

## 2026-08-25 增量：编排精炼与前端成熟化

在保持全部安全边界不变的前提下，对既有实现做了三类精炼：

1. **真正的条件路由**：路由结果现在会裁剪执行路径——普通问候直接由本地流程回复（不调用模型、工具或网络）；规则与证据问题在已选成员时以规则记录为准、跳过通用资料检索；紧急问题不等待外部搜索；未选成员时数据库智能体保持跳过。受控联网搜索只接收脱敏查询，因此与本地检索并行执行，数据库会话仍保持单线程。
2. **联网搜索健壮化**：搜索结果解析器容忍 DuckDuckGo 页面结构变化（标题容器、重定向链接兜底）并在页面损坏时安全降级；搜索成功但无结果时 trace 记为 `completed` 且摘要明确"未找到"；`/api/v1/assistant/agents` 新增 `web_search_ready`（部署开关与出口白名单同时满足才为 true）。默认 `AGENT_WEB_SEARCH_ENABLED=false` 不变。
3. **前端成熟化**：助手页去除假进度动画，改由响应中的真实 `agent_trace` 驱动状态；移除硬编码模型名，改为显示 API 返回的模型；流程面板默认折叠、文案产品化（"本地分析流程"、"健康参考 · 需人工确认"），不再向用户暴露"智能体/节点/Ollama"等内部术语。

对应测试：`tests/unit/test_hct430_local_agents.py`（新增路由计划、问候快速路径、解析容错、无结果 trace、目录就绪状态用例）与 `tests/contract/test_hct430_local_agents_contract.py`（新增 `web_search_ready` 契约断言）。

## 2026-08-25 增量：性能、流式体验与搜索后端抽象

1. **编排性能**：档案核对与资料检索在独立数据库会话中并行执行；用药安全问题在本地资料库无命中时提前返回 `EVIDENCE_REQUIRED`，跳过 Ollama 调用；`GENERAL` 类型默认跳过资料检索与外部搜索。
2. **流式体验**：新增 `POST /api/v1/assistant/chat/stream`（SSE），逐步推送 `trace` / `external_sources` / `token` / `done` 事件；前端助手页改走流式接口，流程进度与回答生成实时可见。
3. **搜索 Provider 抽象**：新增 `src/api/app/search_providers.py`，支持 `duckduckgo_html`（默认）与 `searxng`（`AGENT_WEB_SEARCH_PROVIDER=searxng`，URL 指向 SearXNG JSON API）；catalog 返回 `web_search_provider`。

对应测试：`tests/unit/test_hct430_search_providers.py`、用药安全提前短路与 GENERAL 路由用例、流式端点契约（`STREAM_REQUIRES_MULTI_AGENT`）。

## 配置与回滚

默认配置保持安全：

```dotenv
AGENT_ORCHESTRATION_ENABLED=true
AGENT_WEB_SEARCH_ENABLED=false
AGENT_WEB_SEARCH_PROVIDER=duckduckgo_html
AGENT_WEB_SEARCH_URL=https://html.duckduckgo.com/html/
AGENT_WEB_SEARCH_ALLOWED_DOMAINS=html.duckduckgo.com
```

演示联网搜索前，部署者显式配置搜索站点白名单；网页端每次请求仍需用户勾选“允许联网搜索”。如发现出口、隐私或模型边界问题，设置 `AGENT_WEB_SEARCH_ENABLED=false`，或将 `agent_mode` 改为 `single`，即可关闭增量能力而不删除家庭数据、事件、知识文档或审计记录。
