# HCT-403：本地健康助手工具调用与证据闭环

## 任务元数据

- FR/NFR：FR-08、NFR-03、NFR-04
- 风险等级：R3
- 前置依赖：HCT-302、HCT-401
- 当前状态：本增量实现完成，待 PR 与维护者人工复核

## 目标与边界

助手在家庭本地通过 Ollama 进行受控工具调用，先判断问题类型，再读取当前授权范围内的已确认家庭事实、成员状态、用药记录和确定性规则，必要时检索已审核本地知识文档。Ollama 不得直连数据库、向量库或外部网络，不能修改健康事实、规则或知识。

用药安全问题（例如询问阿莫西林和刚扫描的布洛芬是否能一起吃）必须同时具备用药记录工具结果和本轮已审核知识片段；缺少知识片段时返回 `EVIDENCE_REQUIRED`/受控降级，不生成用药决定。回答始终显示问题类型、来源标识和“建议咨询医生或药师”的风险提示。

## 验收条件

- [x] 白名单工具真实绑定 `get_health_events`、`get_member_state`、`get_applied_rules`、`get_risk_alerts`。
- [x] 工具读取前重复校验家庭、成员、`READ_EVENTS`、`health_events` 和访问目的；模型参数不能扩大范围。
- [x] 只返回 `CONFIRMED` 事件和 allowlist 字段，不返回原始 payload、evidence 或隐藏字段。
- [x] 用药安全问题确定性分类，并强制要求本轮已审核知识引用；引用只接受本轮检索返回的片段。
- [x] API 返回 `query_type` 与 `risk_notice`，网页显示问题类型、依据标识、可展开知识引用和专业咨询提示。
- [x] Ollama 不可用、越权、无授权知识、伪造引用和危险输出继续走结构化降级。
- [x] 单元测试覆盖真实工具绑定、确认状态过滤、字段最小化、跨成员拒绝、用药安全有/无知识两条路径。

## 风险与回滚

本增量不把 `interaction` 规则当作临床相互作用数据库；它只能作为本地规则提醒，不能单独证明药品可同服或不可同服。若 Ollama、工具授权、知识检索或引用校验异常，关闭模型回答并回退到结构化事实/规则卡。回滚本 Story 的 API/工具/UI 变更即可，不删除健康事件、知识文档或审计记录。
