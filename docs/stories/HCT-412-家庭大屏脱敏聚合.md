## 用户价值

作为家庭管理员，我需要用一次脱敏聚合请求刷新家庭大屏，以便获得事件趋势、风险数量和待处理数量，而不让浏览器按成员下载事件、风险和复核数据后自行汇总。

## 范围与非目标

- 新增仅 Owner 可读的 `GET /api/v1/households/{household_id}/dashboard-summary`，返回成员数、事件数量、七日计数、风险等级数量、待复核和待派发数量。
- 服务端以批量查询和事件关联计算，响应不包含成员名称、药品、事件 payload、证据或未确认事实。
- 后续把 Vue 大屏切换至该端点；天气继续使用现有最小化天气动作卡接口。
- 不做移动端、公共展示、照护者聚合访问、通知或医疗建议。

## Given / When / Then

- Given Owner 有一条已确认事件，When 请求家庭大屏摘要，Then 返回总数和七日计数，不返回药品名称或 payload。
- Given 照护者仅有某成员的读取授权，When 请求家庭大屏摘要，Then 返回 `404 RESOURCE_NOT_FOUND`，不能把摘要当成跨成员侧信道。
