## 1. 用户价值与目标

家庭事件时间线会同时包含用药、生命体征、提醒和照护动作。HCT-435 在已有授权安全游标分页和成员筛选基础上增加事件类型、确认状态筛选，使维护端和家庭 Owner 可以快速定位已确认或待确认的某类事件，同时保持撤权和跨成员隔离。

## 2. 范围与非目标

本切片实现：

1. Owner 或有效授权照护者可按 `event_type`、`confirmation_status` 或两者组合分页查询；
2. 下一页游标绑定家庭、成员、事件类型和确认状态查询范围；
3. 筛选条件改变、游标篡改或跨成员复用时拒绝继续翻页；
4. 补充筛选命中、游标范围、撤权与非授权边界契约测试。

不做：

- 不改变事件追加、确认、更正、投影或风险规则语义；
- 不把 `payload`、`evidence` 或健康正文写入游标；
- 不新增数据库字段、迁移或新的授权能力。

## 3. Given / When / Then 验收

- Given 请求者对成员拥有 `READ_EVENTS`；When 按 `event_type=MEDICATION`、`confirmation_status=CONFIRMED` 查询；Then 只返回同时满足条件的事件。
- Given 第一页返回游标；When 家庭、成员和两个筛选条件保持一致；Then 下一页不重复且只包含同范围事件。
- Given 任一筛选条件改变、游标被篡改或跨成员复用；When 继续分页；Then 返回 `422 EVENT_CURSOR_INVALID`。
- Given 请求者没有成员读取授权或授权已撤销；When 携带筛选参数查询；Then 返回 `404 RESOURCE_NOT_FOUND`。
