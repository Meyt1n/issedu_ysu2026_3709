## 用户价值

作为发布维护者，我需要一份可追溯的受控发布记录，能够把合成数据、服务端、PWA shell、APK、API 和设备测试对应到同一候选版本，从而在联调失败时安全回滚，而不是把本地代理成功误认成正式依赖已经可用。

## 范围

- 提供不包含真实地址或机密的受控发布记录模板。
- 校验 HTTPS、合成数据标签、种子 SHA-256、服务端/APP 提交、API/PWA/Android 版本、设备与场景证据。
- 拒绝敏感字段、占位值、明文 HTTP 和真实数据声明。
- 复用 PWA/Android 现有安全审计，记录发布、安装、升级与回滚的手工验收步骤。

## 非目标

- 不部署后端、不创建真实账号、不发布 APK、不管理签名密钥。
- 不用 mock 或开发代理冒充受控后端能力。
- 不替代 HCT-107/HCT-201/HCT-413/HCT-414 的认证、风险、模型或后端发布审批。

## Given / When / Then

- Given 受控 HTTPS 后端、合成种子和候选 APP，When 填写发布记录并校验，Then 必须能追溯服务端/APP 提交、API、PWA shell、APK、种子哈希和设备场景。
- Given 记录含 HTTP、真实数据、令牌/密码/私钥或占位符，When 执行校验，Then 失败且不产生发布通过状态。
- Given 后端能力不完整或能力探测失败，When APP 启动，Then 入口按不可用处理并显示限制。
- Given 401/403/404/409/429/5xx、断网、升级或回滚，When 执行目标设备演练，Then 只记录可恢复且无泄露的实际结果；未执行时保持 Blocked。

## 测试与证据

- 自动化：`npm run test:controlled-release`、`npm run check`、`npm run test`、`npm run audit:pwa`、`npm run audit:android-security`、`npm run build`、`npm run android:sync`。
- 手工：按 `APP/docs/MOB-147-受控发布环境运行手册.md` 执行 PWA/Android 安装、会话、授权、写回、能力、错误、离线、升级与回滚。
- 真实环境证据不可在仓库伪造；必须使用脱敏报告并关联未提交发布记录的校验输出。

## 风险

受控环境缺失 HTTPS、CORS、Android SDK/设备或后端能力时，端到端验收被阻塞。发布候选一旦版本指纹不一致，应停用该候选并恢复上一套已验证组合。

## 回滚

停用/销毁受控环境配置，恢复上一份通过校验的 PWA shell、APK、API 契约和合成种子组合。不要只回退单一客户端产物，也不要继续使用旧 shell 访问新 API。
