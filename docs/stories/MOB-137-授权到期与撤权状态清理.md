## 需求与用户价值

当家庭服务器返回授权到期、撤权、成员范围不可见或隐藏式资源拒绝时，移动端不能继续显示先前加载的成员、任务、风险、事件、视觉候选或能力快照。本 Story 让应用立即进入 fail-closed 的重新验证状态，并引导用户到“我的”重新测试连接；移动端不猜测授权是否恢复。

## 实现范围

- 在会话状态中维护仅内存存在的授权边界状态与世代号，不写入 `localStorage`。
- 将 401、403、隐藏式 404 及明确撤权/过期错误码视为授权拒绝；每次拒绝都清当前成员并改变上下文键。
- 数据 Provider 外层统一捕获授权拒绝，立即清能力快照和 Provider 内存缓存；后续数据请求被本地拒绝，直到用户显式重新测试连接成功。
- 既有页面监听的 `sessionContextKey` 因世代变化失效，迟到响应不能写回旧成员、风险、任务、事件或视觉候选。
- 在设置页展示重新验证说明；仅成功完成连接测试后恢复请求边界。
- 补充授权拒绝分类、上下文失效和成员清理单元测试。

## 非目标

- 不在客户端实现、推断或恢复任何字段授权；后端仍是唯一权威。
- 不缓存健康数据、API 响应、图片、视觉候选或撤权决定。
- 不伪造正式登录、token 刷新、撤权联调成功或 Android 真机证据。
- 不将“不可见”展示为字段空值；字段裁剪仍按服务端返回和现有 `UNAUTHORIZED` 表达处理。

## Given / When / Then

1. Given 当前授权到期或被撤回，When 任一联机 Provider 请求收到 401、403 或隐藏式 404，Then 立即清成员选择、能力快照和 Provider 内存状态，所有页面上下文键变化，并显示重新验证引导。
2. Given 用户停留在成员、今日、风险、扫描页面，When 授权被撤销后刷新、切换页面或恢复网络，Then 旧响应因上下文键失效不得写回，新的敏感请求在本地阻断直至重新验证。
3. Given 只有字段授权发生变化，When 服务端返回仍允许读取的成员详情，Then 只展示服务端保留字段；`UNAUTHORIZED` 字段显示“不可见”说明，不能显示为空值。
4. Given 身份、服务地址或访问目的变化，When 用户调整设置，Then 原 Provider 因会话键变化被丢弃，不能跨上下文复用内存状态。
5. Given 清理出现不确定状态，When 页面再次尝试加载，Then 按 fail-closed 返回重新验证引导，绝不自动恢复本地旧快照。
6. Given 用户在“我的”成功测试连接，When 健康检查通过，Then 才恢复请求边界；随后页面须重新向服务端加载当前授权范围。

## 测试用例

| 编号 | 场景 | 操作 | 预期 |
| --- | --- | --- | --- |
| MOB137-UT-01 | 401 | 传入 `UNAUTHENTICATED` 错误 | 被识别为授权拒绝 |
| MOB137-UT-02 | 403 撤权 | 传入 `CONSENT_REVOKED` 错误 | 被识别为授权拒绝 |
| MOB137-UT-03 | 隐藏式 404 | 传入 `RESOURCE_NOT_FOUND` 错误 | 被识别为授权拒绝并 fail-closed |
| MOB137-UT-04 | 网络异常 | 传入状态码 0 网络错误 | 不误判为授权恢复或撤权 |
| MOB137-UT-05 | 撤权清理 | 设置当前成员后触发边界失效 | 当前成员清空、上下文键改变、状态为重新验证 |
| MOB137-WEB-01 | 迟到响应 | 发起请求后模拟撤权再返回旧响应 | 页面不能回写成员、任务、风险或事件 |
| MOB137-WEB-02 | 字段撤权 | 服务端返回成员详情中字段为 `UNAUTHORIZED` | 显示不可见说明，不显示为空值 |
| MOB137-WEB-03 | 重新验证 | 撤权后在“我的”成功测试连接 | 请求边界恢复，页面从服务端重新加载 |
| MOB137-AND-01 | WebView | Android 真机撤权、后台恢复、弱网恢复 | 无旧敏感内容、无可用写操作，记录环境与结果 |
| MOB137-AND-02 | 多标签 | 两个浏览器标签分别加载后撤权并刷新 | 每个标签在下一次请求后 fail-closed；不依赖本地健康缓存 |

## 验收证据与回滚

- 自动化质量门：`npm run check`、`npm run test`、`npm run build`、`npm run android:sync`。
- 真实联调需要记录撤权、到期、网络恢复、后台返回和多标签/WebView 各一次的无敏感数据证据；不得记录真实健康数据、图片、token 或服务端响应正文。
- 在获得真实证据前，状态只能是“待验收”。
- 回滚方式：回退本 Story 对应提交，恢复原有会话指纹路径；不恢复、复制或持久化任何已清理的健康数据或授权快照。
