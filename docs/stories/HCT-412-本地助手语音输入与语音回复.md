# HCT-412 本地助手语音输入与语音回复

## 1. Story

作为家庭成员，我希望在本地助手页面用语音输入问题，并能按需朗读回答，以降低长辈输入和阅读的负担。

## 2. 需求与边界

- 关联 Issue：[#210](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/210)
- 依赖：HCT-411 相关追问建议已合并；本增量不修改助手回答、引用、规则和事实链路。
- 关联 FR：FR-08 本地证据型助手
- 关联 NFR：NFR-02 隐私与数据权利、NFR-04 基础档降级可用、NFR-07 可访问与可理解
- 风险等级：R3。麦克风权限和浏览器识别服务的实际处理位置可能涉及隐私。
- 语音输入使用浏览器 Speech Recognition 能力；进入助手页后自动尝试进入唤醒聆听（浏览器仍要求至少一次用户手势开麦），识别到可配置唤醒词（默认“小燕小燕”，本机可改）才进入语音输入态；静音后停麦并提示确认发送。
- 共享实现位于 `shared/voice/`，Web 通过 `src/web/src/assistant/voice.ts` 转发，避免与随身版漂移。
- 听写结束后可聆听白名单语音指令：无新输入则倒计时自动发送（可配置）；可说取消、继续说；说「发送吧」可立即发送；支持上一条再说一遍、停止朗读、重说；不解析开放域意图。
- 句末静音（2026-08-26 决策 1A）：默认连续 15 秒无新识别结果才结束听写（`SILENCE_PRESETS` 提供 1.6s/2.2s/3.0s/15s 档位）；本机偏好 v1→v2 迁移时把旧默认 2.2s 存量升级为 15s，用户自定义值保留。中途停顿续说始终累加进草稿，不覆盖（决策 2A）。
- 指令聆听期兜底（根因 B）：倒计时等待时说出非白名单语音（也不是指令前缀）会回到听写态，把这段话累加进草稿并取消自动发送倒计时，禁止丢弃；疑似指令前半句（如「上一条再说」）继续等待完整指令。
- 识别启用 `continuous` 与 `interimResults`，因此临时转写会快速写入草稿；这里的“流式”指浏览器临时文字流，不是向服务端上传原始音频流。
- HCT API 不接收、不存储、不记录原始音频，不新增 MediaRecorder、音频文件或服务端音频字段；浏览器识别服务的实际处理位置依浏览器实现而定，不能宣称为本地离线语音识别。
- 识别文字只写入草稿，倒计时自动发送、用户点击发送或说出「发送吧」后才调用既有聊天 API。
- 语音回复使用浏览器本地 `speechSynthesis`。2026-08-26 决策 3A：新增本机持久偏好「语音回复」（默认关闭）；开启后每条回答完成自动播报，播报期间不开麦回听（播完由回调恢复唤醒聆听），可随时点「停止朗读」打断。未开启时保持原「朗读回答」手动播放与白名单「再说一遍」。
- 音色（决策 6C）：默认自动优选更自然的中文女声；设置抽屉提供「播报音色」下拉（本机 `preferredVoiceName` 偏好，Web/APP 共用），`speakText` 支持按偏好或参数覆盖音色，并可试听。
- 结束回复（决策 4B）：流式回答的气泡下提供「结束回复」小按钮；点击后 abort 本次请求，保留当前已显示内容、不再输出新内容，不删除气泡（与「停止」按钮的丢弃语义并存）。

## 3. 验收条件

1. 支持语音识别的浏览器显示“开启唤醒”；用户点击后可用“小燕小燕”激活输入，唤醒前不把普通环境语音写入草稿。
2. 激活后，`interimResults` 文字在识别未结束时即可进入输入框；识别服务重启不会自动发送，权限拒绝、接口不存在或识别失败时明确提示且可继续手动输入。
3. 识别文本不会自动发送、创建健康事件或跳过用户修改；发送后复用原有 `/api/v1/assistant/chat` 请求。
4. 每条已完成的助手回答提供“朗读回答/停止朗读”；回答切换或页面离开时停止播放。
5. 语音按钮和发送按钮在桌面与移动布局中保持可辨识的一致尺寸；助手对话区按视口高度扩展，长对话仍在区内滚动。
6. 语音按钮具备键盘操作、可访问名称、按下状态和不支持能力时的安全降级；减少动效设置不影响文字流程。
7. 补充语音能力、唤醒词匹配、临时转写、异常处理和回归测试；回滚只移除语音控件，不影响文字聊天。
8. （2026-08-26 增量）句末静音默认 15 秒且可配置；听写中停顿约 10 秒后续说不结束、草稿累加；倒计时期间说非指令语音回流累加且取消倒计时。
9. （2026-08-26 增量）开启「语音回复」后回答完成自动播报、播完自动回听、期间可停止；「结束回复」保留已显示文本、不删气泡；「播报音色」下拉可改音色并即时生效。

## 4. 实现与证据

- `src/web/src/assistant/voice.ts`：浏览器能力检测、连续识别配置、转写拼接、唤醒词匹配和本地朗读封装；朗读优选更自然的中文音色（Natural/Neural 等加分、机械默认降权）、`voiceschanged` 延迟加载等待（带超时）、长回答按句分段朗读、停止/打断后旧回调失效。**实际听感受操作系统/浏览器已安装语音包限制**；演示机准备与自检见 [中文语音包与听感准备说明](../demo/中文语音包与听感准备说明.md)。
- `src/web/src/views/AssistantView.vue`：唤醒态/输入态、临时转写预览、语音输入按钮、朗读/停止按钮、权限错误和隐私提示；听说互斥（开始聆听先停止朗读、朗读前停止聆听），识别服务自动重启时把已写入草稿折叠为前缀继续追加而不覆盖。

- `src/web/src/style.css`：对话区高度、等尺寸操作按钮和唤醒波纹动画。
