# HCT-412 本地助手语音输入与语音回复

## 1. Story

作为家庭成员，我希望在本地助手页面用语音输入问题，并能按需朗读回答，以降低长辈输入和阅读的负担。

## 2. 需求与边界

- 关联 Issue：[#210](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/210)
- 依赖：HCT-411 相关追问建议已合并；本增量不修改助手回答、引用、规则和事实链路。
- 关联 FR：FR-08 本地证据型助手
- 关联 NFR：NFR-02 隐私与数据权利、NFR-04 基础档降级可用、NFR-07 可访问与可理解
- 风险等级：R3。麦克风权限和浏览器识别服务的实际处理位置可能涉及隐私。
- 语音输入使用浏览器 Speech Recognition 能力，仅将识别文字写入草稿；用户点击发送后才调用既有聊天 API。
- 不上传、不存储、不记录音频，不新增 MediaRecorder、音频文件或服务端音频字段；不把功能宣称为本地离线语音识别。
- 语音回复使用浏览器本地 `speechSynthesis`，只在用户点击“朗读回答”后播放，并支持停止。

## 3. 验收条件

1. 支持语音识别的浏览器显示“语音输入”，识别中的文字进入输入框；权限拒绝、接口不存在或识别失败时明确提示且可继续手动输入。
2. 识别文本不会自动发送、创建健康事件或跳过用户修改；发送后复用原有 `/api/v1/assistant/chat` 请求。
3. 每条已完成的助手回答提供“朗读回答/停止朗读”；回答切换或页面离开时停止播放。
4. 语音按钮具备键盘操作、可访问名称、按下状态和不支持能力时的安全降级；减少动效设置不影响文字流程。
5. 补充语音能力、转写拼接、异常处理和回归测试；回滚只移除语音控件，不影响文字聊天。

## 4. 实现与证据

- `src/web/src/assistant/voice.ts`：浏览器能力检测、转写拼接和本地朗读封装。
- `src/web/src/views/AssistantView.vue`：语音输入按钮、朗读/停止按钮、权限错误和隐私提示。
- `src/web/src/components/AppIcon.vue`：麦克风和音量图标。
- `src/web/src/assistant/voice.test.ts`：能力降级与转写拼接测试。

## 5. 回滚

回滚 PR 后，文字聊天、追问建议、健康事实、引用、权限和规则均不受影响；隐私评审未通过时可只隐藏语音输入，保留文字输入和浏览器本地朗读。
