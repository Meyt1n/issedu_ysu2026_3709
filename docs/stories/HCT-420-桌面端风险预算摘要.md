## 用户价值

作为桌面端家庭管理员或授权照护者，我需要知道当前显示的风险是否经过每日预算压制，以及使用的规则集版本，以免把“当前展示”误解为“全部命中”。

## 范围与非目标

- 在现有风险列表响应中增加 `ruleset_version`、`non_severe_budget`、`suppressed_count` 三个服务端计算字段。
- `suppressed_count` 只统计去重后、因非严重每日预算被截断的信号；严重信号仍全部保留，风险确认和指纹逻辑不变。
- 桌面风险页在存在压制信号时展示规则版本、已展示数量、预算和压制数量的受控说明。
- 不改变规则判定、不提供医疗建议、不新增移动端、不写入本地预算状态、不展示被压制信号正文。

## Given / When / Then

- Given 当前事实触发超过每日预算的普通信号，When 读取风险列表，Then 返回预算、规则版本和被压制数量，且 `total` 等于实际返回告警数。
- Given 存在严重信号，When 应用预算，Then 严重信号不计入压制数量并继续返回。
- Given 桌面风险页收到压制元数据，When 用户查看风险页，Then 看见受控提示，不把本地推算结果冒充服务端状态。
