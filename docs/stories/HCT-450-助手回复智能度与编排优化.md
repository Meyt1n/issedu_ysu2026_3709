# HCT-450：助手回复智能度与编排优化（FR-08）

- FR/NFR：FR-08、NFR-04（医疗边界）、NFR-07（可用体验）
- Issue：关联 #310 / FR-08 助手安全路由（延续 PR #426 方案 A 与 PR #446 / HCT-448；无独立 Issue 时随助手 PR 绑定说明；本任务 agent 无 issues 权限，需维护者创建后回填）
- 用户价值：用户反馈「本地助手回复还是不太聪明」——有知识卡也常撞 `EVIDENCE_REQUIRED` 墙、追问建议千篇一律、分流说明满是双通道术语、GENERAL 教学问完全用不上已审核资料、回复下方警示与元信息堆叠淹没正文。本 Story 在不动医疗硬边界的前提下，让「有回答时」的回答更聪明、更像靠谱的家庭照护助手
- 范围（五个增量）：
  1. **引用点名 + 一次补正重试**（`local_agents._synthesis_agent`）：命中知识时在 synthesis 提示词里逐条点名可引用的 `chunk_id｜资料名`，要求原样填入 `sources`；模型漏引用时追加一条确定性纠正 system 消息并重试一次，仍失败才按原有 `EVIDENCE_REQUIRED` 降级
  2. **回答结构提示**（`tool_call.ASSISTANT_SYSTEM_PROMPT`）：命中知识时先直接回应问题 → 给 2~4 条来自片段的可执行要点 → 一句自然话提醒过敏史与就医边界；多轮对话直接承接上文，不重复自我介绍与完整提醒
  3. **GENERAL 教学问可选用知识库**（`plan_agent_execution` + `_synthesis_agent`）：GENERAL 也运行本地 knowledge 检索（问候快路径不变、外部搜索仍默认跳过）；检索结果是可选增益——模型引用则绑定 citations，未引用则保持原有无引用回答，不新增失败墙；伪造引用仍 `CITATION_NOT_FOUND` 拒绝
  4. **差异化追问**（`tool_call.suggest_follow_up_questions` 增加 `query_type`/`has_citations`）：症状用药命中知识 → 过敏史/就医边界/查成员记录；未命中 → 就医时机/如何入库资料卡；GENERAL 命中 → 资料要点延伸；旧调用方关键字梯子不变
  5. **分流说明与前端元信息瘦身**（`_classifier_explanation` + `AssistantView.vue` + 新 `assistant/replyMeta.ts`）：默认单通道情形输出一句人话「已按「X」处理这个问题」；前端合并问题类型+分流说明为一行、escalate 时不再叠加同义 risk_notice、已展开引用卡的 chunk_id 不再重复罗列裸标识、confidence 翻译为中文、补上 `SYMPTOM_MEDICATION` 类型标签
- 非目标：
  - 不删除医疗边界词表、不关闭引用校验（伪造引用仍拒绝；症状用药/用药安全命中知识却引用失败在补正一次后仍如实降级）
  - 不改变 `MEDICATION_SAFETY` 无本地证据的 `EVIDENCE_REQUIRED` 硬降级 + escalate
  - 不回退 HCT-448 空库友好降级（`KNOWLEDGE_UNAVAILABLE`、escalate=false）
  - 不默认开启外网搜索或模型分类器；不改检索评分/同义词表（金标 kb-gold-025/026 已钉住感冒卡命中）
  - 不动人脸、天气、Android 等无关模块
- 风险：P1（医疗边界相邻改动；补正重试最多多一次本机推理调用；GENERAL 检索为纯本机只读、权限过滤不变）
