## 用户价值

作为家庭管理员或已授权照护者，我需要在桌面端看到服务端确认的计划待办、到期状态和最近处理记录，以便在不推断本地任务、不修改医嘱的前提下完成确认、延期或跳过。

## 范围与非目标

- 新增只读 `GET /api/v1/households/{household_id}/members/{member_id}/plan-workbench`；服务端基于已确认、未被补偿的计划和计划处理事件生成摘要。
- 返回计划、下一动作时间、`NORMAL`/`REMINDER`/`ESCALATED` 状态、最近处理和允许动作；所有读取沿用 `health_events` 的成员级 `READ_EVENTS` 授权。
- Vue 计划页改用该摘要作为待办事实源，写操作继续复用既有确认/延期/跳过接口。
- 不创建移动端界面、通知、自动停药/换药/改剂量、客户端任务缓存或医学判断。

## Given / When / Then

- Given 有一条已确认且超过默认到期时间的计划，When 授权用户读取工作台，Then 返回服务端计算的 `REMINDER` 状态、下一动作时间和三个受控动作。
- Given 授权被撤回，When 原照护者重新读取同一成员工作台，Then 返回 `404 RESOURCE_NOT_FOUND`，不泄露计划存在性。
- Given API 不可用，When 桌面页面加载失败，Then 显示不可用状态，不用旧时间线或本地缓存伪造待办。
