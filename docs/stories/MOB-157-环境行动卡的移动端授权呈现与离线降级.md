## 用户价值

作为已授权照护成员，我希望在今日页看到由家庭服务器生成的环境行动安排及其来源、生成时间、有效期和版本，以便据此安排低风险生活事项；当授权或服务证据不完整时，应用必须明确不可用，而不是用旧天气或本地猜测替代。

## 实现范围

- 新增显示专用的 `EnvironmentActionCard` 与 `EnvironmentActionState` 数据模型。
- 今日页呈现可用卡片的行动、来源、生成时间、有效期、规则/配置版本及非医疗边界。
- 演示模式只使用标注“演示”的虚构环境行动；一个未授权演示成员返回最小权限说明且无卡片。
- 联机模式先检查服务端能力快照；当前 HCT-305 契约没有成员授权绑定、来源、生成时间、有效期、规则/配置版本和去重键，因此不请求该接口，始终安全降级为不可用。
- 不缓存环境响应、健康数据或外部天气响应，不创建提醒/通知或写回操作。

## 非目标

- APP 不直连第三方天气 API，不上传位置坐标、健康正文、联系人或成员信息。
- 不生成诊断、处方、停药、换药、剂量或紧急医疗建议。
- 不在客户端创建环境行动卡、通知或去重记录。

## Given / When / Then

- Given 当前成员获授权且服务端返回带完整审计元数据的行动卡，When 打开今日页，Then 显示行动、来源、生成时间、有效期、规则/配置版本和低风险边界。
- Given 未授权环境标签、访问目的不匹配或成员级契约缺失，When 加载今日页，Then 不请求或展示环境推断，仅显示最小权限/不可用说明。
- Given 服务离线、超时、能力未声明、行动过期或响应缺少版本证据，When 刷新或恢复前台，Then 显示不可用，不把缓存结果冒充实时结论。
- Given 同一环境事件有效，When 刷新、切后台或恢复，Then 客户端不创建重复行动、提醒或通知；未来以服务端去重键和有效期为准。
- Given 行动内容含医疗相关措辞，When 渲染，Then 不接受为可展示行动，保持服务端/人工复核边界。

## 后端契约缺口

现有 `GET /api/v1/weather/action-cards` 只返回通用 `status/action_cards(level,message)`，且没有绑定家庭、成员、授权字段或访问目的。它不能证明当前成员有环境行动标签，也不能提供验收所需的 source、generated_at、valid_until、rule_version、config_version、deduplication_key。因此移动端不可调用并映射为实时成员行动卡。联调前需要 HCT-305 提供经授权的成员级受控结果契约。

## 测试与回滚

- 自动化覆盖演示可用、未授权、非医疗文案、能力缺失与契约不完整降级。
- 运行 `npm run check`、`npm run test`、`npm run build`、`npm run android:sync`。
- 手工验收需在合成城市编码、授权/未授权、离线、过期、PWA 和 Android WebView 环境执行；缺环境时保持 Blocked。
- 回滚时移除今日页行动卡入口，保留既有任务、风险与趋势功能；不得恢复客户端直接天气访问。
