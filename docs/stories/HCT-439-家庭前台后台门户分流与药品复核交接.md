# HCT-439：家庭前台/管理员后台门户分流与药品复核交接

## Story

作为一个家庭成员，我希望登录后只看到拍照录药、服药提醒和自己的已确认记录；作为家庭管理员，我希望进入后台处理成员、权限、药品复核和风险，这样长辈不需要理解后台术语，药品也不会未经确认直接进入健康档案。

## 范围

- 一个家庭继续使用同一套本地 API 和 Vue 应用，根据登录账号所属范围分为成员前台和家庭管理员后台。
- 家庭管理员由 `Household.created_by` 明确识别；家庭成员由 `Member.actor_id` 绑定识别。角色名称不能替代成员级权限判断。
- 成员前台提供：我的家庭、拍照录药、服药提醒、我的记录。
- 管理员后台保留：家庭总览、成员档案、健康计划、视觉扫描、人工复核、用药安全、健康图谱、本地助手、家庭大屏、授权、知识、模型和人脸凭证。
- 成员照片创建视觉任务后进入待识别/待复核链路；成员不能直接追加健康事件；管理员确认后才生成健康事件，成员前台只展示确认后的记录，并从服务端恢复最近任务状态。
- 管理员确认后的风险会回到成员前台，以“需要留意的情况”摘要展示；成员只能读取自己的风险，不能借此读取家庭其他成员。

## 验收标准

1. 绑定成员账号登录后，自动进入 `member-home`，侧栏只出现四个成员前台入口，后台入口不可见。
2. 管理员登录后自动进入 `overview`，管理员原有后台导航和人工复核入口可用。
3. 成员只能读取自己绑定的成员范围；读取时间线时不返回未确认记录。
4. 成员提交视觉任务只允许绑定到自己的 `member_id`；`POST /households/{id}/events` 仍需要管理员或明确的 `WRITE_EVENTS` 授权。
5. 成员前台不展示教学演示、OCR、模型版本、任务编号等后台技术信息。
6. 后台计划工作台兼容缺少可选展示字段的旧本地 Demo 响应，不因 `times` 或处理历史缺失而停留在加载态。
