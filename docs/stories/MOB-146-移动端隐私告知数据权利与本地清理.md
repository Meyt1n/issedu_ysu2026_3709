## 用户价值

用户能看懂移动端保存了什么、哪些只在内存中，并能在退出联机或换人前清理本机设置。导出、删除和撤权仍交由受控家庭网页端/服务端办理，移动端不复制健康数据，也不伪造完成状态。

## 范围

- 展示隐私告知版本、演示/联机边界、服务器地址、访问目的、拨号/相机/通知能力和本地保存清单；
- 清理 session、无障碍偏好、联系人、服务器地址、开发期身份、家庭/成员选择、能力快照、Provider/请求回执和上传运行时状态；
- 清理失败或 `localStorage` 不可用时只清理可清理的内存状态，并明确不声称持久数据已删除；
- 仅当配置的服务器地址是 HTTPS 时提供受控网页端入口；查询参数和片段被移除；
- 不清理、不导出、不伪造服务端健康事实。

## Given / When / Then

- Given 用户首次使用或隐私版本更新；When 打开本地数据管理；Then 看到适老、可读、可播报的隐私边界和保存清单。
- Given 用户确认清理本机设置；When 清理完成；Then 本地联系人、身份、服务器、成员和偏好被移除，服务端健康事实不变。
- Given 浏览器隐私模式或存储被阻断；When 用户清理；Then 返回失败提示，不声称已删除。
- Given 用户需要导出、删除或撤权；When 打开受控网页端；Then 仅跳转 HTTPS 家庭服务器根入口，不把 token、电话或健康数据拼入 URL。
