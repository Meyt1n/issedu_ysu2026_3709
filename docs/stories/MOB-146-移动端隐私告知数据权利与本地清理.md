## 用户价值

老人第一次打开应用就能听懂（可朗读）这个应用保存什么、不保存什么、相机/通知/拨号用在哪；家人随时能在"我的"看到本机数据的完整清单并一键清理；需要导出、删除、撤回健康数据时有明确的网页端办理指引，且清理本机不影响服务端事实。

## 范围

- 版本化隐私告知（`stores/privacy.ts` + `PrivacyNoticeSheet.vue`）：首次使用或版本更新时展示；内容覆盖演示/联机模式、访问目的、相机/通知/拨号能力、本机保存字段、健康数据边界；支持整篇语音朗读（适老）；确认只记录"已读版本 + 时间"；
- 本地数据管理（`stores/localData.ts` + MeView 区块）：清单区分"本机保存"（联机设置与紧急联系人、无障碍偏好、隐私确认）与"不保存"（凭据、能力快照、运行时状态、健康数据/照片）；"清理本地设置并退出联机"二次确认后执行——重置会话/能力/正式会话内存态并删除两个设置键，逐键校验结果；
- 数据权利卡片：显示当前状态（演示模式 / 联机服务器地址），说明导出、删除、撤回由 Owner 在网页端办理（服务端已提供导出清单与删除任务），移动端不复制健康数据；
- fail-closed：存储不可用、写入被拒或清理后键仍存在时，如实列出失败项，不声称已删除/已确认。

## 非目标

- 不在 APP 内直接发起导出/删除/撤回（网页端 Owner 流程）；
- 不清理或伪造服务端健康事实；
- 不把隐私确认从存储中清除（避免反复弹窗；清单中如实标注该键保留）。

## Given / When / Then

- 首次使用/版本更新 → 告知展示，可朗读，确认后不再出现（版本变更再出现）—— 浏览器验证 01 + 测试；
- 查看"我的 → 本地数据管理" → 清单区分保存/不保存，列出具体内容 —— 验证 02；
- 清理本地设置 → 二次确认 → 键被删除、回到演示模式、服务端事实不受影响 —— 验证 03（清理后两键读回为 null）；
- 清理失败（存储不可用/删除无效）→ 逐项列出失败，不声称已删除 —— 单元测试（抛错/键残留两路径）；
- 数据权利 → 当前状态 + 网页端办理引导，不在本机复制健康数据 —— 验证 02。

## 实现证据

- `APP/src/stores/privacy.ts`（版本常量、五段告知内容、确认读写、播报文本合成）、`APP/src/components/PrivacyNoticeSheet.vue`、`App.vue` 接线；
- `APP/src/stores/localData.ts`（清单 + 逐键校验清理）、`APP/src/views/MeView.vue`（本地数据管理、数据权利两区块与二次确认）；
- 联调中发现并修复一个缺陷：清理成功后 `resetSession()` 会立即把默认值重新持久化导致"清理后键仍存在"——已把内存重置调整到删键之前，浏览器验证清理后两键读回为 `null`。

测试（`APP/` 下 `npm run test`，2026-08-23 全部通过，26 files / 201 tests，新增 8 项）：
