## 用户价值

让用户听懂应用保存什么、不保存什么以及相机/通知/拨号用途；用户可以查看本机数据清单并清理本地设置。导出、删除和撤回仍由家庭 Owner 在网页端按授权办理，移动端不复制健康数据，也不伪造服务端完成状态。

## 范围

- 版本化隐私告知：首次使用或版本更新时展示，覆盖演示/联机模式、访问目的、设备能力、本机保存字段和健康数据边界；支持整篇语音播报，确认只记录版本号与时间。
- 本地数据清单与清理：`localData.ts` 区分本机持久化与仅运行时状态，清理会话和无障碍设置，逐键校验并 fail-closed；隐私确认键保留，避免重复弹窗。
- 独立 `/me/privacy` 页面：展示隐私边界、数据清单、受控 HTTPS 网页端交接和二次确认清理；“我的”页保留原有本地数据管理入口/能力，不替代服务端事实。
- 不清理、不导出、不伪造服务端健康事实；网页交接移除查询参数和片段，避免泄露 token、电话或健康数据。

## Given / When / Then

- Given 用户首次使用或隐私版本更新；When 打开应用；Then 展示适老、可读、可播报的隐私告知，确认后仅记录版本和时间。
- Given 用户查看“我的 → 本地数据管理”或 `/me/privacy`；When 查看清单；Then 明确区分本机保存、运行时状态和不保存的健康数据/照片。
- Given 用户确认清理本机设置；When 清理成功；Then 会话、联系人、服务器地址和无障碍偏好被删除，隐私确认保留，服务端健康事实不变。
- Given 存储不可用、删除失败或键仍存在；When 用户清理；Then 返回失败项，不声称已删除。
- Given 用户需要导出、删除或撤权；When 打开网页端交接；Then 仅允许 HTTPS 根入口，不把 token、电话或健康数据拼入 URL。

## 安全、隐私与回滚

- 告知确认、清理结果和日志不含健康正文；清理不触碰服务端事实。
- 回滚本 PR 即移除独立隐私页和入口，保留既有版本化告知、本地清单与服务端隐私边界；不涉及数据库、模型或健康事件。
