# HCT-451：开放对话演示模式（评估本机模型真实回复）

> **2026-08-27 收敛（[ADR-0007](../decisions/0007-助手统一安全策略与受控开放联网.md) 决策 8C）：** `AGENT_OPEN_CHAT` 收敛为**体验项 only**——保留注入本机时间、提高 token 下限、非 JSON 草稿尽力放行；**不再豁免**证据/引用处理、医疗边界与外链检查（现全环境统一为句级黑名单 + 尾注 + 风险说明，剂量硬拒不受任何模式影响）。`OPEN_CHAT_SYSTEM_PROMPT` 废弃，统一使用 `ASSISTANT_SYSTEM_PROMPT`。因不再绕过安全，生产环境不再强制 `AGENT_OPEN_CHAT=false`（config 门禁已修订）。回归见 `tests/unit/test_hct451_open_chat.py::test_open_chat_no_longer_bypasses_safety_sanitisation`。

- FR/NFR：FR-08（体验）、NFR-04（边界可开关）、NFR-07
- 用户价值：演示/联调时助手不再被证据墙、空库季节模板、外链拦截打断；可看本机 LLM 真实回答质量，并正确回答日期；腹泻类问题不再串「空调鼻塞」模板
- 范围：
  - `AGENT_OPEN_CHAT`（**本地默认 true**；见 [助手开放演示模式](../助手开放演示模式.md)）：跳过 citation/证据硬墙、医疗边界与外链拦截、症状空库短接模板；注入本机时间；提高 `max_tokens` 下限；非 JSON 草稿尽力放行
  - 单元测试经 `tests/conftest.py` 自动关闭开放模式，保留硬墙回归
  - 生产环境强制 `AGENT_OPEN_CHAT=false`
  - 关闭开放模式时：腹泻等空库友好回答按主题选照护句，避免串夏季节鼻塞文案
- 非目标：不把开放模式当作正式医疗安全默认；不默认外发家庭健康字段
- 风险：R3（开放模式关闭了教学证据墙；仅用于本机演示评估）
- 回滚：`AGENT_OPEN_CHAT=false` 立即恢复硬墙；或 revert 本 PR
- 状态：本分支落地
