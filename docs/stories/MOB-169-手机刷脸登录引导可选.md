## 用户价值

网页成员前台已把人脸作为登录选项之一（HCT-425），移动端目前只有账号密码与家庭 PIN。**本 Story 为可选项**：只有在阈值现场标定（HCT-505）通过、并确认教学演示级定位可接受后才启动；启动后也只做「引导 + 降级」，不把人脸作为唯一或默认登录方式。

## 范围

- 刷脸登录的引导页：适用条件、教学演示级定位声明、失败后的替代方式。
- 与家庭 PIN、账号密码的关系：人脸始终是可选加速项，不得成为唯一入口。
- 识别失败的可教学反馈桶（光线、角度、遮挡、超时），复用服务端返回的失败分类。
- 拒绝授权摄像头、设备不支持、阈值未标定三种情况的 fail-closed 处理。

## 非目标

- 不声称生产级生物识别，不用于任何安全关键判定。
- 不在本机保存人脸图像或特征；不做本地比对。
- 阈值标定未完成前不得启用本入口（依赖 HCT-505）。
- 不做活体检测或反欺骗声明。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 阈值未完成现场标定，When 打开登录页，Then 不展示刷脸入口，或展示为不可用并说明原因。
2. Given 用户拒绝摄像头权限或设备不支持，When 尝试刷脸，Then fail-closed 回到家庭 PIN/账号密码，不反复索权。
3. Given 识别失败，When 返回结果，Then 展示服务端给出的可教学失败分类与重试建议，不暴露阈值或比分细节。
4. Given 刷脸成功，When 建立会话，Then 会话生命周期与授权判定与既有正式鉴权完全一致，不获得额外权限。
5. Given 引导页展示，When 阅读说明，Then 明确写出「教学演示级、非生产级生物识别、可随时改用其它方式」。

## 安全、隐私与回滚

- 人脸图像仅即时用于服务端校验，APP 不落盘、不缓存、不上传第三方。
- 人脸不得成为唯一登录方式；任何时候都能改用 PIN 或账号密码。
- 全部授权判定仍由服务端完成，刷脸不改变任何权限边界。
- 回滚：移除刷脸入口，登录退回家庭 PIN 与账号密码，无数据残留需清理。
