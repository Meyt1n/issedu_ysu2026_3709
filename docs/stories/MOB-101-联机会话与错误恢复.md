## 用户价值

把联机模式从"可以联调"提升为"异常可解释、状态可恢复"：老人在弱网、家庭切换、授权不足或服务不可达时，能看到诚实、清晰、不误导的提示，而不是空白页或伪造成功。

## 范围

- 统一家庭服务器连接、身份缺失、网络异常、家庭切换和授权不足的状态表现；
- API 错误码到用户文案的映射（401/403/404/409/422、网络失败），均不误导；
- 后端能力探测：联机入口显示服务可用性与能力限制，不把未提供接口包装成可用功能；
- 会话边界：网络失败或授权变化时清理遗留家庭数据，不残留旧数据。

## 非目标

- 正式鉴权落地（依赖主仓库 HCT-107，本 story 只做适配设计与测试桩）；
- 健康数据的采集、上传或缓存（仍遵循数据不出网承诺）。

## Given / When / Then

- Given 联机模式未填写身份或家庭为空；When 进入联机入口；Then 显示明确的引导提示，不进入空数据页面。
- Given 服务不可达或网络失败；When 请求家庭/成员数据；Then 显示可恢复的错误提示与重试入口，不残留旧家庭数据。
- Given 返回 401/403；When 加载成员或事件；Then 提示身份失效或授权不足，并引导回到身份配置，不以空数据伪装。
- Given 后端未提供某接口（如风险"我已知晓"回写）；When 进入对应功能；Then 如实显示"当前无法使用"，不包装成可用。
