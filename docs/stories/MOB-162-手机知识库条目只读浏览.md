## 用户价值

服务端已提供 `GET /knowledge/documents/{id}` 只读详情与分块（HCT-401），网页端能点开查看，移动端只能看到助手引用的片段、无法完整阅读来源条目。补一个只读的知识库浏览入口，让用户能顺着引用读完整条目并看清版本与来源。

## 范围

- 知识条目列表与详情的只读展示：标题、来源、批准状态、索引版本、分块正文。
- 从助手回复的引用一键跳到对应条目并定位到被引用的分块。
- 非 steward 身份的 403 显式引导，与未批准/staging 条目的不可见处理。
- 长文本在窄屏与特大字号下的阅读体验（分块折叠、回到顶部）。

## 非目标

- 不提供任何写操作：不抓取、不审核、不晋升、不入库、不编辑。
- 不在移动端暴露 staging 草稿或未批准内容。
- 不改服务端知识权限与前置过滤（属 HCT-401）。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 已授权身份，When 打开知识条目详情，Then 展示正文分块、来源、批准状态与索引版本。
2. Given 条目未批准或仍在 staging，When 尝试访问，Then 移动端不展示正文，仅说明该条目当前不可查看。
3. Given 非 steward 身份访问受限接口，When 请求，Then 显示服务端返回的 403 引导文案，不暴露条目是否存在。
4. Given 助手回复带引用，When 点击引用，Then 跳到该条目并高亮对应分块，版本与助手回答所用版本一致。
5. Given 服务端知识服务不可用，When 打开入口，Then 显示可恢复错误并保留助手其余功能。

## 安全、隐私与回滚

- 只读；APP 不具备任何知识写入路径。
- 不缓存未批准内容；本机不落盘知识正文。
- 展示的版本必须与助手引用所用索引版本一致，避免版本二义。
- 回滚：隐藏知识浏览入口，助手引用仍以片段形式呈现。

## 实现与验证证据

- `APP/src/api/`：新增 `KnowledgeDocumentSummaryResponse`、`KnowledgeDocumentDetailResponse`、`KnowledgeChunkResponse` 契约，与 `ApiClient.listKnowledgeDocuments()`、`ApiClient.getKnowledgeDocument()` 两个只读方法；没有新增任何知识写入方法。
- `APP/src/data/`：`DataProvider` 增加 `listKnowledgeDocuments()` 与 `getKnowledgeDocument()`。`httpProvider` 只做字段映射，权限与批准过滤完全交给服务端；**只有 `status === 'active'` 才把分块正文带回界面**（验收 2），其它状态只保留元信息。`demoProvider` 新增两条虚构条目，其中一条固定为 `staging` 用于走查不可查看路径。
- 新增 `APP/src/views/KnowledgeLibraryView.vue`（路由 `/knowledge`）与 `APP/src/views/KnowledgeDocumentView.vue`（路由 `/knowledge/:docId`）：详情页展示标题、来源、许可、批准状态、索引版本、生效区间与分块正文（验收 1），未批准时改为「该条目当前不可查看」说明而不渲染正文；长正文支持逐块/全部收起与展开，并提供避开底部导航的「回到顶部」操作。
- 助手引用跳转（验收 4）：`AssistantEvidencePanel.vue` 的引用卡片改为 `RouterLink`，跳转时带上 `chunk` 与 `version` 查询参数；详情页据此高亮并滚动定位到被引用分块，并在服务端当前版本与助手所用版本不一致时用 `role="alert"` 显式告警，避免版本二义。引用的分块已不在当前版本时给出说明而非静默忽略。
- 错误路径（验收 3、5）：两页都复用 `presentListApiError()` 与 `ErrorNotice`，服务端 403/404 文案原样透出，不在客户端推断条目是否存在；知识服务不可用只影响本页，助手对话页不受影响，可重试。
- 入口：「我的」页新增只读入口，文案明确「只读」。
- `cd APP && npm run check` 通过；`npm run test -- --reporter=dot` 通过（39 个测试文件、356 项，其中知识条目相关回归覆盖权限过滤、版本告警和引用定位）；`npm run build`、`npm run privacy:scan`、`git diff --check` 通过；390×844 PWA 烟测覆盖全部折叠/展开、单块切换与回到顶部。
- [MOB-162 手机知识条目只读验收记录](../testing/MOB-162-手机知识条目只读验收记录.md)：记录荣耀 AAP-AN00 入口/列表/详情烟测、演示 staging 过滤、PWA 长正文交互和 APK 重建限制。
