## 用户价值

服务端已提供 `GET /knowledge/documents/{id}` 只读详情与分块（HCT-401），网页端能点开查看，移动端只能看到助手引用的片段、无法完整阅读来源条目。补一个只读的知识库浏览入口，让用户能顺着引用读完整条目并看清版本与来源。

## 范围

- 知识条目列表与详情的只读展示：标题、来源、批准状态、索引版本、分块正文。
- 从助手回复的引用一键跳到对应条目并定位到被引用的分块。
- 非 steward 身份的 403 显式引导，与未批准/staging 条目的不可见处理。
- 长文本在窄屏与特大字号下的阅读体验（分块折叠、回到顶部）。

## 非目标

- 不提供任何写操作：不抓取、不审核、不晋升、不入库、不编辑。
- 不在移动端暴露 staging 草稿或未批准内容。
- 不改服务端知识权限与前置过滤（属 HCT-401）。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 已授权身份，When 打开知识条目详情，Then 展示正文分块、来源、批准状态与索引版本。
2. Given 条目未批准或仍在 staging，When 尝试访问，Then 移动端不展示正文，仅说明该条目当前不可查看。
3. Given 非 steward 身份访问受限接口，When 请求，Then 显示服务端返回的 403 引导文案，不暴露条目是否存在。
4. Given 助手回复带引用，When 点击引用，Then 跳到该条目并高亮对应分块，版本与助手回答所用版本一致。
5. Given 服务端知识服务不可用，When 打开入口，Then 显示可恢复错误并保留助手其余功能。

## 安全、隐私与回滚

- 只读；APP 不具备任何知识写入路径。
- 不缓存未批准内容；本机不落盘知识正文。
- 展示的版本必须与助手引用所用索引版本一致，避免版本二义。
- 回滚：隐藏知识浏览入口，助手引用仍以片段形式呈现。
