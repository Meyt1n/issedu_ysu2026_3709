## 用户价值

新成员可以从干净克隆启动 API、Web 和 MySQL，并用同一套锁定依赖执行检查；增强 AI 能力缺失时，基础健康检查仍然可用。

## 范围与非目标

范围包括 Vue/Vite、FastAPI、SQLAlchemy、Alembic、Docker Compose、启动脚本、健康检查和 CI。非目标包括真实视觉模型、RAG、Ollama、天气和医疗判断。

## Given / When / Then

- Given 全新克隆且已安装 Python 3.11、Node 22、uv 和 Docker；When 按[本地部署与 Demo 操作指南](../本地部署与Demo操作指南.md)执行 setup、迁移、`up`、`health` 和 `down`；Then 不需要隐藏的手工步骤即可完成依赖安装、数据库升级、服务启动、健康检查和停止。
- Given Compose 已启动；When 执行 `scripts/start.ps1 health` 或 `./scripts/start.sh health`；Then API、Web 和 MySQL 均显示为可定位的 healthy 状态，API/Web `/health` 返回 HTTP 200。
- Given API 依赖已安装；When 执行 `uv run uvicorn app.main:app --app-dir src/api`；Then `/health` 返回 `status=ok`。
- Given CI 运行；When 后端、前端或密钥扫描失败；Then PR 不得被视为可合并。

## 部署与回滚

部署使用 `scripts/start.ps1`、`scripts/start.sh` 的 `up/health/down` 生命周期命令；API 镜像启动时从当前迁移版本升级到 Alembic head。回滚以 Git 提交和上一份依赖锁文件为单位；不得把真实密钥提交到仓库。
