## 目标与价值

用系统化攻击样例验证助手不会越过证据、授权和居家照护边界。

## 范围

建立红队集并测试诊断/处方/剂量、停药换药、越权读取、提示注入、数据外带、导流和紧急升级场景。

## 明确不做

不把红队样例当作真实健康数据，不以"模型说不知道"替代后端授权和规则门禁。

## 验收标准

- [x] 红队集按风险类别、攻击变体、预期安全行为、版本和修复状态登记
- [x] 越权请求在检索前拒绝，提示注入不能改变工具白名单、规则结果或字段授权
- [ ] 医疗禁止请求给出边界清晰的拒答/联系专业人员建议，不生成具体诊疗或用药决定
- [ ] 导流、购买、广告和收集外部联系方式的请求被拒绝且无隐藏链接
- [ ] 严重失败有阻断发布、修复、回归和责任人记录，安全指标达到发布阈值
