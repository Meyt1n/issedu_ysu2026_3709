# HCT-534：卡片透明花纹、大屏氛围优化与桌宠快捷入口

## 1. 范围

- FR/NFR：FR-09（家庭/模型大屏展示）、FR-08 入口体验（助手快捷入口）、NFR-02（不展示敏感正文）、NFR-04（基础档可降级）、NFR-07（可访问与可理解）。
- 关联：本地前端展示层；Issue 由维护者创建后回填。承接 [HCT-533](HCT-533-展演并入普通模式与卡片纹理统一.md) 的浏览器复核反馈。
- 目标：纯表现层与全局陪伴入口，不新增业务能力：
  1. 卡片背景弃用位图（`glass-panel-texture.png` 自带撕边与透明外框，任何平铺方式都无法贴满卡片），改为纯 CSS 无缝透明植物花纹（内联 SVG data-URI）；
  2. 大屏氛围优化（twin 区块响应式、沙盘炊烟与萤火、回溯基线光）；
  3. 桌宠（GuardianPet v3）：角色化陪伴小精灵，作为 AI 聊天等功能的快捷入口。

## 2. 验收条件

### 卡片透明花纹

- 全部卡片背景层不再引用任何位图；花纹为 148×148 无缝 SVG 平铺（暖墨描叶 + 浆果点，全透明底），配合暖米色半透底与对角晕染，纹理在卡片边缘与中心完全一致，不存在图片边界。
- 覆盖面：`--card-texture` 令牌（`.card`、`.home-dashboard-card`、`.bs-tile`、`.bs-panel`、`.bs-member-chip`、天气面板、沙盘）、暖阳纸笺装饰层的 `:is(...)` 卡片组、`.home-dashboard-card` 专属规则、`.graph-stage`、助手主区。
- `glass-panel-texture.png` 删除；`src/web/public/showcase/` 仅剩 `health-matrix-rain.png` 与 `ambient-border.png`（页面点缀仍在用）。
- 简洁主题仍为纯白无纹理。

### 大屏氛围

- `bs-twin-row`/`bs-twin-grid` 在 ≤1050px 折为单列，窄屏不再挤压。
- 家庭沙盘：烟囱炊烟循环升起消散、视口内四枚暖金萤火游移；`prefers-reduced-motion` 下静止。
- 时间回溯柱条底部增加基线光。

### 桌宠（AI 聊天快捷入口）

- 登录后常驻右下角；角色为暖色小精灵 SVG（新芽、腮红、眨眼、状态表情）。
- 状态沿用 `guardianStateFor` 真实映射：idle 漂浮眨眼、loading 新芽摇摆、scanning 快速摇摆、assistant 眯眼+腮红、attention 眯眼+叹气滴+状态点闪烁、offline 闭眼。
- 情境气泡：按小时段轮播问候与隐私提示；attention 时提示「有 N 条识别候选等你复核，不会自动入档」；offline 提示服务离线；进入页面 4 秒后首次打招呼；hover 立即显示；`aria-live="polite"`。
- 快捷菜单（点击打开，Esc 关闭）：打开健康助手、回到首页（成员）或家庭总览（管理员）、扫描药盒（仅管理员）、待人工复核（仅在有候选时显示，带数量徽标）、摸摸头。菜单底注「视觉陪伴 · 不做健康判断」。
- 摸摸头：爱心粒子上升 + toast 提醒陪伴边界。
- 拖拽重位：pointer 拖动超过 6px 视为拖拽（与点击区分），位置 clamp 在视口内并记忆到 `localStorage`（`hct:pet-pos`），窗口缩放时自动回夹。
- 键盘可用：主按钮 `aria-haspopup`/`aria-expanded`，菜单项为按钮，Esc 关闭；`prefers-reduced-motion` 下漂浮/眨眼/爱心动画停用。

## 3. 实现边界

- 仅修改 Web Vue 组件、样式与文档；不修改 API、数据库、权限或健康事件状态机。
- 桌宠不读取健康正文，只使用 `session` 中已有的聚合信号（待复核数、能力在线、路由）；不输出诊断/用药建议。
- 旧桌宠全局 CSS 块（约 77 行）删除，新桌宠样式全部 scoped。

## 4. 回滚与风险

- 回滚：还原 `GuardianPet.vue`、`style.css`（令牌与装饰层）；删除 `HealthCalendar` 无涉。PNG 不可恢复（已由 Story 记录废弃）。
- 风险：SVG data-URI 在极老浏览器不支持 data-URI background 的场景退化为无花纹纯色底，可接受；桌宠拖拽在触屏由 pointer events 覆盖，`touch-action: none` 只作用于按钮本身。
- 本 Story 不证明真实视觉识别、AI 推理、健康风险判断或隐私 R3 验收已经完成。
