- 关联需求：FR-02、FR-04、FR-06；NFR-03、NFR-06

## 验收标准

- [x] 移动端写入的虚构事件可以通过网页端时间线读取。
- [x] 只读照护者不能提交网页复核结果；owner 在授权范围内确认计划后，移动端以照护者身份重新读取可以看到 `plan_confirmed` 事件。
- [x] 造数和验证入口可重复执行，数据使用固定的“演示家庭（联调）”和幂等事件键，不包含真实健康信息。
- [x] 两端使用同一组接口路径、事件类型和授权请求头：`/api/v1/households/{household_id}/members/{member_id}/timeline`、`plan_confirmed`、`X-Actor-Id`、`X-Access-Purpose`。

## 实现

- `APP/scripts/seed-live-demo.mjs`：创建可重复使用的虚构家庭、成员、过敏、用药、计划和只读照护者授权。
- `APP/scripts/verify-web-linkage.mjs`：检查后端健康状态、网页端读取移动端写入事件、授权拒绝越权复核、owner 网页复核以及照护者移动端回读。
- `APP/package.json`：增加 `npm run verify:linkage` 入口。

## 验证命令

先启动主仓库 FastAPI（默认 `http://127.0.0.1:18800`），然后在 `APP/` 执行：

```text
npm run seed:live -- --base http://127.0.0.1:18800
npm run verify:linkage -- --base http://127.0.0.1:18800
npm run check
npm run test
npm run build
```

脚本失败时返回非零退出码，并打印具体的接口、状态码或验收断言，便于 CI/教学演示定位。脚本只读写演示数据；回滚时删除本分支和 Story，不触碰真实家庭数据。
