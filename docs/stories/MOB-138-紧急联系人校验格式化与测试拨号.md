## 用户价值

联系人号码离开输入框时得到可理解的校验和规范化结果；求助页、风险详情和测试拨号始终读取最新的本地会话值，并在系统电话能力不可用时给出可恢复提示。

## 范围

- 支持常见空格、短横线、括号、`00` 国际前缀和本地数字格式；拒绝 URL scheme、控制字符和异常长度；
- 联系人称呼限制长度并拒绝控制字符，允许清空联系人以关闭联系人拨号入口；
- 联系人号码只写入本机设置，不进入 API 请求、健康事件、日志或通知；
- 求助页、风险详情和测试拨号统一使用规范化号码，并保留拨号前二次确认；
- 测试拨号只请求系统 `tel:` 拨号界面，不自动拨出；PWA/设备未接管时展示手动拨号降级提示。

## Given / When / Then

- Given 用户输入带分隔符的本地或国际号码；When 离开输入框；Then 保存规范化号码并显示可拨号状态。
- Given 用户输入 scheme、控制字符或异常长度；When 保存或测试拨号；Then 显示校验错误，号码不得进入 `tel:` 链接。
- Given 用户修改或清空号码；When 打开求助页或风险详情；Then 页面立即使用最新值，旧号码不残留。
- Given 用户点击测试拨号；When 再次确认；Then 只打开系统拨号界面，并在 PWA/设备不支持时提示手动拨号。
