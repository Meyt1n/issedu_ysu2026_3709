# HCT-444：首页健康新闻与助手跳转

- FR/NFR：FR-08（本地证据型助手）、NFR-02（本地优先）
- 用户价值：首页主动展示换季/季节照护提醒；一点即带着问题进入本地助手
- 范围：`GET /api/v1/health-news` 日历型教学新闻；成员首页与家庭总览常驻卡片；点击写入助手种子问题并跳转 `assistant`；成员端可进入共享助手视图
- 非目标：不编造实时疫情病毒名/病例数；不把新闻当诊断；不默认外发健康数据
- 风险：P2（展示与导航）
- 允许修改：`src/api/app/health_news.py`、`routes.py`、`src/web` 首页/助手/store/API、本 Story、单测
- 验收：Given 已登录首页，When 打开成员首页或总览，Then 看到季节健康新闻；When 点击条目，Then 进入助手并带上 chat_prompt
- 回滚：删除端点与面板，恢复 MEMBER_VIEWS 门禁即可
- 状态：本 PR 落地
- 视觉增量（2026-09-02）：本地秋季目录扩展为 6 条互不重复的照护卡片；另增加 6 张明亮的远程资讯编辑插画。两类卡片均采用整卡铺底图 + DOM 文字遮罩，图片使用 `cover` 裁剪且不使用懒加载，避免卡片露白。
- 视觉素材：`src/web/public/seasonal-art/`、`src/web/public/news-art/`；卡片绑定与本地/远程素材隔离：`src/web/src/healthNews/healthNewsVisuals.ts`
