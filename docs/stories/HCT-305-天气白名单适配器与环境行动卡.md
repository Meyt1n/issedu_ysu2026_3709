## 用户价值

基于 HCT-004 出口守卫基础设施，对接真实天气服务，为家庭照护生成环境行动卡——天气不可用时自动降级，不阻塞核心链路。

## 范围与非目标

**范围：**
- 真实天气 API 对接（基于 weather_adapter.py 白名单出口）
- 环境行动卡生成逻辑
- 降级策略（超时/错误 → 空行动卡）
- 仅传城市/区划代码，不含健康数据

**明确不做：**
- 不修改用药建议
- 不向天气服务发送健康数据

## Given / When / Then

- Given 天气 API 可用；When 请求城市天气；Then 返回行动卡（如高温提醒、空气质量提醒）。
- Given 天气 API 超时或不可用；When 请求天气；Then 返回空行动卡，不抛异常。
- Given 请求体含健康字段；When 出口守卫校验；Then 拒绝发送。

## 测试与证据

- 天气 API 正常响应 → 行动卡解析
- 超时降级
- 健康字段拒绝
- 日志脱敏验证
