## 用户价值

家庭可以在正式 Vue 总览中直接看到公开天气产生的低风险生活行动卡，同时明确知道数据来源时间、位置粒度、规则版本和是否使用旧缓存。天气服务不可用时，页面不会伪造实时数据，也不会阻塞本地健康事实、规则和任务。

## 范围与非目标

### 范围

- 仅允许配置白名单中的 6 位城市/区县行政区划代码出网，拒绝经纬度、精确地址和任意健康字段。
- 对外部响应做严格类型、范围、长度和时间格式校验，忽略未批准字段。
- 最多三次（默认两次）受控重试；429 不重试；通过最小请求间隔和 TTL 缓存限制出口频率。
- 天气超时、5xx 或完全离线时优先展示最后有效缓存，并明确标记 `stale`；无缓存时展示不可用状态。
- 使用人工审核、版本化的确定性规则生成高温、低温、雨雪、高湿和 AQI 行动卡。
- 在家庭总览显著展示行动卡，在家庭大屏同步展示正常/缓存/不可用状态。
- 当 `WEATHER_PROVIDER=uapis` 时，仅使用已校验的 `adcode` 请求，并将提供方天气、风力和本地时间归一化为内部响应契约；默认 `generic` 行为保持不变。
- 行动卡默认突出天气、指标、更新时间和生活提醒；规则版本等实现信息保留在辅助文本中，不占用主要视觉空间。

### 明确不做

- 不发送成员 ID、姓名、病史、药品、报告、图片、向量、对话或精确住址。
- 不根据成员健康事实个性化天气建议，不生成诊断、治疗、停换药或剂量建议。
- 不把天气数据写入正式健康事件、风险计算或药物计划。
- 不在仓库中提交天气密钥；真实提供方 URL、域名和位置代码只通过部署环境配置。
- 本增量使用进程内缓存，不承诺跨实例共享或重启后保留；多实例共享缓存属于后续基础设施任务。

## Given / When / Then

- Given 天气出口关闭；When 用户进入家庭总览；Then 页面显示“天气出口未启用”，且不发送网络请求、不影响本地功能。
- Given 天气出口已启用但位置代码未进入白名单；When 请求天气；Then 后端返回 `location_not_allowed`，且不会创建外部 HTTP 客户端。
- Given 外部服务返回合法天气；When 请求获批城市/区县；Then 仅外发位置代码，返回来源时间、位置粒度、规则版本、免责声明和确定性行动卡。
- Given 相同位置仍在缓存有效期；When 页面自动或手工刷新；Then 返回 `cache_status=fresh`，不重复访问外部服务。
- Given 外部服务超时或 5xx 且存在最后有效缓存；When 请求天气；Then 返回 `status=stale` 和降级原因，前端继续展示旧卡并标明缓存状态。
- Given 外部服务返回 429；When 适配器请求天气；Then 不重试，返回限速/旧缓存状态。
- Given 外部服务返回字符串温度、越界湿度或非对象 JSON；When 响应校验；Then 返回 `invalid_response`，不生成虚假天气和行动卡。
- Given 前端收到正常、旧缓存、未启用或不可用状态；When 渲染总览；Then 文字、图标和颜色共同表达状态，并提供刷新、来源、范围、规则版本和非医疗声明。

## 安全、隐私与人工复核

- 外发字段固定为 `city_code`/`district_code`；经纬度和未知字段由出口守卫拒绝。
- API 响应只公开“城市级/区县级”粒度，不回显位置代码；Vue 使用文本插值，不执行提供方 HTML。
- 日志只记录状态、尝试次数和位置粒度，不记录健康正文、位置代码或提供方响应正文。
- 行动卡来自 `weather-actions-v1` 确定性规则，不调用 LLM；合并动作代表维护者完成人工文案与网络出口复核。
