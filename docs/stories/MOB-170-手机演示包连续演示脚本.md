## 用户价值

后端已有双门户连续演示与演示造数（HCT-405、HCT-499），网页端能按剧本走完，移动端还没有对应的演示包与脚本。补一份可复现的移动端连续演示：从演示造数到首页健康资讯、再到助手问答，全程用虚构数据、不依赖外网。

## 范围

- 移动端演示包：固定版本的 APK/PWA 产物 + 演示身份 + 演示家庭的一键就绪步骤。
- 连续演示脚本：进入 → 首页健康资讯 → 点资讯进助手 → 追问并看引用 → 回到今日任务，逐步给出预期界面。
- 离线/弱网兜底：外网不可用时脚本仍能走完（用离线教学夹具）。
- 脚本自检清单与失败时的回退话术。

## 非目标

- 不使用任何真实成员、真实药品或真实健康数据。
- 不依赖真实外网抓取；资讯与知识一律用教学夹具。
- 不做录屏自动化或 CI 化演示（本 Story 只交付可人工复现的脚本与包）。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 干净设备与演示包，When 按脚本第一步执行，Then 在不接外网的前提下进入演示家庭并看到虚构成员。
2. Given 首页资讯区，When 按脚本点击资讯卡片，Then 进入助手且提问草稿带上该资讯上下文。
3. Given 助手追问，When 返回回答，Then 至少一条可点开的引用指向教学知识库条目，且版本可见。
4. Given 外网不可用，When 走完全部步骤，Then 脚本不中断，降级态有对应话术。
5. Given 演示结束，When 执行清理步骤，Then 演示数据与本机缓存可一键清除，不残留在设备上。

## 安全、隐私与回滚

- 全程虚构数据；演示包不得内置任何真实家庭配置或凭据。
- 脚本不得引导观众进入管理后台或暴露开发身份头用法。
- 演示不得呈现诊断、处方或购药导流内容。
- 回滚：删除演示脚本与演示包记录即可；不影响 APP 运行时行为。

## 实现与验证证据

- [手机连续演示脚本](../../APP/docs/MOB-170-手机连续演示脚本.md) 固化了 PWA 与 Capacitor debug APK 的构建、安装、默认演示模式、可选本地联机引用、断网回退、失败话术和清理步骤。
- `APP/scripts/mobile-demo-ready.mjs` 提供本地只读预检：检查 `dist/` 应用外壳、Manifest 的 `start_url/scope/display/orientation`、图标和 Service Worker 外壳资源，确认 `/api` 与 `/health` 不进入缓存，并可选输出 APK 大小与 SHA-256；脚本不启动服务、不访问网络、不读取健康数据。
- `APP/package.json` 新增 `npm run demo:ready`；推荐在 `npm run check`、`npm run test`、`npm run build` 后运行，并用 `npm run release:manifest` 留存本机产物清单。
- 离线边界沿用 `APP/public/sw.js`：页面导航网络优先、失败回退安全应用外壳，健康接口永不缓存；默认 `demoProvider` 仅返回虚构成员、任务与本地季节日历资讯。

### 本次可复跑命令

```powershell
cd APP
npm run check
npm run test
npm run build
npm run demo:ready
```

可选 APK 预检（APK 只保留在本机）：

```powershell
npm run demo:ready -- --apk android/app/build/outputs/apk/debug/app-debug.apk --require-apk
```
