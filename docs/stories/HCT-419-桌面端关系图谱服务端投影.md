## 用户价值

作为家庭管理员或已授权照护者，我需要在桌面端查看服务端重建的成员关系图谱及每个节点的来源，以便理解当前已确认事实，而不把完整时间线、事件载荷或证据下载到浏览器后自行计算。

## 范围与非目标

- 新增只读 `GET /api/v1/households/{household_id}/members/{member_id}/relationship-graph`，仅返回当前有效节点、来源事件 ID、来源记录时间和记录人。
- 服务端仅从已确认事件构建投影；被补偿、未确认、空标签的事实不会生成节点，响应不含 payload、evidence 或完整事件内容。
- 读取沿用成员级 `READ_EVENTS`/`health_events` 授权；家庭不存在、成员不存在、已删除、越权和撤权统一返回 `404 RESOURCE_NOT_FOUND`。
- Vue 图谱页切换为该端点，保留节点可访问性与来源展示。
- 不做移动端、医学本体、自动医学推理、图谱写入、跨成员聚合或公开展示。

## Given / When / Then

- Given 成员有一条已确认药品事件、一条被补偿的过敏事件和一条未确认疾病事件，When 读取关系图谱，Then 只返回药品节点及其最小来源元数据。
- Given 照护者获得成员读取授权，When 读取关系图谱，Then 可见；当授权撤回后再次读取，Then 返回 `404`，不泄露成员或图谱存在性。
- Given 用户进入桌面图谱页，When 页面加载，Then 只请求 `relationship-graph`，不请求完整 `timeline`。

## 隐私、部署与回滚

- 响应严格限制为节点和来源元数据，不输出事件 payload、证据或未确认事实；不记录敏感内容日志。
- 无迁移、无外部网络出口、无移动端改动。
- 回滚移除只读端点和 Vue 调用；事件链、授权、时间线和既有关系投影数据保持不变。
