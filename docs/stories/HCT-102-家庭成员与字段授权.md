# HCT-102：家庭成员与字段级授权

- 需求：FR-01、NFR-01、NFR-02
- 状态：进行中
- 负责人：Meyt1n（仓库维护者，需项目组确认）
- 复核人：待项目组指定；必须由非实现者复核越权和撤权场景
- 风险：高；授权错误可能造成跨家庭或字段泄露
- 允许修改：`src/api/app/security.py`、`src/api/app/routes.py`、`src/api/app/models.py`、`src/api/app/schemas.py`、`migrations/`、`tests/`

## 用户价值

家庭管理员可以只授权指定成员的指定数据域和动作，并在到期或撤回后立即阻断照护者访问。

## 范围与非目标

本 Story 建立本地开发身份头、家庭/成员、数据域/动作/目的/期限和撤权骨架。真实账号、密码、PIN、二维码和生产身份认证不在本 Story 内。

## Given / When / Then

- Given `owner` 创建家庭和成员；When `daughter` 没有授权访问事件；Then API 返回 `403`。
- Given `owner` 是该家庭的创建者；When 查询本家庭成员目录或健康事件；Then owner 可访问本家庭完整结果；该权限不扩展到其他家庭，也不由 `daughter`/`caregiver` 角色名称自动获得。
- Given `owner` 授予 `daughter` 对 `health_events` 的 `READ_EVENTS` 权限且未过期；When `daughter` 查询事件；Then 只返回被授权成员的事件。
- Given 授权被撤回；When `daughter` 再次查询；Then API 立即返回 `403`。
- Given `other-family` 操作不属于自己的家庭；When 创建成员或写入事件；Then API 拒绝请求。
