## 用户价值

家庭 Owner 可以查询、创建、修改和撤销指定成员的授权；非 Owner 只有在成员、数据域、动作、目的和期限全部匹配时才可访问。撤权和到期立即阻断新请求，且授权生命周期和拒绝决定可审计。

## 范围与非目标

本 Story 完成家庭/成员边界、授权查询与变更、乐观锁、最小审计和前端 API 类型。`Household.created_by` 是当前 Owner 身份事实字段。开发身份仍使用仅开发环境允许的 `X-Actor-Id`；真实账号、密码、PIN 和二维码属于 HCT-107。照护者字段裁剪页面和完整可见范围接口属于 HCT-106，本 Story 不提前实现页面。

## 冻结契约

- 非 Owner 请求通过 `X-Access-Purpose` 携带稳定的 ASCII 目的代码，必须与授权 `purpose` 精确匹配。
- 授权 `purpose` 使用 1 至 64 位字母、数字、点、下划线、冒号或连字符，不使用会受 HTTP Header 编码影响的展示文案。
- `PATCH /api/v1/households/{id}/authorizations/{auth_id}` 和撤权请求必须携带 `expected_version`；版本不匹配返回 `409 AUTHORIZATION_VERSION_CONFLICT`。
- 未登录返回 `401`。跨家庭、未授权、成员 ID 猜测和授权 ID 猜测统一返回 `404 RESOURCE_NOT_FOUND`，不通过状态或错误详情暴露资源是否存在。
- `access_audit` 只保存家庭/授权 ID、操作者、动作、数据域、目的、决定、原因和前后版本，不保存健康事件正文、证据、图片或成员状态。

## Given / When / Then

- Given 请求没有开发身份；When 访问授权接口；Then 返回 `401`。
- Given 调用者不是目标家庭 Owner；When 查询/修改授权、添加成员或猜测其他家庭 ID；Then 统一返回隐藏式 `404`。
- Given Owner 创建授权；When 查询授权列表；Then 返回授权人、被授权人、范围、目的、期限、撤回状态和版本。
- Given 非 Owner 的成员、字段、动作和期限匹配但目的缺失或不匹配；When 访问健康事件；Then 返回隐藏式 `404` 并写入脱敏拒绝审计。
- Given 两个客户端都基于版本 1 修改授权；When 第一个请求已提交版本 2；Then 第二个请求返回 `409`，不覆盖版本 2。
- Given 授权被撤回或已到期；When 非 Owner 发起新请求；Then 立即拒绝，并记录 `CONSENT_REVOKED` 或 `AUTHORIZATION_EXPIRED` 审计原因。

## 风险与回滚

- 风险重点：目的绕过、跨家庭可枚举、撤权延迟、并发静默覆盖、审计包含健康正文。
- 应用回滚：回退授权 API 与策略版本，停止非 Owner 新访问并保持默认拒绝；不删除、改写或回滚已有 `access_audit`。
- 数据库迁移只允许在 `access_audit` 为空时降级；已有审计时迁移会拒绝破坏性 downgrade。生产处置使用前滚修复。
- HCT-106/HCT-107 接入前必须复用本 Story 的家庭边界、目的和版本语义，不得建立旁路。
