## 用户价值

提供家庭健康总览、视觉录入、人工复核、关系图谱、用药安全、健康计划、本地助手、家庭大屏和模型实验室的 React 页面骨架，便于后续按冻结的 API 与权限契约逐页接入。

## 范围与非目标

本 PR 在现有 React 演示入口中实现模型实验室的版本登记、同口径指标对比、发布状态说明、失败类别、空/错误/离线/未授权状态，以及需要权限声明和二次确认的幂等回滚教学演练。页面指标只引用仓库中的 HCT-203 v1.2/v1.3 模型卡和机器可读登记。

本 PR 不实现真实 API 接入、认证、授权判断、健康事件写入、模型调用、规则发布、数据库访问、真实健康数据处理或医疗结论。后端 API 是权限、事件、模型和证据的唯一权威层。

## Given / When / Then

- Given 用户启动 React 前端；When 访问根页面或切换 hash 路由；Then 页面可以加载总览和各演示页面，浏览器不需要访问外部图片、视频或字体资源。
- Given 用户进入模型实验室；When 查看版本、指标、失败样本和回滚入口；Then 页面显示合成演示状态，并明确不得据此发布模型或执行医疗决策。
- Given HCT-203 v1.2/v1.3 均未获批准；When 查看版本登记；Then 两个版本均显示 `EXPERIMENTAL_UNRELEASED` 语义，候选/已批准/已回滚状态显示当前数量为 0，家庭运行时保持 `vision_model_version=unavailable`。
- Given 用户查看版本指标；When 比较 v1.2/v1.3；Then 页面使用同一候选 test 输入集和哈希，展示 mAP、CPU P95 退化、困难负样本误检与复现缺口，并明确该集合不是获批固定集。
- Given 用户启动回滚演练；When 未声明权限或未输入 `ROLLBACK`；Then 执行按钮保持禁用；When 完成二次确认并重复提交相同请求；Then 本地演练状态幂等恢复且不会追加第二条审计。
- Given 页面进入空、错误、离线或未授权状态；When 查看页面；Then 不显示版本登记详情，不加载真实家庭数据、样本原图或模型权重。
- Given 页面展示家庭成员、事件、风险或证据；When 查看页面免责声明；Then 用户能看到当前未接入真实 API，不能把演示内容当成真实健康事实。
- Given 后续接入真实数据；When 前端通过 API 客户端替换演示数据；Then 服务端仍负责授权、字段过滤、事件确认、版本审计和回滚状态机，页面不自行放宽边界。

## 测试与证据

- `npm.cmd ci`：安装 `src/web/react/package-lock.json` 锁定的依赖。
- `npm.cmd run build`：React/Vite 生产构建。
- `npm.cmd run test:e2e`：在桌面 Chromium 与 Pixel 7 视口运行模型实验室 Playwright 验收。
- `git diff --check`：提交空白检查。
- `rg -n --glob '!package-lock.json' "https?://|fetch\\(|axios" src/web/react`：确认页面不包含外部资源或直连 API。
- 人工验收：打开 `#/模型实验室`，依次切换版本登记、版本指标、回滚状态和状态演练；核对模型卡数值、发布阻断、教学演练声明和移动端布局。

## 已知限制

- 页面仍是静态教学演示；模型版本和指标来自 HCT-203 v1.2/v1.3 登记，页面状态、权限声明、回滚请求和审计记录为合成演练。
- `localStorage` 只用于回滚教学演练的刷新恢复，不是生产审计；真实 API、权限、审计、模型/规则/知识版本和回滚状态机必须由后续 Story 按契约接入。
- 生产接入前需要补充 API 契约测试、越权/撤权测试、键盘与移动端验收及真实模型实验室证据。

## 回滚

回退本 PR 即可移除 React 演示入口、页面资源和构建配置，不修改后端 API、数据库、健康事实、模型权重、规则或知识库。恢复页面时仍必须保留原有 Vue 前端作为正式接入基线。
