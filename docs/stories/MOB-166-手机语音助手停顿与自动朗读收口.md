## 用户价值

PR #490 已把 15 秒句末静音、自动朗读与结束回复的语音体验合并进来，但规划包明确记录「欠隐私 R3 与真机矩阵」（`docs/testing/MOB-150-Android真机语音助手验收记录.md` 待设备签收）。本 Story 把移动端这部分收口：把停顿与自动朗读的行为定死，并补真机矩阵与隐私记录。

## 范围

- 15 秒句末静音判定在真机上的实测：正常停顿、长思考、环境噪声、被打断四种情形。
- 自动朗读的开关语义：默认状态、静音/勿扰/耳机拔出时的行为、公共场合的手动接管。
- 麦克风占用与释放：退出助手、切后台、来电、录音被系统抢占时必须释放。
- 真机矩阵签收与隐私 R3 记录归档。

## 非目标

- 不改语音识别或 TTS 引擎选型（属 HCT-412）。
- 不做唤醒词常听；麦克风必须由用户显式触发。
- 不在移动端本地保存任何语音音频。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 用户说话后停顿满 15 秒，When 判定句末，Then 自动提交本轮并释放麦克风，界面明确显示已停止录音。
2. Given 用户长时间思考但未达 15 秒，When 继续说话，Then 不误判为句末，草稿内容不被截断提交。
3. Given 自动朗读开启且处于系统静音或勿扰，When 助手回复，Then 不强行播报，改为可点击播放的提示。
4. Given 切后台、来电或麦克风被系统抢占，When 事件发生，Then 立即释放麦克风并显示已中断，不静默继续录音。
5. Given 真机矩阵执行完毕，When 归档，Then `docs/testing/MOB-150-Android真机语音助手验收记录.md` 由设备持有人签收，并附隐私 R3 记录。

## 安全、隐私与回滚

- 麦克风仅在用户显式触发后开启，且任何中断都必须释放。
- 语音音频不落盘、不上传第三方；只把识别文本交给家庭服务器。
- 真机语音矩阵不得由 Cloud Agent 代签。
- 回滚：关闭自动朗读并把句末判定退回手动提交，语音输入仍可用。

## 实现与验证证据

- `APP/src/views/AssistantView.vue` 不再在进入页面时调用自动启动逻辑；即使系统已经授予过麦克风权限，也必须由用户点按「开启唤醒」后才创建识别会话，避免公共场合或后台意外占用麦克风。
- 页面切后台时复用 `visibilitychange` 立即调用 `stopVoiceInput()`；离开助手页时在 `onBeforeUnmount()` 释放识别与播报，系统抢占/无可用麦克风则由共享识别模块进入停止态并给出文字提示。
- 15 秒句末停顿、续说提示延长、自动发送确认倒计时、重复唤醒保护由 `shared/voice/dictation.ts` / `shared/voice/shared.voice.test.ts` 覆盖；自动朗读默认关闭，`useSpeech()` 只在无障碍设置开启时调用，无法播放时退回屏幕文字。
- `cd APP && npx vue-tsc --noEmit`、`npx vitest run`（35 个测试文件、330 项）、`npx vite build`、`node scripts/privacy-scan.mjs` 与 `git diff --check` 作为本分支验证门槛。

## 平台边界

- Web Speech API 无法可靠读取 Android 系统静音/勿扰和电话音频焦点状态，因此“静音/勿扰不强行播报”“来电/系统抢占立即释放”必须在 Android 真机矩阵中由设备持有人签收；本分支不伪造这些证据。
- 语音识别文本仍只在用户确认发送后交给家庭服务器，移动端不保存音频；真机矩阵须补充隐私 R3 记录后才可把 Issue 标记完成。

## 未完成证据
