## 用户价值与范围

让移动端在联机初始化和会话切换时诚实表达当前状态：身份或访问目的未配置时先引导设置；没有家庭或成员时不展示空健康数据；服务不可达、授权不足和资源变化时提供可恢复提示；身份、访问目的或服务器切换后清理旧 Provider 缓存、成员、风险、档案、任务和视觉录入状态。

本 Story 不落正式鉴权、不新增后端接口、不缓存健康数据，也不改变家庭服务器的授权判定。

## Given / When / Then

- Given 联机模式身份或访问目的为空，When 进入今日、家人、提醒、成员档案或拍药盒，Then 不请求家庭数据，显示“请到我的补充身份/访问目的”的设置引导。
- Given 身份没有可访问家庭，When 初始化联机 Provider，Then 返回可识别的 `NO_HOUSEHOLD`，页面显示家庭设置/授权引导，不进入空数据页。
- Given 家庭存在但成员为空，When 进入今日、家人、提醒或拍药盒，Then 显示明确的成员/授权引导；拍药盒不可选择成员或开始录入。
- Given 服务不可达、401/403 或后端未提供接口，When 页面加载，Then 显示现有可恢复错误和重试/设置入口，不保留上一会话数据。
- Given 用户切换服务器、身份、访问目的或演示/联机模式，When 新会话开始加载，Then Provider 指纹变化并丢弃旧家庭缓存；页面先清空旧成员/风险/档案/扫描结果，再展示新状态。
- Given 页面正在加载，When TalkBack 或视觉用户查看，Then 看到并可读到具体的“正在加载家庭/成员/风险提醒/视觉录入数据”提示。

## 人工验收记录

当前开发机未配置可用的家庭服务器实例，也没有已连接 Android 设备；因此不把本地演示模式或代码检查宣称为联机/真机验收。维护者验收时应按以下顺序记录环境与结果：

1. 清空身份，切到家庭服务器，依次打开今日、家人、提醒、拍药盒；确认设置引导、无健康空白页和检查设置入口。
2. 使用没有家庭的身份，确认 `NO_HOUSEHOLD` 文案；使用空成员家庭，确认成员引导和拍药盒禁用。
3. 关闭服务器或制造网络失败，确认重试入口；使用 401/403 身份，确认身份/授权文案。
4. 先用身份 A 加载成员，再切换身份 B/访问目的/服务器，确认旧成员、风险、档案和扫描候选不残留。
5. 记录 Android 设备型号、应用版本、后端版本、身份/家庭、结果和失败复现步骤。
