# MOB-150：随身版本地助手语音输入与联机提问

## 1. Story

作为老人或照护者，我希望在手机上用与网页端相同的唤醒语音输入，并把问题发到家里电脑上的家健镜后端，从而在随身场景也能问本地助手。

## 2. 需求与边界

- 关联：Related to HCT-412 / #210；MOB-118 / #176
- FR/NFR：FR-08；NFR-02、NFR-04、NFR-07
- 风险：R2（麦克风权限与浏览器识别服务位置可能涉及隐私；不上传音频到 HCT API）
- 语音输入：用户点击「开启唤醒」后监听；识别到「小燕小燕」才进入听写；临时文字只写草稿，点发送才请求家庭服务器
- 联机：使用「我的」中配置的家庭服务器地址（例如电脑局域网 `http://192.168.x.x:8000`）；优先 `POST /api/v1/assistant/chat/stream`（多智能体阶段反馈），失败回退 `/assistant/chat`
- 演示模式：诚实说明未连接后端，不伪装助手可用
- 非目标：不新增服务端音频接口；不把助手做成诊断/处方工具；不挤占长辈模式底部四入口验收结构

## 3. 验收

1. Given 设备支持 SpeechRecognition；When 点击开启唤醒并说出「小燕小燕」；Then 进入听写并把后续文字写入草稿，不自动发送。
2. Given 联机且服务器地址指向电脑后端；When 发送草稿；Then 优先调用家庭服务器流式接口，音频不上传；可停止生成；可选本次脱敏联网参考。
3. Given 演示模式或未填服务器；When 发送；Then 显示可理解降级说明，文字操作仍可用。
4. Given 助手回答；When 点「朗读回答」或开启长辈语音播报；Then 走与网页端一致的自然中文音色优选（依赖本机语音包，见听感准备说明）。
5. `npm run check` / `npm run test` / `npm run build` 通过。

## 4. 实现

- `APP/src/composables/useVoiceInput.ts`：唤醒、多候选、最新 interim、同音纠偏
- `APP/src/views/AssistantView.vue`：助手页 UI、听说互斥、联机流式聊天、阶段文案与停止
- `APP/src/api/client.ts`：`assistantChat` / `assistantChatStream`
- 入口：今日页、我的页；路由 `/assistant`
