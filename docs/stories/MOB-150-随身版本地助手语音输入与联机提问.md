# MOB-150：随身版本地助手语音输入与联机提问

## 1. Story

作为老人或照护者，我希望在手机上用与网页端相同的唤醒语音输入，并把问题发到家里电脑上的家健镜后端，从而在随身场景也能问本地助手。

## 2. 需求与边界

- 关联：Related to HCT-412 / #210；MOB-118 / #176
- FR/NFR：FR-08；NFR-02、NFR-04、NFR-07
- 风险：R2（麦克风权限与浏览器识别服务位置可能涉及隐私；不上传音频到 HCT API）
- 语音输入：助手页前台自动尝试进入唤醒聆听（仍需一次用户手势开麦）；识别到「小燕小燕」才进入听写；静音约 1.6s 后停麦并聚焦发送；临时文字只写草稿，点发送才请求后端
- 联机：使用「我的」中配置的家庭服务器地址；优先流式 `POST /api/v1/assistant/chat/stream`
- 会话：按身份/家庭/成员用 `sessionStorage` 短期隔离，与网页端规则对齐
- 共享逻辑：`shared/voice/`（Web/APP 共用唤醒、热词、听写、TTS、会话与音色自检）
- 演示模式：诚实说明未连接后端，不伪装助手可用
- 非目标：不自建离线 ASR/TTS、不接云厂商语音、不后台常驻免手势唤醒；不把助手做成诊断/处方工具；不挤占长辈模式底部四入口验收结构

## 3. 验收

1. Given 设备支持 SpeechRecognition 且已允许麦克风；When 进入助手页；Then 自动进入唤醒聆听，说「小燕小燕」后听写进草稿，不自动发送。
2. Given 听写中；When 静音约 1.6s；Then 停麦、草稿保留、宜聚焦发送，可点发送或重新聆听。
3. Given 联机且服务器地址指向电脑后端；When 发送草稿；Then 调用家庭服务器流式聊天接口，音频不上传。
4. Given 切换成员；When 再打开助手；Then 对话按身份/家庭/成员隔离，不串话。
5. Given 助手回答；When 点「朗读回答」或开启长辈语音播报；Then 分段朗读、可跳过本句，音色优选依赖本机语音包（见听感准备说明与设置页自检）。
6. 真机矩阵：`docs/testing/MOB-150-Android真机语音助手验收记录.md` 可勾选签收（**须 Android 真机填写**；Cloud Agent 不得代填通过结论）。
7. Web/APP 助手页含「改一句/重说」、静音偏好、双次唤醒、朗读分段跳转与语音预检；`verify-android-voice-evidence.mjs` 仅校验真机记录完整性。
8. `npm run check` / `npm run test` / `npm run build`（APP）与 `npm run check:web` / `npm run test:web` 通过。

## 4. 实现

- `shared/voice/`：识别、热词、听写状态机、TTS、会话隔离、音色自检
- `APP/src/composables/useVoiceInput.ts` / `src/web/src/assistant/voice.ts`：薄转发
- `APP/src/views/AssistantView.vue`、`src/web/src/views/AssistantView.vue`：自动唤醒、静音结束、ready 态「发送/改一句/重说」、朗读分段跳转、流式降级
- `APP/src/api/client.ts`：`assistantChat` + `assistantChatStream`
- `APP/src/views/AccessibilityView.vue`：听写偏好（静音档位、确认音、双次唤醒）与中文语音包自检
- `APP/src/views/VoiceCheckView.vue`（`/me/voice-check`）：`runVoicePreflight` 清单
- 入口：今日页、我的页；路由 `/assistant`、`/me/voice-check`
