## 用户价值

MOB-157 已把环境行动卡的移动端呈现与离线降级写完，但验收停在合成城市编码，真实天气提供方部署下的联调证据一直没补，因此 MOB-157 处于 Blocked。本 Story 只做一件事：在接入真实提供方的后端上，把行动卡的授权、降级、去重与版本证据补齐。

## 范围

- 真实提供方部署下：已授权成员的行动卡展示、来源、生成时间、有效期、规则/配置版本。
- 未授权环境标签、城市编码缺失、访问目的不匹配三种拒绝路径的实测记录。
- 提供方超时、限速、上游失败与仅有旧缓存四种降级态的实测记录。
- 同一环境事件在有效期内刷新/后台恢复不重复创建行动卡与通知的去重证据。

## 非目标

- 不改移动端行动卡的实现（属 MOB-157），只补证据；发现缺陷回填到 MOB-157。
- 不改后端天气白名单、出口与缓存策略（属 HCT-305）。
- 不接入任何需要付费或需要真实位置精确坐标的提供方。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 真实提供方已配置且成员已授权环境标签，When 打开今日/提醒，Then 行动卡展示行动、来源、生成时间、有效期与规则/配置版本。
2. Given 成员未授权环境标签或城市编码缺失，When 加载，Then 不发起推断请求、不展示敏感内容，只给最小权限解释。
3. Given 提供方超时或返回失败，When 加载，Then 显示服务端降级状态；若仅有旧缓存则明示缓存时间，不冒充实时。
4. Given 同一环境事件仍在有效期，When 刷新或从后台恢复，Then 不重复创建行动卡、提醒或通知。
5. Given Android 真机与 PWA 两端，When 走完上述路径，Then 证据记录含截图与请求/版本标识，且不含真实位置坐标。

## 安全、隐私与回滚

- 只上传城市/区县编码，不上传精确坐标、成员姓名或健康正文。
- 环境行动不等于医疗建议或紧急提醒。
- 真机截图与签收不得由 Cloud Agent 代签，需设备持有人执行。
- 回滚：隐藏行动卡入口即可回到 MOB-157 之前的今日/提醒功能。
