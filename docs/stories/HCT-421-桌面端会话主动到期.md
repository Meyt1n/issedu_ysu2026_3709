## 用户价值

作为桌面端家庭成员，我希望正式账号会话到期后立即退出当前家庭空间，避免在等待下一次 API 请求前继续看到过期上下文。

## 范围与非目标

- 使用登录响应中的 `expires_at` 在浏览器内存中调度一次到期清理。
- 到期、登出、重新登录和 `401` 清理路径共用现有会话清理逻辑。
- 不持久化 token，不刷新 token，不改变服务端会话 TTL，不新增移动端行为。

## Given / When / Then

- Given 正式登录返回未来的 `expires_at`，When 到达该时间，Then 清空 token、家庭、成员和会话状态并回到登录入口。
- Given 用户在到期前主动登出，When 原到期时间到达，Then 不重复显示过期错误或恢复旧上下文。
