# HCT-442：助手问题分类双通道（模型 + 词表兜底）

- FR/NFR：FR-08、NFR-04、NFR-05（安全边界）
- Issue：关联 #310 / FR-08 助手安全路由（本 Story 独立切片；无单独 Issue 时随助手 PR 绑定说明）
- 用户价值：口语化高危用药问题不再因关键词漏配落入 GENERAL，同时保留确定性词表作为硬兜底
- 范围：用本地分类头/小模型输出问题类型，与 `ai.safety.lexicon` 词表按严重度取并集（宁可多路由到 MEDICATION_SAFETY / URGENT）
- 非目标：不把分类结果当诊断；不云端分类；不替代证据校验；不默认开启模型分类
- 风险：P1（安全路由）
- 依赖：现有 `classify_question` / `src/ai/safety/lexicon.py`；可选回环 Ollama
- 允许修改：`src/api/app/tool_call.py`、`src/api/app/config.py`、`src/ai/safety/`、相关 unit/safety 测试、本 Story、需求追踪矩阵
- 验收：
  - [x] Given 口语「吃错药了/药吃多了」；When 词表分类；Then 进入 MEDICATION_SAFETY
  - [x] Given 词表未命中但模型返回 MEDICATION_SAFETY；When 双通道开启；Then 合并为 MEDICATION_SAFETY
  - [x] Given 模型失败或非回环地址；When 分类；Then 仍按词表正确路由
  - [x] Given `AGENT_CLASSIFIER_ENABLED=false`（默认）；When 分类；Then 纯词表可运行
- 回滚：保持或设置 `AGENT_CLASSIFIER_ENABLED=false`，回退词表-only
- 状态：已实现（默认关闭模型通道；开启需回环 Ollama）
