# HCT-516 演示入口收口、扫描原图与前台门禁

- Issue：[#650](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/650)
- 关联：HCT-430、HCT-439、HCT-511、HCT-512、HCT-513、HCT-514、HCT-515
- FR/NFR：FR-01、FR-03、FR-08、NFR-01、NFR-07
- 风险等级：R2（入口与助手 UX；不改变授权判定、不伪造 capabilities）
- 状态：实现完成，待 Issue/PR 与人工验收

## 1. Story

作为演示使用者，我希望助手页更干净、侧栏不出现知识文档、资讯跳转会带上联网、同一对话有上下文、扫描原图重启后还在，并且成员前台在后台尚未完成本机就绪时先去管理后台。

## 2. 产品决定

| 项 | 决定 |
|---|---|
| 助手「本地分析」胶囊与流程面板 | 隐藏，不删除编排能力 |
| 「接下来可以问」chips | 隐藏 |
| 侧栏「知识文档」 | 隐藏；`KnowledgeView` 仍保留，不从导航进入 |
| 资讯「去问问助手」 | 新开一条对话，并默认勾选联网搜索（仍受部署双门） |
| 同一线索连续追问 | 发送最近有效的 user/assistant 轮次；新闻跳转不并入旧线索 |
| 扫描原图 | `FILE_ROOT` 解析到仓库绝对路径；Compose 挂卷；任务卡预取并展示原图 |
| 家庭大屏运行状态 | 展示真实可用的本地能力；不把 `llm-cloud` / 正式药品集标绿 |
| 成员前台 | 本机已绑定且**管理后台当前保持登录**（`hct-admin-ready` 与家庭匹配，且 `instance_id` 一致）才显示刷脸/PIN，否则图六门禁 |

与 HCT-511「绑定后管理员离线也可 PIN」冲突：本增量改为「管理后台保持登录期间才开放前台凭据」。冲突记在此，不改冻结规格正文。

资讯跳转或用户消息中的 HTTPS 网址：在勾选联网且 `AGENT_WEB_SEARCH_ENABLED=true` 时直接抓取该页（公开 HTTPS + SSRF，不要求搜索引擎白名单）。默认搜索出口仍受 allowlist 约束。

助手可见回复不得是「回答正文」占位，也不得复述智能体名称/错误码/引用重试提示。资讯或公开网页问题按一般教学处理；未勾选联网时说明去勾选或从首页点资讯。一般问答不展示「按用药安全再查一次」。

不把 `llm-cloud` 或 `hct201-formal-drug-set` 标成已启用。

## 3. 验收

- Given 管理后台助手页，When 打开对话，Then 右上角没有「本地分析」，气泡里没有「接下来可以问」，侧栏没有「知识文档」。
- Given 首页健康资讯，When 点「去问问助手」，Then 新开一条对话且「联网搜索」勾选（部署未开双门时仍不可真正出网）。
- Given 同一条对话连续追问，When 发送，Then 请求带最近有效 user/assistant 轮次；资讯跳转不并入旧线索。
- Given 本机识别任务，When 关闭项目再启动 API，Then 任务卡能再次拉到原图（仓库绝对 `FILE_ROOT` + 兼容旧 CWD 路径）。
- Given 家庭总览/大屏，When 查看本地运行状态，Then 展示真实已启用的本地能力；`llm-cloud` 与正式药品集不出现为绿灯。
- Given 成员前台，When 管理后台当前没有保持登录（无匹配的管理员就绪 cookie），即使本机残留家庭绑定，Then 显示「请先到管理后台」，不进入刷脸/PIN。
- Given 在成员前台退出登录，When 当前标签是调试单入口（5173 auto），Then 欢迎页仍按成员前台渲染（门禁或刷脸/PIN），不落回带残留家庭名的默认刷脸页。
- Given 首页健康资讯或用户消息含 HTTPS 网址，When 勾选联网搜索且部署已开启，Then 助手抓取该页正文再回答，不因搜索引擎白名单拦住指定网址。
- Given 用户问「最近有什么新闻吗」且未勾选联网，When 模型只输出占位或内部草稿，Then 助手给出可读说明（勾选联网或从首页点资讯），不展示「回答正文」或空气泡。
- Given 资讯/公开网页教学提问，When 本地知识库无授权文档，Then 可见回复是教学说明，不出现 `TOOL_SCOPE_DENIED`、`database_agent` 或「上一稿」等内部控制词；一般问答不出现「按用药安全再查一次」。
