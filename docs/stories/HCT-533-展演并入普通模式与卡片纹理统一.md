# HCT-533：展演并入普通模式与卡片纹理统一

## 1. 范围

- FR/NFR：FR-09（家庭/模型大屏展示）、NFR-02（不展示敏感正文）、NFR-04（基础档可降级）、NFR-07（可访问与可理解）。
- 关联：本地前端展示层；Issue 由维护者创建后回填。
- **替代关系**：本 Story 撤除 [HCT-531](HCT-531-Web展演模式视觉增强.md) 引入的独立「展演模式」开关及其 ImageGen 科幻层；原展演能力按「温暖照护」方向重做后并入普通模式。HCT-531 中与开关/科幻视觉相关的验收条目随之作废，数据边界类验收（聚合展示、不虚报状态）由本 Story 继续承袭。
- 目标：纯表现层重构，不新增业务功能：
  1. 卡片纹理统一为「纸色晕染全覆盖」：底色带极淡主题色，四角晕染直达边缘，饱和度约为原来一半，边缘不再发白；
  2. 撤除展演模式：启动仪式在登录成功后每次浏览器会话播放一次，守护光球常驻右下角；
  3. 大屏常驻四件温暖化的「数字孪生」投影：家庭空间沙盘（纯 SVG）、家庭心跳仪表盘、健康脉络图（Canvas 真实关系图谱）、近七日时间回溯。

## 2. 验收条件

### 卡片纹理

- 新增令牌 `--card-texture`（四角极淡 pine/gold/clay 晕染）与 `--card-bg`（纸色调和底色）；`.card`、`.home-dashboard-card`、`.bs-tile`、`.bs-panel`、`.bs-member-chip`、`.weather-action-panel`、`.health-news-item` 均改为「晕染层 + 有色纸底」，任何位置不再露出半透明白边。
- `--overview-accent` 由 40–50% 不透明角斑改为 5–8% 的对角淡彩底色；快捷卡、天气指标盒、新闻条目同步减淡。
- 简洁主题（minimal）覆写 `--card-texture: none; --card-bg: #fff`，保持纯净白。

### 展演并入普通模式

- `ui/showcase.ts` 不再导出 `showcaseMode`/`toggleShowcaseMode`；`Ctrl+Shift+H`、主题菜单项、命令面板「切换展演模式」命令全部移除。
- 启动仪式（温暖版）在 `session.status === 'ready'` 后播放，`sessionStorage` 保证每次浏览器会话最多一次，Esc 可跳过；成员门户与管理后台一致。
- 守护光球登录后常驻右下角，状态映射 `guardianStateFor` 不变；点击仍跳转助手页。
- `CareAtlasBackdrop` 页面点缀仅暖阳纸笺主题生效（大屏除外），不再受展演开关影响。
- 大屏新增常驻区块 `bs-twin-row`（脉络图 + 心跳仪表盘）与 `bs-twin-grid`（沙盘 + 时间回溯），不再依赖任何开关。

### 大屏四件温暖化

- HomeDiorama：删除深色 ImageGen 底图，改为内联 SVG 暖色等距小屋（屋顶/墙/门/窗/灌木/烟囱，pine 描线、clay 屋顶、gold 窗光），窗光呼吸与灌木摇曳为装饰动画；四个聚合热区（成员/任务/待复核/严重信号）数据绑定不变，指针视差与缩放保留且可键盘操作。
- VitalPulsePanel：删除 HUD 底图；脉搏线（pine→clay 渐变）、成员计划环、链路健康度保留；文案中文化，保留「不代表医学生命体征」边界声明。
- TemporalReplayPanel：删除「时光隧道」全屏弹层与底图；保留滑块、正向回放/倒带、柱条与「仅回放数量」声明。
- HealthConstellationView：删除深空底图，Canvas 节点配色加深适配纸底、节点标签改为墨色，文案中文化；仍只读取已授权关系图谱 API。

### 清理

- 删除组件：`HolographicConsole.vue`、`CrystalHealthOrb.vue`、`EventWaterfallWall.vue`、`AchievementToast.vue`、`HealthMatrixRain.vue`、`AmbientDataField.vue` 及其全部 CSS。
- 删除无引用 PNG：`holographic-console.png`、`crystal-health-orb.png`、`event-waterfall.png`、`achievement-burst.png`、`temporal-wormhole.png`、`home-diorama.png`、`vital-pulse-hud.png`、`holographic-scan-stage.png`、`constellation-space.png`、`boot-ceremony.png`、`guardian-robot.png`。保留 `health-matrix-rain.png`、`ambient-border.png`、`glass-panel-texture.png`（页面点缀仍在用）。
- 助手页空态旧机器人 PNG 替换为与守护光球一致的暖色 SVG。
- 旧版深色启动页 `.showcase-boot-*` 全套死样式（约 240 行）与 `.showcase-mode` 全部覆写（约 700 行）删除，style.css 净减约 1350 行。

### 第二轮打磨（同日，浏览器截图反馈后）

- **白边根因修正**：暖阳纸笺主题装饰层有一条高优先级规则用「近白 veil (0.82) + 纹理图」覆盖所有卡片，使前一轮的新底色失效。该规则重写为「暖米色半透底 (0.84) + 暖 veil (0.72) + 纸纹 multiply + 7% pine/clay 对角晕染」，并新增 `.home-dashboard-card` 专属规则保留每卡 7–10% accent 晕染；`.graph-stage` 对已删除 `constellation-space.png` 的引用改指 `glass-panel-texture.png`；助手主区 veil 同步调暖；快捷卡渐变终点由近白 `var(--card)` 改为暖纸调和色。
- **排版对齐**：健康月历卡与成员卡同理恢复 `overflow: visible`（否则被定高 grid 压成只剩标题的一条）；天气卡经 `.home-dashboard-weather` 拉伸到与右列等高、来源页脚 `margin-top: auto` 锚底，消除左列空洞；新闻卡标题最多 3 行、摘要最多 4 行（line-clamp）且 CTA 锚底，同排卡片高度一致。
- **数字孪生轨道核心**：VitalPulsePanel 从纯形状绘制升级为 Canvas 2D 轨道核心——深暖观测台底、呼吸发光核心（DOM 叠加链路健康度%）、三层透视虚线轨道与彗星光点、最多 6 个成员节点按真实成员公转并连引力线、雷达扫掠、42 颗漂浮尘埃、底部示波脉搏线（幅度由今日事件/待复核/严重信号驱动）、HUD 四角框。`prefers-reduced-motion` 下绘制单帧静像；成员计划环 DOM 与旧脉搏线 CSS 移除，组件 props 不变。

## 3. 实现边界

- 仅修改 Web Vue 组件、样式、`ui/showcase.ts` 及文档；不修改 API、数据库、权限、健康事件或视觉任务状态机。
- 脉搏线/链路健康度/沙盘热区仍只反映聚合数量与真实运行状态，不生成预测或医疗结论。
- `prefers-reduced-motion` 下视差、漂浮、窗光、脉搏、回放动画全部停用（全局降级块与组件内降级均已覆盖）。

## 4. 回滚与风险

- 回滚：还原 `App.vue`、`CommandPalette.vue`、`ui/showcase.ts(+test)`、`BigScreenView.vue`、`OverviewView.vue`、`AssistantView.vue`、`HealthNewsPanel.vue`、`style.css` 及保留的四个展演组件；被删组件/PNG 不可恢复（方案已明示废弃）。无迁移与数据变更。
- 主要风险：CSS 令牌改动波及所有主题——通过「主题只覆写令牌值、晕染层用 color-mix 引用主题变量」保证其他主题（dusk/sakura/ocean/indigo/classic）自动适配；minimal 显式覆写。
- 本 Story 不证明真实视觉识别、AI 推理、健康风险判断或隐私 R3 验收已经完成。
