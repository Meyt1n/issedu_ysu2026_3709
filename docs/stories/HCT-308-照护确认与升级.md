## 用户价值

照护计划支持确认、延期、跳过操作，分级提醒推动执行，超时自动升级照护级别。

## 范围

- 计划确认 / 延期 / 跳过 API（复用 HCT-103 幂等）
- 分级提醒推送（临近 → 逾期 → 升级）
- 超时自动照护升级
- 操作审计链

## Given / When / Then

- Given 计划到期未确认；When 超过宽限期；Then 自动升级照护级别并通知照护者。
- Given 用户选择延期；When 提交延期操作；Then 计划时间窗口后移，记录延期审计。
