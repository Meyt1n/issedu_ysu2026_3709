## 用户价值

照护计划支持确认、延期、跳过操作，分级提醒推动执行，超时自动升级照护级别。

## 范围

- 计划确认 / 延期 / 跳过 API（复用 HCT-103 幂等）
- 分级提醒推送（临近 → 逾期 → 升级）
- 超时自动照护升级
- 操作审计链

自动写入采用 fail-closed 授权：只有计划载荷中的 `automation.authorization=AUTHORIZED` 才允许服务端生成
`plan_missed`、`course_ended` 和 `care_escalated` 事件；只有同时声明
`caregiver_notification.authorization=AUTHORIZED` 时，才会为当前仍有效且具备 `READ_EVENTS` 授权的家庭照护者生成
`caregiver_notified` 本地事件。未声明授权的既有计划只展示状态，不会被自动改写。

本增量新增 Owner 可触发的 `POST /api/v1/households/{household_id}/members/{member_id}/plans/evaluate`
和本地 `app.care_plan_worker`。一键 Demo 会同时启动该 worker；worker 按家庭时区扫描明确授权的计划，事件键包含计划和到期时段，
因此进程重启和重复轮询不会重复产生漏服、升级或通知事件。疗程结束后工作台返回 `COMPLETED` 并移除服药动作。

2026-08-22 新增 `scripts/hct308_acceptance_report.py` 作为连续验收入口。缺少疗程结束、照护者通知或重启/时区证据时，
报告保持 `BLOCK_REMINDER_ACCEPTANCE`，不能只凭确认/延期单测关闭 Story。

## Given / When / Then

- Given 计划到期未确认；When 超过宽限期；Then 自动升级照护级别并通知照护者。
- Given 用户选择延期；When 提交延期操作；Then 计划时间窗口后移，记录延期审计。
- Given 计划明确授权自动处理且超过宽限期；When worker 扫描；Then 追加漏服、照护升级和面向仍有效照护授权的本地通知事件。
- Given worker 重启或重复扫描同一到期时段；When 再次执行；Then 不重复追加生命周期事件。
