## 用户价值

老人在旧手机、弱网环境里也能完成"确认任务、看提醒、拍药盒、求助"这些核心动作：发布前用可复跑的预算脚本卡住首屏变慢、包体膨胀和断网不可用；预算超标时构建报告直接 FAIL，不允许"感觉还行"式发布。

## 范围

- `APP/scripts/perf-budget.mjs`（`npm run perf:budget` / `perf:budget:low-end`）：Playwright 对生产构建测量——冷启动（首次内容绘制 + 可交互）、路由切换（今日→提醒→拍药盒→我的，取最慢）、断网场景（Service Worker 缓存外壳可用时间 + 恢复网络后可交互时间）、产物体积（JS/CSS gzip 分类汇总、图片、字体、单文件上限，可选 `--apk`）；
- `APP/scripts/perf-budget-lib.mjs`：预算判定纯函数（PASS/FAIL/SKIP），`npm run test:perf-budget` 自测；
- `APP/perf-budget.config.json`：阈值与推导依据（见"预算依据"）；
- 四套复跑环境：浏览器/PWA（默认）、受控/PWA 部署（`--base <url>`）、Android WebView（`--base http://127.0.0.1:<adb reverse 端口>`）、弱网/低端模拟（`--cpu 4 --network 'Slow 3G'`）。

## 非目标

- 不采集任何健康数据用于性能采样（测量全部使用演示模式与静态产物）；
- 不做真机农场或电量仪测量（待设备环境，脚本已参数化）；
- 不通过删除安全状态、可追溯信息或缩短数据实现"变快"。

## Given / When / Then

- 空缓存冷启动进入今日/提醒/拍药盒：测得 FCP/可交互并按预算判定 —— 报告两份（基线/低端模拟）全部 PASS；
- 路由切换：四页切换最慢 222ms（低端模拟），远低于预算；
- 断网/恢复：Service Worker 外壳兜底 10ms、恢复后可交互 2364ms；轮询退避/超时/清理由 MOB-132/144 的单元测试覆盖（`useVisionTaskPolling.test.ts`、`client.test.ts`）；
- 请求取消/去重/上限：页面级 `generation` 守卫（TodayView/ScanView）、路由组件卸载清理、轮询次数上限与 15s 超时已实现并有测试，Story 记录定位；
- 体积/启动/内存/网络测量报告：体积与启动见报告；内存与电量无法在本机可靠测量，待真机（如实标注）；
- 低端 Android + TalkBack：待真机（脚本已支持 `--base` 对准 WebView 调试端口复跑）。
