# HCT-440 视觉全链路性能探针与 P95 门禁

- Issue：[#393](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/393)（父任务 HCT-409 [#72](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/72)）
- 负责角色：后端组
- 阶段：P1-W8
- 风险：R2
- 状态：实现中（合成性能证据切片，待 PR、CI 和维护者复核）

## 用户故事

作为后端发布验收人员，我希望用固定的合成输入测量视觉质量门控、OCR-first 证据归一化和候选融合的 CPU 延迟及 P95，从而发现代码回归；同时报告必须明确它不是正式模型准确率或生产部署性能证明。

## 背景与边界

HCT-409 已有基础档健康接口和家庭 CRUD 探针，但视觉全流程 P95 仍缺少可复跑入口。HCT-440 使用生产代码中的 `assess_image`、`process_evidence` 和 `fuse_evidence`，配合本地固定合成图像、证据和主数据，不访问网络、不读取真实健康数据、不下载 OCR/YOLO/LLM 权重。

该切片输出可被 HCT-409 机器门禁消费的 `api_perf.vision_full_pipeline_p95_ms`，但不把合成结果标为正式视觉性能。批准固定集、真实适配器推理、部署环境 CPU P95、人工 R3 和项目负责人签署仍是父任务阻塞项。

## 验收标准

- [x] Given 干净 Python 环境和默认参数，When 执行 `uv run python scripts/hct440_vision_perf.py`，Then 生成 JSON 报告并返回合成门禁结果。
- [x] Given 固定合成输入，When 重复执行质量、证据和融合阶段，Then 每个阶段均报告样本数、P50、P95、均值、最大值和错误率。
- [x] Given 视觉全链路 P95 超过预算或存在异常样本，When 执行探针，Then `gate.passed=false` 且进程返回非零，不输出通过结论。
- [x] Given 报告需要进入发布审计，When 检查 JSON，Then 包含 Git SHA、运行环境、RSS、数据策略和限制，不包含 payload、路径、密钥或健康正文。
- [x] Given HCT-409 release pack，When 执行后端回归，Then 能发现该探针和测试；父任务仍保留正式固定集 P95、R3 与负责人签署的人工阻塞。

## 实现内容

1. `scripts/hct440_vision_perf.py` 生成确定性高对比药盒示意图、OCR token、包装区域和本地主数据记录。
2. 对质量门控、证据归一化、候选融合和组合链路分别计时，并将组合 P95 映射到 HCT-409 所需字段。
3. 同时复用基础档 API 探针，报告健康、数据库、家庭列表和视觉 P95 的兼容摘要；不覆盖多主机压力或真实模型推理。
4. `--max-p95-ms` 超限或错误率非零时 fail-closed；默认输出到本地 `artifacts/`，不提交运行时报告。

## 测试与回滚

- `tests/unit/test_hct440_vision_perf.py` 覆盖报告结构、敏感内容防护和预算超限。
- `uv run ruff check .`、`uv run pytest`、探针 smoke run。
- 回滚只需移除探针、测试和 HCT-409 release pack 引用，不改变线上视觉任务、授权、复核或健康事件逻辑。
