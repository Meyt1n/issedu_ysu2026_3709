## 用户价值

移动端助手目前只有单一会话，换个话题就把上文冲掉，也无法回看之前问过什么。补多会话标签与历史栏，同时把跨成员、跨家庭的会话隔离规则明确下来。

## 范围

- 会话列表/历史栏：新建、切换、重命名、删除，按最近活跃排序。
- 每个会话独立保存草稿与上下文；切换会话不携带上一个会话的历史。
- 切换成员或家庭时按 MOB-158 的作用域清理规则丢弃会话上下文。
- 本机保存范围与保留期限，以及一键清空历史。

## 非目标

- 不做服务端会话持久化或跨设备同步。
- 不做会话搜索、导出与分享。
- 不改助手回答内容、路由与安全策略。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 存在多个会话，When 切换会话，Then 只加载该会话的消息与草稿，不出现其它会话内容。
2. Given 切换当前成员或家庭，When 返回助手，Then 旧作用域的会话上下文被丢弃，不作为新提问的历史。
3. Given 删除某个会话，When 确认，Then 该会话的消息与草稿从本机彻底清除，不可通过返回恢复。
4. Given 一键清空历史，When 确认，Then 所有会话与草稿清除，并明确告知已清除的内容范围。
5. Given 窄屏与特大字号，When 打开历史栏，Then 标题不截断、触控区达标，TalkBack 能朗读会话名与最近时间。

## 安全、隐私与回滚

- 本机只保存问答文本与草稿，不保存成员姓名之外的健康正文标识。
- 跨成员、跨家庭一律不继承历史（与服务端跨成员历史丢弃语义一致）。
- 登出与撤权时会话历史一并清除。
- 回滚：隐藏历史栏并退回单会话行为，本机已存历史在回滚时清除。
