- 允许修改目录：`APP/src/data/`、`APP/src/views/`、`APP/src/data/*.test.ts`、`docs/stories/`

## 用户价值
作为移动端照护者，我在提交合格照片后需要看见真实的视觉任务状态与下一步人工复核说明，以便知道候选尚未入档，并转到网页端由有权限的人员确认或修正。

## 范围
- 联机模式显示创建视觉任务 API 返回的任务编号与状态。
- 结果页展示状态、下一步和网页端人工复核说明；演示模式显著标注演示任务。

## 非目标
不在移动端查询、确认、修正或拒绝人工复核任务；不创建健康事件；不新增服务端接口或缓存健康数据。

## Given / When / Then
- 正常：Given 合格图片已创建联机视觉任务，When 返回任务，Then 显示返回的任务 ID 和状态，并说明需网页端人工复核。
- 边界：Given 状态为 `QUEUED`、`RUNNING` 或其他服务端状态，When 显示交接信息，Then 原样展示状态，不推断为已确认。
- 失败：Given 上传或任务创建失败，When 识别提交，Then 保留质量检查结果并显示错误，不显示成功交接。
- 未授权：Given 服务端拒绝成员、文件或任务访问，When 请求失败，Then 显示 API 错误且不暴露任务或候选缓存内容。

## 测试
`cd APP && npm run check`；`npm run test`；`npm run build`。手工验证演示交接提示、联机任务 ID/状态及无移动端确认按钮。
