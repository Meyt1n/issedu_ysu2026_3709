# HCT-426 PIN 与人脸认证隐私、安全和删除治理

- Issue: [#282](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/282)
- 依赖：HCT-423、HCT-424、HCT-425
- 范围：桌面 Web、本地 API、数据治理与安全验证；不包含移动端。

## 用户故事

作为家庭成员，我希望 PIN 和人脸认证只在必要的家庭范围内短暂生效，并可以撤销、删除和追溯认证结果；审计记录应能证明发生了什么，但不能反推出 PIN、人脸模板、相似度或原始图片。

## 验收标准

1. PIN 哈希只保留在对应家庭范围；家庭/成员删除会清理 PIN 哈希、撤销绑定的 PIN/人脸 session，并清空人脸模板。
2. `AUTHENTICATION` 审计只包含家庭、账号、认证方式、结果、原因码、用途和时间等元数据，不包含 PIN、密码、token、模板、图片、向量或相似度。
3. PIN/人脸错误、重放、跨家庭、撤销凭证和异常流量继续使用统一错误与限流，不暴露账号或家庭存在性。
4. 数据字典记录人脸凭证、PIN 哈希、challenge、session 的敏感级别、保存期限、加密和删除边界。
5. 删除传播说明覆盖主库、内存状态、文件/缓存、备份跳过标记、测试 fixture 和审计脱敏；提供自动安全回归和人工桌面验收清单。

## 非目标

- 不保存或恢复原始人脸照片、视频、PIN 或访问 token。
- 不把生物特征用于健康事实、风险规则、训练集或导出。
- 不修改移动端，不引入生产级分布式 session/密钥轮换实现；这些属于后续部署治理工作。

## 回滚

暂停 PIN/人脸入口并撤销现存凭证；保留正式账号登录和最小化脱敏审计。删除传播仍必须执行，不能通过回滚恢复已清空的模板或 PIN 哈希。
