# HCT-519 家庭数字孪生与 RAG 词项向量展示

- Issue：待维护者登记（当前 agent 无 Issue 创建权限）
- 关联：HCT-103、HCT-301、HCT-401、HCT-403、HCT-415、HCT-514、HCT-518
- FR/NFR：FR-01、FR-05、FR-08、FR-09；NFR-01、NFR-02、NFR-03、NFR-04、NFR-07
- 风险等级：R3（聊天中自动提取的健康信息会形成长期记录；必须保留授权、来源、确认、拒绝和删除边界）
- 状态：实现中，待 Issue、PR、全量门禁和维护者人工复核

## 1. Story

作为家庭管理员，我希望在一个新的“家庭数字孪生”页面里看到整个家庭的成员、已确认疾病、药品、过敏史、用药计划、聊天中学到的线索和 RAG 知识分块，并通过立体词云/关系图理解它们之间的词项向量联系；聊天线索应在每次聊天后自动提取并长期保存，不要求用户额外点击，但模型不能自行把线索升级为正式健康事实。

## 2. 已确认的产品方案

| 范围 | 决定 |
|---|---|
| 展示范围 | 管理后台新增独立页面，默认展示当前操作者有权读取的全家庭成员；成员前台不新增入口。 |
| 节点内容 | 家庭、成员称呼/角色、已确认疾病/药品/过敏史/用药计划、聊天记忆和有权读取的知识分块。年龄/性别若成员表尚无字段，可由用户在聊天中明确陈述后作为 `PROFILE` 线索展示。 |
| 向量 | 复用现有稀疏 `term_vector`，按词项余弦相似度生成关系边并做确定性三维投影；页面必须明确这不是神经网络语义 embedding，也不是模型隐藏思维链。 |
| 自动提取 | 每次助手回答后，主回答仍使用有界近期上下文，另以当前会话最近 24 条用户原话作为记忆索引语料，综合多轮上下文抽取并回查原文证据；助手回复、知识库内容、上传文件提取文字、服务端上下文、提问假设、否定句和无原文依据内容不得进入记忆。模型不可用时聊天回答仍正常返回。 |
| 长期保存 | 抽取结果写入 `digital_twin_memory`，保留成员、类别、值、细节、来源会话、原文摘要、摘要哈希、置信度、首次/末次出现时间和 `term_vector`。聊天正文仍由 Web 本机保存；服务端只保存被抽取的最小线索和证据摘要。 |
| 事实闸门 | 新线索固定为 `UNCONFIRMED`，可展示和关联知识，但不参与风险、计划或正式健康状态；有写权限的人确认后，疾病/药品/过敏/计划才追加不可变健康事件。拒绝后保留最小审计记录，但不再出现在孪生图中，也不参与关系判断。 |
| 删除与权限 | 图、列表和操作均先按家庭/成员权限过滤；家庭或成员擦除必须同步物理删除对应聊天记忆。知识节点沿用文档的家庭/成员/创建者/知识管理员权限。 |
| 页面呈现（2026-09-04 最新决定） | 数字孪生页只保留“家庭数字孪生”标题与“家庭语义空间”主图；统计卡、说明横幅、右侧详情、底部流程和页脚从该页移除。左侧/顶部应用框架以及主图内部的面包屑、视图和动画控制保留。 |

## 3. Given / When / Then 验收

1. Given 管理员进入当前家庭；When 打开“数字孪生”；Then 页面显示全家庭可见成员、已确认健康事实、聊天线索、知识分块、来源和 `term_vector` 词项，并提供可交互的三维关系投影。
2. Given 用户在聊天中明确说“王奶奶正在服用阿莫西林”；When 回答完成；Then 系统自动生成一条 `UNCONFIRMED` 药品线索，无需用户点击，且保存原始用户证据摘要、时间、成员和词项向量。
3. Given 早期用户消息明确陈述疾病而末轮讨论其它话题；When 自动提取运行；Then 系统仍可从用户聊天历史索引该疾病并保存对应原文证据；同一历史原文被后续请求重复携带时必须幂等，不增加出现次数。助手建议仍不得进入记忆。
4. Given 聊天线索尚未确认；When 风险、计划或成员状态被计算；Then 该线索不作为正式事实。When 有写权限的人确认；Then 对应疾病/药品/过敏/计划追加一个可追踪健康事件，图中显示“聊天线索 ↔ 已确认事实”。
5. Given 用户拒绝一条线索；When 刷新孪生图；Then 该线索不再展示或参与向量关系，且相同抽取不会静默恢复为未确认事实。
6. Given 知识文档只授权给某成员；When 有权读取该成员的操作者打开页面；Then 对应知识分块可见。When 无成员权限或跨家庭访问；Then 返回资源不存在且不泄露节点数量或内容。
7. Given 家庭/成员执行擦除；When 删除传播完成；Then 对应 `digital_twin_memory` 被物理清理，知识缓存/文件/健康事件隐藏仍遵循既有删除规范。
8. Given 模型不可用、返回非法 JSON 或候选无法在任何用户聊天原文中找到词项依据；When 自动提取运行；Then 返回 `MODEL_UNAVAILABLE`/`NO_CANDIDATES` 元数据但不影响原聊天回答，也不写入线索。
9. Given 管理员在 16:9 桌面打开页面；When 查看数字孪生页；Then 页面只展示“家庭数字孪生”标题和“家庭语义空间”主图，主图中的节点、关系边和增量提示均来自当前接口数据，不得把示意词项或截图数字冒充家庭事实；页面同时明确当前是稀疏 `term_vector`，最终模型位置由部署配置决定。
10. Given 管理员查看全家庭语义空间；When 点击任一一级类别球；Then 该类别成为局部中心球，真实子节点按双环展开，面包屑可平滑返回总览；页面每 20 秒在可见状态下拉取增量，并继续监听现有健康数据刷新事件，新节点按真实 ID 显示 6 秒淡入、簇脉冲和 `+N`，不因定时刷新清空当前钻取或选择。

## 6. 风险与回滚

- 自动抽取可能误判或漏判，因此只保存为未确认线索，并通过全部用户消息的词项落地检查与原文摘要幂等键降低幻觉和重放写入；这不是医学准确率保证。
- `term_vector` 能解释词项重合，不能证明语义因果或医学关系；页面文案和接口 `vector_note` 必须持续披露该限制。
- 云端模型部署时，聊天正文会按现有助手云端配置外发；HCT-519 不新增独立外发通道，但新增长期最小线索，因此必须纳入隐私告知、权限和删除验收。
- 回滚时先隐藏 `digital-twin` 导航并停止聊天后的自动提取，再回滚 API/页面；迁移表可保留以避免不可逆丢失，确认产生的健康事件不可删除，只能按既有补偿事件修正。
