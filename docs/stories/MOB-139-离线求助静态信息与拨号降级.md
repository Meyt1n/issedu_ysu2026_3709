## 用户价值

网络不可用时，用户仍能进入求助页、阅读静态安全指引、使用固定的 120 和已保存且已校验的紧急联系人，并在拨号前进行二次确认。应用不把自己描述成急救服务，也不在离线时朗读、恢复或猜测风险数据。

## 范围

- 监听页面在线/离线事件，在离线时展示清晰状态说明。
- 离线语音播报不调用风险 API；播报固定的 fail-closed 说明，提示直接拨打 120 或联系家人。
- 保留 120、已校验联系人、二次确认、取消和焦点恢复路径，且不依赖网络。
- 识别桌面等可能无电话能力的宿主，提示系统可能无法直接完成拨号；仍允许尝试将 `tel:` 交给系统。
- Service Worker 缓存名升级；导航请求在外壳缓存缺失时返回静态、不含健康内容且 `no-store` 的离线说明。
- `/api`、`/health` 和健康正文继续完全绕过缓存。

## 非目标

- 不新增急救 API、风险缓存、诊断、处方、自动呼救或真实号码配置。
- 不把浏览器、模拟器或本地构建结果写成 Android/PWA 真实离线签收。
- 不将网络恢复前的成员、任务、风险、事件或视觉候选从本地快照恢复。

## Given / When / Then

1. Given 应用已安装且网络断开，When 打开求助页，Then 静态指引、120、已保存联系人和二次确认可用，并显示离线状态。
2. Given 离线无法读取风险，When 点击语音播报，Then 不发起风险请求，说明无法读取实时提醒且不会朗读旧缓存或虚构风险；拨号入口不被阻塞。
3. Given Service Worker 未完成安装或外壳缓存损坏，When 离线导航，Then 返回可理解静态离线说明，不缓存 API、健康页面正文或响应。
4. Given Android WebView、PWA 或无电话能力的桌面浏览器，When 用户确认拨号，Then 尝试交给系统；无电话能力场景先显示可理解的降级提示。
5. Given 网络恢复，When 用户返回在线页面，Then 风险仅通过当前授权范围的实时请求重新加载，不恢复旧健康快照。

## 自动化测试

## 现场验收与回滚

- 需在 Android WebView 与 PWA 分别记录断网、冷启动、后台恢复、电话能力缺失和网络恢复。记录仅使用虚构演示数据，不含真实健康数据、号码、token 或日志正文。
- 真机/PWA 现场验收前本 Story 保持待验收。
- 回滚本提交可恢复旧的静态求助页面；不得移除既有二次确认、号码校验或离线 fail-closed 行为。
