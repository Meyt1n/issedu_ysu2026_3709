## 验收

- 无 Web Speech API 时静默降级，并显示可关闭的文字提示；
- 已加载语音中无中文语音时，引导安装中文“文字转语音”；
- 首次交互限制或手动播报运行时错误时，引导轻触页面后重试；
- 上述路径均不阻塞照护任务、提醒或求助等核心操作。

## 证据与回滚

- 自动验证：`npm run check`、`npm run test`、`npm run build`（移动端副本共 45 个测试通过）；
- 真机验收仍需覆盖无中文 TTS 与 Android WebView 首次交互限制；
- **听感/语音包准备**：演示与签收前阅读 [中文语音包与听感准备说明](../demo/中文语音包与听感准备说明.md)；未装 Natural 类中文包时不得把机械默认音色记为“自然播报已通过”；
