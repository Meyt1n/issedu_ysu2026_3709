# HCT-413：风险“已知晓”回写与网页闭环

## 目标

网页风险卡提供“我已知晓”入口。确认必须由服务端依据当前规则结果、风险指纹和授权状态写入最小回执；前端不得用本地按钮状态冒充成功。

## 绑定

- Issue：[#247](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/247)
- FR-05 风险规则与告警预算
- NFR-01 安全、NFR-02 隐私、NFR-03 可追溯、NFR-07 可理解

## 契约

- `GET /meta/capabilities` 声明 `risk-acknowledgement` 后，风险列表返回 `rule_version`、服务端计算的 `risk_fingerprint` 和已有回执摘要。
- `POST /households/{household_id}/members/{member_id}/risks/{rule_id}/acknowledge` 必须携带 `Idempotency-Key`、规则版本和风险指纹。
- 服务端重新计算风险；规则版本/来源事件变化时返回 `RISK_VERSION_CONFLICT`，风险不存在时返回 `RISK_NOT_FOUND`。
- Owner 或明确具有 `ACK_RISK` + `risk_alerts` + 当前 purpose 的有效授权身份可以写回；过期、撤权、跨家庭和未授权请求统一隐藏为 `RESOURCE_NOT_FOUND`。
- 相同幂等键和相同载荷返回原回执且标记 `replayed=true`；同键异载荷返回 `IDEMPOTENCY_KEY_CONFLICT`。
- 回执只包含 receipt ID、家庭/成员/规则 ID、规则版本、风险指纹、操作者和服务端时间；不写风险消息、健康正文、证据正文、图片或模型思考链。

## 验收条件

- Owner 可以从风险卡提交确认并看到操作者、时间、规则版本。
- 重复提交不新增回执或业务审计；同键异载荷和旧风险指纹被拒绝。
- 撤权身份、无动作授权、无当前风险、API 离线时页面显示明确未成功状态。
- 迁移可升级/回滚，单测和 API 测试覆盖成功、重试、冲突、撤权和脱敏审计。

## 风险与回滚

R3。回滚本 Story 的迁移、接口和前端按钮即可恢复“只读风险展示”；历史健康事件不改写，已有回执在回滚前需要保留备份/迁移处置记录。
