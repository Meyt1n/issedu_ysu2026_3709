## 用户价值

网页端助手已把证据引用做成可展开的依据区（HCT-415），移动端只显示一行来源名称，用户无法就地判断答案依据是否可信。补引用依据的折叠/展开，把被引用的原文片段、来源与版本在移动端完整呈现。

## 范围

- 回答下方的依据区：默认折叠，展开后显示被引用分块原文、来源名称与索引版本。
- 多条引用的排序与去重；点击某条可跳到 MOB-162 的只读条目详情。
- 无证据可答与降级回答的显式标注，区别于有引用的回答。
- 窄屏、特大字号与 TalkBack 下依据区的可读性与朗读顺序。

## 非目标

- 不改服务端引用校验与检索评分（属 HCT-401/HCT-450）。
- 不做引用的编辑、纠错反馈或人工标注。
- 不在无引用时伪造依据区。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 回答带引用，When 展开依据区，Then 显示被引用分块原文、来源名称与索引版本，版本与回答所用一致。
2. Given 同一来源被多次引用，When 展示，Then 去重并合并展示，不重复堆叠相同片段。
3. Given 回答为无证据可答或降级回答，When 查看，Then 明确标注没有可引依据，不展示空的依据区。
4. Given 点击某条引用，When 跳转，Then 进入该知识条目只读详情并定位到对应分块。
5. Given TalkBack 与特大字号，When 展开依据区，Then 展开状态可朗读，原文片段不截断且朗读顺序为来源→原文→版本。

## 安全、隐私与回滚

- 依据区只展示服务端返回的引用，不做本地推断或补全。
- 版本必须与回答所用索引版本一致，避免版本二义。
- 不因展示依据而暴露未批准知识内容。
- 回滚：退回单行来源展示，助手回答与安全策略不受影响。

## 实现与验证证据

- 新增 `APP/src/utils/assistantEvidence.ts`：按「文档 + 索引版本 + 分块」三元组去重（验收 2），同一文档的不同分块与不同版本仍分别保留，避免把回答的证据范围压缩错；引用条数上限 24、片段正文上限 4000 字符，仅用于保护移动端渲染与会话内存，不改服务端引用校验。
- 新增 `APP/src/components/AssistantEvidencePanel.vue`：默认折叠的 `<details>` 依据区，摘要行给出「N 条引用 · M 个其他来源 · 是否降级」；卡片朗读顺序固定为 来源 → 原文 → 版本 · 片段（验收 5），正文用 `white-space: pre-wrap` 与 `overflow-wrap: anywhere` 保证特大字号下不截断。
- `APP/src/views/AssistantView.vue`：`ChatEntry` 增加 `citations` 与当前回答的 `evidencePreview`；`applyAssistantReply()` 写入回答事件/完成事件中的服务端预览，兼容旧服务端只在 SSE 预览事件发送元数据；`settleCancelledReply()` 在停止/结束回复时连同 `sources`、`citations` 与预览一起清空，避免把不完整回答的引用当作已核验依据。
- 版本一致性（验收 1）：依据区只渲染 `AssistantResponse.citations` 原样返回的 `version`，无本地补全或推断；`citations` 不写入 `StoredChatEntry`（该类型属 `shared/voice`，在本 Story 允许修改范围外），会话恢复后退回单行来源展示，与回滚方式一致。
- 空依据（验收 3）：`shouldShowAssistantNoEvidence()` 仅在降级，或服务端 `evidence_preview` 明确表示本轮没有本地/外部资料且无其他来源标识时显示显式说明；只含家庭事实来源的回答不会被误报成无证据，旧版缺少预览元数据的会话仍按兼容策略不推断。
- 证据预览回归（2026-09-02）：完成事件缺少 `evidence_preview` 时沿用同一轮 SSE `evidence_preview`，并新增 4 项空状态判定测试，保证无证据提示不会因流式协议差异丢失。
- 跳转（验收 4）：随 MOB-162 一起落地。引用卡片的「查看条目详情」为 `RouterLink`，跳到 `/knowledge/:docId?chunk=&version=`，由知识条目只读页高亮并滚动定位到被引用分块，并在服务端当前版本与本次回答所用版本不一致时显式告警。该跳转必须与 MOB-162 的路由同批合入，单独合并会指向不存在的路由。
- `cd APP && npx vue-tsc --noEmit` 通过；`npx vitest run` 通过（39 个测试文件、362 项，其中 `src/utils/assistantEvidence.test.ts` 13 项）；`npx vite build` 与 `git diff --check` 通过。
