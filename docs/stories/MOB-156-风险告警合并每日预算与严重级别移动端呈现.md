- 状态：实现与自动回归完成；真实后端设备矩阵待联调环境和设备执行
- 风险：R3（只读风险元数据呈现，不改变规则、预算或医疗结论）

## 目标与边界

移动端风险页只展示家庭服务器返回的风险等级、规则版本、预算摘要、去重/合并元数据、有效期和脱敏证据摘要。客户端不重新计算风险、不推测被预算压制的告警、不把未返回的数据解释为“无风险”。

当服务端缺少规则版本、预算、去重/合并、有效期或证据字段时，页面明确显示“服务端未返回完整审计信息”，并保持只读安全降级。

## Given / When / Then

- Given 服务端返回规则集版本、普通预算和压制数量，When 打开提醒页，Then 展示服务端实际值及严重信号独立通道说明。
- Given 风险返回规则版本、指纹和去重/合并字段，When 查看提醒列表或详情，Then 展示服务端元数据，不使用固定 `rules-v0` 或客户端推断。
- Given 严重风险与普通预算同时存在，When 加载提醒页，Then 严重数量采用服务端计数，预算压制说明不压低或静默严重风险。
- Given 审计字段缺失，When 查看风险列表或详情，Then 显示不完整提示，不伪造有效期、合并结论、证据摘要或医疗建议。
- Given 切换家庭、成员、用途、授权或会话，When 页面重新加载，Then 风险列表与预算摘要随当前 Provider 上下文刷新，旧页面请求结果不会覆盖当前上下文。

## 实现范围

- `APP/src/api/types.ts`：对齐风险列表、规则版本、指纹、回执和可选审计字段。
- `APP/src/data/httpProvider.ts`：映射服务端元数据，聚合多成员的服务端预算摘要，并对缺失字段 fail-closed。
- `APP/src/data/demoProvider.ts`：提供明确标注为演示的完整元数据，保持演示模式可验收。
- `APP/src/views/AlertsView.vue`、`AlertDetailView.vue`：呈现规则版本、预算摘要、压制说明、去重/合并、有效期和证据摘要。
- `APP/src/data/httpProvider.test.ts`：覆盖完整/缺失契约、严重计数和多成员摘要聚合；移动端页面的视觉验收需使用 APP 自己的运行入口，不与桌面端 `tests/browser` 混用。

## 验收证据

- Provider 定向测试覆盖完整服务端元数据、缺失字段不回退固定规则/预算、严重计数和摘要聚合。
- Provider 合成数据覆盖风险页所需的预算说明、服务端规则版本、合并元数据和详情审计卡；所有数据均为合成数据。
- `npm run check`、`npm test -- --run`、`npm run build`、`npm run privacy:scan` 和 Android 安全审计在 PR 中记录。
- 真实后端、PWA 安装态和 Android 真机的严重/较高/一般/信息/重复/预算耗尽/撤权矩阵需在联调服务启动后由验收人执行；自动化合成测试不替代设备验收。

## 安全、隐私与回滚

- 风险正文、健康事件正文和证据 payload 不写入本地缓存、通知或新的本地状态；只展示服务端脱敏摘要。
- 客户端不改变规则判定、预算、严重级别、授权范围或医疗结论。
- 无数据库迁移、无新增网络出口；回滚时删除预算元数据卡和映射，保留原只读风险列表并显示限制。
