# HCT-536：图谱节点特色化、卡片花纹差异化与桌宠互动扩展

## 1. 范围

- FR/NFR：FR-09（健康图谱/首页展示）、NFR-02（不展示敏感正文）、NFR-04（可降级）、NFR-07（可访问）。
- 关联：本地前端展示层；Issue 由维护者创建后回填。承接 [HCT-535](HCT-535-大屏信息架构重排与助手交互优化.md) 后的浏览器反馈（图谱太素、卡片纹理雷同）。

## 2. 验收条件

### 健康图谱节点特色化（GraphView）

- 五类节点从「圆球+三字」升级为类别专属图形：在用药品=斜置双色胶囊、过敏史=水滴、关注疾病=圆角医疗十字、用药计划=表盘时钟、照护者=小人（头+肩），全部白底描边、随球体一起浮动。
- 每个节点底加类别色柔光晕；中心外围加两层反向慢旋的虚线轨道环；选中节点放大 1.16 倍并投出高光；hover/键盘焦点沿用既有放大与投影。
- 数据与权限不变：节点仍仅由已确认事件生成，详情卡/图例/粒子流动保留。

### 卡片花纹与颜色差异化（首页）

- 每张首页区块卡在 `--overview-accent` 之外新增 `--card-pattern` 专属透明花纹：待确认=菱形与对勾、今日用药=胶囊与十字、最近识别=同心扫描环、家庭成员=爱心、近期变化=波浪线、健康日历=点阵；天气卡=云朵雨滴；通用卡片组的默认花纹仍为叶子。
- accent 对角晕染提高到 15%/10%，各卡色相（陶土/深绿/天蓝/琥珀/玫瑰/灰绿）明显可辨。
- 实现方式为纯 CSS 变量注入（`var(--card-pattern, 默认叶子)`），新增卡片只需声明一个变量即可换花纹。

### 健康日历

- 标题统一为「健康日历」（含 aria-label）。
- 月首尾补位空格渲染为纯占位 span（无按钮、无背景、无边框），网格对齐但视觉上完全留白。

### 桌宠互动与表现形式扩展

- 新增「喂小饼干」：饼干落下 → 桌宠弹性咀嚼 → 气泡「谢谢投喂！数据小饼干最好吃了」。
- 双击桌宠本体 = 摸摸头（爱心粒子），与单击打开菜单区分。
- 状态配饰：扫描时佩戴放大镜（摇摆）、陪伴中戴耳机、离线头顶飘 z z；22 点后进入夜晚模式——身体转暖夜色、头顶月牙、空闲时闭眼打盹。
- 打开菜单有 30% 概率随机「啾一下」短气泡（嘿嘿，找我呀？等）。
- `prefers-reduced-motion` 下全部新增动画停用；桌宠不输出任何健康判断。

### 大屏内容收敛（同日增量，用户反馈「去掉两个数字孪生投影」）

- 家庭大屏移除「家庭轨道核心」与「家庭空间投影」两张数字孪生卡，保留事实指标、趋势、脱敏详情和运行状态。
- 健康日历迁入家庭大屏，沿用事件/计划/复核数量聚合，不展示健康正文。

## 3. 实现边界

- 修改展示层与浏览器断言；不修改 API、权限或数据边界。

## 4. 回滚与风险

- 回滚：还原四个文件即可；无数据/权限影响。
- 风险：SVG data-URI 花纹在极老浏览器退化为纯色底；节点图形在导出/截图场景与旧版观感不同（纯视觉）。
