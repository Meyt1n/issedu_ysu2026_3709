## 用户价值

出现问题时家人或维护者可以拿着"请求标识"去服务端日志定位：每个请求（成功、失败、超时、重试）都有可展示的定位信息；写操作能关联事件回执与幂等键结果；风险与视觉详情展示的版本全部来自服务端返回，不猜测；标识缺失时如实标注"回执信息不可用"。

## 范围

- `requestLog`（新，`APP/src/api/requestLog.ts`）：内存环形缓冲（最近 30 条）记录每次请求的 method、脱敏 path（去 query）、结局（success/client-error/server-error/unreachable/timeout）、HTTP 状态、服务端 `X-Request-ID`、时间；写请求附幂等键与响应中的事件/任务 ID；不记录健康正文、URL query 与任何凭据；
- `ApiClient`：15s 超时（AbortController）区分"超时"与"不可达"；成功与失败响应统一记录 requestLog（成功路径从此也有可定位回执）；
- `ErrorPresentation` 携带 `requestId`，`ErrorNotice` 展示"请求标识"（缺失时显示"回执信息不可用"，不伪造）；
- `我的` 页新增"最近请求与回执（本机诊断）"卡片；登录/登出/切换会话时随既有清理注册表清空；
- 风险详情与视觉候选的版本展示维持"只显示服务端返回"（既有行为回归覆盖）。

## 非目标

- 不在本地持久化请求日志（不写 localStorage）；不上传日志；
- 不生成或猜测任何服务端标识；不由 APP 推断规则/模型/主数据版本；
- 不改变后端契约；不展示健康正文于诊断信息。

## Given / When / Then

- Given 任一 API 请求成功或失败；When 用户查看"最近请求与回执"或错误提示；Then 可看到请求标识（或如实标注不可用），并区分成功、失败、超时与重试（同一幂等键多次出现即重试）。
- Given 确认/延期/跳过/视觉任务创建；When 服务端返回事件/任务；Then 诊断条目与操作历史可关联动作、事件 ID、服务端时间与最终状态（操作历史沿 MOB-135）。
- Given 风险卡或视觉候选含版本；When 展示详情；Then 只显示服务端返回的版本（AlertDetail 规则版本、ScanView 服务端版本行既有回归）。
- Given 请求 ID/事件 ID 缺失；When 展示；Then 标注"回执信息不可用"，绝不生成伪造 ID。
- Given 会话切换、撤权或清理本地状态；When 回看诊断；Then 旧身份的标识与正文不残留（随 `registerSessionCleanup` 清空）。

## 实现证据

- `APP/src/api/requestLog.ts`（新）：内存环形缓冲（30 条）记录 method、去 query 的 path、结局（success/client-error/server-error/unreachable/timeout）、状态、`X-Request-ID`、时间、写请求幂等键与响应体回执对象 ID；不落盘、不含健康正文；
- `APP/src/api/client.ts`：15s AbortController 超时区分"超时"（`REQUEST_TIMEOUT`）与"不可达"（`DEPENDENCY_UNAVAILABLE`）；成功与失败统一记录 requestLog，成功路径从此也有可定位回执；外部 `signal` 仍受尊重；
- `APP/src/api/errors.ts`：`ErrorPresentation.requestId`（缺失为 null）+ `presentApiError` 统一附加 `ApiClientError.requestId` + `REQUEST_TIMEOUT` 专用文案（结果未知、重试复用幂等键）；
- `APP/src/components/ErrorNotice.vue`：展示"请求标识"，缺失时如实显示"回执信息不可用（服务端未返回请求 ID）"，不伪造；
- `APP/src/views/MeView.vue`："最近请求与回执"诊断卡片（最近 10 条，含结局/状态/请求标识/幂等键/回执对象/时间）；
- `APP/src/data/index.ts`：会话/上下文清理注册表统一调用 `clearRequestTraces()`，登出/切换身份后旧标识不残留；
- 风险规则版本（AlertDetail"规则 x · 版本 y"）与视觉版本（ScanView"服务端"版本行、状态卡 modelVersion）维持只显示服务端返回值，本 PR 未改变语义。

## 安全、隐私与回滚

- 诊断条目只含 method/path（去 query）/状态/请求 ID/时间/幂等键/事件 ID，不含健康正文、token、PIN、密码或图片；
- 幂等键是内部关联标识，不是凭据，可展示但不得与凭据同现；
- 回滚：回退本 PR 即恢复现有错误 request ID 捕获，移除诊断卡片与超时区分。
