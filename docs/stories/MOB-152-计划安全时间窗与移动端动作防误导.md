- 风险: R2。客户端不得依据设备时钟、频次或剂量推断允许操作。

## 范围

任务卡只消费服务端 `planVersion`、`allowedActions`、`nextAllowedAt` 和时间窗说明。缺失任一策略时显示只读说明，不启用确认。`TIME_WINDOW_VIOLATION` 会保留原任务状态，提示下一允许时间/联系路径，不自动重试。

## Given / When / Then

- Given 服务端返回完整计划策略，When 展示任务，Then 显示计划版本和可执行范围。
- Given 策略缺失，When 打开任务，Then 任务只读，不使用本地时钟放行。
- Given 服务端返回 `TIME_WINDOW_VIOLATION`，When 提交失败，Then 保留状态并显示安全原因，不重复提交。
- Given 计划更新或 409，When 刷新，Then 使用服务端最新快照，不混用旧计划。
- Given 401、撤权或离线，When 操作失败，Then 保持不可用状态并走既有鉴权/网络错误处理。
