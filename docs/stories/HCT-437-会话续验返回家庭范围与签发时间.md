## 1. 用户价值与目标

客户端从后台或网络恢复时需要知道当前 Bearer 会话属于哪个家庭、何时签发以及何时到期。HCT-437 扩展既有 `/auth/session` 续验响应，返回这些非秘密元数据，帮助网页和手机端清理旧上下文、展示正确家庭并提前处理会话到期。

## 2. 范围与非目标

本切片实现：

1. `/auth/session` 返回 `actor_id`、`household_id`、`issued_at`、`expires_at`；
2. 密码登录的会话家庭范围为空，PIN/人脸家庭会话返回绑定家庭；
3. 续验仍只接受真实 Bearer 会话，登出、撤销或过期继续返回 401；
4. 响应不返回 `session_token`、token hash、密码、PIN 或其他凭据；
5. 补充普通密码会话、PIN 会话和无秘密契约测试。

不做：

- 不改变会话 TTL、撤销、轮换、CSRF 或持久化模型；
- 不新增数据库字段或迁移；
- 不允许客户端通过响应字段修改服务端会话范围。

## 3. Given / When / Then 验收

- Given 有效密码 Bearer 会话；When 调用 `/auth/session`；Then 返回 actor、空家庭范围、正的 `issued_at` 和晚于签发时间的 `expires_at`。
- Given 有效 PIN 家庭会话；When 调用 `/auth/session`；Then `household_id` 与会话服务端记录一致。
- Given 登出、撤销或过期令牌；When 调用续验；Then 返回 401。
- Given 任意有效会话；When 检查响应；Then 不包含令牌、token hash、密码或 PIN。
