## 用户价值

从事件链重建成员-疾病-过敏-药品关系图，支持全量重放和 checkpoint 增量更新。

## 范围

- 事件时间线 API：按成员/时间范围查询完整事件链
- 关系投影：从事件链重建实体关系图（member→disease→allergy→drug→plan→caregiver）
- 全量重建：从空投影或 checkpoint 确定性重放所有事件
- 每一条边可追溯到源事件

## Given / When / Then

- Given 成员有多条健康事件；When 查询时间线；Then 返回按时间排序的完整事件链。
- Given 空数据库；When 执行全量重放；Then 重建的关系投影与在线状态一致。
- Given checkpoint 之后有新事件；When 增量重放；Then 仅处理 checkpoint 之后的事件。

## 测试

- 时间线查询（正常/空/跨成员）
- 关系投影与在线状态一致性
- 空投影全量重放
- Checkpoint 增量重放
