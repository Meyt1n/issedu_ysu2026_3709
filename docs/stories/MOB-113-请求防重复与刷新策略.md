## 用户价值

在弱网、慢请求或用户重复点击时，移动端只提交一次照护动作，并在回执丢失后使用同一幂等键重试。收到服务端成功回执后，页面以服务端重新读取的数据为准；仅刷新失败时不再次提交健康事件。

## 范围

- 今日页确认、延期、跳过写操作的单轮加载锁定与重复触发守卫；
- 计划动作按 `action + plan_event_id` 复用主仓库幂等键；
- 视觉任务创建在当前运行时复用同一 File 的上传结果和任务幂等键，创建失败后可重试；
- 写操作成功后统一刷新成员、任务、趋势和风险；刷新失败保留已收到的写回执，并只提供刷新重试；
- 会话或当前成员切换时丢弃旧上下文回执，不把旧家庭结果写入新页面。

## 非目标

- 不新增或修改主仓库 API、数据库迁移或事件语义；
- 不把文件上传接口包装成服务端持久幂等能力；当前运行时只共享同一 File 的上传请求，服务端视觉任务仍以任务幂等键去重；
- 不缓存健康数据、幂等键或视觉任务快照到 `localStorage`；
- 不改变演示模式的虚构数据和既有医疗安全边界。

## Given / When / Then

- Given 今日页正在提交确认/延期/跳过；When 用户重复点击或重复触发键盘事件；Then 写操作保持加载锁定，不产生第二次调用。
- Given 写请求发出后网络回执丢失；When 用户点击错误提示中的重试；Then 同一计划动作使用同一幂等键，服务端返回原事件，不追加重复事件。
- Given 视觉任务创建在上传后失败；When 用户重试；Then 当前运行时复用已上传文件和任务幂等键，不重复上传或创建第二个视觉任务。
- Given 写操作已收到服务端成功回执；When 后续刷新失败；Then 页面不再次提交写操作，保留回执状态并提供刷新重试。
- Given 写操作进行中切换会话或当前成员；When 旧请求返回；Then 丢弃旧上下文回执，不覆盖新家庭/成员页面。
