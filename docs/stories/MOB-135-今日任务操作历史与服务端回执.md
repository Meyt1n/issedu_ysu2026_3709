## 用户价值

家人在"今日"页确认、延期或跳过任务后，可以打开"操作历史"查看完整记录：做了什么动作、哪个任务、哪位成员、服务端记录的时间、事件（回执）标识和该计划当前的最终状态。网络失败或回执丢失时，历史里如实标注"未获服务端回执"，不把本地点击当作成功，并提供安全重试。

## 范围

- `DataProvider.listTaskActionHistory(memberId)`：从服务端时间线事件（`plan_confirmed`/`plan_deferred`/`plan_skipped`）推导操作历史；同一 `plan_event_id` 只计一条有效动作（最新一条），更早的同类动作标注"已被后续操作覆盖"（服务端幂等保留）；
- `deriveTaskActionHistory` 纯函数：动作标签、任务标题（复用计划事件标题推导）、服务端时间（`occurred_at`）、事件 ID、最终状态、回执状态（`RECEIPTED`/`SUPERSEDED`）；
- 演示模式：内存操作日志（随演示状态重置），条目明确标注演示来源；
- `TodayView` "操作历史"卡片：默认收起，展开时按当前成员加载；本地待确认/失败条目置顶并明确标注（仅内存展示层，切换会话/成员即清空，不建立第二份健康事实库）；
- 空态/未授权/接口不可用分别展示原因，不展示猜测数据。

## 非目标

- 不在 APP 建立第二份健康事实库；历史是服务端事件的只读展示；
- 不展示未授权健康正文，只展示脱敏动作摘要（动作、任务标题、时间、事件 ID、状态）；
- 不改变任务操作本身（确认/延期/跳过）的提交与幂等语义（MOB-113 已定）；
- 不新增后端接口。

## Given / When / Then

- Given 用户执行确认/延期/跳过且服务端返回成功事件；When 打开操作历史；Then 展示动作类型、任务、成员、服务端时间、事件（回执）标识和最终状态。
- Given 请求网络失败、返回 409 或回执丢失；When 查看历史；Then 该次尝试以"本地未获回执"置顶展示，不当作成功，提供安全重试（沿用幂等键语义，不重复创建事件）。
- Given 同一动作因超时被重试；When 历史重新加载；Then 依靠后端幂等事件每个 `plan_event_id` 只有一条有效动作，更早动作标注覆盖关系，不重复计数。
- Given 用户切换成员、身份或数据源；When 打开历史；Then 旧会话记录（含本地待确认条目）立即清空，不与新家庭混合。
- Given 无历史、无权限或接口不可用；When 打开入口；Then 分别显示空态/未授权/不可用原因。
