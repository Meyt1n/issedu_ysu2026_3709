# HCT-448：症状用药空库友好降级（延续方案 A / FR-08）

> **2026-08-27 局部替代（[ADR-0007](../decisions/0007-助手统一安全策略与受控开放联网.md) 决策 2B）：** 本 Story 非目标中「`MEDICATION_SAFETY` 无证据仍 `EVIDENCE_REQUIRED` 硬降级 + escalate」条款已被替代——现在无本地证据也可回答，服务端统一追加风险说明；明确个体剂量数字问题改由 `DOSE_DECISION` 确定性硬拒。空库友好降级仅保留在模型不可用等真实降级场景，且季节模板改按症状词触发、不按日历。相关旧测试（`test_medication_safety_short_circuits_without_knowledge` 等）已更新为新行为断言。

- FR/NFR：FR-08、NFR-04（医疗边界）、NFR-07（可用体验）
- Issue：关联 #310 / FR-08 助手安全路由（延续 PR #426 方案 A；无独立 Issue 时随助手 PR 绑定说明）
- 用户价值：首页「夏天吹空调后有点鼻塞，一般可以了解哪些用药资料？」这类教学向、非个体处方问题，在本机知识库无命中/空库时不再触发「缺少可核验引用 + 超出系统边界 + 受控回复」三连风控墙，能完成一轮正常教学对话
- 范围：
  - `SYMPTOM_MEDICATION` 无知识命中时改走友好教学降级 `KNOWLEDGE_UNAVAILABLE`（`escalate=false`、确定性回答：季节情境 + 一般照护 + 明确本机暂无已审核知识卡 + 建议咨询医生药师）；单 agent（`run_assistant`）与多 agent（`run_local_multi_agent`）路径行为一致
  - knowledge agent 对空库/无授权文档（`NO_AUTHORISED_DOCUMENTS`/`EMPTY_INDEX`）trace 记 `degraded`，不再伪装成 `blocked`（拦截）；`blocked` 仅保留给真实工具/范围失败
  - 前端 `AssistantView.vue` 对 `KNOWLEDGE_UNAVAILABLE` 显示友好提示，不再套用警示三连
  - 补充演示知识卡《感冒样症状居家照护教学卡》使教学 demo 对该类问题可命中带引用回答
- 非目标：
  - 不放开无证据自由生成（无命中时回答是确定性模板，不含模型草稿）
  - 不改变 `MEDICATION_SAFETY`（同服/停换药/个体剂量）无证据时的 `EVIDENCE_REQUIRED` 硬降级与 escalate
  - 不改变引用校验：知识有命中但模型未引用仍 `EVIDENCE_REQUIRED`；伪造引用仍 `CITATION_NOT_FOUND`
  - 不编造病毒名/病例数；不提供购药问诊导流
- 风险：P1（医疗边界相邻改动，已用单测钉死硬边界不回退）
- 依赖：方案 A（PR #426）已合并的 `SYMPTOM_MEDICATION` 路由与提示词；`seasonal_care_context`
- 允许修改：`src/api/app/tool_call.py`、`src/api/app/local_agents.py`、`src/ai/safety/seasonal_context.py`、`src/web/src/views/AssistantView.vue`、`docs/demo/`（教学卡/清单/金标集）、相关单测、本 Story、需求追踪矩阵
- 验收：
  - [x] Given 空库 + 问「夏天吹空调后有点鼻塞，一般可以了解哪些用药资料？」；When 多 agent 编排；Then `degraded=true`、`degrade_reason=KNOWLEDGE_UNAVAILABLE`、`escalate=false`、回答含季节照护与「暂时没有已审核知识卡」、保留追问建议、synthesis 不调用模型
  - [x] Given 同问题走单 agent（`run_assistant`）且检索空/模型无引用；When 生成；Then 与多 agent 一致的友好降级，不返回模型无证据草稿

  - [x] Given 知识库含感冒照护卡；When 检索「夏天吹空调后有点鼻塞…」；Then 命中《感冒样症状居家照护教学卡》（金标 kb-gold-025/026），正常生成带 citations 的教学回答
