## 用户价值

联机模式先确认家庭服务器实际提供的能力，再向用户展示可用范围和限制。服务端没有声明的接口不会被移动端包装成“可用”，弱网、旧后端或能力探测失败时也会安全降级。

## 范围

- 在“我的 → 数据来源 → 家庭服务器”测试连接时请求 `/api/v1/meta/capabilities`；
- 展示服务阶段、已提供能力、未提供/未启用能力及其中文说明；
- 能力探测失败时保留健康检查结果，但将未确认能力按不可用处理；
- 风险“我已知晓”回写和视觉任务入口按能力声明 fail-closed：只有服务端明确声明能力可用时才开放；
- 能力快照只保存在当前运行时，不写入 localStorage，切换身份、访问目的、服务器或模式时清理。

能力 ID 的用户文案集中在 `APP/src/stores/capabilities.ts`。未知 ID 保留显示但不推断语义；服务端同时列入 `available` 和 `unavailable` 时以后者为准。

## 非目标

- 不在本 Story 内实现主仓库缺失的风险回写、视觉推理或正式鉴权接口；
- 不缓存健康数据或能力快照，不改变演示模式的本地虚构数据；
- 不把“视觉任务可创建”解释为“手机端已有视觉推理结果”，候选仍需网页端人工复核。

## Given / When / Then

- Given 联机模式填写了开发期身份和访问目的；When 点击“测试连接”；Then 先显示健康服务状态，再显示能力阶段、可用列表和未提供列表。
- Given 能力响应把同一 ID 重复返回或同时列入两类；When 移动端归一化响应；Then 去重，并以 unavailable 优先，避免误开放入口。
- Given 能力响应未声明风险知晓回写；When 打开风险详情；Then “我已知晓”按钮禁用并说明当前能力限制，不调用不存在的写接口。
- Given 能力响应未声明视觉任务；When 打开“拍药盒”；Then 拍摄、相册和“开始识别”入口禁用并标注未提供。
- Given 健康检查成功但能力探测失败；When 用户进入联机功能；Then 显示“能力探测未完成”，未确认能力全部按不可用处理，不把服务包装成完整可用。
- Given 切换服务器、身份、访问目的或数据模式；When 会话边界变化；Then 清理旧能力快照，防止沿用另一家庭或另一授权上下文的结果。
