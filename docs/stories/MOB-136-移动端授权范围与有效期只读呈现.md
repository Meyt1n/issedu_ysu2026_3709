## 用户价值

家庭 Owner 在手机上打开成员档案就能看到"谁、能看什么字段、做什么动作、什么用途、有效期到哪天、现在是什么状态"，到期或撤回有明确文字提示；照护者视角如实显示"无权查看授权管理"而不是误导性的"暂无对外授权"。

## 范围

- `ApiClient.listAuthorizations` 升级为返回 `AuthorizationRead[]`（HCT-102 契约：member/grantee/字段/动作/用途/valid_from/valid_until/revoked_at/version）；
- `authorizationStatus` 纯函数：状态只由服务端时间与撤回字段推导（待生效/有效/即将到期[7 天]/已到期/已撤回），解析失败按已到期 fail-closed；
- `HttpDataProvider.getMemberDetail`：加载授权列表并按成员过滤；非 Owner 的 403/404（隐藏式拒绝）映射为 `'UNAUTHORIZED'`，与"暂无授权"空态区分；其他异常如实抛出；
- `MemberDetailView`"谁可以查看"：完整字段 + 状态标签 + 有效期文字（含到期/撤回提示）+ 服务端版本；被授权人显示服务端身份标识（actor id），不做姓名猜测映射；
- 演示模式授权数据升级为完整形态并演示"即将到期"状态。

## 非目标

- 授权创建/修改/撤回仍在网页端（移动端只读）；
- 不由 APP 推断被授权人姓名或扩大服务端已授予范围；
- 不改变服务端授权判定与隐藏式拒绝语义。

## Given / When / Then

- Owner 查看成员详情 → 列表展示被授权人（身份标识）、字段、动作、用途、有效期（起止 + 状态文字）、服务端版本 —— 联调截图；
- 非 Owner → 服务端 403/404 → 显示"当前身份无权查看授权管理（服务端隐藏式拒绝）；这不代表没有授权"，不与空态混淆 —— 单元测试 + 联调截图；
- 接口异常（非 403/404）→ 页面如实报错可重试，不伪造"暂无授权" —— 单元测试；
- 即将到期（≤7 天）/已到期/已撤回 → 标签与文字提示，不再暗示有效 —— 纯函数测试 + 联调截图（到期/撤回由服务端数据制造）；
- 字段未授权 → 沿用既有"未获授权"与"无记录"区分（时间线/用药）。

## 实现证据

- `APP/src/api/types.ts`：`AuthorizationRead`（HCT-102 契约字段）；`APP/src/api/client.ts`：`listAuthorizations` 从 `unknown[]` 升级为强类型；
- `APP/src/data/types.ts`：`AuthorizationStatus`（待生效/有效/即将到期/已到期/已撤回）与完整 `AuthorizationView`；`MemberDetail.authorizations` 支持 `'UNAUTHORIZED'`；
- `APP/src/data/httpProvider.ts`：`authorizationStatus` 纯函数（7 天"即将到期"阈值；解析失败按已到期 fail-closed）+ `getMemberDetail` 按成员过滤映射；非 Owner 的 403/404 → `'UNAUTHORIZED'`，其余异常如实抛出；
- `APP/src/views/MemberDetailView.vue`：被授权人（服务端身份标识，不做姓名猜测）、可见字段、允许动作、用途、有效期（起止 + 状态文字提示）、服务端版本；`'UNAUTHORIZED'` 显示"服务端隐藏式拒绝；这不代表没有授权"；
- `APP/src/data/demoProvider.ts`：演示授权升级为完整形态，含"即将到期"示例。

测试（`APP/` 下 `npm run test`，2026-08-23 全部通过，24 files / 196 tests，新增 3 项）：

- 状态推导：有效/即将到期/已到期/已撤回/待生效/非法日期 fail-closed；
- Owner 视角：完整字段映射、按成员过滤、走授权端点；
- 非 Owner：403/404 → `'UNAUTHORIZED'`（与"暂无授权"区分）；502 等其他异常如实抛出。
