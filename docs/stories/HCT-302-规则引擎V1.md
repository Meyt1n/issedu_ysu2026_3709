## 用户价值

从事件链自动检测过期药品、低库存、重复成分、过敏冲突和药物相互作用，每条告警可追溯到源事件。

## 范围

- 规则引擎框架：输入事实 → 匹配规则 → 输出告警
- 过期检测 / 低库存阈值 / 重复成分 / 过敏冲突 / 相互作用
- 每条告警携带源事件 ID 链
- 规则版本化，可回滚

本次增量将重复成分和相互作用的输入收紧为已确认药品事实及批准本地主数据：重复成分读取主数据的 `active_ingredients`；相互作用只读取主数据显式登记的药品对和提示等级。未知药品组合不自动推断相互作用，也不让大模型直接下结论。

## Given / When / Then

- Given 药品过期日期已过；When 运行规则；Then 产出过期告警。
- Given 同一成分出现在多个药品中；When 运行重复规则；Then 产出重复成分告警。
- Given 成员过敏清单含青霉素；When 添加含青霉素药品；Then 产出过敏冲突告警。
