在干净环境和最终 `master` SHA 上执行，并把结果与环境信息保存到交付包；命令失败时保持 Story 为“进行中/阻塞”：

```powershell
uv run python scripts/hct405_acceptance_gate.py
uv run python scripts/hct409_release_gate.py
uv run pytest
uv run ruff check src/api src/ai scripts tests migrations
npm.cmd run check:web
npm.cmd run test:web
npm.cmd run build:web
git diff --check
git ls-remote origin refs/heads/master
```

移动端和双仓库证据还必须附上对应环境、Android/PWA 形态、Actions 运行链接以及两端 `master` SHA；没有这些证据不得标记“已验证”。

## 5. 风险、回滚与归档规则

- 若演示、报告或追踪矩阵出现事实错误，冻结交付包，回到上一通过版本，修复事实源后重新生成，不覆盖历史归档。
- 若部署、模型、隐私或设备门禁失败，只记录失败证据和责任人，保留上一可运行版本，不降低授权、拒识、无证据拒答或无导流门槛。
- 归档前执行秘密/敏感文件扫描；发现真实数据、密钥、权重、日志或缓存时停止归档并删除制品，不关闭相关 Issue。
