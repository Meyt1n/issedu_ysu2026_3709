- Issue: #238
- 状态: 已实现受控网页交接与本地降级；真实网页复核接口与设备联动待环境验收。
- 负责人: ry12-20
- 风险: R2。人工复核前，视觉候选不得写入健康事实。

## 范围

扫描结果展示任务状态、任务标识和既有轮询状态。应用只在 `VITE_REVIEW_WEB_BASE` 是 HTTPS 且与当前应用同源时打开网页复核，URL 仅包含 `task` 参数。未配置、外部、HTTP 或格式错误地址均被拒绝，使用者可复制任务标识并在已登录网页端查询。

## Given / When / Then

- Given 已授权任务和可信网页地址，When 打开交接，Then 在新窗口以 `noopener,noreferrer` 打开网页复核；不传递密码、PIN、Bearer、Cookie、成员或候选正文。
- Given 网页地址未配置或不可信，When 尝试打开，Then 不跳转，显示原因并保留复制任务标识降级。
- Given 网页端完成或拒绝复核，When 返回 APP 并轮询，Then 只显示服务端最终任务状态和下一步，不把跳转当作确认成功。
- Given 授权撤回、任务不存在或网络不可用，When 回读失败，Then 使用既有受控错误路径，不泄露候选正文。

## 测试与回滚

单元测试覆盖 HTTPS 同源允许、外部 URL、HTTP 和缺少配置拒绝。回滚时移除网页入口，保留任务标识与既有只读状态回查。
