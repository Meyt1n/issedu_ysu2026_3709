## 用户价值

网页端首页已有健康新闻常驻展示（HCT-444），移动端首页还没有对应入口。补一张季节健康资讯小卡片，消费家庭服务器已抓取并缓存的白名单资讯，让长辈在首页就能看到当季提示，并能一步跳到本地助手继续追问。

## 范围

- 首页新增季节健康资讯小卡片：标题、一句话摘要、来源名称、发布/抓取时间、缓存新鲜度。
- 卡片点击进入本地助手，并把该条资讯作为上下文带入提问草稿。
- 能力未声明、服务端无资讯、抓取失败或仅有旧缓存时的四种降级态文案。
- 长辈模式与特大字号下的卡片布局；TalkBack 朗读顺序与可聚焦区域。

## 非目标

- 不在 APP 内直接请求任何第三方资讯源；只消费家庭服务器受控结果。
- 不做资讯收藏、分享、评论或推送。
- 不改后端抓取、白名单与缓存策略（属 HCT-444）。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given 服务端返回白名单资讯且能力已声明，When 打开首页，Then 展示资讯卡片并同时显示来源与抓取时间。
2. Given 资讯含用药或诊疗措辞，When 展示，Then 只保留科普口径与查看来源入口，不生成停药、换药、剂量或诊断结论。
3. Given 服务端资讯不可用、超时或能力未提供，When 打开首页，Then 显示明确的不可用说明并保留首页其余功能，不展示空白卡片。
4. Given 只有过期缓存，When 展示，Then 明示这是缓存内容与其时间，不冒充实时资讯。
5. Given 点击卡片，When 进入本地助手，Then 提问草稿带上该条资讯标题与来源，用户可自行修改后再提交。
6. Given 长辈模式与特大字号，When 查看卡片，Then 文字不截断、触控区不小于既有标准，TalkBack 能按标题→摘要→来源顺序朗读。

## 安全、隐私与回滚

- 资讯不是医疗建议；卡片不得出现购药、问诊、导流入口。
- 不把成员姓名、健康事件或位置发送给任何外部资讯服务。
- 本机不缓存资讯正文之外的任何健康数据。
- 回滚：隐藏首页资讯卡片入口，首页其余模块不受影响。
