## 用户价值

家庭 Owner 可以在页面中查看家庭成员，创建、编辑和撤销照护者授权，并清楚看到授权的数据域、动作、目的和有效期。照护者只能看到当前身份仍有效且匹配的授权范围；健康事件正文不在本页面加载。

## 范围与非目标

本 Story 覆盖前端授权工作台、家庭与成员查询、授权 CRUD、版本冲突提示、撤权后的即时视图更新，以及照护者授权范围预览。后端 API 的授权判断和健康数据字段过滤是权威安全边界，本 PR 不复制或替代后端策略。

本 Story 不实现真实账户登录、PIN/密码/二维码、健康事件录入或展示、字段策略扩展，也不提交真实健康数据、密钥、缓存或运行日志。

## 冻结契约

- 前端请求授权 API 时携带开发环境允许的 `X-Actor-Id` 和 `X-Access-Purpose`。
- 授权范围只使用后端已冻结的 `health_events` 数据域及其动作，不擅自发明健康字段。
- 更新和撤销携带 `expected_version`；服务端返回 `409 AUTHORIZATION_VERSION_CONFLICT` 时保留页面状态并提示刷新。
- 未授权、跨家庭、已撤销或已过期的资源由 API 统一以隐藏式 `404 RESOURCE_NOT_FOUND` 处理。
- 撤权成功后，授权立即从照护者预览中消失；预览仅展示授权元数据，不是后端安全证明。

## Given / When / Then

- Given 未填写开发身份或家庭不可用；When 打开工作台；Then 页面显示可定位的错误状态，不发起带空身份的授权请求。
- Given 当前身份是 Owner；When 创建、编辑或撤销授权；Then 页面调用对应 API，显示 loading/成功/错误状态，并在撤权后立即更新列表和预览。
- Given 当前身份是 caregiver；When 选择家庭；Then 页面仅展示后端返回的当前有效授权元数据，不加载健康事件正文。
- Given 授权已撤销或过期；When caregiver 刷新页面；Then 该授权不出现在预览中，后端拒绝任何越权数据请求。
- Given 两个客户端基于同一版本更新授权；When 后提交者保存；Then 页面识别 `409` 版本冲突并要求重新加载，不覆盖较新版本。

## 安全、隐私与回滚

- API 是授权的唯一权威层；前端过滤只负责用户界面展示，不能视为访问控制。
- 页面不持有或记录健康事件正文，错误提示不回显敏感响应内容。
- 回滚只需回退本 PR 的前端静态资源和 API 客户端改动，不修改数据库迁移或既有 `access_audit` 记录。
