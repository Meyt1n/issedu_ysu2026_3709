# HCT-411 本地助手相关追问建议

## 1. Story

作为家庭成员，我希望在本地助手回答后看到与当前问题相关的后续问题，从而继续核对健康记录、规则依据和需要补充的证据，而不是重新组织问题。

## 2. 需求与边界

- 关联 Issue：[#203](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/203)
- 关联 FR：FR-08 本地证据型助手
- 关联 NFR：NFR-03 全链版本与审计、NFR-04 基础档降级可用、NFR-07 可访问与可理解
- 风险等级：R2。建议是交互提示，不是健康事实、规则结论或照护动作。
- 只处理最新一条用户问题的意图类别，不读取私有事实、工具结果或隐藏思考链来拼接建议。
- 不生成诊断、处方、剂量、停药/换药结论；不包含外链、购买、问诊导流、广告或未授权字段。

## 3. 验收条件

1. `POST /api/v1/assistant/chat` 的响应包含可选 `suggested_questions` 数组，正常回答最多返回 3 条，空问题、重复项、超长项和越界措辞被过滤。
2. 药品/用药、症状、规则/证据、普通问候和未知问题分别返回对应的本地核对型建议；未知问题不能泄露成员或家庭事实。
3. 模型不可用、请求失败、引用校验失败或受控降级时不生成无证据建议；原有回答、引用、权限、降级和安全边界保持不变。
4. Vue 助手在回答完成后显示“你还可以问”按钮；按钮有可访问名称，点击复用现有发送流程，不写入健康事件。
5. 后端和前端单测覆盖数量、去重、限长、风险分支、降级分支和异常响应。

## 4. 实现与证据

- 后端：`src/api/app/tool_call.py` 的 `suggest_follow_up_questions`，`AssistantResponse.suggested_questions`。
- 前端：`src/web/src/assistant/followUp.ts` 和 `AssistantView.vue` 的回答后追问按钮。
- 测试：`tests/unit/test_hct411_follow_up_suggestions.py`、`src/web/src/assistant/followUp.test.ts`。

## 5. 回滚

回滚 PR 后，响应字段被客户端忽略且回答、事实、规则、引用和事件链路不受影响；若只需临时关闭展示，可让前端忽略 `suggested_questions` 并保留后端字段兼容。
