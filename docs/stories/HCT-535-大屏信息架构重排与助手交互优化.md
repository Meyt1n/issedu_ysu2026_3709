# HCT-535：家庭大屏信息架构重排与健康助手交互优化

## 1. 范围

- FR/NFR：FR-09（家庭/模型大屏展示）、FR-08（本地证据型助手的前端体验）、NFR-02（不展示敏感正文）、NFR-04（可降级）、NFR-07（可访问）。
- 关联：本地前端展示层；Issue 由维护者创建后回填。承接 [HCT-533](HCT-533-展演并入普通模式与卡片纹理统一.md)/[HCT-534](HCT-534-卡片透明花纹大屏氛围与桌宠入口.md) 的浏览器反馈「大屏多处不明所以、助手体验可再优化」。
- 目标：纯前端表现与交互优化，不新增业务能力、不修改任何 API/权限/数据边界。

## 2. 验收条件

### 家庭大屏信息架构重排

- 阅读顺序改为「先事实、后洞察」：标题与值守状态行 → 六张实时指标卡 → 成员条 → 时间趋势与运行状态 → 四张详情面板 → 健康日历 → 跑马灯 → 页脚；按用户反馈移除轨道核心与家庭沙盘两件数字孪生投影卡。
- 移除健康脉络星图（`HealthConstellationView`）：成员级关系图与 GraphView 职责重复、在家庭大屏上语义不明；组件文件与全部样式删除（GraphView 的关系图谱不受影响）。
- 标题下新增值守状态行：本地在线 X/Y、数据不出网、待复核数（仅有候选时显示），一眼可读。
- 六张指标卡增加图标；「今日新增事件」卡内嵌近七日迷你柱（今天高亮），与下方时间回溯呼应。
- 「近七日已确认事件」静态折线图（`bs-spark`）删除，由可交互的时间回溯面板（柱条 + 播放/倒带 + 滑块）替代，消除重复表达；数字孪生双画布投影移除，健康日历迁入家庭大屏。
- 数据边界不变：全部为既有聚合数量/状态，正文脱敏声明保留。

### 健康助手交互优化

- 流式输出此前已具备（SSE `assistantChatStream` + 打字机揭示 + 停止保留半程回复），本轮不重写管线，补齐体验缺口：
- **滚动智能跟随**：仅当用户位于底部 96px 内时流式输出才自动下滚；回看历史不再被拽底；发送新问题时强制回底。
- **复制回答**：每个回答操作区新增「复制」按钮（Clipboard API + toast 反馈），朗读/重查按钮不受影响。
- **输入框自适应高度**：随内容自动增高（上限约 7 行 168px），Enter 发送、Shift+Enter 换行的提示同时出现在 placeholder title 与输入区左侧小字（窄屏隐藏）。
- **Web 语音恢复**：按用户明确要求恢复共享语音状态机、常开唤醒监听、临时转写、白名单指令、语音偏好设置和本地 TTS；浏览器仍可能要求首次点按授权麦克风，手动关闭后不再自动重开。
- **首页收敛**：天气卡移除范围/免责声明大段尾注并增加晴/云/雨、温度计与风向动态元素；无特别提醒时按本地日期轮换鼓励文案；今日用药移除重复副标题并在无计划时改为带图形的轻量空态；成员状态文案改为「状态暂未记录」；移除首页本地运行状态侧卡并拉伸近期变化；资讯卡片统一等高。
- **大屏天气与授权信息**：大屏天气在无行动建议时使用图形化空态并保留动态天气事实；首页移除授权说明长文案，保留紧凑的「管理授权」入口。
- **导航与日历**：隐藏侧栏「授权管理」，将单项分组改名为「账户安全」「家庭洞察」；健康日历从首页迁移到家庭大屏。
