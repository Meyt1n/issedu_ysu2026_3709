## 用户价值

报告、药品图片和视频引用安全存储——文件正文不进日志、不进数据库文本列、不意外出网，每次访问都有授权校验和脱敏审计。

## 范围与非目标

**范围：**
- 文件类型与大小校验（扩展名、MIME、魔数、大小、白名单）
- 路径遍历和 zip-bomb 防御
- 随机不可猜测存储密钥，DB 仅存最小元数据 + 加密完整性引用
- 每次下载/预览的逐请求授权，撤权/过期/删除后立即拒访
- 脱敏审计日志（操作者、目的、文件 ID、时间、结果——不含正文或敏感路径）
- 删除传播至文件、缩略图、缓存、索引

**明确不做：**
- 公开静态 URL
- 文件上传至云存储、Review Bot 或日志

## Given / When / Then

- Given 客户端上传伪造 MIME 的可执行文件；When 服务端校验魔数不匹配；Then 拒绝上传，记录脱敏审计。
- Given 文件名包含 `../` 路径遍历；When 解析存储路径；Then 拒绝上传，不写入文件系统。
- Given 用户请求下载文件；When 授权已撤权或过期；Then 返回 403，不提供文件。
- Given 日志/错误输出；When 包含文件正文或本地绝对路径；Then 脱敏层替换为 `<REDACTED>`。
- Given 文件被删除；When 传播执行；Then 原始文件、缩略图、缓存和索引条目全部清除，仅保留审计记录。

## 测试与证据

- `uv run pytest tests/ -k "upload"` — 类型/大小/路径遍历/MIME 校验
- `uv run pytest tests/ -k "file_auth"` — 授权/撤权/过期拒访
- `uv run pytest tests/ -k "file_delete"` — 删除传播验证
- 日志/错误脱敏验证
- PR 描述附命令、环境、结果和链接

## 部署与回滚

部署随 PR 合入 master 生效。回滚步骤：
1. 立即禁用上传和外部预览
2. 保留受控文件不改动
3. 恢复前一版读取策略
4. 隔离新格式，禁止降级为公开访问
