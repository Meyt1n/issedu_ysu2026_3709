## 用户价值

告警按严重/警告/信息/提示分级，同事件去重合并，每日预算防疲劳。

## 范围

- 四级分类：SEVERE / WARNING / INFO / TIP
- 同事件去重合并（同 source_event 相同规则 → 合并为一条）
- 每日告警预算上限
- 严重告警豁免预算限制

## Given / When / Then

- Given 多条同源告警；When 去重合并；Then 仅保留一条，携带计数。
- Given 当日普通告警已达预算；When 新普通告警产生；Then 延迟到次日。
- Given 严重告警；When 超过预算；Then 仍然发送。

- 四级告警生成
- 去重合并
- 预算限额与严重豁免
