## 1. 用户价值与目标

审计明细适合追溯单次操作，但管理页面还需要快速知道某个家庭发生了多少次读取、设置变更、登录成功或拒绝。HCT-438 增加 Owner-only 摘要接口，按动作和结果聚合已有审计记录，返回最小统计元数据，不需要把明细或健康正文加载到客户端。

## 2. 范围与非目标

本切片实现：

1. 新增 `GET /api/v1/households/{household_id}/authorization-audits/summary`；
2. 返回总数、按 `action` 聚合数量、按 `outcome` 聚合数量和生成时间；
3. 复用现有 Owner 权限边界，非 Owner 返回 `404 RESOURCE_NOT_FOUND`；
4. 聚合结果覆盖授权、认证、家庭设置等已有审计，不返回操作者、请求 ID 或正文。

不做：

- 不新增数据库字段、迁移或审计保留策略；
- 不改变审计明细分页、签名游标或授权结论；
- 不返回 actor、request、payload、evidence、健康事件正文或凭据。

## 3. Given / When / Then 验收

- Given 家庭存在多类审计记录；When Owner 请求摘要；Then `total` 等于明细总数，`by_action` 与 `by_outcome` 的计数准确，且返回生成时间。
- Given Owner 请求摘要；When 检查响应；Then 不出现 actor、request_id、payload、evidence 或健康正文。
- Given 非 Owner 请求摘要；When 调用接口；Then 返回 `404 RESOURCE_NOT_FOUND`。
