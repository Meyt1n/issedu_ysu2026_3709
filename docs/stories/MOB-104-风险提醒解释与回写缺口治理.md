# MOB-104：风险提醒解释与回写缺口治理

- 需求：FR-05、NFR-01、NFR-02、NFR-03、NFR-07
- Issue：[ #163 ](https://github.com/Meyt1n/issedu_ysu2026_3709/issues/163)
- 状态：进行中
- 负责人：ry12-20
- 风险：R2。将没有服务端审计接口的“已知晓”显示为成功，会误导家庭成员并破坏事实边界。
- 允许修改目录：`APP/src/views/`、`APP/src/data/`、`APP/src/data/*.test.ts`、`docs/stories/`

## 用户价值
作为照护者，我需要理解风险提醒来自什么脱敏证据，并准确知道当前能否记录“已知晓”，避免把尚未写回的状态当作已完成。

## 范围
- 风险详情保留规则解释、脱敏证据摘要及“未返回摘要”的边界说明。
- 演示模式可记录虚构知晓状态；联机模式在服务端未提供回写接口时禁用操作并明确提示。

## 非目标
不新增后端风险回写接口；不推断未返回证据；不输出诊断、处方或用药决策。

## Given / When / Then
- 正常：Given 演示模式风险未被知晓，When 点击“我已知晓”，Then 仅演示数据更新为已记录。
- 边界：Given 没有脱敏证据事件，When 打开详情，Then 显示“未返回摘要”，不推断风险消失。
- 失败：Given 联机模式没有回写接口，When 打开详情，Then 操作禁用并说明不可用，不显示成功状态。
- 未授权：Given 风险详情请求被拒绝，When 页面加载，Then 显示错误且不展示缓存或未授权证据。

## 测试
`cd APP && npm run check`；`npm run test`；`npm run build`。手工验证演示与联机两种状态、空证据和未授权错误。
