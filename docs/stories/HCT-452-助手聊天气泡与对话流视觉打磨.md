## 用户价值

家庭管理员与照护者在健康助手页获得与主流 AI 助手一致的阅读体验：消息集中在舒适的阅读列宽内，用户提问是柔和的右侧气泡，助手回答以近乎白纸的通栏正文呈现，引用、风险提示与追问建议收纳为紧凑的次级信息块，长辈更容易聚焦「回答本身」而不是卡片装饰。

## 设计系统（单一连贯体系，Claude 式，适配家健镜暖纸/松绿主题）

1. 阅读列：全幅画布保留，消息内容居中收进 `min(820px, 100%)` 的阅读列（`.chat-thread`），不再从左端铺到右端。
2. 用户消息：右对齐软填充气泡（松绿 tint、圆角 18px、无边框/玻璃堆叠、行高 1.7），最大宽度约 76%。
3. 助手消息：左侧小头像 + 通栏正文（不再套玻璃描边卡），衬线正文 15.5px / 行高 1.8，接近 Claude 的答案排版；流式插入符与打字机行为不变。
4. 次级信息块：降级/风险提示、分流一句话、依据状态、引用卡、外部参考统一为回答下方的紧凑 meta 区（12–12.5px、细分隔、软底色引用卡）；保留 HCT-450 的 replyMeta 瘦身逻辑与全部文案。
5. 追问建议：「你还可以问」软胶囊只在最后一条助手消息下方出现；每条助手消息保留一行纤细操作（朗读 / 按用药安全再查一次）。
6. 空状态：吉祥物 + 一句短提示 + 建议胶囊，压缩纵向留白；法律边界文案保留在页脚细字（`.assistant-footnote`）。
7. 输入框：与阅读列同宽居中、大圆角（22px）、发送为输入框右下角的圆形主按钮（↑ 图标，aria-label「发送」）；「联网搜索」保持紧凑开关，语音按钮为次级样式；设置仍在右上角齿轮抽屉。
8. 动效：新消息 6px 轻抬淡入（去弹跳缩放），`prefers-reduced-motion` 下全部关闭；平滑滚动到底保留。
9. 历史栏：仅轻打磨（active 左侧松绿指示条、hover/排版微调），结构不变。

## Given / When / Then

- Given 管理员打开健康助手且无历史消息；When 页面加载；Then 空状态为吉祥物 + 一句提示 + 建议胶囊的紧凑布局，页脚保留教学免责细字。
- Given 管理员发送一个问题；When 消息渲染；Then 用户消息为右对齐松绿软气泡，助手回答为左侧小头像 + 通栏正文（无玻璃描边卡），两者都收在居中阅读列内。
- Given 助手回答带引用与追问建议；When 回答完成；Then 引用/依据/风险提示以紧凑次级块出现在正文下方，`details.chat-citation` 仍可展开显示片段正文；「你还可以问」胶囊只出现在最后一条助手消息下。
- Given 系统开启「减少动态效果」；When 新消息进入；Then 无入场动画，内容立即完整呈现。
- Given 视口在 1440/1280/1024 宽度间切换；When 查看助手页；Then 纵向滚动仍收在 `.chat-window` 内，页面无整体滚动（hct418 既有用例保持通过）。
- Given 用户使用键盘操作；When 聚焦输入框并按 Enter；Then 行为与改版前一致（发送）；圆形发送按钮可聚焦且 accessible name 为「发送」。
