## 用户价值

PR #481 让服务端暴露风险告警的去重键、合并数、预算结论与下次可见时间；MOB-156 已按契约写好移动端呈现，但缺真实后端下的截图证据。本 Story 在 #481 合并后，用真实后端把这些字段的呈现与降级路径截图签收。

## 范围

- 真实后端下的字段呈现截图：去重键、合并条数、预算结论、下次可见时间、严重级别。
- 字段缺失或旧版本服务端时的安全降级截图（不猜测、不伪造合并数）。
- 合并告警与单次告警在界面上的区分证据。
- 证据索引更新与需求追踪矩阵回填。

## 非目标

- 不改移动端风险呈现实现（属 MOB-156），只补证据；发现缺陷回填 MOB-156。
- 不改服务端审计元数据契约（属 HCT-458）。
- 本 Story 不负责评审合并 #481（属 HCT-502）。
- 不做诊断/处方/停药/换药/剂量判断；不买药/问诊/广告导流。
- 健康数据默认不出网（联网搜索遵循 ADR-0007 显式 opt-in）。

## 验收（Given / When / Then）

1. Given #481 已合并且后端返回完整审计元数据，When 打开风险页，Then 截图显示去重键、合并条数、预算结论与下次可见时间。
2. Given 同一风险被合并多次，When 展示，Then 界面明确写出「合并 N 条」并与单次告警区分。
3. Given 后端未返回部分字段，When 展示，Then 对缺失字段安全降级，不显示 0 或猜测值。
4. Given 严重级别为已知严重，When 展示，Then 不被普通告警预算合并掩盖。
5. Given 证据归档，When 更新索引，Then 截图与请求/版本标识对应，且不含真实健康数据。

## 安全、隐私与回滚

- 截图使用虚构成员与合成风险事件，不含真实健康数据。
- 去重键等内部标识在截图中可见时须确认不含成员可识别信息。
- 回滚：证据类交付，回滚只需删除记录。

## 实现与验证证据

- [Android 风险告警字段验收矩阵](../../docs/testing/MOB-173-Android风险告警字段验收矩阵.md) 固化完整字段、合并告警、普通预算暂缓、严重风险、旧版本缺字段、恢复联机、上下文切换和截图隐私 10 项用例；记录 API/规则版本、设备与 APK 哈希，但不复制健康正文或完整响应。
- `APP/scripts/verify-android-risk-evidence.mjs` 提供签收门禁：要求真机元数据、每项通过结果、字段完整/信息不完整两条路径、合并字段证据和至少一条脱敏附件哈希；模板、浏览器/模拟器或缺失字段记录会被拒绝。
- `APP/package.json` 新增 `npm run verify:android-risk-evidence`，并将证据索引回填至 `APP/docs/移动端发布门禁证据索引.md` 与需求追踪矩阵。
- 自动检查：`npm run check`、`npm run test`、`npm run build`、`npm run privacy:scan`、证据门禁（待验收模板按预期拒绝）与 `git diff --check`。
