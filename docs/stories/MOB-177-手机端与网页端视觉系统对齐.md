## 用户价值

让随身版与电脑端共享「暖阳纸笺」视觉语言：暖纸背景、松绿主色、陶土强调色、衬线标题、纸感卡片与克制阴影，使两端看起来是同一产品，同时保留手机的单列阅读、底部导航和大触控目标。

## 范围与非目标

- 范围：`APP/src/style.css` 的设计令牌、全局卡片/按钮/标题/背景、`App.vue` 的装饰背景、`public/sw.js` 的离线外壳缓存清单与底部导航视觉；保留所有既有业务结构与路由。
- 非目标：不修改 API、数据请求、授权、健康文案、AI 能力、提醒逻辑或桌面端样式；不把桌面侧栏直接移植到手机。
- 不使用外部字体、图片或网络资源；健康数据默认不出网。

## 验收

1. Given 浅色主题，When 打开今日、家人、提醒、我的，Then 使用与网页端一致的暖纸/松绿/陶土色阶、卡片和标题层级。
2. Given 深色或高对比模式，When 切换主题，Then 文字和边界仍清晰，高对比模式关闭纯装饰与玻璃效果。
3. Given 320px、横屏、折叠屏或特大字号，When 浏览主要页面，Then 不产生横向滚动，底部导航和主要按钮仍可触达。
4. Given 减少动效，When 进入/切换页面，Then 不运行背景或卡片装饰动画。

## 验证与回滚

- 验证：`cd APP && npm run check && npm run test && npm run build && npm run audit:responsive`，再执行桌面/PWA 视觉走查。
- 回滚：恢复本 Story 所列移动端全局样式与 `App.vue` 的视觉改动；不影响业务数据或服务端。
