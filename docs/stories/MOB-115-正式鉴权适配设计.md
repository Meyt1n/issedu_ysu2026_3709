## 用户价值

在主仓库 HCT-107 提供正式接口前，先冻结移动端需要的鉴权边界，避免继续扩大开发期 `X-Actor-Id` 的使用范围。接口确定后，移动端只需替换适配器，不需要重新改造家庭、成员、任务和风险页面。

## 范围

- 定义登录、短生命周期会话、登出/撤销和 PIN/二维码二次确认的移动端适配契约；
- API Client 支持正式 Bearer 或 HttpOnly Cookie 会话，同时保留明确标注的开发期身份头兼容路径；
- 正式会话未配置时不得回退到 `X-Actor-Id`，避免把生产请求伪装成联调请求；
- 统一登录失败、会话失效、二次确认过期/重放的安全文案；
- 在“我的”页说明当前状态、未来页面改造和未接入限制；
- 提供不发网络请求、不写本机存储的内存测试桩。

## 非目标

- 不实现账号密码后端、bcrypt、速率限制、锁定或会话数据库；
- 不新增或猜测 HCT-107 的正式 API 路径、字段和部署配置；
- 不在移动端保存密码、Bearer token、Cookie、PIN、QR 内容或健康数据；
- 不把测试桩、演示模式或页面提示宣称为正式登录/二次确认已上线；
- 不改变服务端家庭、成员、字段、动作、目的和期限授权判定。

## 移动端鉴权契约

| 场景 | 请求凭据 | 移动端行为 | 状态/限制 |
|---|---|---|---|
| 当前本地联调 | `X-Actor-Id` + `X-Access-Purpose` | 仅在未配置正式会话提供方时发送 | 明确标注“开发期身份（仅本地联调）”，不得用于生产 |
| 正式 Bearer | `Authorization: Bearer …` + `X-Access-Purpose` | 不再发送 `X-Actor-Id`；token 只从内存会话读取 | 过期前阻断请求并引导重新登录 |
| 正式 Cookie | `credentials: include` + `X-Access-Purpose` | Cookie 由 WebView/浏览器管理，移动端不读取内容 | 服务端负责 HttpOnly、短生命周期和撤销 |
| 二次确认 | challenge id + action + method + 一次性 code | 绑定当前会话和动作，过期或重复提交拒绝 | `STEP_UP_EXPIRED` / `STEP_UP_REPLAY` |

正式会话至少包含服务端确认的 `actorId`、ASCII `accessPurpose`、传输类型和 `expiresAt`。移动端不根据姓名、成员 ID 或页面角色推断身份；家庭/成员/字段/动作权限仍由服务端判定。

## 页面改造设计

“我的 → 数据来源 → 家庭服务器”保留当前开发期联调入口，但将身份字段明确改名为“开发期身份（仅本地联调）”。联机入口增加“正式鉴权（适配设计）”说明卡，展示：

1. 账号密码登录成功后进入短生命周期会话，登出或撤销后立即清理；
2. 授权、删除等高风险动作需要 PIN/二维码一次性二次确认；
3. 正式会话只传给 API Client 的内存适配器，不写入 localStorage、URL、日志或缓存；
4. HCT-107 接口尚未提供时，不显示登录成功、会话有效或二次确认成功的伪状态。

页面在 `401`、会话过期、撤销和二次确认错误时沿用“检查设置/重新登录/重新发起操作”的可恢复入口，不展示账号是否存在、家庭是否存在或后端内部错误详情。

## Given / When / Then

- Given 未配置正式会话提供方；When 本地联调请求家庭 API；Then 只允许使用明确标注的开发期身份头路径。
- Given 已配置正式会话提供方但当前未登录；When 请求家庭 API；Then 不回退发送 `X-Actor-Id`，返回可恢复的身份失效提示。
- Given 正式 Bearer 会话已过期；When API Client 准备发请求；Then 在发出请求前阻断并提示重新登录。
- Given 已登录会话发起高风险动作；When 使用不同动作、不同会话、过期或已使用的 challenge；Then 拒绝确认并分别记录无效、过期或重放状态。
- Given 用户查看联机设置；When HCT-107 接口尚未提供；Then 页面明确显示“未接入正式鉴权”，不出现伪造登录按钮或成功状态。

## 安全、隐私与回滚

- 不提交真实健康数据、真实人物信息、密码、密钥、Cookie、token、日志或缓存；
- `X-Actor-Id` 只保留开发期联调兼容路径，正式会话配置后 fail closed；
- API Client 不解析、不持久化 Cookie；Bearer 会话和密码不进入 `localStorage`；
- PR 未合并前关闭分支即可回滚；合并后回退本 PR，恢复到 HCT-107 接口确定前的明确开发期联调边界；
- HCT-107 接口、会话撤销和高风险动作契约确定后，必须另行联调并补充服务端/Android 证据，不能仅凭本 Story 关闭正式鉴权需求。
