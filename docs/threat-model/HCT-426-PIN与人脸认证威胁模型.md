# HCT-426 PIN 与人脸认证威胁模型

| 威胁 | 防护 | 回归证据 |
|---|---|---|
| PIN 暴力破解 | 家庭/账号维度失败限流和锁定 | HCT-423 集成测试、HCT-426 限流检查 |
| 人脸帧重放或 challenge 重放 | 一次性 TTL challenge、至少两帧运动序列 | HCT-425 契约/单元测试 |
| 跨家庭冒用 | 服务端校验 household、actor 和 active credential | PIN/人脸跨家庭测试 |
| 删除后继续使用 | 清理 PIN 哈希、清空模板、撤销家庭绑定 session | HCT-426 删除回归 |
| 审计泄露秘密 | 认证审计只允许固定原因码和元数据 | 审计字段安全断言 |
| 未认证 challenge 内存耗尽 | TTL 清理、内存上限、登录失败限流 | challenge 生命周期检查 |

## 人工桌面验收清单

- 拒绝摄像头权限后页面明确提供 PIN 回退，且不会建立 session。
- 连续错误后显示通用限流提示，不显示候选账号、家庭或相似度。
- 删除家庭后旧 PIN、人脸凭证和对应 Bearer session 均失效。
- 家庭审计页面只能看到认证方式、结果、原因码和时间，不出现 PIN、token、模板或图片。

## 回滚演练

关闭人脸入口并撤销 active credential；验证密码登录仍可用，认证审计仍只保留最小元数据，删除任务和备份跳过标记不被回滚覆盖。
