## 使用规则

1. 每个数据类型（图像、视频、文档、标注集、训练集）入库前必须填写完整数据卡
2. 数据卡随数据一起版本化，存储在数据目录的 `DATA_CARD.md`
3. 许可评审人不得与数据负责人为同一人
4. 训练同意为"是"的数据集，需单独签署训练同意书，不得自动从业务授权派生
5. 真实性声明（是否含真实患者数据）如有虚假，数据立即隔离
