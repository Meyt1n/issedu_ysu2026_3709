## 1. 标注类别体系

### 1.1 药品识别标注

| 类别 | 说明 | 示例 |
|---|---|---|
| `drug_name` | 药品通用名 | 阿莫西林胶囊 |
| `drug_brand` | 商品名/品牌 | 阿莫仙 |
| `drug_form` | 剂型 | 胶囊/片剂/口服液/注射剂 |
| `dosage` | 规格/剂量 | 0.5g×24粒 |
| `manufacturer` | 生产厂家 | XX制药有限公司 |
| `batch_number` | 批号 | 20250101 |
| `expiry_date` | 有效期至 | 2027-01-01 |
| `barcode_value` | 条形码/二维码解析值 | 69XXXXXXXXXXXX |
| `package_type` | 包装类型 | 盒装/瓶装/铝塑板/袋装 |

### 1.2 视觉质量标注（元标注）

| 类别 | 说明 |
|---|---|
| `clear` | 文字清晰可辨 |
| `blurred` | 局部模糊但不影响关键字段 |
| `severe_blur` | 关键字段不可辨认（标记为 UNKNOWN） |
| `glare` | 反光遮挡 |
| `partial` | 包装不完整（仅拍到部分） |
| `rotation` | 拍摄角度过大 |
| `multiple` | 多盒药品同框 |

### 1.3 困难样本

| 类别 | 说明 |
|---|---|
| `hard_font` | 非常规字体/手写/艺术字 |
| `hard_layout` | 排版密集/多语言混排/竖排 |
| `hard_condition` | 破损/褶皱/褪色/潮湿 |
| `hard_similar` | 同品牌不同规格包装极其相似 |
| `hard_foreign` | 外文药品（非中英文） |
| `negative` | 非药品物品（用于拒识测试） |

## 2. 标注状态模型

```
                    ┌─────────┐
                    │ UNKNOWN  │ ← 初始状态 / 拒识
                    └────┬─────┘
                         │ 人工标注
                    ┌────▼─────┐
                    │ MATCHED  │ ← 确认匹配
                    └────┬─────┘
                         │
              ┌──────────┼──────────┐
              ▼          ▼          ▼
         MATCHED    CONFLICT    MANUAL_CORRECT
         (直接确认)  (多人标注    (人工修正后确认)
                     结果冲突)
```

**核心规则：**
- `UNKNOWN` 和 `CONFLICT` 是**合法结果**，不得强制映射
- 只有 `MATCHED` + 人工确认的药品才能进入关系图谱和风险计算
- 冲突由第三人仲裁，不得由标注工具自动裁决

## 3. 标注流程

### 3.1 单人标注流程

```
采集图像 → 质量门控 → 全图 OCR → YOLO 辅助包装/条码定位 → 条码专用解码 → 字段候选抽取 → 人工核对 → 确认/修正/拒识
```

### 3.2 双人抽检流程（质量保障）

```
批次完成 → 随机抽取 20% → 第二人独立标注 → 计算一致性
         │
         ├── Kappa ≥ 0.8 → 批次通过
         ├── Kappa 0.6-0.8 → 全量复检
         └── Kappa < 0.6 → 全量重标注 + 分析原因
```

### 3.3 冲突仲裁流程

```
标注人 A 标注人 B
    │        │
    └───┬────┘
        ▼
    结果不一致
        │
        ▼
    第三人（不得为 A 或 B）查看原始数据
        │
        ├── 选 A → 记录仲裁人、理由
        ├── 选 B → 记录仲裁人、理由
        └── 两者都不对 → 重新标注，记录
```

## 4. 标注工具要求

1. 标注界面必须同时展示：原始图像 + OCR 原始文字框 + 条码解析结果 + 可选 YOLO 辅助框
2. 每个标注字段提供"确认"和"修改"两种操作
3. 困难样本标注时需选择困难类型（可多选）
4. 标注工具记录每个标注的：标注人、时间戳、原始预测、确认/修改后的值
5. 标注数据导出格式：JSON Lines，每行一个标注单元

## 6. 质量控制指标

| 指标 | 目标 | 测量方法 |
|---|---|---|
| 双人一致性 Kappa | ≥ 0.8 | 每批次抽样 20% |
| 困难样本占比 | ≤ 15% | 困难样本数 / 总标注数 |
| 拒识率（UNKNOWN） | 允许，无上限 | UNKNOWN 数 / 总标注数 |
| 冲突率（CONFLICT） | ≤ 5% | CONFLICT 数 / 双人标注重叠数 |
| 仲裁超时 | ≤ 24h | 冲突产生到仲裁完成 |
