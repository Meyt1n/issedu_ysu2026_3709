# HomeCare Twin 提醒确认与未确认升级教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明提醒确认、再提醒与未确认升级的产品口径。本卡不构成诊断、处方或「是否已经服药」的证明；「已确认」只代表用户在系统中的操作记录。演示产品不提供买药、问诊、广告或佣金导流。

## 2. 提醒确认的含义

- 提醒（reminder）到达后，用户可以「确认已处理」「稍后」「需要帮助」等操作；系统记录操作者、时间和提醒版本。
- 「已确认」不等于医学上证明药物已经吞服，也不等于治疗效果。
- 照护者看到的确认状态必须受字段授权与成员范围限制，不能越权查看未授权成员的提醒。

## 3. 再提醒与升级

- 再提醒只能在既有医嘱或用户预设的安全时间窗（safe window）内触发，不能改变服药频次、剂量或药品。
- 连续未确认时，可按预算与等级通知有效授权的照护者；升级路径必须可审计、可关闭。
- 紧急症状（胸痛、呼吸困难、意识不清等）不属于普通提醒升级，应走紧急联络口径。

## 4. 系统演示口径

- 提醒优化不得改写医嘱内容；只能调整提醒时机与再提醒节奏。
- 未确认升级失败或预算耗尽时，返回结构化状态，不由模型编造「已通知某人」。
- 缺少授权或成员范围时，不展示他人提醒细节。
