# HomeCare Twin 居家照护沟通与紧急联络教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），提供居家照护中"何时联系医务人员、何时联系急救、联系时准备什么"的教学表述，不构成诊断或治疗建议。本系统不是急救工具，不能替代紧急救治。

## 2. 需要立即联系急救服务的情形（教学表述）

出现下列可能危及生命的情况时，应立即联系当地急救服务（emergency services），不要等待系统或助手的进一步回答：

- 胸痛、胸闷持续不缓解，或伴随大汗、放射性疼痛；
- 呼吸困难、嘴唇发紫；
- 意识不清、叫不醒、抽搐；
- 大量出血、严重外伤、疑似骨折且无法移动；
- 疑似误服药品、过量服药或接触有毒物质；
- severe allergic reaction（严重过敏表现）：全身皮疹迅速扩散、喉头发紧、声音嘶哑、呼吸费力。

演示系统在识别到这类描述时会停止普通问答并提示紧急升级（urgent escalation）。

## 3. 建议尽快联系医务人员的情形（教学表述）

以下情况不一定危及生命，但建议尽快联系医生、药师或社区医务人员：

- 用药后出现新的不适，怀疑与药品有关；
- 发热、疼痛等症状持续加重或反复出现；
- 慢性病指标记录出现让家人担心的持续变化；
- 对药品的用法、漏服处理或相互作用有疑问——这些问题系统一律不代替回答。

## 4. 联络前的准备清单

联系医务人员或急救时，提前准备以下信息可以节省沟通时间：

- 成员的年龄和主要慢性病史；
- 正在使用的药品清单（名称、规格），最好携带原包装；
- 已登记的过敏信息；
- 症状开始的时间和变化过程；
- 如疑似误服：误服的药品、大致数量和时间。

## 5. 家庭内部沟通建议

- 家庭可以约定紧急联系人顺序，并在系统中登记有效的照护授权，保证提醒升级能送达。
- 照护者收到升级通知后应先与本人确认状态，再决定是否联系医务人员。
- "已确认服药"只代表用户在系统里做了确认操作，不能作为已实际服药的医学证据。
## FAQ（教学问答）

**Q: 哪些情况应立刻联系急救？**  
A: 胸痛、呼吸困难、意识不清、大量出血、严重过敏表现或自伤风险等；应停止普通问答并提示急救。

**Q: 打电话前可以准备什么？**  
A: 可准备过敏摘要、在用药品清单（已确认）、最近变化与联络人；不代替分诊。

**Q: 普通不适是否也走紧急升级？**  
A: 不一定。紧急口径用于可能危及生命的情况；一般不适应联系医务人员并保留记录。
