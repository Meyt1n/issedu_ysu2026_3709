# 家庭用药安全演示知识卡

## 适用范围

本文仅用于验证本项目的知识引用和安全提示流程，不构成诊断、处方或个体化用药建议。

## 识别与核对

服用药品前，应核对原包装上的通用名、商品名、规格、有效期、用法用量和储存条件。仅凭药片颜色、形状、照片或他人描述不能可靠确认药品身份。

包装缺失、文字模糊、药品过期或身份无法确认时，不应继续服用，应咨询医生或药师。

## 高风险处理

胸痛、呼吸困难、意识不清、大量出血或自伤风险等情况可能需要紧急处理。应立即联系当地急救服务或尽快前往急诊，不要等待 AI 系统进一步判断。

## 项目说明

Demo 问答只使用固定规则和本知识卡。正式 RAG 模块接入后，仍必须执行权限过滤、引用验证、低证据拒答和 S0-S3 医疗安全分级。
