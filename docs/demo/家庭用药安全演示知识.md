# HomeCare Twin 家庭用药安全演示知识卡

## 1. 用途和边界

本文是 P0 固定知识源，用于验证版本化入库、权限检索、引用、规则解释和无证据拒答，不构成诊断、处方或个体化用药建议。不得把本文扩展成“可以一起吃”“必须停药”“应调整剂量”等结论。演示产品只做居家照护，不提供买药、问诊、广告或佣金导流。

## 2. 药品身份核对

录入药品时应核对原包装上的通用名/商品名、规格、厂家、批次、有效期、条码及说明书。仅凭药片颜色、形状、单张照片或相似包装不能可靠确认身份。

出现以下任一情况时返回 `CONFLICT`、`UNKNOWN` 或 `REVIEW`，由用户核对原包装并在必要时咨询医生/药师：

- OCR 药名与条码主数据不一致；
- 规格、厂家或有效期缺失/冲突；
- 包装模糊、反光、遮挡或已拆散；
- 候选药品过于相似或主数据中没有该 SKU。

## 3. 规则演示口径

- **过期/临期**：只提示核对有效期和妥善处置，不指导继续服用。
- **重复成分**：表示已确认药品存在相同成分记录，需要由专业人员进一步核对，不等同于禁用结论。
- **登记过敏**：规则命中时标为高关注并要求人工确认；系统不判断过敏反应诊断。
- **有限相互作用**：只在 30–50 组人工审核的教学规则覆盖内提示“发现已知资料”，显示规则来源、版本和未覆盖范围。
- **天气行动卡**：只提供低风险生活安排提示，不修改药品、频次或剂量。

只有 `MATCHED` 且人工确认的药品参加规则计算。

## 4. 计划与照护

提醒优化只能在既有医嘱或用户预设的安全时间窗内调整首次提醒和再提醒；系统不能改变服药频次、剂量或药品。连续未确认可以通知有效授权的照护者，但“已确认”只代表用户操作，不能证明药物已经吞服。

## 5. 高风险与紧急情况

胸痛、呼吸困难、意识不清、大量出血、严重过敏表现或自伤风险等可能需要紧急处理。系统应停止普通问答，提示立即联系当地急救服务或尽快就医，不等待模型进一步判断。

## 6. 演示证据要求

风险卡和助手回答分区显示：已确认家庭事实、命中规则及版本、本文或说明书引用、人工确认状态、模型/知识版本、当前调用者可见范围和下一步待办。缺少必要证据时明确说明信息不足，不由大模型补写事实。家庭版不把健康上下文发送到互联网，模型离线时退化为结构化事实和规则结果。
## FAQ（教学问答）

**Q: 只拍一张药盒照片能不能确定是什么药？**  
A: 不能。应核对通用名/商品名、规格、厂家、批次、有效期与条码等多证据；冲突时进入人工复核，不由单张照片定案。

**Q: 系统提示「重复成分」是不是就不能吃了？**  
A: 不是。它只表示已确认记录中存在相同成分，需要专业人员进一步核对，不等于禁用或停药结论。

**Q: 「已确认服药」能否证明药已经吞下？**  
A: 不能。确认只代表用户在系统中的操作，不能证明吞服或疗效。

**Q: 能不能问助手「这个药该吃几片」？**  
A: 不能作为本系统能力。剂量、停药、换药必须由医生或药师判断；助手应拒答并引导核对医嘱/原包装。
