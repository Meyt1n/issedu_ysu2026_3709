# HomeCare Twin 家庭药箱分类盘点教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于家庭药箱分类与定期盘点的操作教学。内容参考公开科普中的常见存放与清理原则，改写为产品演示口径；不构成官方指南原文复制，不做个体化用药建议。

## 2. 分类建议

- 内服与外用分开；成人与儿童分开；急救用品与常规备药分开。
- 保留原包装与说明书；不要用饮料瓶或零食罐分装，以免误服。
- 外观相似、名称相近的药品分开放置，降低拿错风险。

## 3. 存放环境

- 优先阴凉、干燥、避光处；避免浴室潮湿与暖气旁高温。
- 标注需冷藏的药品按包装提示处理，避免冷冻损坏。
- 「避光」与「遮光」以说明书为准；不确定时咨询药师，不由助手臆测。

## 4. 定期盘点

- 建议按固定周期（如每季度）取出全部药品核对有效期与性状。
- 变色、异味、结块、分层等异常移出常用区并记录。
- 过期药品按有害垃圾或当地回收渠道处置；去除包装上的个人信息。

## 5. 儿童安全

- 放在儿童不易触及处；优先儿童安全盖；服药后立即收起。
- 不要把药品说成糖果；误服立即联系急救并携带原包装。

## 6. 系统演示口径

- 盘点结果可更新家庭药品清单事件；低库存仅提醒核对。
- 识别冲突时走人工复核，不自动清空或合并药品。
## FAQ（教学问答）

**Q: 多久盘点一次比较合适？**  
A: 教学上可按固定周期（如每季度）核对有效期与性状；具体频率由家庭自行约定。

**Q: 过期药扔进生活垃圾桶可以吗？**  
A: 更稳妥的是按当地有害垃圾或回收渠道处理，并去除包装上的个人信息。
