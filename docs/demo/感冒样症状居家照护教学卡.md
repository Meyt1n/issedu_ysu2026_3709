# HomeCare Twin 感冒样症状居家照护教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明家庭成员出现鼻塞、流鼻涕、咽痛、咳嗽、低热等感冒样不适时，一般可以了解哪些照护资料和非处方资料类别。本卡不构成诊断、处方或个体化用药建议；能不能吃、吃多少、停不停，都由医生或药师结合本人情况判断。

## 2. 常见诱因与生活照护

换季温差、着凉、夏天空调房与室外温差大（俗称「热伤风」）、空气干燥都可能诱发感冒样不适。一般生活照护包括：

- 避免冷风直吹，空调温度不宜过低，注意颈肩保暖；
- 多补水、清淡饮食、保证休息；
- 房间适度通风、加湿，减少烟尘刺激；
- 观察症状变化并做居家记录，方便就医时说明。

## 3. 可以了解的非处方资料类别

面向教学演示，感冒样症状常见的说明书资料类别包括：解热镇痛类、缓解鼻塞流涕类、镇咳祛痰类和中成药感冒类。查阅这些资料时应重点看：适应症状、禁忌（尤其过敏史、慢性病、孕产哺乳期）、相互作用提示和「连续使用不缓解应就医」的期限。同类成分不要叠加使用；具体选药与剂量必须咨询医生或药师。

## 4. 需要尽快就医的情况

出现高热不退、呼吸困难、胸痛、意识异常、严重过敏表现，或婴幼儿、老人、孕产妇、慢性病成员症状加重时，应停止自行查资料，尽快联系医务人员或当地急救服务。

## 5. 系统演示口径

- 助手只解释已审核知识卡与已确认家庭事实，结合过敏史、疾病史提示注意事项；
- 助手不判断「你得的是感冒还是流感」，不编造正在流行的病毒名称或病例数；
- 知识库没有命中时，助手说明本机暂无已审核资料并建议咨询医生或药师，不凭空补写药品结论。
## FAQ（教学问答）

**Q: 夏天吹空调后有点鼻塞，一般可以了解哪些用药资料？**  
A: 可以先了解缓解鼻塞流涕类与解热镇痛类非处方说明书资料的通用注意事项，同时做好避免冷风直吹、补水休息等生活照护；具体选药请咨询医生或药师。

**Q: 感冒样不适可以同时吃几种感冒药吗？**  
A: 不建议自行叠加。多种感冒药可能含相同成分，是否同服属于用药安全判断，必须由医生或药师结合本人情况确认。

**Q: 什么时候不能只靠居家照护？**  
A: 高热不退、呼吸困难、意识异常、严重过敏表现，或老人、婴幼儿、孕产妇、慢性病成员症状加重时，应尽快就医。
