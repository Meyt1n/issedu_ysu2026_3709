# HomeCare Twin 删除撤权与知识传播教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明删除、遗忘与撤权后的传播（propagation）要求。本卡不替代完整隐私合规评估，但演示产品必须让「撤权后不可见」可验证。

## 2. 撤权传播

- 字段或成员授权撤销后，列表、详情、导出、助手检索与引用均不得继续返回该范围数据。
- 已生成的临时会话缓存应失效或过滤；不得靠「模型还记得」继续回答。

## 3. 删除与知识库

- 家庭私有文档删除后，索引与分块应不可被检索；公开教学演示卡不受家庭删除影响。
- 删除责任人、时间与范围应可审计。
- 重建索引不得把已删除家庭文档「复活」，除非有明确的合法恢复流程。

## 4. 常见失败模式

- 只在 UI 隐藏、API 仍返回；
- 检索后过滤导致时序侧信道；
- 引用校验仍接受已不可访问的旧 `chunk_id`。

## 5. 系统演示口径

- 权限过滤必须在检索前完成。
- 伪造或过期引用结构化降级；相关 e2e/单测应覆盖删除传播场景。
## FAQ（教学问答）

**Q: 页面上隐藏了就安全了吗？**  
A: 不够。API、检索、引用与缓存都必须同步不可见，禁止只做 UI 遮挡。

**Q: 删除家庭文档后重建索引会不会回来？**  
A: 不应「复活」已删除家庭文档，除非走明确合法恢复流程。
