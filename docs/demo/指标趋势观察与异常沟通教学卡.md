# HomeCare Twin 指标趋势观察与异常沟通教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于血压、血糖等居家指标的**记录、趋势观察与沟通准备**。本卡不解读某次数值是否「正常」，不给出诊断阈值结论，不建议调整药物剂量。

## 2. 记录时建议记下的上下文

- 测量时间、与进餐/服药的先后（按用户自己的医嘱习惯记录，系统不推断对错）。
- 设备型号或来源（家用血压计/血糖仪），以及是否重复测量。
- 主观感受（头晕、心悸等）仅作为沟通备注，不作为系统诊断输入。

## 3. 趋势观察

- 关注同一设备、相近条件下的序列变化，避免把单次波动直接写成病情结论。
- 投影出的「最近值/趋势」必须能追溯到健康事件；缺失时显示不完整。
- 跨成员查看趋势必须有字段授权。

## 4. 异常沟通准备清单

联系医务人员前，可准备：近期记录摘要、目前在用药品清单（已确认）、过敏摘要、最近计划变更。本卡不代替急诊分诊。

## 5. 系统演示口径

- 助手可以解释「如何记录」和「如何展示证据分区」，不得输出「你这是高血压急症」等诊断语句。
- 数值录入冲突或单位不清时进入人工复核，不由模型擅自换算定论。
## FAQ（教学问答）

**Q: 趋势图能不能直接下诊断？**  
A: 不能。只用于观察与沟通准备，不做诊断阈值结论。

**Q: 单位不清楚时怎么办？**  
A: 进入人工复核，不由模型擅自换算定论。
