# HomeCare Twin 居家环境跌倒风险观察教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于居家环境与跌倒风险相关的**观察与沟通清单**。本卡不做跌倒风险评估量表评分，不诊断骨质疏松或神经疾病，不指导停药或改药。

## 2. 可观察的环境因素（教学列举）

- 地面是否湿滑、杂物是否挡路、夜间照明是否不足。
- 浴室是否有防滑与可抓握支撑（以家庭实际情况为准，本卡不指定品牌）。
- 常用药品与助行器具是否放在稳定、易取位置，避免攀高取物。

## 3. 与用药相关的沟通（非医学结论）

- 若成员出现明显头晕、步态不稳等新变化，照护者应记录发生时间与情境，并联系医务人员，而不是让助手判断「是不是药的问题」。
- 系统不得根据环境描述自动给出停药或减量建议。

## 4. 何时升级

- 跌倒后意识不清、剧烈疼痛、头部撞击、无法站起或疑似骨折时，按紧急联络口径处理。
- 普通环境改善建议属于低风险生活提示，不能写成医疗处方。

## 5. 系统演示口径

- 可将观察结果记为健康事件或照护笔记（若产品支持），需授权与审计。
- 助手仅基于用户提供的观察与授权事实解释「下一步谁确认」，不做诊断。
## FAQ（教学问答）

**Q: 系统能给我做跌倒风险评分吗？**  
A: 本卡只提供环境观察与沟通清单，不做量表评分或疾病诊断。

**Q: 头晕是不是药的问题？**  
A: 助手不作此判断。应记录情境并联系医务人员，不得建议停药减量。
