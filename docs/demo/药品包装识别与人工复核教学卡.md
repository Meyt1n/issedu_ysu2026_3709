# HomeCare Twin 药品包装识别与人工复核教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），解释多证据包装识别和人工复核（human review）的教学口径，不构成诊断、处方或用药建议。识别结果在人工确认前只是候选，不进入正式健康档案，也不参与风险计算。

## 2. 多证据识别原则

药盒识别遵循多证据原则（multi-evidence principle），单一线索不能决定药品身份：

- 全图 OCR 读取包装文字，保留原始文字框和置信度；
- 条码/二维码（barcode/QR code）由专用解码器读取，命中主数据后仍需与文字证据互相印证；
- 包装类型、规格、厂家与本地主数据比对；
- 仅凭药片颜色、形状、单张照片或相似包装不能可靠确认药品。

条码命中也不能覆盖与包装文字的冲突；证据冲突时系统必须交给人工判断。

## 3. 四种识别状态

- MATCHED：各证据一致且超过校准阈值，仍需人工确认后才能入档；
- CONFLICT：OCR 药名、条码、规格或日期之间存在冲突；
- UNKNOWN：主数据之外的药品或候选不足；
- REVIEW：图片质量低、关键字段缺失或候选之间差距不足。

拒识（refusing to guess）是正常行为，不是故障；宁可要求重拍，也不自动猜测入库。

## 4. 人工复核的操作要点

- 复核人对照原包装逐项核对：通用名、规格、厂家、批号、有效期；
- 修正字段时保留原识别值和修正原因，不原地覆盖识别证据；
- 复核确认后才生成健康事件；确认动作和操作者会被审计记录；
- 对无法确认的候选选择拒绝或退回重拍，不要"先入库再说"。

## 5. 常见需要重拍的情况

- 包装反光、模糊、遮挡或倾斜过大；
- 药板已从外盒拆出，缺少完整包装信息；
- 光线过暗导致关键字段无法辨认；
- 一张照片中混入多个不同药品。

## 6. 系统内的对应演示口径

- 演示环境仅使用合成药盒图片；禁止上传真实处方标签或包含个人信息的包装照片。
- 助手解释识别结果时，只描述证据与状态，不猜测未识别出的字段。
## FAQ（教学问答）

**Q: 条码对上了就一定是这种药吗？**  
A: 不一定。条码命中不能覆盖与包装文字的冲突；多证据一致且人工确认后才进入正式事实。

**Q: MATCHED 还要人确认吗？**  
A: 要。MATCHED 表示证据较一致，仍需人工确认，不能自动当作最终医嘱。

**Q: OCR 看不清怎么办？**  
A: 应重拍或进入 REVIEW；模型不得编造看不清的药名、批号或有效期。
