# 联网搜索与知识库刷新：启用指南

面向本地演示与课堂用户。这两项能力**默认不开启或受限**，需要按下面步骤配置后才能在网页里用起来。

> **边界：** 不做诊断、处方、剂量建议；健康数据默认不出网；知识爬虫**永不自动入库**；联网结果只是「外部参考」，不是本地审核证据。

---

## 你需要先有什么

1. 仓库已按 [本地部署与 Demo 操作指南](../本地部署与Demo操作指南.md) 启动 API 与网页（Compose 或本地进程均可）。
2. 有一份可编辑的 `.env`（可从 `.env.example` 复制）。
3. 网页里能填写 **Actor ID**（开发模式）。

改完 `.env` 后必须**重启 API**，配置才会生效。

---

## 一、启用联网搜索（助手页）

联网搜索要**两道开关同时打开**：

| 开关 | 在哪里 | 作用 |
|---|---|---|
| 部署开关 | `.env` → `AGENT_WEB_SEARCH_ENABLED=true` | 允许本机部署使用联网能力 |
| 请求勾选 | 助手页 →「补充联网参考」 | 仅本次提问允许联网 |

只改 `.env` 不勾选、或只勾选不改 `.env`，都不会真正走联网节点。

### 路线 A：课堂 / 无网演示（推荐，完全不出网）

适合「想看多智能体里联网节点亮起来，但机器不能出网」。

**1. 编辑 `.env`**

```dotenv
AGENT_WEB_SEARCH_ENABLED=true
AGENT_WEB_SEARCH_PROVIDER=fixture
```

**2. 重启 API**

```powershell
# Compose
scripts/start.ps1 down
scripts/start.ps1 up

# 或本地进程：停掉 api 终端后重新 scripts/start.ps1 api
```

**3. 打开网页助手**

1. Actor ID 填 `demo-parent`（或其他演示账号）。
2. 进入「助手」页。
3. 勾选 **「补充联网参考」**（若未启用，勾选旁会显示原因，例如「部署未开启」）。
4. 问一句普通科普问题（例如「家庭药箱存放要注意什么」）。
5. 展开回答下方的协作 / 依据：应看到「联网参考」节点；结果带「教学夹具 / 外部参考」标注，**不是**医疗结论。

**4. 可选：用接口确认部署已就绪**

```powershell
curl.exe http://localhost:8000/api/v1/assistant/agents -H "X-Actor-ID: demo-parent"
```

期望大致为：

- `web_search_enabled` = `true`
- `web_search_ready` = `true`
- `web_search_unavailable_reason` = `OPT_IN_REQUIRED`（还差页面勾选）
- `web_search_provider` = `fixture`

### 路线 B：真实联网（白名单出口）

仅在确认本机允许访问搜索站点、且接受「问题文本会发到搜索引擎（已脱敏）」时使用。

**1. 编辑 `.env`**

```dotenv
AGENT_WEB_SEARCH_ENABLED=true
AGENT_WEB_SEARCH_PROVIDER=duckduckgo_html
AGENT_WEB_SEARCH_URL=https://html.duckduckgo.com/html/
AGENT_WEB_SEARCH_ALLOWED_DOMAINS=html.duckduckgo.com
```

自建 SearXNG 时改为：

```dotenv
AGENT_WEB_SEARCH_PROVIDER=searxng
AGENT_WEB_SEARCH_URL=https://你的-searxng-地址/search
AGENT_WEB_SEARCH_ALLOWED_DOMAINS=你的-searxng-域名
```

**2. 重启 API → 助手页勾选「补充联网参考」→ 提问。**

硬规则：

- 只发送脱敏后的问题，不发送家庭档案、药品、成员 ID。
- 外部结果单独展示为「外部参考（非本地审核证据）」，不会变成本地 RAG 引用。
- 搜索失败只影响联网节点，本地档案 / 规则 / 知识仍可回答。

### 联网搜索排障

| 页面/接口提示 | 含义 | 怎么处理 |
|---|---|---|
| `DEPLOYMENT_DISABLED` | `.env` 未开部署开关 | 设 `AGENT_WEB_SEARCH_ENABLED=true` 并重启 API |
| `EGRESS_BLOCKED` | URL 域名不在白名单 | 检查 `AGENT_WEB_SEARCH_ALLOWED_DOMAINS` 与 `AGENT_WEB_SEARCH_URL` |
| `OPT_IN_REQUIRED` | 部署已开，本次未勾选 | 在助手页勾选「补充联网参考」 |
| 勾选灰掉 / 看不到开关 | 前端未拉到 agents 目录或身份异常 | 确认 API 可达、Actor ID 已填、刷新页面 |
| 想立刻关掉 | — | `.env` 设回 `AGENT_WEB_SEARCH_ENABLED=false` 并重启 |

## 二、启用知识库刷新（受控爬虫）

爬虫**不是**开放上网搜知识，而是：

```text
白名单来源 → staging 草稿 → 人工批准 → 晋升到 approved/incoming → dry-run 入库
```

默认只抓本地教学夹具；**禁止自动写入正式检索索引**（`auto_ingest=false`）。

### 谁可以操作

| 身份 | 能否点爬虫按钮 |
|---|---|
| `demo-parent` / `knowledge-steward` | 可以 |
| 任意 `demo-` / `test-` 前缀账号 | 可以（演示/测试） |
| 其他账号 | 需要把 Actor ID 写进 `.env` 的 `KNOWLEDGE_ADMIN_ACTORS` |

```dotenv
# 可选：把正式账号提升为知识管理员（逗号分隔），重启 API
KNOWLEDGE_ADMIN_ACTORS=alice,bob
```

非管理员打开知识页时，应看到「需要知识管理员身份」说明，而不是空白无提示。

### Web 一键教学闭环（推荐）

1. 网页 Actor ID 填 `demo-parent`。
2. 打开 **「知识文档」** 页。
3. 找到右侧 **「知识爬虫 / Staging」**。
4. 点击 **「一键教学闭环：抓取 → 批准 → 晋升」**（或分步：全量/到期抓取 → 批准 → 晋升）。
5. 页面会给出 **ingest dry-run** 命令提示；复制到终端执行预检查，确认无误后再去掉 `--dry-run` 正式入库。

抓取默认只跑 `fixture://` 夹具，**服务端 API 不会真实出网**。

### 等价命令行

```powershell
# 1) 状态与抓取（默认离线夹具）
uv run python scripts/crawl_knowledge_sources.py --status
uv run python scripts/crawl_knowledge_sources.py

# 2) 批准一篇草稿
uv run python scripts/promote_knowledge_staging.py review --source-id fixture-med-storage --reviewer demo-parent --approve

# 3) 晋升到 approved/incoming
uv run python scripts/promote_knowledge_staging.py promote --actor-id knowledge-steward

# 4) 预检查入库（独立索引版本；通过后再去掉 --dry-run）
uv run python scripts/ingest_local_knowledge.py `
  --manifest docs/knowledge/approved/incoming/正式知识清单.crawl.json `
  --source-root docs/knowledge/approved `
  --actor-id knowledge-steward `
  --index-version approved-crawl-v1 `
  --dry-run
```

### 远程白名单源（进阶，可选）

1. 在 `docs/knowledge/crawl/allowlist.json` 把目标源 `enabled` 改为 `true`，并确认域名在 `policy.allowed_hosts`。
2. 仅用 CLI（不要指望 Web API 出网）：

```powershell
uv run python scripts/crawl_knowledge_sources.py --live --due-only
```

3. 仍须人工批准 → 晋升 → dry-run 入库。禁止整页版权复制入库。

更细的运营说明见 [知识爬虫 README](../knowledge/crawl/README.md)。

### 知识爬虫排障

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 知识页提示需要管理员 | Actor 不是 steward | 改用 `demo-parent`，或配置 `KNOWLEDGE_ADMIN_ACTORS` |
| 抓取 0 条 | 已全部未到期且用了「到期刷新」 | 改用「全量抓取」，或等 `refresh_hours` 到期 |
| 晋升 0 篇 | 没有 `approved` 状态草稿 | 先点「批准」再晋升 |
| 想远程抓取但 Web 无效 | API 强制离线 | 使用 CLI `--live` |
| 担心误入库 | — | 永不 auto_ingest；正式入库前务必 `--dry-run` |

## 三、五分钟最小演示清单

按顺序做完即可确认「功能能启动」：

1. `.env`：`AGENT_WEB_SEARCH_ENABLED=true` + `AGENT_WEB_SEARCH_PROVIDER=fixture` → 重启 API。
2. Actor=`demo-parent` → 助手页勾选联网 → 提问 → 看到联网节点与夹具参考。
3. 同一身份 → 知识文档 →「一键教学闭环」→ 看到 staging 状态变为已晋升，并出现 dry-run 提示。
4. （可选）执行 dry-run 命令，确认清单可解析。
