# HomeCare Twin 天气行动卡低风险提示教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明天气或季节相关「行动卡」只能提供低风险生活安排提示。本卡不根据气温给出停药、换药或剂量调整建议，也不把天气预报当作医疗指标。

## 2. 允许的提示类型

- 高温/严寒天气下减少不必要外出、注意补水与保暖等一般性生活提醒。
- 提醒用户核对立医嘱的既有注意事项（若用户已记录），但不新造医嘱。
- 提示检查药品是否按说明书要求避高温存放。

## 3. 明确禁止

- 「今天太热，某某药减半」；
- 「感冒季节预防性加药」；
- 把天气卡片与商业促销、买药链接绑定。

## 4. 与用药规则的隔离

- 天气行动卡不得改写规则引擎的风险等级。
- 不得占用高等级用药安全告警预算掩盖真实规则命中。

## 5. 系统演示口径

- 行动卡展示来源与版本；模型解释时不得升格为医疗指令。
- 无天气数据或服务降级时，显示受控状态而不是编造气温。
