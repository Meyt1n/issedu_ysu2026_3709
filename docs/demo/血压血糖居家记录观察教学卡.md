# HomeCare Twin 血压血糖居家记录观察教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），只讲"怎么记录、怎么观察、什么时候把记录交给医务人员"，不解读数值是否正常，不设定诊断阈值，不构成诊断、处方或治疗建议。任何关于指标高低含义、是否需要调整治疗的问题，都应咨询医生。

## 2. 血压记录的通用做法

- 记录血压（blood pressure）时，同时记下测量时间、测量前状态（如刚运动、情绪波动、是否服药后）和使用的设备。
- 每次记录包含收缩压、舒张压和脉搏三个读数，单位按设备显示抄录（常见为 mmHg），不自行换算。
- 尽量在每天相近的时间、相同的姿势下测量，测量前静坐休息几分钟，便于观察趋势。
- 单次读数波动很常见；把连续多天的记录整体交给医务人员解读，比对某一次读数更有参考价值。

## 3. 血糖记录的通用做法

- 记录血糖（blood glucose）时，标注测量时间点属于哪一类：空腹、餐前、餐后或睡前，不同时间点数值不可直接互相比较。
- 单位按设备显示抄录（常见为 mmol/L），不自行换算或四舍五入。
- 同时记录当天饮食、运动或身体不适等可能影响读数的情况，作为给医务人员的背景信息。

## 4. 观察与升级的教学表述

- 系统和本卡都不判断某个读数"正常"或"异常"；观察的对象是记录是否完整、趋势是否值得向医务人员反馈。
- 如果测量时伴随明显不适（如胸闷、头晕加重、意识模糊、大汗），应优先处理不适症状并及时联系医务人员，而不是反复测量。
- 就诊时把完整记录（时间、读数、单位、背景说明）一起提供，医务人员才能做出专业判断。

## 5. 系统内的对应演示口径

- 指标记录以追加方式保存，修改历史可追溯；演示环境只使用合成数据。
- 助手回答指标问题时，只复述已记录的数值和时间，不给出高低判断或治疗建议。
## FAQ（教学问答）

**Q: 助手能告诉我这次血压正不正常吗？**  
A: 不能。本卡只教如何记录与观察，不解读数值、不做诊断。

**Q: 记录时要写哪些上下文？**  
A: 建议记录测量时间、与进餐/服药的先后、设备来源，以及需要沟通的主观感受备注。

**Q: 一次偏高就要改药吗？**  
A: 系统不得建议改药。出现持续异常或紧急症状应联系医务人员或急救，而不是让模型调剂量。
