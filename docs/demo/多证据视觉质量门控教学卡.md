# HomeCare Twin 多证据视觉质量门控教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明药盒/包装视觉录入的质量门控与多证据原则。本卡不提供具体模型权重指标，也不把整盒图像分类结果当作唯一药品身份。

## 2. OCR-first 与多证据

- 先对受控图片做 OCR，保存文字框、原始值与置信度。
- 条码/二维码由专用解码器读取；YOLO 等检测仅辅助定位包装与码区。
- 药品身份由 OCR、条码、包装类型、规格/厂家主数据与人工确认共同决定。

## 3. 质量门控常见问题

- 模糊、反光、严重倾斜、遮挡、裁切过紧：应提示重拍或进入 `REVIEW`。
- 感知哈希可用于去重教学样本，但不能用来覆盖人工确认。
- 视频抽帧应选择清晰帧；低质量帧不得单独定案。

## 4. 输出状态口径

- `MATCHED`：证据一致且过阈值，仍需人工确认。
- `CONFLICT`：条码、药名、规格或日期冲突。
- `UNKNOWN`：主数据之外或候选不足。
- `REVIEW`：质量低、关键字段缺失或候选间隔不足。

## 5. 系统演示口径

- LLM 只做字段语义解析/槽位填充，必须返回来源 token/区域 ID；不得生成不存在的药名或批号。
- 自动通过精确率优先于覆盖率；纠错保留原预测与修正原因。
