# HomeCare Twin 规则命中解释与证据分区教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明确定性规则命中后如何分区展示证据。规则负责风险等级与告警预算；大模型只做通俗解释，不得改写规则等级或发明未覆盖结论。不做诊断、处方、停药或剂量判断。

## 2. 规则与模型的分权

- 过期/临期、重复成分、登记过敏、有限相互作用等由版本化规则计算。
- 只有 `MATCHED` 且人工确认的药品参加规则计算。
- 模型不得把「发现已知资料」升级成「禁止同服」或「必须停药」。

## 3. 证据分区展示

回答或风险卡建议分区显示：

1. 已确认家庭事实（authorized facts）；
2. 命中规则及规则版本；
3. 知识库或说明书引用（本轮可访问片段）；
4. 人工确认状态；
5. 模型/知识版本与调用者可见范围；
6. 下一步待办（由人确认，不由模型擅自执行）。

缺少任一必要证据时，明确说明信息不足。

## 4. 未覆盖范围

- 教学规则通常只覆盖有限组相互作用；未覆盖不等于安全。
- 规则库版本变更必须可回滚；不得用提示词关闭安全规则。

## 5. 系统演示口径

- 引用必须匹配本轮返回的 `document_id/version/chunk_id`。
- 规则等级不可被模型改写；校验失败返回结构化事实卡。
