# HomeCare Twin 本地优先与隐私不出网教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明家庭版「健康数据默认不出网」与本地优先（local-first）部署口径。本卡不是渗透测试报告，也不保证特定主机的安全配置已达标。

## 2. 本地优先原则

- 健康事件、授权、规则、知识检索与助手推理默认在家庭可信域运行。
- Ollama、向量/文档索引与数据库默认本地；依赖不可用时返回结构化降级，而不是偷偷改走公有云健康上下文。
- 任何云端推理必须是单独部署档，不属于默认回退。

## 3. 隐私与日志

- 禁止把真实健康对话、密钥、原始证件或未脱敏日志提交到仓库。
- 对话临时恢复只允许当前标签页隔离存储，不得把健康对话写入不受控服务端日志。
- 知识库演示文可入库；真实家庭文档必须经授权、许可与删除责任登记。

## 4. 出口与降级

- 出网探测失败或被拒绝时，助手应显示具体受控状态（如模型不可用、知识降级）。
- 不得为了「回答完整」而绕过出口守卫上传健康上下文。

## 5. 系统演示口径

- 前端不直连数据库、向量库或 Ollama。
- 检索与工具调用经 FastAPI 校验；伪造引用与越权参数结构化降级。
## FAQ（教学问答）

**Q: 模型挂了会不会自动改用云端分析健康数据？**  
A: 家庭版默认不会。应结构化降级，云端推理必须是单独部署档。

**Q: 对话会不会存到服务器日志里？**  
A: 不应把健康对话写入不受控日志；临时恢复仅限当前标签页隔离存储。
