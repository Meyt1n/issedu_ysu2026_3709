# HomeCare Twin 医嘱变更人工确认教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明医嘱或用药计划变更必须经人工确认的产品边界。本卡不解析真实医嘱影像中的处方合法性，也不自动批准任何变更。

## 2. 什么算变更

- 药品替换、停用、剂量/频次调整、时间窗调整等，均视为高风险变更。
- OCR 或助手抽出的「疑似变更」只是候选，必须由授权用户确认后才能进入正式事件。

## 3. 确认前必须可见的信息

- 变更前后对照（diff）；
- 证据来源（包装、医嘱照片、人工录入）；
- 冲突与低置信度字段；
- 将影响的规则、提醒与授权范围提示。

## 4. 禁止自动执行的事项

- 模型不得因「用户说好像换药了」就写入正式计划。
- 不得在证据冲突时擅自选定一个药名或规格。
- 不得在未确认时触发基于新计划的规则与提醒。

## 5. 系统演示口径

- 状态：`REVIEW` / `CONFLICT` / `UNKNOWN` 时以人工复核为主路径。
- 确认后追加事件，保留原记录与操作者；支持按版本回滚讨论（以实现为准）。
