# HomeCare Twin 家庭药品存放与过期处置教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于验证本地知识入库、权限检索和引用展示，不构成诊断、处方或个体化用药建议。本卡不回答"能不能继续吃""该吃多少"这类问题；这些问题必须由医生或药师判断。演示产品不提供买药、问诊、广告或佣金导流。

## 2. 家庭药品存放常识

- 药品应保留原包装（original packaging）和说明书一起存放，方便核对名称、规格和有效期（expiry date）。
- 内服药与外用药分开存放；成人药品与儿童药品分开存放；外观相似的药品避免混放在同一个盒内。
- 存放位置应避免高温、潮湿和阳光直射；标注"冷藏"的药品按包装提示存放，并避免受冻。
- 家庭可以维护一份药品清单，记录名称、规格、数量、开封日期和存放位置，便于定期核对。

## 3. 儿童与认知障碍成员的安全

- 药品应存放在儿童看不到、够不到的位置，优先选择可上锁或有安全盖（child-resistant cap）的容器。
- 不要把药品叫作"糖果"哄孩子服药，避免形成误导。
- 家中有认知障碍成员时，建议由照护者统一管理药品，服药过程有人在场确认。
- 发现儿童或家庭成员误服药品时，属于紧急情况，应立即联系当地急救服务或就医，并携带药品原包装。

## 4. 过期药品识别与处置

- 定期（例如每季度）核对家中药品的有效期；已过期药品（expired medicine）不应继续存放在常用药品区域。
- 过期或变质迹象（变色、异味、结块、糖衣开裂）出现时，将药品移出常用区并做好记录。
- 过期药品处置建议优先咨询当地社区、药店或有资质机构的回收渠道（drug take-back）；不随意丢入儿童可接触的垃圾桶。
- 处置前可去除或涂抹包装上的个人信息，保护隐私。
- 本卡不判断某个过期药品是否仍可服用；这类问题一律建议咨询药师。

## 5. 系统内的对应演示口径

- 规则引擎的"过期/临期"提醒只提示核对有效期和妥善处置，不指导继续服用。
- 药品数量低于预设值时提示"低库存"，仅用于提醒补充核对，不提供任何购买入口。
- 所有存放与处置操作由用户或照护者人工完成并确认；系统不代替人做处置决定。
## FAQ（教学问答）

**Q: 过期药还能不能吃？**  
A: 本卡不判断。过期或变质药品应移出常用区，优先走回收渠道，是否可服用只能咨询药师。

**Q: 药品可以放在浴室吗？**  
A: 一般不建议。浴室潮湿高温，不利于多数药品保存；应按说明书选择阴凉干燥处。

**Q: 为什么不能用饮料瓶分装？**  
A: 容易与食品混淆，显著增加儿童误服风险；应保留原包装与说明书。

**Q: 发现孩子误服怎么办？**  
A: 属于紧急情况，立即联系当地急救或就医，并携带药品原包装；不要等待助手「判断严不严重」。
