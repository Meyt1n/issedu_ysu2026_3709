# HomeCare Twin 外出备药与旅行清单教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于外出或短途旅行前的备药清单教学。本卡不建议携带哪些处方药、不计算行程天数对应的剂量份数医学方案；具体备药种类与数量必须由医生/药师与家庭既有医嘱决定。

## 2. 出发前核对清单

- 核对药品通用名/商品名、规格、有效期与原包装是否完整。
- 带上说明书或清晰拍照备份（注意隐私，勿上传到未授权云相册）。
- 确认冷藏药的存放条件与行程中是否可维持（本卡不指定设备型号）。
- 列出紧急联络人、就诊信息卡与过敏摘要（仅含已授权字段）。

## 3. 途中管理

- 药品放在随身行李，避免托运遗失；与食品分开放。
- 跨时区行程若涉及服药时间调整，必须由专业人员指导；系统不得自动改医嘱。
- 发现包装破损、药品受潮或身份不清时，暂停服用并咨询药师/医生。

## 4. 回程与盘点

- 回程后核对剩余数量与有效期，更新家庭药品清单。
- 过期或变质药品按回收口径处理，不放回常用区。

## 5. 系统演示口径

- 「低库存」提示只提醒核对补充，不提供购买链接。
- 旅行清单可以是结构化待办；助手不得生成购物导流。
