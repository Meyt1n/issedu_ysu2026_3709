# HomeCare Twin 语音交互与证据边界教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明语音输入/播报只是交互层，不是新的证据来源或模型能力。Speech Recognition 只形成待发送文字草稿；Speech Synthesis 只朗读已经返回的文字。

## 2. 允许做什么

- 用语音把问题转成文字，经用户确认后发送。
- 朗读助手已返回的、经过校验的文字回复。
- 在能力不可用时回退到纯文字流程。

## 3. 不允许做什么

- 把原始音频上传到云端作为健康数据默认路径。
- 用语音结果直接写入药品、过敏或医嘱事件而不经文字确认（若产品要求确认）。
- 把播报内容当成知识库引用或规则证据。
- 在语音链路中绕过授权或出口守卫。

## 4. 无障碍与体验

- 可提供更清晰的中文音色与分段朗读（以实现为准），但不改变证据边界。
- 朗读失败时保留屏幕文字，不假装「已经告知成功」。

## 5. 系统演示口径

- 语音功能降级不影响档案、事件、规则与本地 RAG 主路径。
- 助手页面展示的引用仍必须来自本轮授权检索。
## FAQ（教学问答）

**Q: 语音识别结果算不算健康证据？**  
A: 不算。语音只形成文字草稿；证据仍来自授权事实、规则与本轮知识引用。

**Q: 没有麦克风还能用助手吗？**  
A: 可以。能力不可用时应回退到纯文字，不影响档案与规则主路径。
