# HomeCare Twin 服药时间窗与提醒预算教学卡

## 1. 用途和边界

本卡是合成教学演示知识（internal-demo），用于说明服药时间窗（dosing window）与提醒预算（alert budget）的产品约束。本卡不计算、不建议任何具体剂量或服药间隔医学方案；时间窗只能来自既有医嘱或用户预设。

## 2. 安全时间窗

- 首次提醒与再提醒只能落在允许的时间窗内。
- 系统不得为了「提高依从性」而擅自缩短间隔、增加次数或改药品。
- 用户手动调整计划若超出安全约束，应拦截并要求人工确认或拒绝。

## 3. 提醒预算与等级

- 告警按等级与预算控制，避免同一风险在短时间刷屏。
- 预算耗尽时保留结构化状态与审计信息，而不是静默丢弃后由模型假装已提醒。
- 高等级风险（如严重过敏登记命中）优先于低等级生活提示。

## 4. 与规则引擎的关系

- 风险等级由确定性规则给出；提醒通道只负责投递与确认闭环。
- 天气或生活提示不得占用用药安全高等级预算来「抢通道」。

## 5. 系统演示口径

- 连续未确认可通知授权照护者，但仍受预算与权限约束。
- 助手解释提醒策略时必须引用规则/配置版本，不得编造窗口数值。
