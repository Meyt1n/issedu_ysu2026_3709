# 助手开放演示模式（HCT-451）

> 本地教学演示默认开启，用于直接观察本机 Ollama 模型的真实回复能力。  
> **生产环境必须关闭**（`APP_ENV=production` 时若仍为 true，API 启动会失败）。

## 1. 默认行为

从 HCT-451 起，仓库默认与 `.env.example` 一致：

```bash
AGENT_OPEN_CHAT=true
AGENT_OPEN_MAX_TOKENS=4096
```

复制 `.env.example` → `.env` 后，**无需再手改**即可进入开放演示模式。若你本地已有旧 `.env`，请补上上述两行并**重启 API**。

开启后助手会：

- 跳过证据 / 引用硬墙（不再轻易 `EVIDENCE_REQUIRED` / `CITATION_NOT_FOUND`）
- 跳过空库季节短接模板（例如腹泻不再误回「空调鼻塞」）
- 跳过医疗边界词与回答内嵌外链的硬拦截（演示评估用）
- 向模型注入**本机日期时间**（可回答「今天几号」）
- 提高生成 token 下限（默认至少 4096，请求更大则取更大值）
- 允许综合本地档案、知识卡与（若有）联网摘要作答；非 JSON 草稿也会尽力放行

关闭开放模式、恢复教学证据墙：

```bash
AGENT_OPEN_CHAT=false
```

然后重启 API。

## 2. 一键启用（已有旧 .env 时）

在项目根目录 `.env` 中写入或修改：

```bash
# 开放演示：看本机模型真实回复（默认建议 true）
AGENT_OPEN_CHAT=true
AGENT_OPEN_MAX_TOKENS=4096

# 真实生成仍需要本机 Ollama
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=你的模型名
```

重启 API（按你的启动方式二选一）：

```bash
# Compose
./scripts/start.sh down && ./scripts/start.sh up

# 或本地 uv 进程：停掉旧进程后重新
uv run uvicorn app.main:app --app-dir src/api --reload --host 0.0.0.0 --port 8000
```

前端默认请求 `max_tokens=4096`；服务端在开放模式下还会把过小的请求抬到 `AGENT_OPEN_MAX_TOKENS`。

## 3. 联网搜索仍是「双重开关」

开放演示模式**不会**自动出网。要看到「外部参考」：

1. 部署侧打开搜索，例如离线教学夹具：

```bash
AGENT_WEB_SEARCH_ENABLED=true
AGENT_WEB_SEARCH_PROVIDER=fixture
```

或真实 DuckDuckGo HTML（需白名单）：

```bash
AGENT_WEB_SEARCH_ENABLED=true
AGENT_WEB_SEARCH_PROVIDER=duckduckgo_html
AGENT_WEB_SEARCH_URL=https://html.duckduckgo.com/html/
AGENT_WEB_SEARCH_ALLOWED_DOMAINS=html.duckduckgo.com
```

2. 助手页每次提问勾选「补充联网参考」。

外搜结果仍是「外部参考（非本地审核证据）」，不会当作本地知识引用写入正式 citations。详情见 [本地部署与 Demo 操作指南 §4.2](./本地部署与Demo操作指南.md)。

## 4. 生产与安全边界

| 环境 | `AGENT_OPEN_CHAT` | 说明 |
|---|---|---|
| 本地 / Demo（默认） | `true` | 评估模型听感与回答质量 |
| `APP_ENV=production` / `prod` | **必须 `false`** | 配置校验会拒绝启动 |

开放模式关闭了教学证据墙，**不适合**作为正式居家照护安全默认。正式验收、对照 FR-08 硬边界回归时，请设 `AGENT_OPEN_CHAT=false` 再测。

家庭健康数据默认仍不出网；联网仅发送脱敏查询（见 HCT-430）。

## 5. 自检

1. `GET /api/v1/assistant/agents` 响应中 `open_chat` 应为 `true`，`open_max_tokens` 为配置值。  
2. 问「今天是几月几号」→ 应能根据本机时间直接回答，而不是「无法提供日期」。  
3. 问「我有点腹泻要注意什么」→ 不应再出现无关的「空调 / 热伤风 / 鼻塞」套话。  
4. 勾选联网并提问「最近有什么新闻」→ 可参考 `external_sources` 作答，而不应再被引用硬墙整段否掉（开放模式下）。
