# 后端安全设计与隐私保护

> 本文档是家健镜后端的安全设计与隐私保护完整说明，覆盖认证授权、数据加密、输入校验、隐私合规、安全审计、漏洞防护。面向后端开发者和安全人员，作为安全开发的权威依据。

## 1. 安全设计原则

### 1.1 核心原则

1. **最小权限**：每个用户/服务只拥有必要的最小权限
2. **纵深防御**：多层安全防护，单层失效不导致整体失守
3. **默认安全**：默认配置是安全的，需要显式开启非安全选项
4. **隐私优先**：健康数据默认不出网，最小化收集
5. **可审计**：所有敏感操作有日志，可追溯
6. ** fail-safe**：系统失败时进入安全状态，不泄露数据

### 1.2 威胁模型

| 威胁 | 风险 | 防护措施 |
| --- | --- | --- |
| 未授权访问 | 数据泄露 | JWT 认证 + 字段级授权 |
| 数据泄露 | 隐私泄露 | 传输加密 + 存储加密 + 最小化 |
| SQL 注入 | 数据篡改 | 参数化查询（SQLAlchemy） |
| XSS | 会话劫持 | 输出转义 + CSP |
| CSRF | 伪造请求 | SameSite Cookie + Token |
| 暴力破解 | 账户被盗 | 限流 + 密码强度 + 锁定 |
| 重放攻击 | 重复操作 | 幂等键 + 时间戳 |
| 越权访问 | 数据泄露 | 服务端强制授权校验 |

## 2. 认证安全

### 2.1 JWT 认证

```python
# 认证实现
class JWTService:
    def __init__(self, secret: str, expire_hours: int = 24):
        self.secret = secret
        self.expire_hours = expire_hours

    def create_token(self, user_id: str, household_id: str | None = None) -> str:
        payload = {
            "sub": user_id,
            "household_id": household_id,
            "iat": datetime.utcnow(),
            "exp": datetime.utcnow() + timedelta(hours=self.expire_hours),
            "jti": uuid4().hex,  # 唯一标识，用于撤销
        }
        return jwt.encode(payload, self.secret, algorithm="HS256")

    def verify_token(self, token: str) -> dict:
        try:
            payload = jwt.decode(token, self.secret, algorithms=["HS256"])
            return payload
        except jwt.ExpiredSignatureError:
            raise AuthError("TOKEN_EXPIRED", "登录已过期")
        except jwt.InvalidTokenError:
            raise AuthError("INVALID_TOKEN", "无效的登录凭证")
```

### 2.2 密码安全

```python
# 密码哈希（bcrypt）
import bcrypt

def hash_password(password: str) -> str:
    salt = bcrypt.gensalt(rounds=12)
    return bcrypt.hashpw(password.encode(), salt).decode()

def verify_password(password: str, hashed: str) -> bool:
    return bcrypt.checkpw(password.encode(), hashed.encode())

# 密码强度校验
def validate_password_strength(password: str) -> list[str]:
    errors = []
    if len(password) < 8:
        errors.append("密码至少 8 位")
    if not any(c.isupper() for c in password):
        errors.append("密码需包含大写字母")
    if not any(c.islower() for c in password):
        errors.append("密码需包含小写字母")
    if not any(c.isdigit() for c in password):
        errors.append("密码需包含数字")
    return errors
```

### 2.3 登录限流

```python
# 登录失败计数与锁定
class LoginRateLimiter:
    def __init__(self, max_attempts: int = 5, lock_minutes: int = 10):
        self.max_attempts = max_attempts
        self.lock_minutes = lock_minutes
        self.attempts: dict[str, list[datetime]] = {}

    def check(self, username: str) -> None:
        now = datetime.now()
        user_attempts = [
            t for t in self.attempts.get(username, [])
            if (now - t).total_seconds() < self.lock_minutes * 60
        ]
        if len(user_attempts) >= self.max_attempts:
            raise AuthError("ACCOUNT_LOCKED", "登录失败次数过多，请稍后再试")

    def record_failure(self, username: str) -> None:
        self.attempts.setdefault(username, []).append(datetime.now())

    def record_success(self, username: str) -> None:
        self.attempts.pop(username, None)
```

### 2.4 会话管理

- Token 有效期 24 小时
- 修改密码后所有旧 Token 失效（通过 jti 黑名单）
- 同一账户最多 3 个活跃会话
- 敏感操作需要重新验证密码
- 家庭 PIN 用于二次确认

## 3. 授权安全

### 3.1 角色权限

| 角色 | 权限 |
| --- | --- |
| Owner（家庭创建者） | 所有权限，包括管理成员、授权、删除 |
| Caregiver（照护者） | 查看被授权成员数据、创建事件、确认任务 |
| Member（普通成员） | 查看自己的数据 |

### 3.2 字段级授权

```python
# 授权校验中间件
def require_field_authorization(field: str):
    def decorator(func):
        @wraps(func)
        async def wrapper(request, member_id: str, db: AsyncSession, *args, **kwargs):
            user_id = request.state.user_id
            household_id = request.state.household_id

            # Owner 拥有所有权限
            if await is_owner(user_id, household_id, db):
                return await func(request, member_id, db, *args, **kwargs)

            # 检查字段级授权
            auth = await get_active_authorization(
                grantee_user_id=user_id,
                member_id=member_id,
                db=db,
            )
            if not auth or field not in auth.data_fields:
                # 记录拒绝审计
                await record_audit(
                    authorization_id=auth.authorization_id if auth else None,
                    action="access",
                    actor_user_id=user_id,
                    member_id=member_id,
                    result="denied",
                    db=db,
                )
                raise PermissionError("FIELD_NOT_AUTHORIZED", f"无权限访问 {field}")

            # 记录允许审计
            await record_audit(
                authorization_id=auth.authorization_id,
                action="access",
                actor_user_id=user_id,
                member_id=member_id,
                purpose=auth.purpose,
                result="allowed",
                db=db,
            )

            return await func(request, member_id, db, *args, **kwargs)
        return wrapper
    return decorator
```

### 3.3 授权版本控制

```python
# 乐观锁防止并发修改
async def update_authorization(
    auth_id: str,
    updates: dict,
    expected_version: int,
    db: AsyncSession,
) -> Authorization:
    auth = await db.get(Authorization, auth_id)
    if not auth:
        raise NotFoundError("AUTH_NOT_FOUND", "授权不存在")

    if auth.version != expected_version:
        raise VersionConflictError(
            "AUTH_VERSION_CONFLICT",
            f"授权已被修改（当前版本 {auth.version}），请刷新后重试",
        )

    for key, value in updates.items():
        setattr(auth, key, value)
    auth.version += 1
    auth.updated_at = datetime.now()

    await db.commit()
    return auth
```

## 4. 数据安全

### 4.1 传输加密

- 公网部署强制 HTTPS（TLS 1.2+）
- HSTS 头强制 HTTPS
- 家庭局域网可 HTTP（用户明确选择）
- 敏感操作要求 HTTPS

```python
# 安全响应头
@app.middleware("http")
async def security_headers(request, call_next):
    response = await call_next(request)
    response.headers["X-Content-Type-Options"] = "nosniff"
    response.headers["X-Frame-Options"] = "DENY"
    response.headers["X-XSS-Protection"] = "1; mode=block"
    response.headers["Referrer-Policy"] = "strict-origin-when-cross-origin"
    response.headers["Content-Security-Policy"] = (
        "default-src 'self'; "
        "script-src 'self'; "
        "style-src 'self' 'unsafe-inline'; "
        "img-src 'self' data:; "
        "connect-src 'self'"
    )
    if request.url.scheme == "https":
        response.headers["Strict-Transport-Security"] = "max-age=31536000; includeSubDomains"
    return response
```

### 4.2 存储加密

- 密码：bcrypt 哈希（不可逆）
- JWT 密钥：环境变量，不入代码库
- 健康数据：SQLite 文件系统级加密（可选）
- 备份文件：加密存储
- 配置文件：权限 600

### 4.3 数据最小化

- 只收集必要的健康数据
- 不收集精确位置（天气用城市编码）
- 不收集通讯录、相册等敏感信息
- 日志不记录健康数据内容
- 错误响应不包含内部细节

### 4.4 数据脱敏

```python
# 日志脱敏
def sanitize_for_log(data: dict) -> dict:
    sensitive_fields = {"password", "token", "medication", "vitals", "allergy"}
    result = {}
    for key, value in data.items():
        if key.lower() in sensitive_fields:
            result[key] = "[REDACTED]"
        elif isinstance(value, dict):
            result[key] = sanitize_for_log(value)
        else:
            result[key] = value
    return result

# API 响应脱敏
def mask_authorized_fields(data: dict, authorized_fields: list[str]) -> dict:
    return {
        key: value if key in authorized_fields else None
        for key, value in data.items()
    }
```

### 5.2 SQL 注入防护

- 所有查询使用 SQLAlchemy 参数化
- 禁止字符串拼接 SQL
- 禁止 raw SQL（除非必要，且必须参数化）

```python
# 好：参数化
result = await db.execute(
    select(Member).where(Member.member_id == member_id)
)

# 不好：字符串拼接（禁止）
result = await db.execute(
    text(f"SELECT * FROM members WHERE member_id = '{member_id}'")
)
```

### 5.3 XSS 防护

- 所有用户输入输出时转义
- CSP 头限制脚本来源
- 不使用 v-html 渲染用户输入
- Markdown 渲染使用安全库

### 5.4 文件上传安全

```python
ALLOWED_MIME_TYPES = {"image/jpeg", "image/png", "image/webp", "video/mp4"}
MAX_FILE_SIZE = 50 * 1024 * 1024  # 50MB

async def validate_upload(file: UploadFile) -> None:
    # 校验 MIME 类型
    if file.content_type not in ALLOWED_MIME_TYPES:
        raise BusinessError("INVALID_FILE_TYPE", f"不支持的文件类型: {file.content_type}")

    # 校验文件大小
    content = await file.read()
    if len(content) > MAX_FILE_SIZE:
        raise BusinessError("FILE_TOO_LARGE", f"文件过大（最大 {MAX_FILE_SIZE // 1024 // 1024}MB）")

    # 校验文件头（防止伪造 MIME）
    if file.content_type.startswith("image/"):
        if not content[:3] in (b"\xff\xd8\xff", b"\x89PNG", b"RIFF"):
            raise BusinessError("INVALID_FILE", "文件内容与类型不匹配")

    await file.seek(0)
```

## 6. 隐私合规

### 6.1 隐私原则

1. **知情同意**：首次使用明确告知数据用途
2. **目的限制**：数据只用于声明的目的
3. **数据最小化**：只收集必要数据
4. **访问控制**：只有授权人员可访问
5. **可删除**：用户可请求删除数据
6. **可导出**：用户可导出自己的数据

### 6.2 隐私告知

首次使用展示隐私告知：

- 收集哪些数据
- 数据存储在哪里
- 谁可以访问数据
- 数据保留期限
- 用户权利（查看、导出、删除）
- 联系渠道

### 6.3 数据保留

| 数据类型 | 保留期限 | 说明 |
| --- | --- | --- |
| 健康事件 | 永久（用户可删除） | 医疗记录需长期保留 |
| 授权审计 | 3 年 | 合规要求 |
| 操作日志 | 90 天 | 安全审计 |
| 上传文件 | 永久（用户可删除） | 识别用图片 |
| 客户端日志 | 30 天 | 问题排查 |

async def get_audit_logs(
    household_id: str,
    start_date: date,
    end_date: date,
    db: AsyncSession,
) -> list[AuditLog]:
    result = await db.execute(
        select(AuditLog)
        .where(
            AuditLog.household_id == household_id,
            AuditLog.occurred_at.between(start_date, end_date),

        .limit(500)

## 9. API 安全

### 9.1 限流

```python
# 简单内存限流
class RateLimiter:
    def __init__(self, max_requests: int = 100, window_seconds: int = 60):
        self.max_requests = max_requests
        self.window_seconds = window_seconds
        self.requests: dict[str, list[float]] = {}

    def check(self, key: str) -> None:
        now = time.time()
        window_start = now - self.window_seconds
        recent = [t for t in self.requests.get(key, []) if t > window_start]

        if len(recent) >= self.max_requests:
            raise RateLimitError("RATE_LIMITED", "请求过于频繁，请稍后再试")

        recent.append(now)
        self.requests[key] = recent
```
