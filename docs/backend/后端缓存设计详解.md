# 后端缓存设计详解

> 本文档是家健镜系统后端缓存的完整设计说明，覆盖缓存策略、缓存层级、缓存失效、缓存一致性、性能优化。

## 1. 缓存概述

### 1.1 设计目标

1. 降低延迟：热点数据毫秒级响应
2. 减轻数据库压力：减少重复查询
3. 提高吞吐量：支持更多并发请求
4. 数据一致：缓存与数据库最终一致
5. 高可用：缓存故障不影响系统运行

### 1.2 缓存层级

- L1 本地内存缓存：进程内，最快，容量小
- L2 Redis 缓存：分布式，中等延迟，容量大
- L3 数据库：持久化，最慢，容量无限

### 1.3 缓存策略

| 策略 | 说明 | 适用场景 |
| --- | --- | --- |
| Cache-Aside | 应用先查缓存，未命中查数据库并回填 | 通用场景 |
| Read-Through | 缓存层自动从数据库加载 | 读多写少 |
| Write-Through | 写时同时更新缓存和数据库 | 写少读多 |
| Write-Behind | 写时只更新缓存，异步写数据库 | 写多，可容忍丢失 |

## 2. 本地缓存

### 2.1 LRU 缓存

```python
from functools import lru_cache
from cachetools import TTLCache, cached

@lru_cache(maxsize=1000)
def get_medicine_template(medicine_id):
    return db.query(MedicineTemplate).get(medicine_id)

medicine_cache = TTLCache(maxsize=2000, ttl=300)

@cached(medicine_cache)
def get_medicine_info(medicine_id):
    return fetch_from_db(medicine_id)
```

### 2.2 本地缓存注意事项

- 多实例间数据不一致
- 适合不常变更的配置数据
- 容量有限，需要设置 maxsize
- 进程重启后缓存丢失

## 3. Redis 缓存

### 3.1 缓存服务

```python
import json
from datetime import timedelta
from redis.asyncio import Redis

class CacheService:
    def __init__(self, redis):
        self.redis = redis

    async def get(self, key):
        data = await self.redis.get(key)
        if data:
            return json.loads(data)
        return None

    async def set(self, key, value, ttl=None):
        data = json.dumps(value, ensure_ascii=False, default=str)
        if ttl:
            await self.redis.setex(key, int(ttl.total_seconds()), data)
        else:
            await self.redis.set(key, data)

    async def delete(self, key):
        await self.redis.delete(key)

    async def delete_pattern(self, pattern):
        keys = await self.redis.keys(pattern)
        if keys:
            await self.redis.delete(*keys)

    def make_key(self, prefix, *args):
        return ":".join([prefix] + [str(a) for a in args])
```

### 3.2 Cache-Aside 模式

```python
class MedicineService:
    async def get_medicine(self, medicine_id):
        cache_key = self.cache.make_key("medicine", medicine_id)
        cached = await self.cache.get(cache_key)
        if cached:
            return Medicine(**cached)

        medicine = await self.db.get(Medicine, medicine_id)
        if not medicine:
            raise NotFoundError("MEDICINE_NOT_FOUND", "药品不存在")

        await self.cache.set(
            cache_key, medicine.to_dict(), ttl=timedelta(minutes=10)
        )
        return medicine

    async def update_medicine(self, medicine):
        self.db.add(medicine)
        await self.db.commit()

        cache_key = self.cache.make_key("medicine", medicine.id)
        await self.cache.delete(cache_key)
        await self.cache.delete_pattern("medicine:list:*")
        return medicine
```

### 3.3 缓存穿透防护

空值缓存 + 布隆过滤器，防止恶意查询不存在的数据。

```python
class CachePenetrationGuard:
    def __init__(self, cache, redis):
        self.cache = cache
        self.redis = redis
        self.null_ttl = timedelta(minutes=5)

    async def get_with_guard(self, key, fetch_func, null_ttl=None):
        cached = await self.cache.get(key)
        if cached is not None:
            if cached.get("__null__"):
                return None
            return cached

        result = await fetch_func()

        if result is None:
            await self.cache.set(
                key, {"__null__": True}, ttl=null_ttl or self.null_ttl
            )
        else:
            await self.cache.set(key, result, ttl=timedelta(minutes=10))
        return result
```

### 3.4 缓存击穿防护

互斥锁 + 逻辑过期，防止热点 key 失效时大量请求打到数据库。

```python
class CacheBreakdownGuard:
    def __init__(self, cache, redis):
        self.cache = cache
        self.redis = redis

    async def get_with_lock(self, key, fetch_func, lock_timeout=10):
        cached = await self.cache.get(key)
        if cached:
            return cached

        lock_key = f"lock:{key}"
        lock_acquired = await self.redis.set(
            lock_key, "1", ex=lock_timeout, nx=True
        )

        if lock_acquired:
            try:
                cached = await self.cache.get(key)
                if cached:
                    return cached
                result = await fetch_func()
                await self.cache.set(key, result, ttl=timedelta(minutes=10))
                return result
            finally:
                await self.redis.delete(lock_key)
        else:
            await asyncio.sleep(0.1)
            return await self.get_with_lock(key, fetch_func)
```

### 3.5 缓存雪崩防护

过期时间随机化 + 多级缓存，防止大量 key 同时过期。

```python
class CacheAvalancheGuard:
    def __init__(self, cache):
        self.cache = cache

    async def set_with_jitter(self, key, value, base_ttl, jitter=60):
        import random
        ttl_seconds = int(base_ttl.total_seconds()) + random.randint(0, jitter)
        await self.cache.set(key, value, ttl=timedelta(seconds=ttl_seconds))
```

## 4. 缓存键设计

### 4.1 命名规范

格式：业务域:实体:标识:字段

示例：
- medicine:info:med_001
- medicine:list:member_001:page1
- member:profile:member_001
- user:session:user_001
- risk:active:household_001

### 4.2 缓存 TTL 规范

| 数据类型 | TTL | 说明 |
| --- | --- | --- |
| 药品信息 | 10 分钟 | 变更不频繁 |
| 成员信息 | 5 分钟 | 可能变更 |
| 药品列表 | 1 分钟 | 列表变化频繁 |
| 用户会话 | 30 分钟 | 与 Token 一致 |
| 风险列表 | 30 秒 | 实时性要求高 |
| 配置数据 | 1 小时 | 极少变更 |
| 空值 | 5 分钟 | 防止穿透 |

## 5. 缓存一致性

### 5.1 缓存更新策略

Cache-Aside：先更新数据库，再删除缓存。延迟双删防止并发脏数据。

```python
class CacheConsistency:
    @staticmethod
    async def cache_aside_update(cache, key, update_func):
        result = await update_func()
        await cache.delete(key)

        async def delayed_delete():
            await asyncio.sleep(0.5)
            await cache.delete(key)
        asyncio.create_task(delayed_delete())
        return result
```

### 5.2 事件驱动失效

通过事件总线失效相关缓存。

```python
class CacheInvalidator:
    def __init__(self, cache):
        self.cache = cache

    async def on_medicine_updated(self, event):
        await self.cache.delete(f"medicine:info:{event.medicine_id}")
        await self.cache.delete_pattern(f"medicine:list:{event.member_id}:*")
        await self.cache.delete_pattern("medicine:search:*")
```

```python
class CacheWarmer:
    async def warmup(self, db, cache):
        templates = await db.execute(select(MedicineTemplate).limit(100))
        for t in templates.scalars():
            await cache.set(
                f"medicine:template:{t.id}",
                t.to_dict(),
                ttl=timedelta(hours=1),
            )
```
