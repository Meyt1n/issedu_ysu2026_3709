# 后端消息队列设计

> 本文档是家健镜系统消息队列的完整设计说明，覆盖队列模型、生产者消费者、消息可靠性、死信队列、延迟队列。

## 1. 消息队列概述

### 1.1 设计目标

1. 异步处理：耗时操作异步执行，不阻塞请求
2. 解耦：生产者和消费者解耦
3. 削峰：高峰期请求缓冲，保护下游
4. 可靠：消息不丢失、不重复
5. 可扩展：消费者可水平扩展

### 1.2 技术选型

| 方案 | 优点 | 缺点 | 选择 |
| --- | --- | --- | --- |
| Redis Stream | 轻量、已部署 | 功能有限 | 轻量任务 |
| RabbitMQ | 功能丰富、可靠 | 较重 | 核心任务 |
| Celery | Python 生态好 | 依赖 Broker | 异步任务 |

决策：使用 Redis Stream 作为轻量消息队列，Celery + Redis 作为任务队列。

### 1.3 使用场景

| 场景 | 队列 | 说明 |
| --- | --- | --- |
| 视觉识别任务 | Celery | 耗时，需要 Worker |
| 邮件发送 | Celery | 异步，可重试 |
| 推送通知 | Redis Stream | 实时，轻量 |
| 事件投影 | Redis Stream | 事件驱动 |
| 数据同步 | Celery | 批量，可重试 |

### 2.2 任务定义

```python
from celery import shared_task

@shared_task(bind=True, max_retries=3, default_retry_delay=60, acks_late=True)
def process_vision_task(self, task_id):
    try:
        result = vision_service.process(task_id)
        return result
    except Exception as exc:
        raise self.retry(exc=exc, countdown=60)

@shared_task(bind=True, max_retries=5)
def send_email(self, to, subject, body):
    try:
        email_service.send(to, subject, body)
    except SMTPException as exc:
        raise self.retry(exc=exc, countdown=300)

@shared_task
def send_push_notification(user_id, title, body):
    push_service.send_to_user(user_id, title, body)
```

## 3. Redis Stream

### 3.1 生产者

```python
class EventPublisher:
    def __init__(self, redis):
        self.redis = redis

    async def publish(self, stream, event):
        await self.redis.xadd(
            stream,
            {"data": json.dumps(event, ensure_ascii=False, default=str)},
            maxlen=10000,
        )
```

### 3.2 消费者

```python
class EventConsumer:
    def __init__(self, redis, stream, group, consumer):
        self.redis = redis
        self.stream = stream
        self.group = group
        self.consumer = consumer

    async def start(self):
        try:
            await self.redis.xgroup_create(
                self.stream, self.group, id="0", mkstream=True
            )
        except ResponseError:
            pass

        while True:
            messages = await self.redis.xreadgroup(
                groupname=self.group,
                consumername=self.consumer,
                streams={self.stream: ">"},
                count=10,
                block=5000,
            )

            for stream_name, message_list in messages:
                for message_id, data in message_list:
                    try:
                        event = json.loads(data[b"data"])
                        await self.handle(event)
                        await self.redis.xack(self.stream, self.group, message_id)
                    except Exception as e:
                        logger.error(f"消息处理失败: {e}")
```

### 3.3 死信处理

投递次数过多的消息移到死信队列。

```python
class DeadLetterHandler:
    def __init__(self, redis):
        self.redis = redis

    async def process_pending(self, stream, group):
        pending = await self.redis.xpending(stream, group)
        if pending["pending"] == 0:
            return

        details = await self.redis.xpending_range(
            stream, group, min="-", max="+", count=100
        )

        for item in details:
            message_id = item["message_id"]
            delivery_count = item["times_delivered"]

            if delivery_count > 5:
                message = await self.redis.xrange(stream, min=message_id, count=1)
                if message:
                    await self.redis.xadd(
                        f"{stream}:dead_letter", message[0][1]
                    )
                await self.redis.xack(stream, group, message_id)
                await self.redis.xdel(stream, message_id)
```

## 4. 消息可靠性

### 4.1 消息不丢失

1. 生产者确认：发送后等待确认
2. 持久化：消息持久化到磁盘
3. 手动确认：消费者处理完成后才确认
4. 死信队列：处理失败的消息不丢弃

### 4.2 消息不重复

1. 幂等消费：消费者实现幂等
2. 消息去重：基于消息 ID 去重
3. 唯一约束：数据库唯一索引

```python
class IdempotentConsumer:
    def __init__(self, redis):
        self.redis = redis

    async def process(self, message_id, handler):
        processed = await self.redis.get(f"processed:{message_id}")
        if processed:
            return

        await handler()

        await self.redis.setex(
            f"processed:{message_id}", 86400, "1"
        )
```

### 4.3 消息顺序

- 同一实体的消息使用相同的分区 key
- 单线程消费者保证顺序
- 事件溯源保证顺序

## 5. 延迟队列

基于 Redis ZSet 实现延迟队列。

```python
class DelayedQueue:
    def __init__(self, redis, queue_name):
        self.redis = redis
        self.queue_name = queue_name

    async def enqueue(self, message, delay_seconds):
        import time
        score = time.time() + delay_seconds
        await self.redis.zadd(
            self.queue_name,
            {json.dumps(message): score},
        )

    async def dequeue(self):
        import time
        now = time.time()

        pipe = self.redis.pipeline()
        pipe.zrangebyscore(self.queue_name, 0, now, start=0, num=1)
        pipe.zremrangebyrank(self.queue_name, 0, 0)
        results = await pipe.execute()

        messages = results[0]
        if messages:
            return json.loads(messages[0])
        return None
```
