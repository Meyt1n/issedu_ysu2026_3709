# 后端测试策略与用例设计

> 本文档是家健镜后端的测试策略完整说明，覆盖测试分层、测试环境、用例设计、测试工具、CI集成、质量门禁。面向后端开发者和测试人员，作为测试工作的权威依据。

## 1. 测试策略概述

### 1.1 测试金字塔

```
        /\           E2E 测试 (10%)
       /  \          端到端 API 流程
      /----\         集成测试 (30%)
     /      \        数据库、多模块交互
    /--------\       单元测试 (60%)
   /          \      函数、类、业务逻辑
  /------------\
```

### 1.2 测试原则

1. **测试行为，不测试实现**：关注输入输出，不关注内部实现
2. **每个测试独立**：不依赖执行顺序，不共享状态
3. **快速反馈**：单元测试 <1s，集成测试 <10s
4. **确定性**：相同输入永远得到相同输出
5. **可重复**：测试可反复运行，结果一致
6. **边界优先**：重点测试边界条件和错误路径

### 1.3 测试范围

| 模块 | 单元测试 | 集成测试 | E2E 测试 |

### 5.2 并发测试

```python
class TestConcurrency:
    async def test_concurrent_event_creation_should_not_duplicate(self, client):
        # 并发创建相同幂等键的事件
        responses = await asyncio.gather(*[
            client.post("/events", json={"idempotency_key": "same-key", ...})
            for _ in range(10)
        ])

        # 只有一个成功，其余返回冲突
        success_count = sum(1 for r in responses if r.status_code == 201)
        conflict_count = sum(1 for r in responses if r.status_code == 409)
        assert success_count == 1
        assert conflict_count == 9
```
