> 本文档是家健镜后端的性能优化完整指南，覆盖数据库优化、查询优化、缓存策略、异步处理、连接池、性能监控。面向后端开发者，作为性能优化的权威依据。

## 2. 数据库优化

### 2.1 索引优化

#### 2.1.1 索引设计原则

- 所有外键列建索引
- 常用 WHERE 条件建联合索引
- 常用 ORDER BY 列建索引
- 低基数字段不建索引（如 status 只有 2-3 个值）
- 避免过多索引（影响写入性能）

#### 2.1.2 联合索引顺序

```sql
-- 好：等值查询列在前，范围查询列在后
CREATE INDEX idx_events_member_time ON health_events(member_id, occurred_at DESC);

-- 好：最左前缀匹配
CREATE INDEX idx_tasks_member_date_status ON daily_tasks(member_id, task_date, status);

-- 不好：范围查询列在前
CREATE INDEX idx_bad ON health_events(occurred_at, member_id);
```

#### 2.1.3 部分索引

```sql
-- 只索引活跃风险（减少索引大小）
CREATE INDEX idx_risks_active ON risk_events(household_id, created_at DESC)
WHERE acknowledged = FALSE;

-- 只索引未过期药品
CREATE INDEX idx_medications_active ON medications(member_id)
WHERE status = 'active';
```

#### 2.1.4 索引使用检查

```sql
-- SQLite：EXPLAIN QUERY PLAN
EXPLAIN QUERY PLAN
SELECT * FROM health_events WHERE member_id = 'm_001' ORDER BY occurred_at DESC LIMIT 20;

-- PostgreSQL：EXPLAIN ANALYZE
EXPLAIN ANALYZE
SELECT * FROM health_events WHERE member_id = 'm_001' ORDER BY occurred_at DESC LIMIT 20;
```

### 2.2 查询优化

#### 2.2.1 避免 SELECT *

```python
# 好：只查询需要的列
result = await db.execute(
    select(Member.member_id, Member.display_name, Member.relationship)
    .where(Member.household_id == household_id)
)

# 不好：查询所有列
result = await db.execute(select(Member))
```

#### 2.2.2 分页优化

```python
# 好：游标分页（深度分页性能好）
async def get_events_cursor(member_id: str, cursor: int | None, limit: int = 20):
    query = select(HealthEvent).where(HealthEvent.member_id == member_id)
    if cursor:
        query = query.where(HealthEvent.sequence_no < cursor)
    query = query.order_by(HealthEvent.sequence_no.desc()).limit(limit)
    result = await db.execute(query)
    return result.scalars().all()

# 不好：OFFSET 分页（深度分页慢）
async def get_events_offset(member_id: str, offset: int, limit: int = 20):
    result = await db.execute(
        select(HealthEvent)
        .where(HealthEvent.member_id == member_id)
        .order_by(HealthEvent.sequence_no.desc())
        .offset(offset)
        .limit(limit)
    )
```

#### 2.2.3 批量查询

```python
# 好：批量查询
async def get_medications_for_members(member_ids: list[str], db: AsyncSession):
    result = await db.execute(
        select(Medication).where(Medication.member_id.in_(member_ids))
    )
    meds = result.scalars().all()
    return {med.member_id: med for med in meds}

# 不好：循环查询（N+1）
async def bad_n_plus_1(members: list[Member], db: AsyncSession):
    for member in members:
        meds = await db.execute(
            select(Medication).where(Medication.member_id == member.member_id)
        )
```

#### 2.2.4 聚合查询

```python
# 好：数据库端聚合
result = await db.execute(
    select(
        HealthEvent.event_type,
        func.count(HealthEvent.event_id).label("count"),
    )
    .where(HealthEvent.member_id == member_id)
    .group_by(HealthEvent.event_type)
)

# 不好：应用端聚合
events = await db.execute(select(HealthEvent).where(...))
counts = {}
for event in events.scalars():
    counts[event.event_type] = counts.get(event.event_type, 0) + 1
```

### 2.3 事务优化

#### 2.3.1 事务大小

- 短事务：只包含必要的数据库操作
- 避免在事务中做外部调用（HTTP、文件 IO）
- 批量操作分批提交

```python
# 好：短事务
async with db.begin():
    await db.execute(insert_event(event))
    await db.execute(insert_outbox(event))

# 不好：长事务（含外部调用）
async with db.begin():
    await db.execute(insert_event(event))
    await llm_client.generate(...)  # 外部调用，不应在事务中
    await db.execute(insert_outbox(event))
```

#### 2.3.2 批量插入

```python
# 好：批量插入
await db.execute(
    insert(HealthEvent),
    [event.dict() for event in events],
)

# 不好：循环插入
for event in events:
    await db.execute(insert(HealthEvent), event.dict())
```

## 3. 缓存策略

### 3.1 缓存层级

```
┌─────────────────────────────┐
│  L1: 进程内缓存 (lru_cache)  │  ← 极快，容量小
├─────────────────────────────┤
│  L2: Redis / 内存数据库      │  ← 快，可共享
├─────────────────────────────┤
│  L3: 数据库                  │  ← 慢，持久化
└─────────────────────────────┘
```

### 3.2 缓存对象

| 对象 | 缓存方式 | TTL | 失效策略 |
| --- | --- | --- | --- |
| 成员信息 | 进程内 | 5 分钟 | 事件更新时失效 |
| 药品列表 | 进程内 | 5 分钟 | 药品变更时失效 |
| 知识文档 | 进程内 | 1 小时 | 文档更新时失效 |
| 天气数据 | 进程内 | 30 分钟 | 定时刷新 |
| 健康资讯 | 进程内 | 1 小时 | 定时刷新 |
| 能力声明 | 进程内 | 1 分钟 | 定时刷新 |

### 3.3 缓存实现

```python
from functools import lru_cache
from cachetools import TTLCache

# 简单 TTL 缓存
cache = TTLCache(maxsize=100, ttl=300)  # 5 分钟

async def get_member_cached(member_id: str, db: AsyncSession) -> Member:
    if member_id in cache:
        return cache[member_id]

    member = await get_member(member_id, db)
    cache[member_id] = member
    return member

# 缓存失效
def invalidate_member_cache(member_id: str):
    cache.pop(member_id, None)
```

### 3.4 缓存注意事项

- 缓存数据可能不一致，设置合理 TTL
- 写操作后主动失效相关缓存
- 缓存穿透：空结果也缓存（短 TTL）
- 缓存雪崩：TTL 加随机偏移
- 不缓存频繁变化的数据（如今日任务状态）

## 4. 异步处理

### 4.1 异步框架

```python
# 所有 IO 操作异步
@app.post("/api/v1/events")
async def create_event(cmd: CreateEventCommand, db: AsyncSession = Depends(get_db)):
    event = await handler.handle(cmd, db)  # 异步
    return event

# 异步数据库查询
async def get_member(member_id: str, db: AsyncSession) -> Member | None:
    result = await db.execute(
        select(Member).where(Member.member_id == member_id)
    )
    return result.scalar_one_or_none()
```

### 4.2 后台任务

```python
# 视觉识别异步处理
class VisionWorker:
    async def run(self):
        while True:
            task = await self.get_next_task()
            if not task:
                await asyncio.sleep(1)
                continue

            try:
                await self.process_task(task)
            except Exception as e:
                logger.error("视觉任务处理失败", task_id=task.task_id, error=str(e))
                await self.mark_failed(task, str(e))

    async def process_task(self, task: VisionTask):
        # 1. 更新状态
        await self.update_status(task.task_id, "PREPROCESSING")

        # 2. 图片预处理
        image = await self.preprocess(task.file_reference)

        # 3. OCR 识别
        ocr_result = await self.ocr_recognize(image)

        # 4. 条码识别
        barcode_result = await self.barcode_recognize(image)

        # 5. 结果融合
        candidates = await self.fuse_results(ocr_result, barcode_result)

        # 6. 更新结果
        await self.update_result(task.task_id, candidates)
```

### 4.3 并发控制

```python
# 限制并发数
semaphore = asyncio.Semaphore(5)

async def process_with_limit(task):
    async with semaphore:
        return await process_task(task)

# 并发处理多个任务
tasks = [process_with_limit(t) for t in pending_tasks]
await asyncio.gather(*tasks)
```

### 5.3 字段筛选

```python
# 允许客户端指定返回字段
@app.get("/api/v1/members/{member_id}")
async def get_member(
    member_id: str,
    fields: str | None = Query(None, description="逗号分隔的字段列表"),
    db: AsyncSession = Depends(get_db),
):
    member = await get_member_full(member_id, db)
    if fields:
        allowed = {"member_id", "display_name", "relationship", "medications"}
        selected = [f for f in fields.split(",") if f in allowed]
        return {k: v for k, v in member.dict().items() if k in selected}
    return member
```

### 5.4 ETag 缓存

```python
@app.get("/api/v1/members/{member_id}")
async def get_member(member_id: str, request: Request, db: AsyncSession = Depends(get_db)):
    member = await get_member(member_id, db)
    etag = hashlib.md5(f"{member.member_id}:{member.updated_at}".encode()).hexdigest()

    if request.headers.get("If-None-Match") == etag:
        return Response(status_code=304)

    response = JSONResponse(content=member.dict())
    response.headers["ETag"] = etag
    return response
```

## 6. 性能监控

### 6.1 慢查询日志

```python
# SQLAlchemy 慢查询日志
import time

@event.listens_for(engine, "before_cursor_execute")
def before_cursor_execute(conn, cursor, statement, parameters, context, executemany):
    conn.info["query_start_time"] = time.time()

@event.listens_for(engine, "after_cursor_execute")
def after_cursor_execute(conn, cursor, statement, parameters, context, executemany):
    duration = time.time() - conn.info["query_start_time"]
    if duration > 0.1:  # 超过 100ms
        logger.warning("慢查询", duration_ms=duration * 1000, statement=statement[:200])
```

### 6.2 API 耗时统计

```python
@app.middleware("http")
async def add_process_time_header(request, call_next):
    start_time = time.time()
    response = await call_next(request)
    process_time = time.time() - start_time
    response.headers["X-Process-Time"] = str(process_time)

    if process_time > 0.5:  # 超过 500ms
        logger.warning(
            "慢请求",
            path=request.url.path,
            duration_ms=process_time * 1000,
            request_id=request.state.request_id,
        )
    return response
```

### 6.3 Prometheus 指标

```python
from prometheus_client import Counter, Histogram, generate_latest

REQUEST_COUNT = Counter("http_requests_total", "Total requests", ["method", "path", "status"])
REQUEST_DURATION = Histogram("http_request_duration_seconds", "Request duration", ["path"])

@app.middleware("http")
async def metrics_middleware(request, call_next):
    start = time.time()
    response = await call_next(request)
    duration = time.time() - start

    REQUEST_COUNT.labels(request.method, request.url.path, response.status_code).inc()
    REQUEST_DURATION.labels(request.url.path).observe(duration)
    return response

@app.get("/metrics")
async def metrics():
    return Response(content=generate_latest(), media_type="text/plain")
```
