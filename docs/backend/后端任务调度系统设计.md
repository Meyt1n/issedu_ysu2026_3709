# 后端任务调度系统设计

> 本文档是家健镜系统任务调度的完整设计说明，覆盖定时任务、任务依赖、任务监控、分布式调度。

## 1. 概述

### 1.1 设计目标

1. 定时执行：支持 Cron 表达式和固定间隔
2. 任务依赖：支持任务间依赖关系
3. 分布式：支持多实例部署
4. 可监控：任务执行状态可监控
5. 可重试：失败任务自动重试

### 1.2 任务类型

| 类型 | 说明 | 示例 |
| --- | --- | --- |
| 定时任务 | 按时间执行 | 每日药品过期检查 |
| 间隔任务 | 固定间隔执行 | 每小时同步数据 |
| 依赖任务 | 依赖其他任务 | 数据同步后生成报表 |
| 手动任务 | 手动触发 | 数据清理 |

from apscheduler.triggers.cron import CronTrigger

scheduler = AsyncIOScheduler()

### 2.3 任务定义

```python
class BaseTask:
    name = "base_task"
    schedule = None  # Cron 表达式或间隔
    max_retries = 3
    timeout = 300

    async def execute(self, *args, **kwargs):
        raise NotImplementedError

    async def on_success(self, result):
        logger.info(f"任务 {self.name} 执行成功")

    async def on_failure(self, error):
        logger.error(f"任务 {self.name} 执行失败: {error}")

class CheckExpiryTask(BaseTask):
    name = "check_medication_expiry"
    schedule = "0 5 0 * * *"  # 每天 00:05

    async def execute(self):
        expired_medicines = await medicine_service.get_expired()
        for medicine in expired_medicines:
            await risk_service.create_expiry_risk(medicine)
        return len(expired_medicines)
```

## 3. 分布式调度

### 3.1 分布式锁

```python
class DistributedLock:
    def __init__(self, redis, key, timeout=60):
        self.redis = redis
        self.key = f"lock:task:{key}"
        self.timeout = timeout
        self.acquired = False

    async def acquire(self):
        self.acquired = await self.redis.set(
            self.key, "1", ex=self.timeout, nx=True
        )
        return self.acquired

    async def release(self):
        if self.acquired:
            await self.redis.delete(self.key)
            self.acquired = False

    async def __aenter__(self):
        await self.acquire()
        return self

    async def __aexit__(self, *args):
        await self.release()
```

### 3.2 分布式任务执行

```python
async def execute_task(task):
    lock = DistributedLock(redis, task.name, timeout=task.timeout)

    async with lock:
        if not lock.acquired:
            logger.info(f"任务 {task.name} 已在其他实例执行")
            return

        try:
            result = await task.execute()
            await task.on_success(result)
            return result
        except Exception as e:
            await task.on_failure(e)
            raise
```

## 4. 任务依赖

### 4.1 DAG 调度

```python
class TaskDAG:
    def __init__(self):
        self.tasks = {}
        self.dependencies = {}  # task -> [upstream_tasks]

    def add_task(self, task, depends_on=None):
        self.tasks[task.name] = task
        if depends_on:
            self.dependencies[task.name] = depends_on

    async def execute(self):
        executed = set()
        results = {}

        while len(executed) < len(self.tasks):
            for name, task in self.tasks.items():
                if name in executed:
                    continue

                # 检查依赖是否完成
                deps = self.dependencies.get(name, [])
                if all(d in executed for d in deps):
                    results[name] = await task.execute()
                    executed.add(name)

        return results
```

## 5. 任务监控

### 5.1 任务记录

```python
class TaskRecord(Base):
    __tablename__ = "task_records"

    id = Column(UUID, primary_key=True)
    task_name = Column(String)
    status = Column(Enum("pending", "running", "success", "failed"))
    start_time = Column(DateTime)
    end_time = Column(DateTime)
    duration = Column(Float)
    result = Column(JSON)
    error = Column(Text)
    retry_count = Column(Integer, default=0)
```

### 5.2 任务执行记录

```python
class TaskExecutor:
    async def execute(self, task):
        record = TaskRecord(
            task_name=task.name,
            status="running",
            start_time=datetime.now(),
        )
        db.add(record)
        await db.commit()

        try:
            result = await task.execute()
            record.status = "success"
            record.result = result
        except Exception as e:
            record.status = "failed"
            record.error = str(e)
            record.retry_count += 1
        finally:
            record.end_time = datetime.now()
            record.duration = (record.end_time - record.start_time).total_seconds()
            await db.commit()

        return record
```
