# 后端架构设计详解

> 本文档是家健镜系统后端的完整架构设计说明，覆盖分层架构、领域模型、事件溯源、CQRS、微服务划分、技术选型、部署拓扑。面向后端开发者和架构师，作为系统设计和开发的权威依据。

## 1. 系统概述

### 1.1 产品定位

家健镜（HomeCare Twin）是面向家庭的健康照护数字孪生系统，通过「实物镜像 + 数字孪生」的方式，帮助家庭管理老人和慢病患者的日常健康照护。系统由三端组成：

| 端 | 技术栈 | 定位 |
| --- | --- | --- |
| 网页端 (Web) | Vue 3 + TypeScript | 管理、复核、大屏、模型实验室 |
| 移动端 (APP) | Vue 3 + Capacitor | 随身照护、拍照识别、语音助手 |
| 后端 (API) | FastAPI + SQLAlchemy | 业务逻辑、数据存储、AI 推理 |

### 1.2 核心设计原则

1. **事件溯源（Event Sourcing）**：所有状态变更以事件形式持久化，状态通过事件回放重建
2. **CQRS**：读写分离，写模型保证一致性，读模型优化查询
3. **隐私优先**：健康数据默认不出网，最小权限，授权可审计
4. **家庭自部署**：支持局域网部署，数据完全在家庭内部
5. **能力声明**：每个能力显式声明可用/不可用，不静默降级
6. **幂等安全**：所有写操作支持幂等键，重试不产生重复

- 上层依赖下层，下层不依赖上层

### 4.3 事件回放

成员当前状态通过事件回放构建：

```python
class MemberProjection:
    def __init__(self, member_id: str):
        self.member_id = member_id
        self.medications = {}
        self.allergies = []
        self.conditions = []
        self.latest_vitals = {}
        self.active_plans = []
        self.last_sequence_no = 0
        self.checksum = ""

    def apply(self, event: HealthEvent):
        handler = getattr(self, f"_on_{event.event_type}", None)
        if handler:
            handler(event)
        self.last_sequence_no = event.sequence_no
        self._update_checksum()

    def _on_medication_added(self, event):
        med = event.payload["medication"]
        self.medications[med["medicine_id"]] = med

    def _on_medication_removed(self, event):
        med_id = event.payload["medicine_id"]
        self.medications.pop(med_id, None)
```

### 4.4 快照机制

为避免每次都从头回放，定期保存投影快照：

```sql
CREATE TABLE member_projection_snapshots (

    last_event_id UUID NOT NULL,

    projection_version VARCHAR(20) NOT NULL,
    projection_checksum VARCHAR(100) NOT NULL,
    state JSONB NOT NULL,

```

回放时从最近快照开始，只回放快照之后的事件。

## 5. CQRS 读写分离

### 5.1 写模型

写模型负责业务规则校验和事件持久化：

```python
class AddMedicationCommand:
    member_id: str
    name: str
    dosage: str
    frequency: str
    idempotency_key: str

class AddMedicationHandler:
    def handle(self, cmd: AddMedicationCommand) -> HealthEvent:
        # 1. 幂等检查
        if exists_idempotency_key(cmd.idempotency_key):
            return get_event_by_idempotency_key(cmd.idempotency_key)

        # 2. 加载聚合根
        member = member_repository.get(cmd.member_id)

        # 3. 业务规则校验
        if not member:
            raise MemberNotFoundError(cmd.member_id)

        # 4. 创建事件
        event = HealthEvent(
            event_type="medication_added",
            member_id=cmd.member_id,
            payload={
                "medication": {
                    "medicine_id": generate_id(),
                    "name": cmd.name,
                    "dosage": cmd.dosage,
                    "frequency": cmd.frequency,
                }
            },
            idempotency_key=cmd.idempotency_key,
        )

        # 5. 持久化事件
        event_repository.save(event)

        # 6. 写入 Outbox
        outbox.save(event)

        return event
```

### 5.2 读模型

读模型负责查询优化，预计算常用查询：

```python
class TodayTasksQuery:

class TodayTasksHandler:

        return TodayTasksResponse(
            date=query.date,
            tasks=tasks,
            summary=calculate_summary(tasks),
        )
```

## 8. 认证与授权

### 8.1 JWT 认证

```python
class AuthMiddleware:
    async def __call__(self, request, call_next):
        token = request.headers.get("Authorization", "").replace("Bearer ", "")
        if token:
            try:
                payload = jwt.decode(token, SECRET_KEY, algorithms=["HS256"])
                request.state.user_id = payload["sub"]
                request.state.household_id = payload.get("household_id")
            except JWTError:
                pass  # 匿名访问
        return await call_next(request)
```

### 8.2 字段级授权

```python
def require_authorization(member_id: str, field: str):
    def decorator(func):
        @wraps(func)
        async def wrapper(request, *args, **kwargs):
            user_id = request.state.user_id
            if not has_authorization(user_id, member_id, field):
                raise HTTPException(status_code=403, detail="无权限访问该字段")
            return await func(request, *args, **kwargs)
        return wrapper
    return decorator
```

## 9. Outbox 模式

### 9.1 为什么需要 Outbox

事件持久化和事件分发需要事务一致性。Outbox 模式将事件写入同事务的 outbox 表，由后台 worker 异步分发，保证「事件已保存」和「事件已分发」最终一致。

### 9.2 实现

```sql
CREATE TABLE outbox_messages (
    outbox_id UUID PRIMARY KEY,
    household_id UUID NOT NULL,
    event_id UUID NOT NULL,
    payload JSONB NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'PENDING',
    attempts INTEGER NOT NULL DEFAULT 0,
    last_error TEXT,
    locked_by VARCHAR(100),
    locked_at TIMESTAMPTZ,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    dispatched_at TIMESTAMPTZ
);
```

```python
# 写事件和 outbox 在同一事务
async with db.begin():
    await db.execute(insert_event(event))
    await db.execute(insert_outbox(event))

# Worker 批量处理
class OutboxWorker:
    async def run(self):
        while True:
            messages = await self.lock_pending(limit=50)
            for msg in messages:
                try:
                    await self.dispatch(msg)
                    await self.mark_dispatched(msg.outbox_id)
                except Exception as e:
                    await self.mark_failed(msg.outbox_id, str(e))
            await asyncio.sleep(1)
```

## 12. 安全设计

### 12.1 传输安全

- 公网部署强制 HTTPS
- 家庭局域网可 HTTP（用户明确选择）
- HSTS 头（HTTPS 时）
- CORS 白名单

### 12.2 输入校验

- 所有请求体 Pydantic 校验
- SQL 参数化查询（SQLAlchemy 自动处理）
- 文件上传校验 MIME 类型和大小
- 输出转义（XSS 防护）

### 12.3 敏感数据

- 密码：bcrypt 哈希，不明文存储
- JWT：HS256 签名，短期有效（24h）
- 健康数据：不记录到日志，不输出到错误信息
- 配置：密钥从环境变量读取，不硬编码

---

*架构是系统的骨架。事件溯源 + CQRS + 隐私优先是家健镜的核心架构决策，支撑家庭健康数据的可信、可追溯、可审计。*
