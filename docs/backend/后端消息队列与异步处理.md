## 1. 概述

### 1.1 设计目标

1. 高吞吐量
2. 消息不丢失
3. 消费幂等
4. 顺序保证
5. 可观测性

### 1.2 使用场景

| 场景 | 说明 | 队列类型 |
| --- | --- | --- |
| 用药提醒推送 | 定时推送提醒通知 | 延迟队列 |
| 健康数据上报 | 设备数据异步处理 | 普通队列 |
| 订单支付回调 | 支付结果异步通知 | 普通队列 |
| 报告生成 | PDF 报告异步生成 | 普通队列 |
| 数据同步 | 多系统数据同步 | 普通队列 |
| 日志收集 | 系统日志异步处理 | 普通队列 |

## 2. 消息队列选型

### 2.1 技术选型

| 特性 | RabbitMQ | Kafka | RocketMQ |
| --- | --- | --- | --- |
| 吞吐量 | 万级 | 十万级 | 十万级 |
| 延迟 | 微秒级 | 毫秒级 | 毫秒级 |
| 可靠性 | 高 | 高 | 高 |
| 延迟消息 | 支持（插件） | 不支持 | 原生支持 |
| 事务消息 | 不支持 | 不支持 | 支持 |
| 运维复杂度 | 中 | 高 | 中 |
| 适用场景 | 业务消息 | 日志/大数据 | 金融/电商 |

### 2.2 选型结论

使用 RabbitMQ 作为主要消息队列，原因：
1. 业务消息场景为主
2. 延迟消息插件支持
3. 运维简单
4. Python 客户端成熟

## 3. RabbitMQ 集成

### 3.1 连接配置

```python
import pika
from pika.adapters.asyncio_connection import AsyncioConnection

class RabbitMQConnection:
    def __init__(self, host: str, port: int, username: str, password: str):
        self.credentials = pika.PlainCredentials(username, password)
        self.parameters = pika.ConnectionParameters(
            host=host,
            port=port,
            credentials=self.credentials,
            heartbeat=60,
            connection_attempts=3,
            retry_delay=5,
        )
        self._connection = None
        self._channel = None

    async def connect(self):
        self._connection = await AsyncioConnection.create(
            self.parameters
        )
        self._channel = await self._connection.channel()
        return self._channel

    async def close(self):
        if self._channel:
            await self._channel.close()
        if self._connection:
            await self._connection.close()
```

import json
from datetime import datetime

class MessageProducer:
    def __init__(self, channel, exchange: str):
        self.channel = channel
        self.exchange = exchange

    async def publish(
        self,
        routing_key: str,
        message: dict,
        persistent: bool = True,
    ):
        properties = pika.BasicProperties(
            delivery_mode=2 if persistent else 1,
            content_type='application/json',
            timestamp=int(datetime.now().timestamp()),
            message_id=str(uuid.uuid4()),
        )

        body = json.dumps(message, ensure_ascii=False).encode('utf-8')

        await self.channel.basic_publish(
            exchange=self.exchange,
            routing_key=routing_key,
            body=body,
            properties=properties,

## 5. 消费者

### 5.1 基础消费者

```python
import asyncio
from abc import ABC, abstractmethod

class BaseConsumer(ABC):
    def __init__(self, channel, queue_name: str):
        self.channel = channel
        self.queue_name = queue_name

    @abstractmethod
    async def handle_message(self, message: dict) -> bool:
        pass

    async def start(self):
        await self.channel.basic_qos(prefetch_count=10)
        await self.channel.basic_consume(
            queue=self.queue_name,
            on_message_callback=self._on_message,
        )

    async def _on_message(self, channel, method, properties, body):
        try:
            message = json.loads(body.decode('utf-8'))
            success = await self.handle_message(message)

            if success:
                await channel.basic_ack(delivery_tag=method.delivery_tag)
            else:
                await channel.basic_nack(
                    delivery_tag=method.delivery_tag,
                    requeue=False,
                )
        except Exception as e:
            logger.error(f"Message handling failed: {e}", exc_info=True)
            await channel.basic_nack(
                delivery_tag=method.delivery_tag,
                requeue=True,
            )
```

### 5.3 幂等消费

```python
class IdempotentConsumer(BaseConsumer):
    def __init__(self, channel, queue_name, redis_client):
        super().__init__(channel, queue_name)
        self.redis = redis_client

    async def handle_message(self, message: dict) -> bool:
        message_id = message.get('message_id')
        if not message_id:
            return await self._process(message)

        # 检查是否已处理
        key = f'processed:{self.queue_name}:{message_id}'
        if await self.redis.exists(key):
            logger.info(f"Message {message_id} already processed, skipping")
            return True

        # 处理消息
        result = await self._process(message)

        if result:
            # 标记已处理，保留 24 小时
            await self.redis.setex(key, 86400, '1')

        return result

    async def _process(self, message: dict) -> bool:
        pass
```

### 7.1 队列监控

```python
class QueueMonitor:
    def __init__(self, channel):
        self.channel = channel

    async def get_queue_status(self, queue_name: str) -> dict:
        result = await self.channel.queue_declare(
            queue=queue_name,
            passive=True,
        )
        return {
            'queue': queue_name,
            'message_count': result.method.message_count,
            'consumer_count': result.method.consumer_count,
        }

    async def monitor_queues(self, queues: list[str]) -> dict:
        statuses = {}
        for queue in queues:
            statuses[queue] = await self.get_queue_status(queue)
        return statuses
```
