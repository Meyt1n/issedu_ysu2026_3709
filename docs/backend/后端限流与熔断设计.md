# 后端限流与熔断设计

> 本文档是家健镜系统限流与熔断的完整设计说明，覆盖限流算法、熔断机制、降级策略、监控告警。

## 1. 概述

### 1.1 设计目标

1. 保护系统：防止流量突增导致系统崩溃
2. 公平使用：防止单个用户占用过多资源
3. 优雅降级：系统过载时提供降级服务
4. 快速恢复：故障后自动恢复
5. 可观测：限流熔断状态可监控

### 1.2 适用场景

| 场景 | 限流阈值 | 说明 |
| --- | --- | --- |
| API 调用 | 100 次/分钟/用户 | 防止恶意调用 |
| 视觉识别 | 10 次/分钟/用户 | GPU 资源有限 |
| 健康助手 | 30 次/分钟/用户 | LLM 资源有限 |
| 文件上传 | 5 次/分钟/用户 | 存储和带宽有限 |
| 短信发送 | 3 次/小时/用户 | 防止短信轰炸 |

## 2. 限流算法

### 2.1 计数器算法

```python
class CounterLimiter:
    def __init__(self, redis, limit=100, window=60):
        self.redis = redis
        self.limit = limit
        self.window = window

    async def allow(self, key):
        current = await self.redis.incr(key)
        if current == 1:
            await self.redis.expire(key, self.window)
        return current <= self.limit
```

### 2.2 滑动窗口算法

```python
class SlidingWindowLimiter:
    def __init__(self, redis, limit=100, window=60):
        self.redis = redis
        self.limit = limit
        self.window = window

    async def allow(self, key):
        now = time.time()
        pipe = self.redis.pipeline()

        # 移除窗口外的记录
        pipe.zremrangebyscore(key, 0, now - self.window)
        # 统计窗口内的请求数
        pipe.zcard(key)
        # 添加当前请求
        pipe.zadd(key, {f"{now}:{uuid.uuid4()}": now})
        # 设置过期时间
        pipe.expire(key, self.window)

        results = await pipe.execute()
        count = results[1]

        return count < self.limit
```

### 2.3 令牌桶算法

```python
class TokenBucketLimiter:
    def __init__(self, redis, rate=10, capacity=100):
        self.redis = redis
        self.rate = rate  # 每秒生成令牌数
        self.capacity = capacity  # 桶容量

    async def allow(self, key):
        # Lua 脚本保证原子性
        lua_script = '''
        local key = KEYS[1]
        local rate = tonumber(ARGV[1])
        local capacity = tonumber(ARGV[2])
        local now = tonumber(ARGV[3])

        local bucket = redis.call('hgetall', key)
        local tokens = capacity
        local last_time = now

        if #bucket > 0 then
            tokens = tonumber(bucket[2])
            last_time = tonumber(bucket[4])
        end

        -- 补充令牌
        local delta = (now - last_time) * rate
        tokens = math.min(capacity, tokens + delta)

        if tokens >= 1 then
            tokens = tokens - 1
            redis.call('hmset', key, 'tokens', tokens, 'last_time', now)
            return 1
        else
            redis.call('hmset', key, 'tokens', tokens, 'last_time', now)
            return 0
        end
        '''

        result = await self.redis.eval(
            lua_script,
            keys=[key],
            args=[self.rate, self.capacity, time.time()],
        )
        return result == 1
```

## 3. 限流中间件

### 3.1 FastAPI 中间件

```python
class RateLimitMiddleware:
    def __init__(self, limiter):
        self.limiter = limiter

    async def __call__(self, request, call_next):
        user_id = request.state.user_id or "anonymous"
        path = request.url.path
        key = f"rate_limit:{user_id}:{path}"

        if not await self.limiter.allow(key):
            return JSONResponse(
                status_code=429,
                content={
                    "error": "RATE_LIMIT_EXCEEDED",
                    "message": "请求过于频繁，请稍后再试",
                },
                headers={"Retry-After": "60"},
            )

        response = await call_next(request)
        return response
```

### 3.2 装饰器

```python
def rate_limit(limit=100, window=60, key_func=None):
    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            request = kwargs.get("request") or args[0]
            key = key_func(request) if key_func else f"default:{request.client.host}"

            limiter = SlidingWindowLimiter(redis, limit, window)
            if not await limiter.allow(key):
                raise HTTPException(status_code=429, detail="请求过于频繁")

            return await func(*args, **kwargs)
        return wrapper
    return decorator
```

## 4. 熔断机制

### 4.1 熔断器状态

```
┌─────────┐  失败率>阈值  ┌─────────┐
│ Closed  │ ───────────→ │  Open   │
│ (正常)  │               │ (熔断)  │
└─────────┘               └────┬────┘
     ↑                         │
     │  半开探测成功             │  超时
     │                         ↓
┌─────────┐  半开探测失败  ┌─────────┐
│ HalfOpen│ ←───────────  │ (等待)  │
└─────────┘               └─────────┘
```

### 4.2 熔断器实现

```python
class CircuitBreaker:
    def __init__(self, name, failure_threshold=5, recovery_timeout=30):
        self.name = name
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.state = "closed"  # closed, open, half_open
        self.failure_count = 0
        self.last_failure_time = None

    async def call(self, func, *args, **kwargs):
        if self.state == "open":
            # 检查是否超时，可以进入半开状态
            if time.time() - self.last_failure_time > self.recovery_timeout:
                self.state = "half_open"
            else:
                raise CircuitBreakerOpen("服务暂不可用")

        try:
            result = await func(*args, **kwargs)
            self._on_success()
            return result
        except Exception as e:
            self._on_failure()
            raise

    def _on_success(self):
        self.failure_count = 0
        if self.state == "half_open":
            self.state = "closed"

    def _on_failure(self):
        self.failure_count += 1
        self.last_failure_time = time.time()

        if self.state == "half_open":
            self.state = "open"
        elif self.failure_count >= self.failure_threshold:
            self.state = "open"
```

### 4.3 熔断装饰器

```python
def circuit_break(name, failure_threshold=5, recovery_timeout=30):
    breaker = CircuitBreaker(name, failure_threshold, recovery_timeout)

    def decorator(func):
        @wraps(func)
        async def wrapper(*args, **kwargs):
            return await breaker.call(func, *args, **kwargs)
        return wrapper
    return decorator
```

## 5. 降级策略

### 5.1 降级方案

| 服务 | 降级方案 |
| --- | --- |
| 健康助手 | 返回预设回答，提示稍后重试 |
| 视觉识别 | 返回手动录入入口 |
| 推送通知 | 记录到队列，稍后发送 |
| 数据同步 | 本地缓存，联网后同步 |
| 统计报表 | 返回缓存数据，标注时间 |

### 5.2 降级实现

```python
class DegradationService:
    def __init__(self, cache):
        self.cache = cache

    async def get_health_advice(self, question):
        try:
            return await llm_service.ask(question)
        except Exception:
            # 降级：返回缓存或预设回答
            cached = await self.cache.get(f"advice:{question}")
            if cached:
                return cached + "

（注：当前为缓存回答，实时服务暂不可用）"
            return "抱歉，健康助手服务暂不可用，请稍后再试。"
```

## 6. 监控告警

### 6.1 监控指标

- 限流触发次数
- 熔断状态变化
- 降级触发次数
- 请求成功率
- 响应时间

### 6.2 告警规则

| 指标 | 阈值 | 级别 |
| --- | --- | --- |
| 限流触发率 > 10% | 持续 5 分钟 | warning |
| 熔断器打开 | 立即 | critical |
| 降级触发率 > 5% | 持续 5 分钟 | warning |
| 请求成功率 < 95% | 持续 5 分钟 | critical |
