# 后端微服务架构与服务治理

> 本文档是家健镜系统后端微服务架构与服务治理的完整设计说明，覆盖服务拆分、服务注册、配置中心、网关路由、熔断限流。

## 1. 概述

### 1.1 设计目标

1. 服务独立部署
2. 故障隔离
3. 弹性伸缩
4. 技术异构
5. 团队自治

### 1.2 服务拆分

| 服务 | 职责 | 数据库 |
| --- | --- | --- |
| 用户服务 | 用户注册、登录、权限 | user_db |
| 用药服务 | 药品管理、用药提醒 | medicine_db |
| 健康服务 | 体征数据、健康评估 | health_db |
| 家庭服务 | 家庭成员、数据共享 | family_db |
| 消息服务 | 推送、短信、邮件 | message_db |
| 报告服务 | 报告生成、导出 | report_db |
| 搜索服务 | 全文检索 | ES |

### 4.2 网关过滤器

```java
@Component
public class AuthFilter implements GlobalFilter, Ordered {
    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        String token = exchange.getRequest().getHeaders().getFirst("Authorization");

        if (token == null || !token.startsWith("Bearer ")) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }

        // 验证 token
        try {
            JwtUtil.validateToken(token.substring(7));
        } catch (Exception e) {
            exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
            return exchange.getResponse().setComplete();
        }

        return chain.filter(exchange);
    }

    @Override
    public int getOrder() {
        return -100;
    }
}
```

## 5. 熔断与限流

### 5.1 Sentinel 熔断

```java
@Service
public class MedicineService {
    @SentinelResource(
        value = "getMedicine",
        blockHandler = "getMedicineBlockHandler",
        fallback = "getMedicineFallback"
    )
    public Medicine getMedicine(String id) {
        return medicineRepository.findById(id);
    }

    public Medicine getMedicineBlockHandler(String id, BlockException ex) {
        return Medicine.createDummy("系统繁忙，请稍后再试");
    }

    public Medicine getMedicineFallback(String id) {
        return Medicine.createDummy("服务暂时不可用");
    }
}
```

### 5.2 限流规则

```java
@Configuration
public class SentinelConfig {
    @PostConstruct
    public void initRules() {
        // 流控规则
        List<FlowRule> flowRules = new ArrayList<>();
        FlowRule rule = new FlowRule();
        rule.setResource("getMedicine");
        rule.setGrade(RuleConstant.FLOW_GRADE_QPS);
        rule.setCount(100);
        flowRules.add(rule);
        FlowRuleManager.loadRules(flowRules);

        // 熔断规则
        List<DegradeRule> degradeRules = new ArrayList<>();
        DegradeRule degradeRule = new DegradeRule();
        degradeRule.setResource("getMedicine");
        degradeRule.setGrade(RuleConstant.DEGRADE_GRADE_EXCEPTION_RATIO);
        degradeRule.setCount(0.5);
        degradeRule.setTimeWindow(60);
        degradeRules.add(degradeRule);
        DegradeRuleManager.loadRules(degradeRules);
    }
}
```

## 6. 服务间通信

### 6.1 Feign 客户端

@FeignClient(name = "user-service", fallback = UserClientFallback.class)
public interface UserClient {
    @GetMapping("/api/users/{id}")

    @PostMapping("/api/users/batch")
    List<User> getUsersBatch(@RequestBody List<String> ids);

public class UserClientFallback implements UserClient {
    @Override
    public User getUser(String id) {
        return new User();
    }

    @Override
    public List<User> getUsersBatch(List<String> ids) {
        return Collections.emptyList();
    }
}

@Service
public class MedicineEventPublisher {
    @Autowired
    private RabbitTemplate rabbitTemplate;

        Map<String, Object> event = new HashMap<>();
        event.put("type", "MEDICINE_TAKEN");
        event.put("userId", userId);
        event.put("medicineId", medicineId);

## 7. 分布式事务

### 7.1 Seata AT 模式

```java
@Service
public class OrderService {
    @GlobalTransactional(name = "create-order", rollbackFor = Exception.class)
    public void createOrder(Order order) {
        // 1. 创建订单
        orderRepository.save(order);

        // 2. 扣减库存
        inventoryClient.deduct(order.getMedicineId(), order.getQuantity());

        // 3. 扣减余额
        accountClient.deduct(order.getUserId(), order.getAmount());
    }
}
```

### 7.2 Saga 模式

```java
@Service
public class MedicineReminderSaga {
    @Autowired
    private SagaManager sagaManager;

    public void createReminder(Reminder reminder) {
        SagaDefinition definition = SagaDefinitionBuilder
            .start()
                .step("createReminder")
                    .compensation("cancelReminder")
                .step("notifyUser")
                    .compensation("cancelNotification")
                .step("updateSchedule")
                    .compensation("revertSchedule")
            .end();

        sagaManager.start(definition, reminder);
    }
}
```
