# 后端部署与运维手册

> 本文档是家健镜后端的部署与运维完整指南，覆盖环境准备、安装部署、配置管理、日常运维、监控告警、备份恢复、故障排查。面向运维人员和家庭管理员，作为部署和运维的权威依据。

## 1. 部署概述

### 1.1 部署方式

| 部署方式 | 适用场景 | 复杂度 | 推荐度 |
| --- | --- | --- | --- |
| Docker Compose | 家庭/小型部署 | 低 | ⭐⭐⭐⭐⭐ |
| 裸机部署 | 开发/测试 | 中 | ⭐⭐⭐ |
| Kubernetes | 生产/多租户 | 高 | ⭐⭐⭐ |

### 1.2 系统要求

| 资源 | 最低配置 | 推荐配置 |
| --- | --- | --- |
| CPU | 2 核 | 4 核 |
| 内存 | 2GB | 4GB |
| 存储 | 10GB | 50GB SSD |
| 网络 | 局域网 | 局域网 + 可选公网 |
| 系统 | Ubuntu 22.04 / Debian 12 / Windows 10 | Ubuntu 22.04 LTS |

### 1.3 端口规划

| 端口 | 服务 | 说明 |
| --- | --- | --- |
| 18800 | FastAPI | 后端 API |
| 80 / 443 | Nginx | 反向代理 / 静态文件 |
| 5432 | PostgreSQL | 数据库（可选） |
| 6379 | Redis | 缓存（可选） |

## 2. Docker Compose 部署

### 2.1 docker-compose.yml

```yaml
version: '3.8'

services:
  backend:
    build: .
    container_name: homecare-backend
    restart: unless-stopped
    ports:
      - "18800:18800"
    environment:
      - DATABASE_URL=sqlite+aiosqlite:///./data/homecare.db
      - JWT_SECRET=${JWT_SECRET:-change-me-in-production}
      - DEBUG=false
    volumes:
      - ./data:/app/data
      - ./uploads:/app/uploads
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:18800/health"]
      interval: 30s
      timeout: 10s
      retries: 3

  nginx:
    image: nginx:alpine
    container_name: homecare-nginx
    restart: unless-stopped
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./web-dist:/usr/share/nginx/html
      - ./ssl:/etc/nginx/ssl
    depends_on:
      - backend
```

### 2.2 Dockerfile

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y --no-install-recommends \
    curl \
    && rm -rf /var/lib/apt/lists/*

# 安装 Python 依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 复制代码
COPY src/ ./src/
COPY alembic.ini .
COPY migrations/ ./migrations/

# 创建数据目录
RUN mkdir -p /app/data /app/uploads

# 健康检查
HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
    CMD curl -f http://localhost:18800/health || exit 1

# 启动
EXPOSE 18800
CMD ["uvicorn", "src.api.app.main:app", "--host", "0.0.0.0", "--port", "18800"]
```

### 2.3 部署步骤

```bash
# 1. 克隆代码
git clone https://github.com/Meyt1n/issedu_ysu2026_3709.git
cd issedu_ysu2026_3709

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env，设置 JWT_SECRET 等

# 3. 构建并启动
docker-compose up -d --build

# 4. 执行数据库迁移
docker-compose exec backend alembic upgrade head

# 5. 验证
curl http://localhost:18800/health
```

### 2.4 Nginx 配置

```nginx
server {
    listen 80;
    server_name homecare.local;

    # 静态文件
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://backend:18800;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 60s;
    }

    # WebSocket
    location /ws/ {
        proxy_pass http://backend:18800;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 3. 裸机部署

### 3.1 环境准备

```bash
# Ubuntu/Debian
sudo apt update
sudo apt install -y python3.11 python3.11-venv python3-pip nginx curl

# 创建用户
sudo useradd -r -s /bin/false homecare
sudo mkdir -p /opt/homecare
sudo chown homecare:homecare /opt/homecare
```

### 3.2 安装应用

```bash
# 切换到应用目录
cd /opt/homecare

# 克隆代码
sudo -u homecare git clone https://github.com/... .

# 创建虚拟环境
sudo -u homecare python3.11 -m venv venv
sudo -u homecare venv/bin/pip install -r requirements.txt

# 配置环境
sudo -u homecare cp .env.example .env
sudo -u homecare nano .env  # 编辑配置

# 数据库迁移
sudo -u homecare venv/bin/alembic upgrade head
```

### 3.3 Systemd 服务

```ini
# /etc/systemd/system/homecare.service
[Unit]
Description=HomeCare Twin Backend
After=network.target

[Service]
Type=simple
User=homecare
Group=homecare
WorkingDirectory=/opt/homecare
EnvironmentFile=/opt/homecare/.env
ExecStart=/opt/homecare/venv/bin/uvicorn \
    src.api.app.main:app \
    --host 0.0.0.0 \
    --port 18800 \
    --workers 2
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
# 启用并启动
sudo systemctl daemon-reload
sudo systemctl enable homecare
sudo systemctl start homecare

# 查看状态
sudo systemctl status homecare
sudo journalctl -u homecare -f
```

## 4. 配置管理

### 4.1 环境变量清单

| 变量 | 说明 | 默认值 | 必需 |
| --- | --- | --- | --- |
| DATABASE_URL | 数据库连接 | sqlite+aiosqlite:///./data/homecare.db | 是 |
| JWT_SECRET | JWT 签名密钥 | - | 是 |
| JWT_EXPIRE_HOURS | Token 有效期 | 24 | 否 |
| DEBUG | 调试模式 | false | 否 |
| LLM_BASE_URL | LLM 服务地址 | - | 否 |
| LLM_API_KEY | LLM API Key | - | 否 |
| LLM_MODEL | LLM 模型名 | gpt-4o-mini | 否 |
| VISION_MODEL_PATH | 视觉模型路径 | - | 否 |
| UPLOAD_DIR | 上传目录 | ./uploads | 否 |
| MAX_UPLOAD_SIZE | 最大上传 | 52428800 | 否 |
| CORS_ORIGINS | CORS 白名单 | * | 否 |

### 4.2 配置最佳实践

- 生产环境必须修改 JWT_SECRET
- 使用强密码生成密钥：`openssl rand -hex 32`
- .env 文件权限 600，仅应用用户可读
- 配置变更后重启服务
- 不同环境使用不同配置文件

## 5. 日常运维

### 5.1 服务管理

```bash
# Docker Compose
docker-compose start backend    # 启动
docker-compose stop backend     # 停止
docker-compose restart backend  # 重启
docker-compose logs -f backend  # 查看日志
docker-compose ps               # 查看状态

# Systemd
sudo systemctl start homecare
sudo systemctl stop homecare
sudo systemctl restart homecare
sudo journalctl -u homecare -f
```

### 5.2 数据库管理

```bash
# 备份（SQLite）
docker-compose exec backend sqlite3 /app/data/homecare.db ".backup /app/data/backup.db"

# 备份（PostgreSQL）
docker-compose exec db pg_dump -U user homecare > backup.sql

# 迁移
docker-compose exec backend alembic upgrade head
docker-compose exec backend alembic downgrade -1
docker-compose exec backend alembic current
docker-compose exec backend alembic history
```

### 5.3 日志管理

```bash
# 查看实时日志
docker-compose logs -f backend

# 查看最近 100 行
docker-compose logs --tail 100 backend

# 日志轮转（logrotate）
# /etc/logrotate.d/homecare
/opt/homecare/logs/*.log {
    daily
    rotate 30
    compress
    delaycompress
    missingok
    notifempty
}
```

### 5.4 更新升级

```bash
# 1. 备份数据
cp data/homecare.db data/homecare.db.bak.$(date +%Y%m%d)

# 2. 拉取最新代码
git pull origin master

# 3. 更新依赖
pip install -r requirements.txt

# 4. 执行迁移
alembic upgrade head

# 5. 重启服务
docker-compose up -d --build
# 或
sudo systemctl restart homecare

# 6. 验证
curl http://localhost:18800/health
```

### 5.5 回滚

```bash
# 代码回滚
git checkout <previous-commit>

# 数据库回滚
alembic downgrade -1

# 数据回滚
cp data/homecare.db.bak data/homecare.db

# 重启服务
docker-compose restart backend
```

## 6. 监控告警

### 6.1 健康检查

```bash
# 应用健康
curl http://localhost:18800/health
# 响应：{"status": "healthy", "database": "ok"}

# 系统资源
docker stats
free -h
df -h
```

### 6.2 关键指标

| 指标 | 告警阈值 | 说明 |
| --- | --- | --- |
| CPU 使用率 | >80% 持续 5 分钟 | 性能瓶颈 |
| 内存使用率 | >85% | 内存泄漏 |
| 磁盘使用率 | >90% | 存储空间不足 |
| API P95 延迟 | >500ms | 性能下降 |
| 错误率 | >5% | 服务异常 |
| 数据库连接数 | >80% 池大小 | 连接泄漏 |
| Outbox 积压 | >100 条 | 分发异常 |

### 6.3 告警方式

- 家庭部署：日志 + 健康检查脚本
- 生产部署：Prometheus + Grafana + Alertmanager
- 告警通道：邮件、企业微信、钉钉

## 7. 备份恢复

### 7.1 备份策略

| 数据 | 备份方式 | 频率 | 保留 |
| --- | --- | --- | --- |
| 数据库 | SQLite .backup / pg_dump | 每日 | 30 天 |
| 上传文件 | rsync / tar | 每日 | 30 天 |
| 配置文件 | git / 手动 | 变更时 | 永久 |
| 日志 | logrotate | 自动 | 30 天 |

### 7.2 自动备份脚本

```bash
#!/bin/bash
# scripts/backup.sh

BACKUP_DIR="/opt/homecare/backups"
DATE=$(date +%Y%m%d_%H%M%S)

# 创建备份目录
mkdir -p $BACKUP_DIR

# 备份数据库
sqlite3 /opt/homecare/data/homecare.db ".backup $BACKUP_DIR/homecare_$DATE.db"

# 备份上传文件
tar -czf $BACKUP_DIR/uploads_$DATE.tar.gz /opt/homecare/uploads

# 备份配置
cp /opt/homecare/.env $BACKUP_DIR/env_$DATE

# 清理 30 天前的备份
find $BACKUP_DIR -name "*.db" -mtime +30 -delete
find $BACKUP_DIR -name "*.tar.gz" -mtime +30 -delete
find $BACKUP_DIR -name "env_*" -mtime +30 -delete

echo "备份完成: $DATE"
```

```bash
# 添加到 crontab
crontab -e
# 每天凌晨 2 点备份
0 2 * * * /opt/homecare/scripts/backup.sh >> /var/log/homecare-backup.log 2>&1
```

### 7.3 恢复流程

```bash
# 1. 停止服务
docker-compose stop backend

# 2. 恢复数据库
cp backups/homecare_20260901.db data/homecare.db

# 3. 恢复上传文件
tar -xzf backups/uploads_20260901.tar.gz -C /

# 4. 恢复配置
cp backups/env_20260901 .env

# 5. 启动服务
docker-compose start backend

# 6. 验证
curl http://localhost:18800/health
```

## 8. 安全加固

### 8.1 系统安全

- 禁用 root 远程登录
- 使用 SSH 密钥认证
- 配置防火墙（ufw/iptables）
- 定期更新系统补丁
- 安装 fail2ban 防暴力破解

```bash
# 防火墙配置
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw enable
```

### 8.2 应用安全

- 生产环境关闭 DEBUG
- 修改默认 JWT_SECRET
- 配置 HTTPS（Let's Encrypt）
- 设置 CORS 白名单
- 限制上传文件大小和类型
- 定期轮换密钥

### 8.3 HTTPS 配置

```bash
# 安装 certbot
sudo apt install certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d homecare.example.com

# 自动续期（certbot 自动配置）
sudo certbot renew --dry-run
```

## 9. 故障排查

### 9.1 服务无法启动

```bash
# 查看错误日志
docker-compose logs backend
sudo journalctl -u homecare -n 100

# 常见原因
# 1. 端口被占用
sudo lsof -i :18800

# 2. 数据库文件权限
ls -la data/homecare.db
chown homecare:homecare data/homecare.db

# 3. 配置错误
cat .env | grep -E "DATABASE_URL|JWT_SECRET"

# 4. 依赖缺失
pip check
```

### 9.2 数据库连接失败

```bash
# SQLite
# 检查文件存在和权限
ls -la data/homecare.db
sqlite3 data/homecare.db "SELECT 1"

# PostgreSQL
# 检查服务状态
docker-compose ps db
docker-compose logs db

# 测试连接
docker-compose exec db psql -U user -d homecare -c "SELECT 1"
```

### 9.3 API 响应慢

```bash
# 查看慢查询
# SQLite
sqlite3 data/homecare.db ".expert"

# 检查索引
sqlite3 data/homecare.db ".indices health_events"

# 查看资源使用
docker stats
top
```

### 9.4 磁盘空间不足

```bash
# 查看空间
df -h
du -sh /opt/homecare/*

# 清理
# 1. 清理旧备份
find /opt/homecare/backups -mtime +30 -delete

# 2. 清理日志
docker-compose logs --rotate
truncate -s 0 /var/log/homecare/*.log

# 3. 清理 Docker
docker system prune -a
```
