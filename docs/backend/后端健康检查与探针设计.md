# 后端健康检查与探针设计

> 本文档是家健镜系统健康检查与探针的完整设计说明，覆盖存活探针、就绪探针、启动探针、深度健康检查。

## 1. 概述

### 1.1 设计目标

1. 及时发现故障：快速检测服务异常
2. 自动恢复：配合编排系统自动重启
3. 流量保护：不健康实例不接收流量
4. 启动保护：启动慢的应用不被误杀
5. 可观测：健康状态可监控

### 1.2 探针类型

| 探针 | 说明 | 失败后果 |
| --- | --- | --- |
| 存活探针（Liveness） | 检测进程是否存活 | 重启容器 |
| 就绪探针（Readiness） | 检测是否可接收流量 | 从负载均衡移除 |
| 启动探针（Startup） | 检测应用是否启动完成 | 重启容器（启动期间） |

## 2. 健康检查端点

### 2.1 基础健康检查

```python
from fastapi import FastAPI
from fastapi.responses import JSONResponse

app = FastAPI()

@app.get("/health")
async def health_check():
    return {"status": "healthy"}

@app.get("/health/live")
async def liveness_probe():
    return {"status": "alive"}

@app.get("/health/ready")
async def readiness_probe():
    # 检查依赖
    checks = await run_dependency_checks()
    all_healthy = all(check["healthy"] for check in checks)

    if all_healthy:
        return JSONResponse(
            status_code=200,
            content={"status": "ready", "checks": checks},
        )
    else:
        return JSONResponse(
            status_code=503,
            content={"status": "not_ready", "checks": checks},
        )
```

### 2.2 深度健康检查

```python
class HealthChecker:
    def __init__(self, db, redis, cache):
        self.db = db
        self.redis = redis
        self.cache = cache

    async def check_all(self):
        checks = []

        # 数据库检查
        checks.append(await self._check_database())

        # Redis 检查
        checks.append(await self._check_redis())

        # 磁盘空间检查
        checks.append(self._check_disk())

        # 内存使用检查
        checks.append(self._check_memory())

        return checks

    async def _check_database(self):
        try:
            await self.db.execute("SELECT 1")
            return {"name": "database", "healthy": True}
        except Exception as e:
            return {"name": "database", "healthy": False, "error": str(e)}

    async def _check_redis(self):
        try:
            await self.redis.ping()
            return {"name": "redis", "healthy": True}
        except Exception as e:
            return {"name": "redis", "healthy": False, "error": str(e)}

    def _check_disk(self):
        import shutil
        total, used, free = shutil.disk_usage("/")
        free_percent = free / total * 100
        return {
            "name": "disk",
            "healthy": free_percent > 10,
            "free_percent": round(free_percent, 2),
        }

    def _check_memory(self):
        import psutil
        memory = psutil.virtual_memory()
        return {
            "name": "memory",
            "healthy": memory.percent < 90,
            "usage_percent": memory.percent,
        }
```

## 3. Kubernetes 探针配置

### 3.1 Deployment 配置

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: homecare-backend
spec:
  replicas: 3
  template:
    spec:
      containers:
        - name: backend
          image: homecare/backend:latest
          ports:
            - containerPort: 8000
          livenessProbe:
            httpGet:
              path: /health/live
              port: 8000
            initialDelaySeconds: 30
            periodSeconds: 10
            timeoutSeconds: 5
            failureThreshold: 3
          readinessProbe:
            httpGet:
              path: /health/ready
              port: 8000
            initialDelaySeconds: 10
            periodSeconds: 5
            timeoutSeconds: 3
            failureThreshold: 3
          startupProbe:
            httpGet:
              path: /health/live
              port: 8000
            initialDelaySeconds: 5
            periodSeconds: 5
            timeoutSeconds: 3
            failureThreshold: 30
          resources:
            requests:
              cpu: "500m"
              memory: "512Mi"
            limits:
              cpu: "2"
              memory: "2Gi"
```

### 3.2 探针参数说明

| 参数 | 说明 | 建议值 |
| --- | --- | --- |
| initialDelaySeconds | 启动后延迟检查 | 存活 30s，就绪 10s |
| periodSeconds | 检查间隔 | 存活 10s，就绪 5s |
| timeoutSeconds | 超时时间 | 3-5s |
| failureThreshold | 失败阈值 | 3 次 |
| successThreshold | 成功阈值 | 1 次 |

## 4. 健康检查最佳实践

### 4.1 存活探针 vs 就绪探针

- 存活探针：只检查进程是否存活，不检查依赖
- 就绪探针：检查所有依赖是否正常
- 启动探针：给慢启动应用足够时间

### 4.2 避免常见错误

```python
# 错误：存活探针检查数据库
@app.get("/health/live")
async def bad_liveness():
    await db.execute("SELECT 1")  # 数据库挂了会导致重启
    return {"status": "alive"}

# 正确：存活探针只检查进程
@app.get("/health/live")
async def good_liveness():
    return {"status": "alive"}

# 正确：就绪探针检查依赖
@app.get("/health/ready")
async def good_readiness():
    checks = await run_dependency_checks()
    # ...
```

### 4.3 优雅关闭

```python
import signal
import asyncio

class GracefulShutdown:
    def __init__(self, app):
        self.app = app
        self.shutting_down = False

    def setup(self):
        signal.signal(signal.SIGTERM, self._handle_sigterm)
        signal.signal(signal.SIGINT, self._handle_sigterm)

    def _handle_sigterm(self, signum, frame):
        self.shutting_down = True
        # 等待正在处理的请求完成
        asyncio.create_task(self._shutdown())

    async def _shutdown(self):
        # 1. 从负载均衡移除（就绪探针失败）
        # 2. 等待正在处理的请求完成
        await asyncio.sleep(5)
        # 3. 关闭数据库连接
        await self.app.state.db.close()
        # 4. 退出
        import os
        os._exit(0)
```

## 5. 健康监控

### 5.1 健康指标

```python
class HealthMetrics:
    def __init__(self):
        self.health_check_count = 0
        self.health_check_failures = 0

    def record_check(self, healthy):
        self.health_check_count += 1
        if not healthy:
            self.health_check_failures += 1

    @property
    def failure_rate(self):
        if self.health_check_count == 0:
            return 0
        return self.health_check_failures / self.health_check_count
```

### 5.2 告警规则

| 指标 | 阈值 | 级别 |
| --- | --- | --- |
| 就绪探针失败率 > 10% | 持续 5 分钟 | warning |
| 存活探针失败导致重启 | 立即 | critical |
| 启动探针失败 | 立即 | critical |
| 数据库健康检查失败 | 立即 | critical |
