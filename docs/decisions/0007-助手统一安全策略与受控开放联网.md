# ADR-0007：助手统一安全策略与受控开放联网（1A/2B/3B/4B/8C）

- 状态：已接受（用户书面确认产品决策；实现与回归见关联 PR）
- 日期：2026-08-27
- 决策人/复核人：项目负责人（书面确认 1A/2B/3B/4B/5B/8C）；实现与自动回归由智能体 4 执行，维护者合并即完成人工复核
- 关联需求、Issue、PR：FR-08、NFR-01、NFR-02、NFR-04；HCT-403 / HCT-430 / HCT-448 / HCT-450 / HCT-451 / HCT-406；Issue #310；本 ADR 随 `cursor/assistant-smart-search-24ff` 分支 PR 提交
- 替代/被替代：局部替代 HCT-448/HCT-450 Story 中「`MEDICATION_SAFETY` 无证据仍 `EVIDENCE_REQUIRED` 硬降级」与 HCT-451 Story 中「open_chat 跳过安全墙、生产强制关闭」条款；替代 FR-08 旧「证据不足时澄清或拒答」条款

## 背景与当前事实

智能体 1/2/3/5 的审计与测试发现四类问题：

1. **误降级过多**：`_medication_safety_short_circuit` 在无本地证据时把同服/停换/漏服等教学向问题整段降级为 `EVIDENCE_REQUIRED` 墙；输出黑名单把模型自带的免责声明当违规整段否决。
2. **剂量拒答漏路由**：「一天吃几粒／吃几片」等明确个体剂量问题被并入普通用药安全流程，可能得到模型生成的剂量文本。
3. **联网名存实亡**：DuckDuckGo HTML 解析器把 `result__snippet` 锚点（`uddg=` 跳转链接）误判为新结果，摘要 100% 丢失；3xx 响应被当成「成功但无结果」并长期缓存。
4. **上下文串台**：同一助手会话切换成员后沿用旧成员历史；短指代追问（「那她还能吃吗」）丢失 `query_type`；空库降级模板按日历季节硬套（腹泻问出「空调鼻塞」文案）。

旧事实源（FR-08、05-隐私规范、HCT-448/450/451 Story）与用户新确认的产品方向冲突，必须同步修订。

## 决策驱动因素

- 家庭照护助手的实际可用性：教学向问题不应被证据墙全部挡死；
- 医疗安全底线：个体剂量数字是不可妥协项，必须比「模型自觉」更强的确定性拦截；
- 用户书面确认接受受控出网的隐私风险，换取真实联网参考能力；
- 全环境策略一致（8C）：避免「演示模式宽、生产模式窄」造成验收与真实行为脱节。

## 候选方案

### 方案 A（旧行为）：证据墙 + 全豁免演示模式

无本地证据即 `EVIDENCE_REQUIRED` 整段墙；`open_chat` 全豁免安全检查且生产强制关闭。优点是边界简单；缺点是误伤大量教学向问题、演示与生产行为割裂、剂量问题反而缺少确定性拦截。

### 方案 B（本决策）：仅硬拒剂量 + 句级黑名单 + 风险说明 + 受控开放联网

见「决策」一节。缺点是隐私暴露面扩大（受控出网）、句级处理引入更细的正则维护成本；通过三档 opt-in、SSRF 公网校验、发送前可见与回归测试缓解。

## 决策

1. **1A 仅硬拒剂量**：新增 `DOSE_DECISION` 问题类型（`src/ai/safety/lexicon.py::is_dose_decision_query`、`classifier.py`），命中「一次吃几粒／剂量是多少／吃多少+药物语境」等明确个体剂量数字问法时，在模型调用前确定性拒答（`tool_call.py::dose_decision_result`、`local_agents.py` 快路径），文案引导咨询医生/药师；库存类问法（「还剩几粒」）与生活问法（「吃多少盐」）不误拒。
2. **2B 无证据可答 + 风险说明**：删除 `_medication_safety_short_circuit` 无证据整段墙与非 GENERAL 引用硬墙；保留伪造引用 `CITATION_NOT_FOUND`。服务端统一 `append_risk_statement`：用药安全/症状/剂量类回答一律追加教学提醒，无本地引用时追加「本回答未绑定本地审核证据」提示。
3. **句级黑名单**：`sanitize_answer_sentences` 只移除含医疗边界词、外链或剂量数字的句子并追加尾注 `（已按安全规范省略部分内容，具体用药请咨询医生或药师。）`；全部句子被移除时才降级。
4. **3B 受控开放联网**：修复 DuckDuckGo 摘要解析 P0；3xx 视为失败（`SearchRedirected`）；空结果短缓存（`AGENT_WEB_SEARCH_EMPTY_CACHE_TTL_SECONDS`，默认 30s）。新增 `AGENT_WEB_SEARCH_EGRESS_MODE=allowlist|open`：open 模式允许跟进公开 HTTPS 结果页，须通过 `is_public_https_url` SSRF 公网校验（回环/私网/内网阻断）、限页（默认 2 页）/限字节（默认 200KB）/限时抓取，并过滤购药/问诊/广告导流结果与话术。默认仍 `allowlist` + `AGENT_WEB_SEARCH_ENABLED=false`。
5. **4B 三档出网上下文**：请求级 `network_context_level=query_only|symptom|member`（默认 `query_only`）；`member` 档只携带过敏/疾病/在用药品三类白名单字段并匿名化；最终出网查询经 `redact_web_query` 脱敏并通过 `network_query` SSE 事件在发送前对用户可见。
6. **8C 全环境统一**：`open_chat` 收敛为体验项（注入本机时间、放宽 token 下限），不再豁免任何安全检查；生产不再禁止 `AGENT_OPEN_CHAT=true`（config 生产门禁相应修订）；`OPEN_CHAT_SYSTEM_PROMPT` 废弃，统一使用 `ASSISTANT_SYSTEM_PROMPT`。
7. **上下文防串台**：`bind_session_member_context` 在同会话切换成员时丢弃跨成员历史；短指代追问经 `inherit_query_type_from_history` 继承上一实质问题的 `query_type`；空库/季节模板改按症状词（`is_seasonal_symptom_query`）而非日历触发。

禁止用途不变：不提供诊断、处方、停药换药结论与个体剂量数字；不提供购药/问诊/广告导流；外部搜索结果仍不算本地审核证据。

## 后果

- 正向影响：教学向问题可用性大幅提升；剂量拦截从「模型自觉」变为确定性路由；联网参考真实可用；多轮对话不串成员。
- 代价/新约束：隐私暴露面受控扩大（用户已书面接受）；句级正则与出网过滤规则需随 badcase 维护；`member` 档出网内容须在隐私审计中重点复核。
- API、数据、授权影响：`AssistantRequest/Response` 新增 `network_context_level`；SSE 新增 `network_query` 事件；catalog 暴露 `web_search_egress_mode` 与 `network_context_levels`；无数据库迁移。
- 已补充的测试：`tests/unit/test_hct403_tool_call.py`（剂量硬拒/风险说明/句级黑名单）、`tests/unit/test_hct430_local_agents.py`（无证据可答、成员绑定、指代继承、剂量快路径）、`tests/unit/test_hct430_search_providers.py`（摘要解析 P0、3xx、空缓存、导流过滤、open 抓页）、`tests/safety/test_hct430_open_egress.py`（SSRF/生产门禁）、`tests/unit/test_hct451_open_chat.py`（open_chat 不再豁免）、`tests/safety/test_hct406_red_team.py`（红队回归）。

## 验证、复审与回滚

- 验证：上述单测/安全/e2e 回归全绿（2026-08-27，`uv run pytest tests/unit tests/safety tests/e2e`）；金标集 `docs/demo/本地RAG拒答金标集.json` 已按 1A 更新 `DOSE_DECISION` 期望。
- 复审触发器：出现剂量数字漏拦、出网内容含身份信息、SSRF 逃逸或导流内容未过滤的任一 badcase 时，回到本 ADR 复审。
- 回滚：
  - 联网整体：`AGENT_WEB_SEARCH_ENABLED=false`（立即停止一切出网）；
  - 开放抓页：`AGENT_WEB_SEARCH_EGRESS_MODE=allowlist`（退回域名白名单模式）；
  - 出网上下文：客户端固定 `network_context_level=query_only`（服务端默认即此档）；
  - 体验项：`AGENT_OPEN_CHAT=false`；
  - 行为整体回退：`git revert` 本分支提交即可恢复旧证据墙与旧解析器，无迁移、无数据清理。
