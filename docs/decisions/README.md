# HomeCare Twin 架构决策记录

ADR 记录会长期影响家庭事实、事件、权限、模型、规则、数据和部署的决策。状态使用 `提议`、`已接受`、`已替代` 或 `已拒绝`。已接受 ADR 不直接重写结论；新决策通过新 ADR 替代并双向链接。

文件命名：`NNNN-简短决策标题.md`。每项决策必须包含当前事实、候选方案、安全/隐私/医疗影响、资源与许可、验证指标、退出条件和回滚。
