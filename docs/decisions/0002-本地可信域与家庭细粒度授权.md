# ADR-0002：本地可信域与家庭细粒度授权

- 状态：已接受，待实现验证
- 日期：2026-08-03
- 关联需求：FR-01、FR-03、FR-05、FR-08、NFR-02

## 背景

家健镜处理成员疾病、过敏、用药、报告、图片、视频、对话和照护关系。用户明确要求健康数据不必上传互联网，且子女需要照护但不应默认看到全部健康信息。已有综合健康工具多采用云端通用服务逻辑，不能直接作为家健镜的信任边界。

## 决策

1. 家庭版建立本地可信域，健康数据、模型输入、向量、对话和原始媒体默认留在家庭局域网/机构内网。
2. 网络出口默认拒绝；天气只允许城市/区县编码；云端推理不作为默认回退。机构扩展若启用云端，必须单独部署、单独同意、脱敏、审计和可撤回。
3. 所有成员数据访问执行 RBAC + 成员/字段级 ABAC，并同时校验动作、目的、有效期和升级条件。
4. 子女授权采用最小权限，不提供默认共享全部健康资料；撤权立即阻止 API、缓存、索引和通知访问。
5. 多证据识别结果必须人工确认/修正后才能进入健康事实和风险规则；原预测和修正不可覆盖。
6. 风险等级由版本化规则决定，LLM 只能调用有权限的事实/规则/文档并解释，不能修改健康事实或给出用药决策。
7. 产品不提供买药、问诊、广告和佣金导流入口。

## 备选方案

| 方案 | 结论 | 原因 |
|---|---|---|
| 默认上传云端，依赖云模型 | 拒绝 | 与隐私承诺冲突，扩大攻击面和合规负担 |
| 本地优先但子女默认看全部 | 拒绝 | 不符合家庭成员知情与最小授权原则 |
| 视觉模型直接判定药品 | 拒绝 | 无法处理未知/冲突，责任边界不清 |
| LLM 自由判断相互作用和剂量 | 拒绝 | 不可验证、不可审计，容易输出危险结论 |
| 本地可信域 + 细粒度授权 + 规则/LLM 分权 | 采用 | 与产品目标、技术能力和教学验收一致 |

## 验证指标

- 默认出口测试：健康正文、图片、视频、向量、对话和模型输入均无互联网请求；
- 字段权限测试：子女只能读取授权字段，过期/撤回后立即返回拒绝或字段不可见；
- 识别测试：条码/OCR/包装冲突进入人工复核，修正保留 before/after；
- AI 测试：无证据拒答，诊断/处方/停药/换药/剂量请求拒绝；
- 产品扫描：不存在买药、问诊、广告和佣金导流入口；
- 降级测试：本地 LLM、向量库、天气离线不影响事实、规则、任务和撤权。

## 影响与回滚

该决策增加本地部署、模型更新和权限测试成本，但降低健康数据外发风险，形成可演示的产品差异化。若硬件算力不足，回退到基础档和模板化规则解释，不回退到默认云上传。若字段授权实现不完整，禁止开放子女协同和公共大屏。
