# HomeCare Twin 产品信息架构与页面设计

> 状态：P0 设计基线；HCT-001 合并后完成范围冻结，页面实现与业务验收仍待后续 Story。
>
> 目标：把“本地隐私、多证据修正、子女细粒度授权、分级提醒、证据型 AI、纯居家照护”落实为可实现、可验收的页面结构。

## 1. 设计总原则

### 1.1 首页回答四个问题

首页不以聊天框或功能宫格为中心，优先回答：

1. 最近发生了什么变化？
2. 哪些事项需要本人或照护者确认？
3. 为什么出现这条提醒，依据是什么？
4. 子女/照护者现在能看到哪些信息？

### 1.2 六条硬规则

- **隐私先行：** 顶部常驻本地状态：“家庭健康数据默认不出网”。网络出口、天气权限和云端扩展状态必须可查看。
- **证据伴随结论：** 识别、风险和 AI 回答不能只显示一句结论，必须提供证据、版本、人工确认状态和修正入口。
- **权限可见：** 子女视图显示“可见范围、用途、到期时间”，不把“家庭成员”误解成“可看全部”。
- **提醒克制：** INFO/GENERAL 默认进入摘要，HIGH 单独升级，URGENT 进入求助流程；页面显示今日已合并数量和预算。
- **AI 有边界：** 显示“基于哪些事实/规则/文档”，缺证据时展示信息不足，不让模型填空。
- **无导流：** 不出现买药、问诊、广告、推荐医生或健康消费入口；页面 CTA 只指向确认、补录、授权、查看证据和联系现有专业人员。

## 3. 页面设计

### 3.1 家庭总览

| 区域 | 展示内容 | 主要动作 |
|---|---|---|
| 顶部状态条 | 本地/增强/研发档、网络出口、最近备份、数据说明 | 查看隐私状态、进入设置 |
| 近期变化 | 新增药品、报告、医嘱、授权和计划变化 | 查看事件证据 |
| 待确认风险 | 等级、标题、成员、原因、处理状态 | 查看依据、确认任务 |
| 今日任务 | 普通摘要、高风险、未响应和升级 | 确认、延期、跳过并记录原因 |
| 证据/授权 | 最近识别修正、谁能看什么、授权即将到期 | 修正、调整授权 |

空状态文案应说明下一步，例如“尚无已确认健康事件，可拍摄药盒或手工录入一条事实”；不得用“AI 正在为你诊断”之类文案。

### 3.2 成员健康档案

默认只显示当前操作者有权访问的字段。字段被隐藏时显示“未获授权”，不显示“存在某项隐私内容”的额外信息。

成员档案中的每个字段/卡片都标注：来源、确认状态、最后更新时间、可见范围和变更事件。疾病史、过敏史、报告正文、对话等高敏数据必须二次确认后查看。

### 3.3 视觉扫描中心

扫描流程固定为：

```text
选择成员 -> 选择输入方式 -> 质量检查 -> 本地识别 -> 多证据结果 -> 进入复核
```

页面需要同时显示：

- 原图或关键视频帧；
- YOLO 框和区域名称；
- OCR 原始文本/规范化文本；
- 条码/二维码原文和解码状态；
- 包装特征和本地主数据候选；
- 模型、OCR、匹配器版本；
- `MATCHED`、`CONFLICT`、`UNKNOWN`、`REVIEW` 状态；
- “确认”“修正”“拒绝”“补拍”按钮。

禁止用单一百分比替代证据列表；高置信度也必须提示“需人工确认”。

### 3.4 人工复核中心

复核页采用左右对照：

```text
左侧：原始图片/帧/检测框/字段来源
右侧：候选列表/冲突解释/可编辑字段/确认动作
底部：before -> after、修正原因、训练同意、审计信息
```

当用户修改药名、规格或有效期时，页面必须明确：“本次修正会进入健康事件；是否允许将脱敏样本用于后续模型训练？”两个同意不可合并为一个默认勾选。

### 3.5 家庭健康图谱

图谱只展示由已确认健康事件生成的成员、疾病、过敏、药品、成分、批次、计划、文档和照护关系。节点和关系边必须显示来源事件、确认状态、最后更新时间和当前可见范围。

未确认识别候选、`CONFLICT`、`UNKNOWN` 或 `REVIEW` 不得生成正式节点和关系边。字段被撤权、事实被补偿更正或投影服务不可用时，页面必须隐藏受影响内容并显示可重建/待同步状态，不能保留旧的敏感缓存。

### 3.6 用药安全中心

每张风险卡的首屏只显示：成员、等级、触发时间、状态、下一步；展开后显示：

1. 已确认事实；
2. 命中的规则及版本；
3. 说明书/知识文档片段及定位；
4. 人工确认状态；
5. 生成该解释的模型和知识版本；
6. 可执行动作及其授权对象。

卡片文案使用“发现已知资料/需要进一步确认”，不使用“可以一起吃/必须停药/建议增加剂量”。

### 3.7 健康计划中心

用药计划按“医嘱事实”和“提醒策略”分栏：

- 医嘱事实：药品、剂量、频次和时间来源于已确认记录，只读；
- 提醒策略：首次提醒、再提醒、渠道和升级对象可在安全时间窗内调整。

任何计划版本变化都显示旧版/新版差异、批准人、批准时间和授权依据。系统不能提供直接修改剂量的快捷按钮。

### 3.8 本地健康助手

助手页面不做开放聊天首页。顶部固定显示：本地模型状态、当前成员、当前可见范围、证据模式和教学免责声明。

回答布局：

```text
结论摘要
-> 依据事实
-> 命中规则
-> 文档引用
-> 人工确认状态
-> 可执行的照护动作
-> 无法回答/需要联系医生或药师的边界
```

没有引用时显示“当前资料不足，无法给出可靠判断”，并提供“补充证据/查看原始记录/联系医生或药师”等动作。

### 3.9 授权设置（跨页面支撑视图）

授权设置不是第十一个核心页面，而是成员健康档案、家庭总览和家庭健康大屏共同调用的支撑视图。它必须使用同一授权事实和 API，不得在不同入口形成独立权限口径。

授权编辑器使用五步表单：

1. 选择被授权人；
2. 选择成员；
3. 选择数据域/字段；
4. 选择动作和目的；
5. 设置开始时间、到期时间和是否允许高风险升级。

提供“只看摘要”“可看用药计划”“可处理提醒”“可看报告正文”等预设，但每个预设都必须可展开修改。默认值为最小权限，不允许“一键开放全部健康资料”。

### 3.10 家庭健康大屏

大屏面向家庭共同查看，默认只放非敏感聚合：任务数量、处理状态、趋势和授权提示。成员姓名、病史、药品详情、报告图片和对话正文需要在授权后进入成员视图，不直接投放到公共大屏。

大屏必须能切换“今日任务/近期变化/告警预算/照护响应/本地运行状态”，而不是把健康数据越多越好当作展示目标。

### 3.11 模型实验室

模型实验室只面向管理员/研发人员，展示：数据集版本、模型版本、阈值、固定集指标、失败样本、V1/V2 对比、延迟、模型哈希、部署状态和回滚按钮。

不得展示真实家庭健康正文，不得让管理员因为能看模型指标而自动获得成员健康数据权限。

## 4. 状态与组件规范

### 4.1 识别状态

使用文字 + 图标 + 颜色三重表达：

| 状态 | 视觉语义 | 必须提供 |
|---|---|---|
| MATCHED | 候选明确但未确认 | 证据展开、确认 |
| CONFLICT | 证据矛盾 | 冲突原因、强制复核 |
| UNKNOWN | 系统不知道 | 手工录入、补拍 |
| REVIEW | 信息不足 | 缺失项、补录 |
| CONFIRMED | 用户确认 | 确认人、时间、事件 |
| CORRECTED | 用户修正 | 前后值、理由、事件 |

### 4.2 提醒状态

所有提醒卡显示等级文本、触发依据、剩余预算、通知渠道和处理状态。免打扰不等于删除，用户可以在摘要中查看被合并的 INFO/GENERAL。

### 4.3 依赖降级

LLM、向量库、视觉、OCR、天气任一依赖不可用时，页面显示明确的“不可用/已降级/待重试”状态，不显示假置信度、假回答或空白成功结果。

## 4.4 十页状态矩阵

“低置信”不仅指模型分数，也包括证据、来源、版本或投影状态不足。所有页面都必须把低置信结果保留在待确认/不可发布状态，不能用看似成功的 UI 掩盖不确定性。

| 页面 | 正常 | 加载 | 空 | 错误 | 离线 | 未授权 | 低置信 |
|---|---|---|---|---|---|---|---|
| 家庭总览 | 展示四区、本地状态和授权摘要 | 固定骨架且不回显其他家庭缓存 | 提示新增已确认事实或配置授权 | 显示请求 ID、重试和不完整范围 | 保留本地事实并标记外部能力降级 | 隐藏家庭内容并要求切换身份/家庭 | 相关识别或证据卡标为待复核，不进入风险摘要 |
| 成员健康档案 | 只展示当前身份获权字段及来源 | 字段级骨架不预填敏感旧值 | 说明尚无已确认记录，不暗示不存在疾病 | 指出失败字段并禁止用旧值冒充最新 | 展示可用本地记录和同步时间 | 返回最小拒绝信息，不泄露字段存在性 | 未确认字段单独标记且不进入正式档案 |
| 视觉扫描中心 | 展示质量、多渠道证据、四态和版本 | 显示本地处理阶段与取消/重试 | 提示选择成员并拍照、上传或录入 | 保留原始文件引用并给出结构化失败原因 | 本地视觉可用则继续，否则进入待重试 | 禁止读取成员文件和创建识别任务 | 进入 REVIEW/UNKNOWN，提示补拍且禁止确认入库 |
| 人工复核中心 | 对照原证据、候选、冲突和修正 | 锁定提交动作并显示证据加载范围 | 说明当前无待复核任务 | 保留草稿但不产生部分健康事件 | 允许本地证据复核，外部能力保持关闭 | 隐藏证据正文并拒绝确认/修正 | 强制补录、补拍或人工选择，不默认最高分候选 |
| 家庭健康图谱 | 展示已确认节点、关系和来源事件 | 保持布局尺寸并显示重建进度 | 说明尚无可投影的已确认事件 | 标记投影失败并提供重建入口 | 从本地事实投影，禁用外部扩展 | 隐藏未授权节点、边和聚合数量 | 不为未确认事实建节点/边，显示待确认来源 |
| 用药安全中心 | 展示规则等级、事实、版本和处理状态 | 风险卡占位但不显示假等级 | 说明当前无已确认规则命中 | 保留事实入口并标记规则计算失败 | 使用本地规则和缓存知识版本 | 隐藏未授权事实、证据和风险摘要 | 证据不足时进入待确认，不给肯定用药判断 |
| 健康计划中心 | 分栏展示医嘱事实和提醒策略 | 锁定变更并显示计划版本加载 | 提示录入已确认医嘱或计划 | 不保存部分变更，显示可重试原因 | 本地计划与提醒继续可用 | 隐藏计划详情并拒绝确认、延期或跳过 | 来源/时间窗不确定时禁止优化或切换计划 |
| 本地健康助手 | 先依据后解释，显示引用和版本 | 显示本地检索/工具阶段并允许取消 | 提示选择成员或补充可访问证据 | 返回结构化错误且不生成自由文本兜底 | 模型不可用时退化为事实/规则卡 | 检索前拒绝越权，不暴露引用标题 | 资料不足时澄清或拒答，不输出医疗结论 |
| 家庭健康大屏 | 展示非敏感聚合、任务和本地状态 | 固定版式且不闪现成员敏感信息 | 展示安全空状态和配置入口 | 隐藏失败指标并标明最后更新时间 | 展示本地聚合，天气/模型卡标记降级 | 公共模式只显示获准聚合 | 未确认数据不进入趋势、排名或成功指标 |
| 模型实验室 | 展示版本、固定集指标和回滚状态 | 保持指标布局并显示任务阶段 | 说明暂无已登记模型或实验 | 标记实验失败并保留可审计记录 | 允许查看本地登记，禁止云端回退 | 非管理员拒绝且不展示样本/指标详情 | 指标或评估不足时保持候选状态，禁止发布 |

## 5. 页面验收清单

- [ ] 首屏出现本地隐私状态，且没有购药/问诊/广告入口；
- [ ] 药品识别同时展示 YOLO、OCR、条码、主数据和人工状态；
- [ ] 冲突/未知结果不能绕过人工复核；
- [ ] 人工修正可看到 before/after 和原因；
- [ ] 子女视图展示当前字段授权、用途和到期时间；
- [ ] 撤权后页面和 API 都立即隐藏相应字段；
- [ ] INFO/GENERAL 合并并受预算约束，HIGH/URGENT 独立展示；
- [ ] 风险卡可展开事实、规则、文档、确认状态和版本；
- [ ] AI 无证据时拒答，危险用药请求进入受控拒答；
- [ ] Ollama/向量库/天气离线时仍可展示事实、规则和任务；
- [ ] 大屏不默认暴露病史、报告正文和对话记录；
- [ ] 模型实验室不混入真实家庭正文。

## 6. 文案基线

推荐：

- “健康数据默认保存在本地家庭可信域”；
- “识别结果仅为候选，确认后才进入健康记录”；
- “发现规则资料，请查看依据并进一步确认”；
- “当前资料不足，系统不会替你做用药判断”；
- “此照护者仅可查看已授权的成员和数据字段”；
- “普通提醒已合并，严重事项仍会单独通知”。

禁止：

- “AI 已经帮你诊断”；
- “可以放心一起吃”；
- “建议立即停药/加量/换药”；
- “一键把全部健康资料分享给子女”；
- “点击购买/在线问医生/领取健康优惠”；
- “模型置信度 99%，无需确认”。
