# HomeCare Twin 数据与隐私安全规范

## 1. 基本原则

本地优先、目的明确、最少必要、明示授权、成员级隔离、最短留存、可访问/导出/更正/删除/撤权、全链可追溯。健康、疾病、用药、检查报告和可能的生物识别信息按敏感个人信息处理。

## 2. 数据分级

| 级别 | 示例 | 控制 |
|---|---|---|
| D0 公开 | 授权公开说明书、公开规则来源 | 记录来源、许可、版本和哈希 |
| D1 内部 | 合成药品主数据、脱敏指标、评估结果 | 限团队访问，不公开原始路径 |
| D2 敏感 | 成员身份、用药、过敏、疾病、事件、对话 | 加密、成员级授权、访问审计 |
| D3 高敏 | 原始报告/处方图片、可识别视频、密钥、备份 | 单独密钥、最短留存、二次确认、禁止进日志 |

## 3. 授权模型

授权记录必须包含授权人、被授权人、家庭/成员、允许动作、目的、开始/到期时间和撤回状态。RBAC 只定义角色上限，最终访问还需成员级 ABAC 校验。家庭管理员不能自动读取所有成员敏感正文；模型/知识管理员不因管理模型而获得家庭数据权限。

## 4. 生命周期

### 采集

- 只收集实现当前功能所需字段；上传前说明用途和保留期。
- 自采药品数据避开姓名、处方号、地址等个人信息；健康报告先裁剪/脱敏。
- 摄像头按用户主动触发，不持续后台采集；P0 不做人脸身份识别。

### 存储与使用

- 传输加密；数据库、文件、备份和密钥分离；默认不暴露公网。
- 日志只记请求 ID、对象 ID、动作、版本和结果，不记报告正文、完整 OCR、提示词上下文或令牌。
- 原图达到留存期后删除；如仅需证据裁剪，优先删除全图。
- 天气服务只接收城市/区县编码。

### 导出、撤权与删除

- 导出包含结构化事实、事件、授权和可理解的版本信息。
- 撤权立即阻止新访问和照护升级；已生成缓存/索引按删除传播规则清理。
- 删除覆盖主库、文件、向量索引、缓存和可控备份；审计保留最小合法证明，不保留健康正文。

## 5. 数据集与困难样本

- 只使用合成、公开许可或明确授权自采数据；每个数据集有数据卡。
- 按实体药盒、日期、设备、视频会话分组划分，禁止相邻帧跨集合。
- 困难样本先检查授权与脱敏，再由数据管理员审核进入训练批次。
- 不把家庭成员纠错默认视为训练同意；撤回后停止后续训练，并按可实现范围清理未发布制品。

## 6. 安全控制

密码哈希、短期访问令牌与刷新轮换、速率限制、上传类型/大小/解压炸弹/恶意内容检查、CSRF/CORS、参数化查询、对象所有权校验、二次确认、脱敏审计、备份加密与恢复演练。

## 7. 事件响应

发现泄露、越权、错误规则或危险回答时：立即隔离入口/版本 → 保全最小审计 → 评估影响成员与数据 → 回滚模型/规则/知识 → 通知责任人 → 修复与回归 → 记录复盘。不得把敏感正文复制到公开 Issue。

## 8. 发布阻断

存在跨家庭越权、撤权不生效、原图/密钥进日志、删除传播失败、训练授权不明、外部服务上传敏感详情或备份无法恢复时，禁止演示发布。
