# 数据与隐私安全规范

## 1. 基本原则

目的限定、最小采集、默认私密、分级授权、全程可追溯、到期删除。实训默认只使用合成、公开许可或不可逆脱敏数据。

## 2. 数据分级

| 级别 | 示例 | 处理要求 |
|---|---|---|
| L1 公开 | 公开说明书、公开医学科普 | 记录来源和许可证 |
| L2 内部 | 配置、非敏感统计、测试报告 | 登录访问，不公开索引 |
| L3 敏感 | 健康指标、过敏史、对话、上传图片 | 加密、细粒度授权、审计、期限 |
| L4 高敏 | 身份证号、完整病历、原始视频、生物特征 | MVP 原则上不采集；确需使用须专项审批 |

## 3. 生命周期

### 采集

- 采集前展示目的、字段、使用方式、保存期限和撤回方式。
- 不以产品功能为由强制收集无关身份信息。
- 文件上传限制类型、大小和数量，并进行内容嗅探与恶意文件防护。

### 存储与访问

- 传输使用 TLS；L3/L4 静态数据加密。
- 数据库保存对象引用，不保存无必要的原始媒体。
- 授权按用户、家庭、角色和资源共同判断；管理员也遵守最小权限。
- 日志只记录脱敏主体 ID、操作、资源类型、结果、时间和请求 ID。

### 使用与导出

- 训练、评估、演示和调试使用不同数据域。
- 模型供应商不得默认获得用户数据训练权。
- 导出前二次认证；导出包加密并设置短期下载链接。

### 保留与删除

建议基线：

| 数据 | 默认期限 |
|---|---|
| 未确认的临时上传 | 24 小时 |
| 视觉推理中间帧 | 请求结束立即清除 |
| 对话记录 | 用户可配置，默认 90 天 |
| 已发布知识文档 | 直至所有者撤回或版本淘汰 |
| 安全审计 | 180 天，内容不含病历正文 |

删除应覆盖业务库、对象存储、向量索引、缓存和派生数据，并记录不可包含正文的删除凭证。

## 4. 数据集规则

- 每份数据集建立数据卡：来源、许可、用途、字段、样本量、偏差、脱敏方式、负责人。
- 按患者/主体划分训练、验证、测试集，禁止同主体跨集合。
- 不从互联网随意抓取药品或患者图片。
- 演示数据必须明确标注“合成/脱敏”，不得让观众误认为真实诊疗数据。

## 5. 安全控制

- 密码使用可靠的自适应哈希；令牌短时有效并支持撤销。
- 对登录、问答、上传、检索和导出分别限流。
- 防护 SQL 注入、越权、路径穿越、SSRF、恶意文档和提示词注入。
- 知识库检索前进行租户/用户权限过滤。
- 敏感操作需要二次确认；生产数据删除和权限提升禁止由 AI 自动执行。

## 6. 事件响应

发现敏感信息泄露时立即停止传播、隔离相关服务、轮换凭据、保留脱敏证据、通知负责人并评估删除范围。不得只删除最新提交；进入 Git 历史的敏感数据必须清理历史并视情况轮换。

## 7. 上线前检查

- [ ] 数据清单、分级、目的和期限已登记
- [ ] 授权撤回、导出和删除流程可用
- [ ] 日志、异常、监控不含敏感正文
- [ ] 模型与第三方数据使用条款已确认
- [ ] 越权、注入、恶意上传和数据删除测试通过
- [ ] 演示数据均为合成、公开许可或脱敏数据
