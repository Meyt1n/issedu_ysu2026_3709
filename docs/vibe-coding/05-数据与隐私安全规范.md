# HomeCare Twin 数据与隐私安全规范

## 1. 基本原则

本地优先、目的明确、最少必要、明示授权、成员级隔离、最短留存、可访问/导出/更正/删除/撤权、全链可追溯。健康、疾病、用药、检查报告和可能的生物识别信息按敏感个人信息处理。

家庭版的默认安全承诺是：**健康数据不出家庭可信域**。网络出口采用默认拒绝策略；天气仅可使用城市/区县编码，不能携带成员、药品、疾病、过敏、报告、图片、视频、会话或模型上下文。任何云端扩展都必须作为独立部署档、单独授权、脱敏、限目的、可撤回并审计，不能悄悄作为本地模型不可用时的回退。

## 2. 数据分级

| 级别 | 示例 | 控制 |
|---|---|---|
| D0 公开 | 授权公开说明书、公开规则来源 | 记录来源、许可、版本和哈希 |
| D1 内部 | 合成药品主数据、脱敏指标、评估结果 | 限团队访问，不公开原始路径 |
| D2 敏感 | 成员身份、用药、过敏、疾病、事件、对话 | 加密、成员级授权、访问审计 |
| D3 高敏 | 原始报告/处方图片、可识别视频、密钥、备份 | 单独密钥、最短留存、二次确认、禁止进日志 |

## 3. 授权模型

授权记录必须包含授权人、被授权人、家庭/成员、数据域/字段、允许动作、使用目的、开始/到期时间、是否允许风险升级和撤回状态。RBAC 只定义角色上限，最终访问还需成员级、字段级 ABAC 校验。

**P0 家庭管理员边界（现行实现）：** 家庭 `created_by`（household owner）在本期内可作为家庭管理边界，读取本家庭成员目录与健康事实以便照护协调与复核；该能力不等于“子女/照护者默认全开”。非 owner 的子女/照护者必须同时满足成员、字段、动作、目的与有效期授权。可通过 `OWNER_REQUIRES_ACCESS_PURPOSE=true` 要求 owner 也声明访问目的（教学/演练收紧）。模型/知识管理员不因管理模型或知识而获得家庭健康数据权限。更细的「owner 也按字段过滤」收紧留待后续迭代。

模型发布（HCT-404）默认开启双人控制：`MODEL_RELEASE_DUAL_CONTROL=true` 时激活者不得是绑定创建者，且 `approved_by` 必须等于会话身份；可用 `MODEL_RELEASE_ADMIN_ACTORS` 限制第二人名单。单人本地演练可临时关闭双人控制。

子女/照护者预设必须从最小权限开始，例如“只看任务摘要”“可看用药计划”“可处理提醒”“可看报告正文”分别授权；禁止提供默认开放全部健康档案的快捷方式。前端隐藏不等于授权，API 返回必须执行字段过滤。

## 4. 生命周期

### 采集

- 只收集实现当前功能所需字段；上传前说明用途和保留期。
- 自采药品数据避开姓名、处方号、地址等个人信息；健康报告先裁剪/脱敏。
- 摄像头按用户主动触发，不持续后台采集；P0 不做人脸身份识别。

### 存储与使用

- 传输加密；数据库、文件、备份和密钥分离；默认不暴露公网。
- 日志只记请求 ID、对象 ID、动作、版本和结果，不记报告正文、完整 OCR、提示词上下文或令牌。
- 原图达到留存期后删除；如仅需证据裁剪，优先删除全图。
- 天气服务只接收城市/区县编码。
- 出口网关记录目的、数据分类、授权依据、请求摘要、响应状态和操作者；未列入允许清单的连接必须阻断。
- Ollama、向量库、OCR 和视觉服务默认在家庭可信域内运行；依赖不可用时不得自动转发敏感内容到云端。

### 导出、撤权与删除

- 导出包含结构化事实、事件、授权和可理解的版本信息。
- 撤权立即阻止新访问和照护升级；已生成缓存/索引按删除传播规则清理。
- 删除覆盖主库、文件、向量索引、缓存和可控备份；审计保留最小合法证明，不保留健康正文。
- 导出前展示范围、字段、目的和过期时间，要求二次确认；导出包加密、设置有效期并记录下载/解密审计。

## 5. 数据集与困难样本

- 只使用合成、公开许可或明确授权自采数据；每个数据集有数据卡。
- 按实体药盒、日期、设备、视频会话分组划分，禁止相邻帧跨集合。
- 困难样本先检查授权与脱敏，再由数据管理员审核进入训练批次。
- 不把家庭成员纠错默认视为训练同意；撤回后停止后续训练，并按可实现范围清理未发布制品。

## 6. 安全控制

密码哈希、短期访问令牌与刷新轮换、速率限制、上传类型/大小/解压炸弹/恶意内容检查、CSRF/CORS、参数化查询、对象所有权校验、二次确认、脱敏审计、备份加密与恢复演练。

## 7. 事件响应

发现泄露、越权、错误规则或危险回答时：立即隔离入口/版本 → 保全最小审计 → 评估影响成员与数据 → 回滚模型/规则/知识 → 通知责任人 → 修复与回归 → 记录复盘。不得把敏感正文复制到公开 Issue。

## 8. 发布阻断

存在跨家庭越权、撤权不生效、原图/密钥进日志、删除传播失败、训练授权不明、默认网络出口未阻断、外部服务上传敏感详情、购药/问诊/广告导流或备份无法恢复时，禁止演示发布。
