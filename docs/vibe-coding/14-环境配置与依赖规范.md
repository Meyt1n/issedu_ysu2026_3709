# HomeCare Twin 环境、配置与依赖规范

## 1. 当前状态

仓库尚无依赖锁文件、容器编排或启动脚本。下表是目标基线，不是已安装事实；第一个工程 Story 必须在 Windows/演示机验证后锁定精确版本。

## 2. 目标依赖

| 层 | 候选基线 | 必须验证 |
|---|---|---|
| Web | Node LTS、Vue 3、TypeScript、Vite、Element Plus、ECharts | 构建、浏览器、包许可 |
| API | Python 3.11、FastAPI、Pydantic、SQLAlchemy 2、Alembic | Windows/Docker、异步驱动 |
| 数据 | MySQL 8 | 迁移、时区、字符集、备份恢复 |
| 视觉 | PyTorch、OpenCV、YOLO11n、PaddleOCR、条码库 | CPU/GPU、ONNX/OpenVINO、许可 |
| RAG | FAISS；Qdrant 为服务化候选 | 权限过滤、备份、重建和延迟 |
| LLM | LLaMA Factory、Ollama、3B–7B 量化模型 | 许可证、显存/内存、工具调用 |
| 测试 | pytest、httpx、Playwright | CI 与本地一致 |
| 部署 | Docker Compose、Nginx | 基础/增强档和卷权限 |

## 3. 第 1 周环境验收

- 干净电脑按文档安装并启动最小健康检查；
- MySQL 中文/时区/迁移/回滚和备份恢复通过；
- 浏览器上传样例文件，后端验证类型/大小并生成请求 ID；
- 视觉最小推理记录硬件、版本、耗时和模型哈希；
- Ollama 缺失时基础档正常，增强档明确降级；
- GPU 训练与家庭部署分离，CPU 模式有性能记录。

## 4. 配置分组

| 分组 | 示例 |
|---|---|
| 应用 | `APP_ENV`、公开地址、日志级别、请求体限制 |
| 数据库 | URL、池大小、连接超时、时区 |
| 安全 | JWT/文件加密密钥路径、令牌期限、允许源 |
| 文件 | 根目录、单文件/像素/视频限制、原图保留天数 |
| 视觉 | 模型/阈值/OCR/匹配器版本、设备、超时 |
| RAG | 索引路径/服务地址、Embedding/切片/知识版本 |
| LLM | Ollama 地址、模型、Schema、超时、并发 |
| 规则 | 规则集版本、告警预算、去重窗口 |
| 天气 | 城市编码、适配器、超时和缓存期 |

配置启动时用 Pydantic 校验；缺少增强档配置时不得影响基础档。密钥不允许默认值。
