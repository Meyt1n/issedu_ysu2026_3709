# 环境、配置与依赖规范

## 1. 基线版本

| 项目 | 基线 |
|---|---|
| Python | 3.11.x |
| Node.js | 前端建立时固定 LTS 版本 |
| API | FastAPI 0.116.1 |
| 测试 | pytest 8.4.1、httpx 0.28.1 |
| 质量 | Ruff 0.12.5、mypy 1.17.0 |
| 数据库 | PostgreSQL 16.4、SQLAlchemy 2.0.41、Alembic 1.16.4 |
| 数据库驱动 | psycopg 3.2.9、aiosqlite 0.21.0 |
| 身份安全 | pwdlib 0.2.1 + Argon2、PyJWT 2.10.1 |
| 缓存/队列 | Redis 7（规划） |
| 向量库 | ChromaDB MVP（规划） |
| 对象存储 | MinIO（规划） |

当前可执行依赖以 `requirements.txt` 和 `requirements-dev.txt` 为准。SQLite/aiosqlite
只用于快速测试；规划组件未接入前不得在文档中写成“已完成”。

## 2. 本地环境

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
docker compose up -d postgres
$env:PYTHONPATH = "src/api"
python -m alembic upgrade head
python -m pytest
python -m uvicorn app.main:app --reload
```

开发者复制 `.env.example` 为本地 `.env` 后修改；`.env` 不得提交。

## 3. 环境变量分组

| 前缀/变量 | 用途 | 敏感 |
|---|---|---|
| `APP_*`、`API_*` | 应用环境、名称、监听地址 | 部分 |
| `DATABASE_URL` | 业务数据库 | 是 |
| `REDIS_URL` | 缓存与任务队列 | 是 |
| `OBJECT_STORAGE_*` | 对象存储 | 密钥为是 |
| `VECTOR_STORE_*` | 向量库 | 视认证配置 |
| `LLM_*` | 模型网关与模型名 | API Key 为是 |

启动时必须验证必需变量；禁止在缺失密钥时静默使用硬编码默认值。除测试环境外，
`APP_SECRET_KEY` 包含 `replace`、`change-me`、`example` 或 `password` 时拒绝启动。

## 5. 依赖变更

新增或升级依赖时在 PR 中写明：

- 解决的问题和不用现有能力的原因；
- 精确版本、许可证和维护状态；
- 对镜像大小、GPU/CPU、启动时间和安全面的影响；
- 替代方案与回滚方式；
- 更新后的依赖安装和测试证据。

核心框架、数据库、模型服务和 RAG 框架变更必须新增 ADR。

一期新增依赖均为主流开源组件：SQLAlchemy/Alembic 建立 ORM 与迁移，
psycopg/aiosqlite 提供 PostgreSQL 与测试驱动，pwdlib+Argon2 提供自适应密码哈希，
PyJWT 负责访问令牌，email-validator 负责邮箱语法校验。主要许可证为 MIT；psycopg 使用
LGPL-3.0，email-validator 使用 Unlicense。数据库和认证选型见
[`ADR-0001`](../decisions/0001-统一业务API与数据库基线.md)；升级前仍需执行依赖漏洞扫描。

## 6. 可复现性

- CI 使用 Python 3.11 和全新环境安装依赖。
- 不依赖全局包、本机绝对路径或 IDE 隐式配置。
- 模型权重不进 Git，通过版本化制品地址和哈希获取。
- 数据集不进 Git，通过数据卡、版本和校验和登记。
- 实验记录随机种子、硬件、依赖、代码提交和参数。
