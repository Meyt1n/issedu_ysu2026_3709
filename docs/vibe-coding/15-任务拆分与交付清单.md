# 任务拆分与交付清单

## 1. 执行原则

- 先打通可测试的纵向链路，再横向扩展功能。
- 认证、授权、审计和安全规则早于真实医疗数据或模型接入。
- 每个任务对应一个 Issue、一个负责人、一个主要 PR。
- 状态以 [需求追踪矩阵](12-需求追踪矩阵.md) 和已合并证据为准。
