# HomeCare Twin AI 与 RAG 设计规范

## 1. 分权原则

| 能力 | 责任主体 |
|---|---|
| 药品候选与字段证据 | OCR/条码/包装辅助检测/匹配器 |
| OCR 字段归类与规范化 | 规则 + 本地 LLM Schema 抽取 |
| 正式事实确认 | 用户或授权复核者 |
| 风险等级和告警预算 | 版本化确定性规则 |
| 文档证据 | 权限过滤后的本地 RAG |
| 工具选择、澄清和通俗解释 | 本地微调 LLM |
| 最终结构、引用和禁止内容 | FastAPI 校验器 |

LLM 不得直接读全库、直连向量库、修改计划、批准医嘱或生成诊断/处方/停药/剂量。

家庭版不得把健康上下文发送到云端。Ollama、FAISS/Qdrant 和文档解析默认在家庭可信域运行；依赖不可用时返回结构化事实/规则卡或受控错误。任何云端推理必须是单独部署档，不属于默认回退。

## 2. 多证据视觉

预处理包含清晰度、曝光、反光、旋转、透视、裁剪、对比度、OCR 二值化、视频抽帧和感知哈希去重。家庭录入采用 OCR-first：先对整张受控图片 OCR，保存文字框、原始值和 OCR 置信度；YOLO 只检测包装对象和条码区域，作为裁剪/定位辅助；条码/二维码由专用解码器读取，OCR 仅作码值兜底。药品身份由 OCR、条码/二维码、包装类型、规格/厂家主数据和人工确认共同决定，不能由整盒图像分类器直接决定。条码命中也不能覆盖与包装或文字的冲突。

LLM 只接收已授权的 OCR token、条码解析结果、包装候选和本地主数据候选，执行字段语义解析/槽位填充，并必须返回来源 token/区域 ID。它不得修改原始 OCR、生成不存在的药名/批号/有效期，或在证据冲突时自行选定一个值。字段原始值、来源区域、系统置信度和版本格式见[HCT-201 OCR 字段提取契约](../data/HCT-201-OCR字段提取契约-V1.md)。

输出状态：

- `MATCHED`：证据一致且超过经校准阈值，仍需人工确认；
- `CONFLICT`：条码、药名、规格或日期证据冲突；
- `UNKNOWN`：训练/主数据之外或候选不足；
- `REVIEW`：质量低、关键字段缺失或候选间隔不足。

自动通过精确率优先于覆盖率。每次推理记录代码、权重、阈值、OCR、主数据和设备信息。人工纠错必须保留原预测、修正值、原因、操作者、时间和训练同意状态，不能原地覆盖识别证据。

## 3. 数据与追加训练

建议 P0 采集 12–20 种药品 SKU、3,000–5,000 张授权图片、30–60 段短视频、500 张困难样本及 5–10 种未知药品。固定集覆盖倾斜、反光、遮挡、相似/新旧包装、不同规格和不同设备。

```text
人工纠错 -> 授权/脱敏审核 -> hard_sample
-> 批量标注复核 -> 追加训练 -> 固定集 V1/V2 对照
-> 旧类别退化检查 -> 登记/发布或拒绝 -> 可回滚
```

## 4. RAG 入库与检索

- 来源限版本化药品说明书、公开权威资料、教学审核规则和经授权家庭文档。
- 入库记录来源、许可、版本、发布日期、哈希、权限域和失效时间。
- 文档解析后保留页码/章节/表格标签；切片与 Embedding 版本化。
- 先按用户、家庭、成员和文档权限过滤，再检索/重排；禁止检索后再遮挡越权结果。
- 文档内提示词视为数据，不得覆盖系统与安全规则。

## 5. LLM 微调

训练任务建议比例：意图/安全路由 20%、MySQL 工具 20%、图谱/规则工具 15%、RAG 15%、风险解释 10%、医嘱差异 5%、信息澄清 5%、隐私/医疗拒答 10%。训练样本不得包含真实未授权家庭数据；产品使用同意与训练同意必须分离。

路由枚举建议：`DIRECT`、`EVIDENCE_REQUIRED`、`RISK_ONLY`、`REFUSE`、`URGENT_ESCALATE`。基础模型与 QLoRA 模型必须使用相同盲测集比较工具选择、参数、引用和安全，不以训练损失代替业务评估。

## 6. 输出校验

后端依次执行 JSON Schema、工具结果绑定、引用存在/可访问、主张—证据忠实性、规则等级不可改写、成员/字段授权、诊断/处方/停药/剂量禁止内容、商业导流词和紧急升级检查。校验失败返回受控错误或结构化事实，不让模型自由重试扩大权限。

回答后的相关追问属于交互辅助，不属于 RAG 事实。默认使用只读取最新用户问题的本地受控模板，最多返回 3 条；不得读取未授权事实、工具原文或隐藏思考链来拼接追问。追问同样经过限长、去重、医疗越界和外链检查，模型/知识降级时返回空数组。

语音输入和语音回复属于客户端交互层，不是模型能力或 RAG 证据：Speech Recognition 仅形成待发送文字草稿，Speech Synthesis 仅朗读已经返回的文字。两者不得新增音频数据流、隐藏上传、健康事实写入或云端模型回退；能力不可用时必须回到普通文字流程。

## 7. 模型登记与发布

每个模型版本登记基础模型与许可证、训练数据版本、参数、代码提交、硬件、随机种子、指标、失败样例、阈值、量化/导出哈希、适用/禁止用途、批准人和回滚版本。家庭端只拉取已批准制品，不运行训练。

## 8. 威胁基线

覆盖提示词注入、恶意文档、工具参数越权、跨成员检索、引用伪造、上下文泄露、模型拒答绕过、资源耗尽、模型/索引替换和训练数据投毒。安全规则不能由普通提示词、管理员页面文本或检索文档关闭。
