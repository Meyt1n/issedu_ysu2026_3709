# 系统架构与模块边界

## 1. 代码目录建议

```text
src/
├─ web/                 Vue 前端
├─ api/
│  ├─ routes/           HTTP/WS 路由，只做协议适配
│  ├─ application/      用例编排
│  ├─ domain/           领域模型与规则
│  ├─ infrastructure/   数据库、对象存储、队列适配器
│  └─ integrations/     LLM、视觉、向量库客户端
├─ ai/
│  ├─ vision/           推理、后处理、评估
│  ├─ rag/              入库、检索、重排、引用
│  └─ safety/           风险分类、拒答、输出校验
└─ admin/               可选 Flask 管理界面
tests/
├─ unit/
├─ integration/
├─ e2e/
├─ safety/
└─ fixtures/            仅合成/脱敏数据
```

## 2. 模块责任

| 模块 | 可以做 | 不可以做 |
|---|---|---|
| Web | 展示、采集输入、客户端校验 | 保存密钥、决定最终权限 |
| API 路由 | 参数解析、身份上下文、响应映射 | 编写核心业务与 SQL |
| 应用层 | 编排用例、事务边界 | 依赖具体 Web 框架对象 |
| 领域层 | 权限、授权、健康记录规则 | 直接调用数据库/模型 |
| 基础设施 | 持久化和第三方适配 | 决定医疗业务规则 |
| 视觉服务 | 推理、阈值、模型元数据 | 自动作出用药决定 |
| RAG 服务 | 入库、过滤检索、引用 | 绕过用户与知识域权限 |
| 安全模块 | 风险升级、拒答、输出检查 | 被普通提示词覆盖 |

## 3. 依赖方向

`routes -> application -> domain`，基础设施通过接口注入应用层。领域层不得反向依赖 FastAPI、SQLAlchemy、LangChain 或具体模型 SDK。

## 4. 数据所有权

- 身份、家庭成员、授权、健康记录：业务 API。
- 对象元数据与访问策略：业务 API；二进制内容：对象存储。
- 文档切片与向量：RAG 服务，但权限源仍是业务 API。
- 模型文件与版本元数据：模型注册目录；不得由请求动态覆盖。
- 审计日志：只追加存储，业务用户无修改权限。

## 5. 通信规则

- 同进程模块优先使用应用服务接口；不跨层导入内部实现。
- 独立服务使用版本化 HTTP/JSON 或任务消息。
- 长耗时任务返回 `202 + task_id`，客户端轮询或订阅状态。
- 所有跨服务请求传递 `request_id`，服务身份使用短期凭据。
- 服务失败返回明确状态，不用空数组或默认文案掩盖故障。

## 6. 需要 ADR 的变化

- 更换核心 Web 框架、数据库、向量库或队列；
- 拆分/合并服务；
- 引入外部医疗数据或云模型；
- 修改敏感数据保存位置和期限；
- 更改认证、授权或加密方案；
- 更换主要模型、嵌入模型或切片策略。
