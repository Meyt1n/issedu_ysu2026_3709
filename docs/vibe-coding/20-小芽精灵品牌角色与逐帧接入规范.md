# 小芽精灵品牌角色与逐帧接入规范

## 1. 产品角色定位

小芽精灵是 HomeCare Twin / 家健镜的家庭健康陪伴助手。它把系统状态、空状态、轻提醒和入口引导转化为温和、可信的反馈，但不提供诊断、用药结论或替代专业意见。它同时承担品牌识别、情绪缓冲、健康助手入口和操作引导四种职责，不作为纯装饰或游戏奖励。

## 2. 统一视觉规范

- 正式名称：小芽精灵；备选名：家芽、芽芽守护。
- 身体：暖米白 #FFF8E8，下腹阴影 #F3EAD3。
- 主描边：森林绿 #496C5B；辅助描边 #75917D。
- 叶芽：鼠尾草绿 #789B76，高光 #9FB494。
- 腮红：柔桃色 #F2B39B；投影：rgba(89, 104, 79, .15)。
- 比例：头身一体，主体高宽约 1.1:1；双叶占总高 16%；手臂落在主体高度 58%—78%，脚部不超过总高 9%。
- 线条：以 120×132 视图为基准，外轮廓 3px，叶片 2.7px，表情 3px；圆角、圆帽端点，不使用硬直角。
- 五官：眼距约主体宽 24%，嘴位于眼线下方 10%；默认小幅微笑，避免夸张牙齿和强动漫高光。
- 情绪变化只调整眼睛、眉毛、嘴、手势、重心和叶芽摆幅；身体轮廓、叶形、颜色和五官基准位置保持一致。

## 5. Vue 组件接口

CompanionPet.vue 提供 state、size、clickable、showBubble、bubbleText、loop、autoplay、placement 和可选 frameSources。默认 idle 循环；可点击时 hover 进入 happy，左击播放 wave 后接 happy，并发出 click 与 complete 事件。

全局桌宠由 GuardianPet.vue 承担拖动与快捷入口：左键互动，右键或 Shift+F10 打开菜单。菜单依据宠物的视口位置选择上/下与左/右方向，并通过水平夹取和紧凑条目保持完整可见，不显示滚动条。

## 6. 页面落点建议

| 页面 | 状态 | 位置 | 气泡/播放/交互 |
| --- | --- | --- | --- |
| 首页 | idle / reminder | 右下悬浮 | 偶发问候；循环；左击互动、右击菜单 |
| 健康助手 | listening / think | 输入区侧边 | 显示“我在认真听”；自动播放 |
| 启动过渡页 | loading / success | 主流程一侧 | 无长期气泡；自动播放 |
| 今日用药空状态 | shy / idle | 卡片下部 | 一句温和鼓励；低频播放 |
| 待确认事项 | reminder | 标题或数量旁 | 仅有事项时显示；可点击进入 |
| 健康图谱/数字孪生 | point / think | 说明区边缘 | 首次引导时显示 |
| 成员档案 | idle | 空状态或提示侧边 | 不主动打断 |
| 登录后欢迎 | wave | 标题侧边 | 一次性欢迎后回 idle |

同一视口原则上只出现一个主动动画宠物；卡片内宠物保持 small/medium，避免与全局悬浮入口争抢注意力。

## 8. 图像生成标准提示词

为 HomeCare Twin / 家健镜生成“小芽精灵”逐帧动画素材。始终保持同一角色身份：头身一体的圆润暖米白身体，森林绿色柔和粗描边，头顶固定双叶芽，淡桃色圆形腮红，短小圆润手脚，成熟家庭健康产品的温柔治愈感；不是儿童动画、游戏宠物、动漫角色或 3D 科技形象。生成动作：【ACTION】，共【FRAME_COUNT】帧，按时间顺序排成等尺寸帧格。每帧角色尺寸、轮廓、叶形、五官基准、色值、光源和脚底锚点完全一致，只改变动作所需的表情、手势、重心和叶芽摆幅。正面或轻微三分之二视角，无文字、无气泡、无道具（除非动作明确要求）、无复杂背景、无裁切、无重影。透明背景，柔和二维水彩矢量混合质感，边缘清晰，适合切分为 384×416 WebP lossless 前端逐帧资源。

推荐负面提示词：赛博、霓虹、机械、医疗器械、写实毛发、强 3D、儿童低幼、二次元、复杂服装、角色变形、叶片数量变化、颜色漂移、不同视角、文字、水印、背景场景。

## 9. 文案边界

文案只做欢迎、陪伴、提醒和操作引导，不做医学判断。颜文字每条最多一个，优先使用低刺激、易读的形式，如 (｡･ω･｡)ﾉ、( •̀ᴗ•́ )و、(｡•́‿•̀｡)；风险和错误提示应保持清楚，不用卖萌弱化严重程度。
