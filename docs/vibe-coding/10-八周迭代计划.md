# 八周迭代计划

## 总体节奏

每周遵循“周一计划与设计、周二至周四小步实现、周五集成验收与复盘”。每日完成短会、开发、评审和记录，所有功能通过 PR 合并。

| 周次 | 目标 | 主要交付物 | 周验收 |
|---|---|---|---|
| 第 1 周 | 项目启动与基线 | 需求、架构、约束、环境、仓库规范、合成数据方案 | 干净环境可启动骨架；文档评审通过 |
| 第 2 周 | 数据与基础 API | 用户/角色/家庭成员、数据库迁移、统一错误、审计骨架 | 权限集成测试通过 |
| 第 3 周 | 视觉 MVP | 数据卡、OpenCV 流程、药物单图模型、评估脚本 | 限定类别可识别，未知类可拒绝 |
| 第 4 周 | RAG MVP | 文档解析、切片、向量检索、引用、权限隔离 | 公开资料问答带可定位引用 |
| 第 5 周 | 医疗问答与多模态 | LLM 网关、多轮对话、图片输入、安全分级与拒答 | S0-S3 安全回归通过 |
| 第 6 周 | Web 与视频集成 | 用户端、管理端、异步任务、视频抽帧演示 | MVP 主链路端到端通过 |
| 第 7 周 | 系统加固 | 性能、安全、隐私删除、监控、故障降级 | 无发布阻断缺陷 |
| 第 8 周 | 部署与答辩 | Compose、部署手册、测试报告、演示数据、录屏与总结 | 从干净环境部署并完整演示 |

## 角色建议

- 项目/产品：维护需求、优先级、验收和风险。
- 架构/后端：认证、权限、数据、API 和集成。
- 算法：视觉、RAG、LLM、安全评估和模型卡。
- 前端：用户端、管理端、可访问性和错误呈现。
- 测试/文档：测试矩阵、回归、证据与操作手册。

角色可兼任，但认证权限、医疗安全规则和最终发布不得由同一人独立完成和审批。

## 里程碑

### M1（第 2 周末）工程可用

仓库、环境、文档、认证与数据骨架就绪；AI 编码和隐私门禁落地。

### M2（第 4 周末）两条 AI 链路可用

药物单图识别和带引用的 RAG 问答可独立演示，并有基线评估。

### M3（第 6 周末）系统集成

用户、视觉、问答、知识库和管理端形成完整业务链路。

### M4（第 8 周末）可交付

安全、性能、部署、演示和文档全部验收，已知限制公开。

## 每周完成定义

- 需求卡片和验收条件已更新；
- 代码经人工复核，测试通过；
- 模型/数据/提示词版本可追溯；
- 无敏感信息和密钥；
- 文档与实现一致；
- 演示环境可重复；
- 未完成项有负责人和下一步。
