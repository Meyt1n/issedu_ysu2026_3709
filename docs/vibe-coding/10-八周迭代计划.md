# HomeCare Twin 八周迭代计划

## 1. 计划原则

八周只交付 P0：六个功能域、十个页面和一条连续业务闭环。先做事实、字段级授权、事件和人工确认，再做规则与 LLM；训练与家庭运行分离；家庭版默认不出网；每周必须同时产出实现、测试、文档和演示证据。

## 2. 周计划

| 周次 | 目标 | 关键任务 | 退出证据 |
|---:|---|---|---|
| 1 | M0 范围冻结 | 用户故事、医疗边界、原型、数据字典、标注规范、默认拒绝出口、字段授权与 ADR | 需求评审、风险清单、页面原型、数据卡草案 |
| 2 | M1 工程骨架 | Vue/FastAPI/MySQL、认证、成员/字段授权、事件模型、迁移、OpenAPI | 干净环境复现、字段越权/撤权与迁移测试 |
| 3 | 视觉 V1 | 授权采集、分组划分、OpenCV 图片/视频管线、YOLO11n 辅助定位 | 数据集 V1、辅助模型卡、固定集报告 |
| 4 | 多证据复核 | PaddleOCR 主链路、条码解码、字段抽取、候选融合、四状态、人工确认/修正 | 拍照到 `health_event` 的纵向演示，保留 before/after |
| 5 | 状态与风险 | 时间线、关系投影、过期/库存/重复/过敏/有限相互作用、告警预算 | 重建测试、规则测试、证据风险卡 |
| 6 | 照护闭环 | 计划安全时间窗、分级提醒、告警预算、照护升级、天气卡、字段授权视图、业务大屏 | 任务闭环、撤权测试、预算报告、离线降级 |
| 7 | 本地助手 | 本地 RAG、指令数据、QLoRA 对照、Ollama、工具调用、Schema、无导流门禁和红队 | 带引用回答、无证据拒答、基础/微调对照、安全报告 |
| 8 | M4 交付 | 困难样本 V2、集成回归、三档部署、性能、隐私、录屏与答辩 | V1/V2 报告、测试报告、部署包、演示证据 |

## 3. 每周节奏

- 周一：范围、风险、Story 和验收样例；
- 周二至周三：小步实现、单测和接口对齐；
- 周四：集成、失败场景、模型/规则评估；
- 周五：演示、文档、追踪矩阵、复盘和下周范围调整。

## 4. 团队分工建议

| 角色 | 主责 | 必须协作 |
|---|---|---|
| 产品/文档 | 范围、Story、追踪、答辩 | 安全边界、验收证据 |
| Web/大屏 | 十个页面、状态和证据展示 | API 契约、可访问性 |
| API/数据 | FastAPI、MySQL、授权、事件、计划 | 迁移、安全和规则 |
| 视觉 | 数据、YOLO、OpenCV、OCR、融合 | 人工复核和固定集 |
| LLM/RAG | 文档、微调、Ollama、工具与引用 | 规则、授权和红队 |
| 测试/规则/部署 | 规则集、自动测试、三档部署 | 全模块独立复核 |

一人可兼任，但成员授权、规则发布、数据/模型发布和最终验收不能仅由实现者自审。

## 5. 缩范围顺序

时间不足时依次削减：复杂图谱查询 → 天气高级规则 → 医嘱版本比较 → SKU 数量 → 有限规则数量 → LLM 训练样本规模。不得削减：本地默认不出网、成员/字段授权、事件可追溯、未知/冲突拒识、人工确认/修正、确定性规则、分级提醒、引用校验、安全拒答、固定集和回滚。

## 6. 里程碑判定

里程碑必须同时有合并代码、自动测试、人工演示和文档证据。只有页面、Notebook、训练曲线、Mock 或口头说明不能通过里程碑。
