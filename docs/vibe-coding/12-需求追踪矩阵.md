# HomeCare Twin 需求追踪矩阵

## 1. 当前基线

截至 2026-08-13，仓库已完成综合研究、产品信息架构和一期工程骨架。HCT-001、HCT-003、HCT-101、HCT-102 已合并验证；HCT-103 已完成不可变事件、补偿、幂等、outbox worker 和重放的本地/MySQL 验收。PR #128 曾误删 HCT-103/204/207/401/403/406/408 的部分迁移、测试和运行模块，当前由 [HCT-132](../stories/HCT-132-恢复后端迁移与回归证据.md)恢复并重新执行 R3 回归；修复合并前不得把受影响能力作为 HCT-405 已完成证据。视觉业务模型、数据集、规则、完整助手和 Demo 仍未交付。本矩阵只记录可验证状态，不因文档描述而把功能标为完成。阶段和 Issue 基线见[项目全生命周期开发流程](19-项目全生命周期开发流程.md)。

状态：`未开始`、`进行中`、`待验收`、`已验证`、`阻塞`、`不做`。

## 4. P0 端到端追踪

```text
FR-03 视觉任务
-> FR-03 人工复核
-> FR-02 健康事件
-> FR-04 关系投影
-> FR-05 风险与告警预算
-> FR-08 RAG/LLM 证据解释
-> FR-06 计划确认与照护升级
-> FR-10 困难样本 V2
```

任一环缺少成功与失败场景证据，P0 不得标记已验证。

## 5. 更新门禁

状态改为 `进行中` 时链接 Issue/负责人；改为 `待验收` 时链接提交/PR 和自动测试；改为 `已验证` 时再链接人工验收、版本/环境和演示证据。未提供链接的状态变更无效。
