# HomeCare Twin 需求追踪矩阵

## 1. 当前基线

截至 2026-08-04，仓库已完成综合研究、产品信息架构和一期工程骨架。视觉、数据集、模型、规则和完整 Demo 仍未交付。本矩阵只记录可验证状态，不因文档描述而把功能标为完成。

状态：`未开始`、`进行中`、`待验收`、`已验证`、`阻塞`、`不做`。

## 2. 功能需求

| 编号 | 需求 | 主要模块 | 核心验收 | 里程碑 | 状态 |
|---|---|---|---|---|---|
| FR-01 | 身份、家庭与成员级授权 | API/Web | 跨家庭拒绝、撤权立即生效、审计脱敏 | M1 | 进行中（[HCT-102](../stories/HCT-102-家庭成员与字段授权.md)） |
| FR-02 | 家庭健康事件中心 | API/DB | 追加写、补偿更正、重放恢复状态 | M1 | 进行中（[HCT-103](../stories/HCT-103-健康事件追加与状态投影.md)） |
| FR-03 | 多证据视觉录入 | Vision/Web | 四状态、未知/冲突拒识、人工确认 | M2 | 未开始 |
| FR-04 | 家庭健康关系投影 | API/DB/Web | 可从事实重建，每条边可追溯 | M2 | 未开始 |
| FR-05 | 风险规则与告警预算 | API/Safety | 已知严重零漏报、普通告警合并、证据完整 | M3 | 未开始 |
| FR-06 | 计划确认与照护升级 | API/Web | 安全时间窗、有效授权、批准可审计 | M3 | 未开始 |
| FR-07 | 环境行动卡 | API/Web | 只传城市编码、不改药物、同事件一次 | M3 | 未开始 |
| FR-08 | 本地证据型助手 | RAG/LLM/API | 工具优先、真实引用、越权/医疗拒答 | M4 | 未开始 |
| FR-09 | 家庭/模型大屏 | Web/Admin | 指标可追溯、无敏感正文 | M4 | 未开始 |
| FR-10 | 困难样本与追加训练 | Vision/Admin | 授权审核、固定集 V1/V2、可回滚 | M4 | 未开始 |

补充验收语义：FR-01 必须覆盖成员/字段/动作/目的/期限授权；FR-03 必须覆盖多渠道证据、人工修正和原预测保留；FR-05 必须覆盖四级提醒、普通预算和严重告警豁免；FR-08 必须覆盖本地不出网、完整证据和无购药/问诊/广告导流。

| NFR-03 | 全链版本与审计 | 请求 ID、事件、模型/规则/知识版本 | 进行中（[HCT-103](../stories/HCT-103-健康事件追加与状态投影.md)） |
| NFR-04 | 基础档降级可用 | Ollama/向量/天气/视觉离线 E2E | 进行中（[HCT-101](../stories/HCT-101-工程骨架与健康检查.md)） |

| NFR-06 | 实验可复现 | 固定集、哈希、种子、配置和模型卡 | 进行中（[HCT-101](../stories/HCT-101-工程骨架与健康检查.md)） |

## 4. P0 端到端追踪

```text
FR-03 视觉任务
-> FR-03 人工复核
-> FR-02 健康事件
-> FR-04 关系投影
-> FR-05 风险与告警预算
-> FR-08 RAG/LLM 证据解释
-> FR-06 计划确认与照护升级
-> FR-10 困难样本 V2
```

任一环缺少成功与失败场景证据，P0 不得标记已验证。

## 5. 更新门禁

状态改为 `进行中` 时链接 Issue/负责人；改为 `待验收` 时链接提交/PR 和自动测试；改为 `已验证` 时再链接人工验收、版本/环境和演示证据。未提供链接的状态变更无效。
