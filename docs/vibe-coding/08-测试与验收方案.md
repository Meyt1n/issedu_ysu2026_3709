# 测试与验收方案

## 1. 测试分层

| 层级 | 内容 | 门禁 |
|---|---|---|
| 静态检查 | 格式、类型、安全扫描、依赖与密钥扫描 | PR 必须通过 |
| 单元测试 | 领域规则、阈值、权限、安全分级 | 核心逻辑覆盖率目标 80% |
| 集成测试 | 数据库、对象存储、向量库、模型适配器 | 关键接口通过 |
| 契约测试 | OpenAPI、错误码、权限和兼容性 | API 变化必须通过 |
| 端到端 | MVP 六条主链路 | 发布必须通过 |
| 模型评估 | 视觉、检索、问答与安全回归集 | 达到登记基线 |
| 非功能 | 性能、并发、故障、安全与恢复 | 无阻断问题 |

## 2. 核心验收用例

### 用户与权限

- 用户只能看到本人及明确授权的家庭成员。
- 普通用户访问管理接口返回 `403`。
- 撤销授权后，API、搜索、缓存和导出均不可再访问。

### 药物识别

- 合规图片返回边界框、候选类别、置信度和模型版本。
- 模糊、遮挡、未知药物返回低置信度或拒识别。
- 恶意文件、超大图片、伪装扩展名被拒绝且无服务崩溃。

### 问答与 RAG

- 有证据的问题返回可定位引用。
- 知识库没有答案时明确“不确定”，不编造出处。
- 用户不能通过提示词访问其他用户文档。
- 高风险症状触发 S3 升级，普通问答不能覆盖该提示。
- 文档中的恶意“忽略系统规则”不会改变系统行为。

### 数据权利

- 用户可导出本人数据，导出包不含他人数据。
- 删除后业务库、对象存储、向量索引和缓存均不可检索。
- 审计保留最小删除事件但不保留被删除正文。

## 3. 性能基线

使用固定硬件和数据集记录结果：

- 普通 API：50 并发下 P95 < 800 ms。
- 单图识别：P95 < 3 s。
- RAG 问答首段：P95 < 8 s。
- 文档入库：50 页 PDF 在 5 分钟内完成或给出可观察的异步进度。
- 视频演示：达到约定抽帧率且业务 API 不被推理阻塞。

若硬件不满足，报告真实数据和瓶颈，不修改指标或伪造通过。

## 4. 发布阻断条件

- 存在越权、密钥或真实敏感数据泄露；
- S3 紧急场景不能稳定触发；
- 模型无版本、无评估或无法回滚；
- RAG 引用虚构或跨用户泄露；
- 删除功能只改界面状态、未删除派生数据；
- 关键流程失败且无明确降级；
- 测试依赖手工修改数据库或关闭安全校验。

## 5. 证据清单

每次里程碑保存测试命令和结果摘要、环境与模型版本、失败用例、性能报告、演示截图/录屏、已知限制和签字确认。缺陷使用“严重度 + 复现步骤 + 期望/实际 + 请求 ID”记录。
