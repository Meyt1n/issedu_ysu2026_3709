# 算法设计-推荐系统冷启动

> 本文档是家健镜系统推荐系统冷启动的完整设计说明，覆盖新用户冷启动、新物品冷启动、系统冷启动、解决方案。

## 1. 冷启动概述

### 1.1 问题定义

冷启动是指在缺乏用户行为数据的情况下，如何为用户提供有效的推荐。

### 1.2 冷启动类型

| 类型 | 说明 | 挑战 |
| --- | --- | --- |
| 新用户冷启动 | 新注册用户无行为数据 | 无法个性化推荐 |
| 新物品冷启动 | 新上架物品无交互数据 | 无法被推荐 |
| 系统冷启动 | 整个系统无数据 | 无法训练模型 |

## 2. 新用户冷启动

### 2.1 基于人口统计学

```python
class DemographicRecommender:
    def __init__(self, user_db, item_db):
        self.user_db = user_db
        self.item_db = item_db

    def recommend(self, new_user, top_n=10):
        # 1. 基于年龄性别匹配相似用户
        similar_users = self._find_similar_users(new_user)

        # 2. 汇总相似用户的偏好
        item_scores = {}
        for user in similar_users:
            for item, rating in user.preferences.items():
                if item not in item_scores:
                    item_scores[item] = 0
                item_scores[item] += rating

        # 3. 排序推荐
        sorted_items = sorted(item_scores.items(), key=lambda x: x[1], reverse=True)
        return [item for item, _ in sorted_items[:top_n]]

    def _find_similar_users(self, new_user):
        # 年龄 + 性别 + 地区匹配
        return [
            user for user in self.user_db
            if abs(user.age - new_user.age) <= 5
            and user.gender == new_user.gender
            and user.region == new_user.region
        ][:100]
```

### 2.2 基于健康档案

```python
class HealthProfileRecommender:
    def recommend(self, user_profile, top_n=10):
        scores = {}

        # 1. 基于疾病推荐
        for condition in user_profile.medical_conditions:
            related_items = self._get_items_for_condition(condition)
            for item in related_items:
                scores[item] = scores.get(item, 0) + 3

        # 2. 基于过敏史排除
        for allergy in user_profile.allergies:
            related_items = self._get_items_with_ingredient(allergy)
            for item in related_items:
                scores[item] = -100  # 排除

        # 3. 基于年龄推荐
        age_items = self._get_items_for_age_group(user_profile.age)
        for item in age_items:
            scores[item] = scores.get(item, 0) + 1

        # 排序
        sorted_items = sorted(scores.items(), key=lambda x: x[1], reverse=True)
        return [item for item, score in sorted_items if score > 0][:top_n]
```

## 3. 新物品冷启动

### 3.1 基于内容相似度

```python
class ContentBasedColdStart:
    def __init__(self, item_features, similarity_model):
        self.item_features = item_features
        self.similarity_model = similarity_model

    def recommend_similar(self, new_item, top_n=10):
        # 计算新物品与现有物品的相似度
        new_feature = self.item_features.get(new_item.id)
        similarities = {}

        for item_id, feature in self.item_features.items():
            if item_id == new_item.id:
                continue
            sim = self.similarity_model.calculate(new_feature, feature)
            similarities[item_id] = sim

        # 返回最相似的物品
        sorted_sims = sorted(similarities.items(), key=lambda x: x[1], reverse=True)
        return [item_id for item_id, _ in sorted_sims[:top_n]]
```

### 3.2 基于属性匹配

```python
class AttributeBasedColdStart:
    def recommend_for_new_item(self, new_item, users, top_n=100):
        # 根据物品属性匹配可能感兴趣的用户
        candidate_users = []

        for user in users:
            score = 0
            # 类别匹配
            if new_item.category in user.preferred_categories:
                score += 2
            # 标签匹配
            common_tags = set(new_item.tags) & set(user.preferred_tags)
            score += len(common_tags)
            # 价格匹配
            if user.price_range[0] <= new_item.price <= user.price_range[1]:
                score += 1

            if score > 0:
                candidate_users.append((user.id, score))

        candidate_users.sort(key=lambda x: x[1], reverse=True)
        return [user_id for user_id, _ in candidate_users[:top_n]]
```

### 3.3 探索与利用

```python
class EpsilonGreedy:
    def __init__(self, epsilon=0.1):
        self.epsilon = epsilon

    def select(self, item_scores):
        if random.random() < self.epsilon:
            # 探索：随机选择
            return random.choice(list(item_scores.keys()))
        else:
            # 利用：选择最优
            return max(item_scores, key=item_scores.get)
```

### 4.2 专家规则

```python
class RuleBasedRecommender:
    def __init__(self, rules):
        self.rules = rules

    def recommend(self, user_context):
        scores = {}
        for rule in self.rules:
            if rule.matches(user_context):
                for item, weight in rule.recommendations:
                    scores[item] = scores.get(item, 0) + weight

        sorted_items = sorted(scores.items(), key=lambda x: x[1], reverse=True)
        return [item for item, _ in sorted_items]
```

## 5. 冷启动过渡

### 5.1 渐进式切换

```python
class HybridRecommender:
    def __init__(self, cold_start_model, collaborative_model):
        self.cold_start = cold_start_model
        self.collaborative = collaborative_model

    def recommend(self, user, top_n=10):
        interaction_count = user.interaction_count

        if interaction_count < 5:
            # 纯冷启动
            return self.cold_start.recommend(user, top_n)
        elif interaction_count < 20:
            # 混合推荐
            cold_results = self.cold_start.recommend(user, top_n)
            collab_results = self.collaborative.recommend(user, top_n)
            return self._merge(cold_results, collab_results, ratio=0.7)
        else:
            # 协同过滤
            return self.collaborative.recommend(user, top_n)
```
