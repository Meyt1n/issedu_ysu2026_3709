# 算法设计-数据同步与冲突解决

> 本文档是家健镜系统多端数据同步与冲突解决算法的完整设计说明，覆盖同步协议、冲突检测、合并策略、一致性保障。

## 1. 同步概述

### 1.1 目标

实现多端（APP、家庭服务器、云端）数据实时同步，支持离线操作，保证数据最终一致性。

### 1.2 同步架构

```
APP (离线可用)
    │
    │ 增量同步
    ▼
家庭服务器 (主数据)
    │
    │ 云端备份
    ▼
云端 (灾备)
```

### 1.3 同步策略

| 策略 | 说明 | 适用场景 |
| --- | --- | --- |
| 增量同步 | 只同步变更 | 常规同步 |
| 全量同步 | 同步所有数据 | 首次同步/恢复 |
| 实时同步 | 变更立即同步 | 重要数据 |
| 定时同步 | 定期批量同步 | 非重要数据 |

### 2.2 同步握手

```python
class SyncProtocol:
    async def sync(self, client_state, server_state):
        # 1. 比较版本向量
        missing_on_client = self._get_missing(
            server_state, client_state
        )
        missing_on_server = self._get_missing(
            client_state, server_state
        )

        # 2. 推送客户端变更
        if missing_on_server:
            await self._push_changes(missing_on_server)

        # 3. 拉取服务端变更
        if missing_on_client:
            server_changes = await self._pull_changes(missing_on_client)

        # 4. 冲突检测与合并
        conflicts = self._detect_conflicts(
            missing_on_client, missing_on_server
        )
        resolved = self._resolve_conflicts(conflicts)

        # 5. 更新版本向量
        new_version = self._merge_versions(
            client_state.version, server_state.version
        )

        return {
            "changes_applied": len(missing_on_client) + len(missing_on_server),
            "conflicts_resolved": len(resolved),
            "new_version": new_version,
        }
```

## 3. 版本向量

### 3.1 版本向量实现

```python
class VersionVector:
    def __init__(self, versions=None):
        self.versions = versions or {}

    def increment(self, device_id):
        self.versions[device_id] = self.versions.get(device_id, 0) + 1

    def compare(self, other):
        a_greater = False
        b_greater = False

        all_devices = set(self.versions.keys()) | set(other.versions.keys())
        for device in all_devices:
            a = self.versions.get(device, 0)
            b = other.versions.get(device, 0)
            if a > b:
                a_greater = True
            elif b > a:
                b_greater = True

        if a_greater and not b_greater:
            return "greater"
        elif b_greater and not a_greater:
            return "less"
        elif a_greater and b_greater:
            return "conflict"
        else:
            return "equal"

    def merge(self, other):
        merged = VersionVector()
        all_devices = set(self.versions.keys()) | set(other.versions.keys())
        for device in all_devices:
            merged.versions[device] = max(
                self.versions.get(device, 0),
                other.versions.get(device, 0),
            )
        return merged
```

## 4. 冲突检测

### 4.1 冲突类型

| 类型 | 说明 | 检测方式 |
| --- | --- | --- |
| 更新-更新 | 两端同时修改同一字段 | 版本向量比较 |
| 更新-删除 | 一端更新，一端删除 | 版本向量比较 |
| 删除-删除 | 两端同时删除 | 版本向量比较 |

### 4.2 冲突检测算法

```python
class ConflictDetector:
    def detect(self, local_changes, remote_changes):
        conflicts = []

        local_map = {c.entity_id: c for c in local_changes}
        remote_map = {c.entity_id: c for c in remote_changes}

        for entity_id in set(local_map.keys()) & set(remote_map.keys()):
            local = local_map[entity_id]
            remote = remote_map[entity_id]

            # 比较版本向量
            relation = local.version.compare(remote.version)
            if relation == "conflict":
                conflicts.append({
                    "entity_id": entity_id,
                    "local_change": local,
                    "remote_change": remote,
                    "type": self._classify_conflict(local, remote),
                })

        return conflicts

    def _classify_conflict(self, local, remote):
        if local.operation == "update" and remote.operation == "update":
            return "update-update"
        elif local.operation == "update" and remote.operation == "delete":
            return "update-delete"
        elif local.operation == "delete" and remote.operation == "update":
            return "delete-update"
        else:
            return "delete-delete"
```

## 5. 冲突解决

### 5.1 解决策略

| 策略 | 说明 | 适用场景 |
| --- | --- | --- |
| Last-Write-Wins | 最后修改的胜出 | 简单场景 |
| 服务端优先 | 服务端数据优先 | 权威数据 |
| 客户端优先 | 客户端数据优先 | 用户输入 |
| 字段级合并 | 逐字段合并 | 复杂对象 |
| 人工解决 | 用户手动选择 | 重要数据 |

### 5.2 字段级合并

```python
class FieldLevelMerger:
    def merge(self, local_data, remote_data, base_data):
        merged = dict(base_data)

        all_fields = set(local_data.keys()) | set(remote_data.keys())

        for field in all_fields:
            local_val = local_data.get(field)
            remote_val = remote_data.get(field)
            base_val = base_data.get(field)

            local_changed = local_val != base_val
            remote_changed = remote_val != base_val

            if local_changed and not remote_changed:
                merged[field] = local_val
            elif remote_changed and not local_changed:
                merged[field] = remote_val
            elif local_changed and remote_changed:
                # 双方都修改，使用最后修改时间
                if local_data.get("_updated_at", 0) > remote_data.get("_updated_at", 0):
                    merged[field] = local_val
                else:
                    merged[field] = remote_val
            else:
                merged[field] = base_val

        return merged
```

### 5.3 自动解决

```python
class ConflictResolver:
    def __init__(self, strategy="field_level"):
        self.strategy = strategy

    def resolve(self, conflict):
        if self.strategy == "lww":
            return self._last_write_wins(conflict)
        elif self.strategy == "server":
            return conflict["remote_change"]
        elif self.strategy == "field_level":
            return self._field_level_merge(conflict)
        elif self.strategy == "manual":
            return None  # 需要人工解决

    def _last_write_wins(self, conflict):
        local_time = conflict["local_change"].timestamp
        remote_time = conflict["remote_change"].timestamp
        if local_time > remote_time:
            return conflict["local_change"]
        return conflict["remote_change"]
```

## 6. 一致性保障

### 6.1 最终一致性

- 所有变更最终会同步到所有端
- 冲突解决后数据一致
- 定期全量校验

### 6.2 校验机制

```python
class ConsistencyChecker:
    async def check_consistency(self, client_data, server_data):
        inconsistencies = []

        for entity_id in set(client_data.keys()) | set(server_data.keys()):
            client_hash = self._hash(client_data.get(entity_id))
            server_hash = self._hash(server_data.get(entity_id))

            if client_hash != server_hash:
                inconsistencies.append({
                    "entity_id": entity_id,
                    "client_hash": client_hash,
                    "server_hash": server_hash,
                })

        return inconsistencies

    def _hash(self, data):
        if data is None:
            return None
        import hashlib
        return hashlib.md5(
            json.dumps(data, sort_keys=True).encode()
        ).hexdigest()
```
