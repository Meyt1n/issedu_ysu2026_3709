# 算法设计-健康风险评估

> 本文档是家健镜系统健康风险评估算法的完整设计说明，覆盖风险因子、评估模型、风险分级、预警机制。

## 1. 算法概述

### 1.1 目标

基于家庭成员的健康数据、用药记录、体征数据，综合评估健康风险，提前预警潜在健康问题。

### 1.2 风险维度

| 维度 | 说明 | 数据来源 |
| --- | --- | --- |
| 用药风险 | 用药冲突、漏服、过量 | 用药记录 |
| 体征风险 | 血压、血糖、心率异常 | 体征记录 |
| 生活风险 | 作息、饮食、运动 | 行为记录 |
| 疾病风险 | 慢性病管理、并发症 | 健康档案 |
| 环境风险 | 天气、空气质量 | 外部数据 |

## 2. 风险因子

### 2.1 用药风险因子

| 因子 | 说明 | 权重 |
| --- | --- | --- |
| 严重用药冲突 | 成分重复/相互作用 | 0.3 |
| 频繁漏服 | 漏服率 > 30% | 0.2 |
| 自行调整剂量 | 未遵医嘱调整 | 0.15 |
| 药品过期使用 | 使用过期药品 | 0.15 |
| 多药联用 | 同时使用 >5 种药品 | 0.1 |
| 用药不规律 | 服药时间偏差大 | 0.1 |

### 2.2 体征风险因子

| 因子 | 说明 | 阈值 |
| --- | --- | --- |
| 高血压 | 收缩压 > 140 或舒张压 > 90 | 持续 3 天 |
| 高血糖 | 空腹血糖 > 7.0 | 持续 3 天 |
| 心率异常 | 静息心率 > 100 或 < 50 | 持续 3 天 |
| 体重异常变化 | 月变化 > 5% | - |
| 体温异常 | 体温 > 37.3 | 即时 |

## 3. 评估模型

### 3.1 加权评分模型

```python
class HealthRiskAssessor:
    def __init__(self):
        self.factor_weights = {
            "medication_conflict": 0.25,
            "medication_adherence": 0.15,
            "vital_abnormality": 0.25,
            "chronic_management": 0.15,
            "lifestyle": 0.10,
            "environment": 0.10,
        }

    def assess(self, member_data):
        scores = {}

        # 用药冲突评分
        scores["medication_conflict"] = self._assess_medication_conflict(
            member_data.medicines
        )

        # 用药依从性评分
        scores["medication_adherence"] = self._assess_adherence(
            member_data.medication_records
        )

        # 体征异常评分
        scores["vital_abnormality"] = self._assess_vitals(
            member_data.vital_records
        )

        # 慢性病管理评分
        scores["chronic_management"] = self._assess_chronic(
            member_data.conditions
        )

        # 生活方式评分
        scores["lifestyle"] = self._assess_lifestyle(
            member_data.lifestyle
        )

        # 环境风险评分
        scores["environment"] = self._assess_environment(
            member_data.location
        )

        # 加权总分
        total_score = sum(
            scores[factor] * self.factor_weights[factor]
            for factor in scores
        )

        return {
            "total_score": round(total_score, 2),
            "level": self._get_level(total_score),
            "factor_scores": scores,
            "top_risks": self._get_top_risks(scores),
        }

    def _get_level(self, score):
        if score >= 80:
            return "critical"
        elif score >= 60:
            return "high"
        elif score >= 40:
            return "medium"
        elif score >= 20:
            return "low"
        else:
            return "safe"
```

### 3.2 用药依从性评估

```python
    def _assess_adherence(self, records):
        if not records:
            return 50  # 无数据，中等风险

        total = len(records)
        taken = sum(1 for r in records if r.status == "taken")
        adherence_rate = taken / total

        if adherence_rate >= 0.9:
            return 10  # 依从性好
        elif adherence_rate >= 0.7:
            return 30  # 依从性一般
        elif adherence_rate >= 0.5:
            return 60  # 依从性差
        else:
            return 90  # 依从性很差
```

### 3.3 体征异常评估

```python
    def _assess_vitals(self, records):
        if not records:
            return 20  # 无数据，低风险

        risk_score = 0
        recent_records = records[-30:]  # 最近 30 天

        # 血压异常
        bp_abnormal = sum(
            1 for r in recent_records
            if r.type == "blood_pressure"
            and (r.systolic > 140 or r.diastolic > 90)
        )
        if bp_abnormal >= 3:
            risk_score += 30

        # 血糖异常
        bg_abnormal = sum(
            1 for r in recent_records
            if r.type == "blood_glucose" and r.value > 7.0
        )
        if bg_abnormal >= 3:
            risk_score += 30

        # 心率异常
        hr_abnormal = sum(
            1 for r in recent_records
            if r.type == "heart_rate"
            and (r.value > 100 or r.value < 50)
        )
        if hr_abnormal >= 3:
            risk_score += 20

        return min(risk_score, 100)
```

## 4. 趋势分析

### 4.1 风险趋势

```python
class RiskTrendAnalyzer:
    def analyze_trend(self, historical_scores):
        if len(historical_scores) < 7:
            return "insufficient_data"

        recent_avg = sum(historical_scores[-7:]) / 7
        previous_avg = sum(historical_scores[-14:-7]) / 7

        change = recent_avg - previous_avg
        if change > 10:
            return "worsening"
        elif change < -10:
            return "improving"
        else:
            return "stable"
```

### 5.2 预警去重

```python
class AlertDeduplicator:
    def __init__(self, redis):
        self.redis = redis

    async def should_alert(self, member_id, risk_type, level):
        key = f"alert:{member_id}:{risk_type}:{level}"
        exists = await self.redis.get(key)
        if exists:
            return False

        # 设置冷却期
        cooldown = {
            "critical": 3600,      # 1 小时
            "high": 86400,         # 1 天
            "medium": 604800,      # 1 周
        }.get(level, 86400)

        await self.redis.setex(key, cooldown, "1")
        return True
```
