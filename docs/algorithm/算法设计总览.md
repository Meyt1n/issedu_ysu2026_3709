### 1.3 设计原则

1. **隐私优先**：敏感数据本地处理，不上传公网
2. **渐进式**：先规则后模型，先简单后复杂
3. **可解释**：算法结果有明确依据
4. **可评估**：每个算法有量化指标
5. **可回滚**：模型版本可管理，支持降级
6. **低成本**：优先轻量模型，降低硬件要求

## 2. 视觉算法

### 2.1 OCR 文字识别

**目标**：从药盒图片中提取药品名称、规格、厂家、批号、有效期等文字信息。

**方案选型**：

| 方案 | 准确率 | 速度 | 资源占用 | 适用场景 |
| --- | --- | --- | --- | --- |
| PaddleOCR | 高 | 中 | 高 | 服务器端 |
| Tesseract | 中 | 快 | 低 | 低端设备 |
| 云端 OCR API | 最高 | 中 | 无 | 有网络时 |

**处理流程**：
1. 图像预处理（去噪、二值化、倾斜校正）
2. 文字检测（DB 算法）
3. 文字识别（CRNN 算法）
4. 后处理（纠错、结构化提取）

**评估指标**：
- 字符准确率（Character Accuracy）≥ 95%
- 字段准确率（Field Accuracy）≥ 90%
- 单张处理时间 < 2s

### 2.2 条码识别

**目标**：识别药盒上的条形码和二维码，获取药品唯一标识。

**方案**：
- 库：pyzbar / OpenCV / ZXing
- 支持类型：EAN-13、Code128、QR Code
- 处理时间 < 500ms

### 2.3 包装识别

**目标**：通过药盒外观图像匹配药品数据库，辅助 OCR 结果。

**方案**：
- 特征提取：ResNet50 / EfficientNet
- 相似度计算：余弦相似度
- 检索方式：向量数据库（FAISS）

**意图分类**：

### 4.2 风险评分

```python
class RiskScorer:
    def calculate_score(self, member_state: MemberState) -> RiskScore:
        scores = {}

        # 用药风险
        scores["medication"] = self._medication_risk(member_state)
        # 过敏风险
        scores["allergy"] = self._allergy_risk(member_state)
        # 体征风险
        scores["vital"] = self._vital_risk(member_state)
        # 依从性风险
        scores["adherence"] = self._adherence_risk(member_state)

        # 加权汇总
        weights = {
            "medication": 0.3,
            "allergy": 0.3,
            "vital": 0.25,
            "adherence": 0.15,
        }
        total = sum(scores[k] * weights[k] for k in scores)

        return RiskScore(
            total=total,
            breakdown=scores,
            level=self._score_to_level(total),
        )

    def _score_to_level(self, score: float) -> str:
        if score >= 80:
            return "severe"
        elif score >= 60:
            return "high"
        elif score >= 40:
            return "medium"
        else:
            return "low"
```

## 5. 数据分析算法

### 5.1 趋势预测

```python
class VitalTrendPredictor:
    def predict(self, history: list[VitalRecord], days: int = 7) -> list[float]:
        if len(history) < 3:
            return []

        # 简单线性回归
        values = [v.value for v in history]
        times = list(range(len(values)))

        slope, intercept = self._linear_regression(times, values)

        predictions = []
        for i in range(1, days + 1):
            predictions.append(slope * (len(values) + i) + intercept)

        return predictions

    def _linear_regression(self, x: list[float], y: list[float]):
        n = len(x)
        sum_x = sum(x)
        sum_y = sum(y)
        sum_xy = sum(xi * yi for xi, yi in zip(x, y))
        sum_x2 = sum(xi * xi for xi in x)

        slope = (n * sum_xy - sum_x * sum_y) / (n * sum_x2 - sum_x * sum_x)
        intercept = (sum_y - slope * sum_x) / n
        return slope, intercept
```

### 5.2 异常检测

```python
class AnomalyDetector:
    def detect(self, value: float, history: list[float]) -> AnomalyResult:
        if len(history) < 10:
            return AnomalyResult(is_anomaly=False, reason="数据不足")

        mean = sum(history) / len(history)
        variance = sum((x - mean) ** 2 for x in history) / len(history)
        std = variance ** 0.5

        z_score = abs(value - mean) / std if std > 0 else 0

        if z_score > 3:
            return AnomalyResult(
                is_anomaly=True,
                severity="high",
                reason=f"数值偏离均值 {z_score:.1f} 个标准差",
            )
        elif z_score > 2:
            return AnomalyResult(
                is_anomaly=True,
                severity="medium",
                reason=f"数值偏离均值 {z_score:.1f} 个标准差",
            )

        return AnomalyResult(is_anomaly=False)
```

```python
class ModelEvaluator:
    def evaluate(self, model: ModelVersion, test_set: TestSet) -> EvalResult:
        predictions = []
        for sample in test_set.samples:
            pred = model.infer(sample.input)
            predictions.append((sample, pred))

        return EvalResult(
            accuracy=self._calc_accuracy(predictions),
            precision=self._calc_precision(predictions),
            recall=self._calc_recall(predictions),
            f1=self._calc_f1(predictions),
            latency=self._measure_latency(model, test_set),
        )
```

### 6.3 灰度发布

```python
class ModelRollout:
    def __init__(self):
        self.routes = {}  # model_id -> percentage

    def route(self, request: InferRequest) -> str:
        # 根据用户 ID 哈希分配
        user_hash = hash(request.user_id) % 100
        cumulative = 0
        for model_id, percentage in self.routes.items():
            cumulative += percentage
            if user_hash < cumulative:
                return model_id
        return self.default_model
```
