# ADR-004: 风险引擎采用规则化方案

## 状态

已采纳

## 背景

家健镜系统需要识别家庭成员的健康风险，如过敏冲突、药品过期、重复成分等。可以选择规则引擎或机器学习模型来实现。

## 决策

风险引擎采用规则化方案，而非机器学习模型：

1. **显式规则**：每条风险有明确的规则定义
2. **可解释**：风险触发有明确原因和证据
3. **可配置**：规则可调整，无需重新训练
4. **预算控制**：风险提醒有数量限制，避免打扰

## 理由

### 为什么选择规则化

1. **可解释性**：健康风险需要明确原因，用户需要知道为什么
2. **准确性**：规则在明确场景下准确率 100%
3. **可维护**：规则可由非算法人员配置和调整
4. **可测试**：每条规则有明确的测试用例
5. **低延迟**：规则匹配速度快，无需模型推理
6. **合规**：医疗健康领域需要可解释的决策

### 为什么不选择机器学习

1. **数据不足**：健康风险标注数据有限
2. **黑盒问题**：模型决策难以解释
3. **误报代价高**：健康风险误报可能导致严重后果
4. **维护成本**：模型需要持续训练和监控

## 后果

### 正面

- 风险可解释
- 规则可配置
- 准确率高
- 易于测试
- 延迟低

### 负面

- 无法发现未知模式
- 规则维护成本随数量增加
- 复杂场景规则编写困难

## 替代方案

1. **机器学习模型**：可发现未知模式，但可解释性差
2. **规则 + 模型混合**：规则处理明确场景，模型处理模糊场景，复杂度高
3. **纯人工审核**：准确但效率低，无法实时

## 实施要点

- 规则有版本管理
- 规则变更需要评审
- 规则有单元测试
- 规则触发有日志
- 规则效果有监控

---

*ADR-004 记录了风险引擎规则化决策，为健康风险的可解释和准确性提供基础。*
