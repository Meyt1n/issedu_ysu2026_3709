# ADR-005: 视觉识别采用多模态融合方案

## 状态

已采纳

## 背景

家健镜系统需要识别药盒图片，提取药品信息。单一识别方式（OCR 或条码）在某些场景下准确率不足。

## 决策

视觉识别采用多模态融合方案：

1. **OCR 识别**：提取药盒文字信息
2. **条码识别**：扫描条形码/二维码
3. **包装识别**：匹配药品包装图像
4. **结果融合**：综合三种结果，提高准确率
5. **人工复核**：低置信度结果进入人工复核

## 理由

### 为什么选择多模态融合

1. **准确率高**：多种方式互补，降低单一方式的错误率
2. **鲁棒性强**：一种方式失败时其他方式可补充
3. **覆盖广**：不同包装、不同角度都能识别
4. **置信度高**：多种方式一致时置信度高

### 各模态作用

- **OCR**：主力，提取药品名、规格、厂家
- **条码**：高置信度，直接匹配药品数据库
- **包装识别**：辅助，OCR 模糊时提供参考

## 后果

### 正面

- 识别准确率高
- 鲁棒性强
- 置信度可评估

### 负面

- 系统复杂度高
- 处理时间较长
- 需要维护多个模型

## 替代方案

1. **纯 OCR**：简单但准确率有限
2. **纯条码**：需要清晰条码，不是所有药盒都有
3. **云端识别 API**：准确率高但隐私风险大、依赖网络

## 实施要点

- 各模态独立运行，结果融合
- 融合有置信度评分
- 高置信度自动确认
- 低置信度人工复核
- 识别结果有日志和质量监控

---

*ADR-005 记录了视觉识别多模态融合决策，为药品识别的准确性和鲁棒性提供基础。*
