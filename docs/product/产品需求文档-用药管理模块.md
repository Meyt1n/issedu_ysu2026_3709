# 产品需求文档-用药管理模块

> 本文档是家健镜系统用药管理模块的产品需求说明，覆盖功能需求、用户故事、交互流程、验收标准。面向产品经理、开发者和测试人员，作为用药管理模块的权威依据。

## 1. 模块概述

### 1.1 目标

帮助家庭成员管理药品信息、用药计划和服药记录，确保按时按量服药，减少用药错误。

### 1.2 用户角色

| 角色 | 权限 |
| --- | --- |
| 家庭管理员 | 全部权限 |
| 普通成员 | 查看和管理自己的药品 |
| 照护者 | 查看和管理被照护者的药品 |

### 1.3 功能清单

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 药品录入 | 手动/拍照录入药品 | P0 |
| 药品列表 | 查看所有药品 | P0 |
| 药品详情 | 查看药品详细信息 | P0 |
| 用药计划 | 设置用药时间和剂量 | P0 |
| 用药提醒 | 到点推送提醒 | P0 |
| 服药记录 | 记录服药情况 | P0 |
| 库存管理 | 药品库存和临期提醒 | P1 |
| 用药统计 | 依从性统计 | P1 |
| 药品搜索 | 搜索药品库 | P2 |

## 2. 用户故事

### 2.1 药品录入

**作为**家庭成员，**我想要**通过拍照快速录入药品，**以便**节省手动输入的时间。

**验收标准：**
- 支持拍照或从相册选择图片
- 自动识别药品名称、规格、厂家
- 识别结果可编辑确认
- 识别失败可手动录入
- 录入后自动保存到药品列表

### 2.2 用药计划

**作为**家庭成员，**我想要**为药品设置用药计划，**以便**系统按时提醒我服药。

**验收标准：**
- 可设置每日用药次数（1-6次）
- 可设置每次用药时间
- 可设置每次用药剂量
- 可设置用药周期（长期/指定天数）
- 可设置饭前/饭后
- 保存后自动创建提醒

### 2.3 用药提醒

**作为**家庭成员，**我想要**在用药时间收到提醒，**以便**不会忘记服药。

**验收标准：**
- 到点推送本地通知
- 通知显示药品名和剂量
- 通知有"已服用"和"稍后提醒"按钮
- 点击"已服用"记录服药
- 点击"稍后提醒"10分钟后再次提醒
- 漏服后记录漏服事件

### 2.4 服药记录

**作为**家庭成员，**我想要**查看服药记录，**以便**了解自己的用药依从性。

**验收标准：**
- 按日期查看服药记录
- 显示已服/漏服/延迟状态
- 可补录服药记录
- 可导出服药记录

## 3. 交互流程

### 3.1 药品录入流程

```
用户点击"添加药品"
    ↓
选择录入方式：拍照 / 手动
    ↓
拍照：调用相机 → 上传图片 → 识别中...
    ↓
显示识别结果（可编辑）
    ↓
用户确认 → 保存成功
    ↓
跳转到药品详情
```

### 3.2 用药提醒流程

```
到达用药时间
    ↓
推送通知
    ↓
用户点击通知
    ↓
打开 APP 显示用药确认页
    ↓
用户选择：已服用 / 稍后提醒 / 跳过
    ↓
已服用 → 记录服药 → 显示成功
稍后提醒 → 10分钟后再次提醒
跳过 → 记录漏服 → 显示风险提示
```

## 4. 页面设计

### 4.1 药品列表页

**布局：**
- 顶部：搜索栏 + 筛选按钮
- 中部：药品卡片列表（按名称排序）
- 底部：添加按钮（FAB）

**药品卡片：**
- 药品图标
- 药品名称
- 剂量和频率
- 库存状态（充足/不足/过期）
- 下一次用药时间

### 4.2 药品详情页

**布局：**
- 顶部：药品图片/图标 + 名称
- 基本信息：规格、厂家、有效期、库存
- 用药计划：时间列表
- 服药记录：最近 7 天
- 操作按钮：编辑、删除、设置提醒

### 4.3 添加药品页

**布局：**
- 拍照区域
- 表单：名称、规格、剂量、频率、时间、有效期、库存
- 保存按钮

## 5. 数据模型

### 5.1 药品

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 药品 ID |
| member_id | UUID | 所属成员 |
| name | String | 药品名称 |
| specification | String | 规格 |
| manufacturer | String | 生产厂家 |
| dosage | String | 单次剂量 |
| frequency | String | 服用频率 |
| times | List<Time> | 用药时间列表 |
| expiry_date | Date | 有效期 |
| stock | Int | 库存数量 |
| notes | String | 备注 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |

### 5.2 服药记录

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 记录 ID |
| medicine_id | UUID | 药品 ID |
| scheduled_time | DateTime | 计划时间 |
| taken_time | DateTime? | 实际服药时间 |
| status | Enum | 已服/漏服/延迟/跳过 |
| notes | String | 备注 |

## 6. 验收标准

### 6.1 功能验收

- [ ] 药品拍照识别准确率 ≥ 85%
- [ ] 用药提醒准时到达（误差 < 1 分钟）
- [ ] 服药记录准确无误
- [ ] 库存不足时正确提醒
- [ ] 药品过期时正确标记

### 6.2 性能验收

- [ ] 药品列表加载 < 1s
- [ ] 拍照识别 < 3s
- [ ] 页面切换流畅

### 6.3 兼容性验收

- [ ] iOS 14+ 正常运行
- [ ] Android 8+ 正常运行
- [ ] 不同屏幕尺寸适配
- [ ] 深色模式正常

## 7. 非功能需求

- 药品数据加密存储
- 提醒不泄露敏感信息（通知只显示"该服药了"）
- 支持离线查看药品列表
- 支持多设备同步

---

*用药管理是健康照护的核心。简单、准确、贴心的用药管理，让每一次服药都安心。*
