# 产品需求文档-健康助手模块

> 本文档是家健镜系统健康助手模块的产品需求说明，覆盖对话功能、知识问答、用药咨询、健康建议。面向产品经理、开发者和测试人员，作为健康助手模块的权威依据。

## 1. 模块概述

### 1.1 目标

提供智能健康对话助手，回答健康问题、提供用药咨询、给出健康建议，成为家庭的健康顾问。

### 1.2 能力范围

| 能力 | 说明 |
| --- | --- |
| 健康问答 | 基于知识库回答健康问题 |
| 用药咨询 | 药品用法、副作用、相互作用 |
| 症状咨询 | 常见症状的健康建议 |
| 健康科普 | 健康知识科普 |
| 用药提醒 | 对话式设置和管理提醒 |
| 体征记录 | 对话式记录体征 |

### 1.3 能力边界

**可以做：**
- 提供健康信息和科普
- 查询药品说明书
- 给出一般性健康建议
- 提醒就医

**不可以做：**
- 医疗诊断
- 开具处方
- 推荐具体药品购买
- 处理紧急医疗情况

## 2. 用户故事

### 2.1 健康问答

**作为**家庭成员，**我想要**向健康助手提问，**以便**获取健康知识。

**验收标准：**
- 支持文字输入
- 回答基于知识库
- 回答有引用来源
- 不知道的问题如实告知
- 不提供医疗诊断

### 2.2 用药咨询

**作为**家庭成员，**我想要**咨询药品相关问题，**以便**安全用药。

**验收标准：**
- 可查询药品用法用量
- 可查询药品副作用
- 可查询药品相互作用
- 可查询药品禁忌
- 建议咨询医生或药师

### 2.3 对话式记录

**作为**家庭成员，**我想要**通过对话记录体征，**以便**更方便地记录健康数据。

**验收标准：**
- 识别"我血压 120/80"等自然语言
- 自动提取体征类型和数值
- 确认后保存记录
- 给出健康反馈

### 2.4 多轮对话

**作为**家庭成员，**我想要**进行多轮对话，**以便**深入讨论健康问题。

**验收标准：**
- 支持上下文理解
- 支持追问
- 对话历史可查看
- 可开始新对话

## 3. 交互设计

### 3.1 对话界面

**布局：**
- 顶部：助手头像 + 名称 + 在线状态
- 中部：消息列表（用户右对齐，助手左对齐）
- 底部：输入框 + 发送按钮 + 语音按钮

**消息类型：**
- 文本消息
- 卡片消息（药品信息、风险提醒）
- 操作按钮（确认、查看详情）
- 引用来源

### 3.2 输入方式

- 文字输入
- 语音输入（可选）
- 快捷问题推荐
- 图片上传（药品图片识别）

### 3.3 回复样式

```
┌─────────────────────────────┐
│ 阿莫西林怎么吃？              │ ← 用户
└─────────────────────────────┘

┌─────────────────────────────┐
│ 阿莫西林一般用法：            │ ← 助手
│ 成人每次 0.5g，每 6-8 小时一次│
│ 每日剂量不超过 4g            │
│                             │
│ 参考：[阿莫西林说明书]       │
│                             │
│ ⚠️ 以上信息仅供参考，具体用  │
│ 药请遵医嘱。                 │
└─────────────────────────────┘
```

## 4. 安全与合规

### 4.1 免责声明

- 每次对话开始显示免责声明
- 医疗相关回答末尾加免责提示
- 紧急症状建议拨打 120

### 4.2 内容审核

- 不提供医疗诊断
- 不推荐具体药品
- 不处理精神类疾病咨询
- 敏感话题引导就医

### 4.3 隐私保护

- 对话内容加密存储
- 用户可删除对话记录
- 不用于训练模型（除非用户同意）
- 数据不出本地服务器

## 5. 验收标准

### 5.1 功能验收

- [ ] 健康问答准确
- [ ] 用药咨询准确
- [ ] 引用来源正确
- [ ] 多轮对话上下文正确
- [ ] 对话式记录正常
- [ ] 免责声明显示
- [ ] 不提供医疗诊断

### 5.2 性能验收

- [ ] 首字响应 < 2s
- [ ] 完整回答 < 10s
- [ ] 支持流式输出

## 6. 非功能需求

- 支持离线基础问答
- 支持语音输入（可选）
- 对话历史可搜索
- 可导出对话记录
