# 产品需求文档-健康评估与风险预测模块

> 本文档是家健镜系统健康评估与风险预测模块的完整产品需求说明，覆盖健康评分、风险评估、趋势预测、个性化建议、报告生成。

## 1. 概述

### 1.1 产品目标

1. 健康状况量化评估
2. 疾病风险提前预警
3. 健康趋势科学预测
4. 个性化健康建议
5. 专业健康报告

### 1.2 评估维度

| 维度 | 指标 | 权重 |
| --- | --- | --- |
| 生理指标 | 血压、血糖、心率、BMI | 40% |
| 生活方式 | 运动、饮食、睡眠、吸烟饮酒 | 30% |
| 用药情况 | 用药依从性、药物相互作用 | 15% |
| 心理状态 | 压力、情绪、睡眠质量 | 15% |

## 3. 用户故事

### 3.1 患者视角

**US-001：查看健康评分**
作为用户，我希望查看我的健康评分，这样能了解自己的整体健康状况。

验收标准：
- 显示 0-100 分综合评分
- 显示各维度评分
- 显示评分等级（优秀/良好/一般/较差）
- 显示与上次评分对比
- 显示评分变化趋势图

**US-002：了解疾病风险**
作为用户，我希望了解我的疾病风险，这样能提前预防。

验收标准：
- 显示常见疾病风险等级
- 显示主要风险因素
- 显示风险变化趋势
- 高风险有预警提示
- 提供预防建议

**US-003：获取个性化建议**
作为用户，我希望获取个性化健康建议，这样能改善健康状况。

验收标准：
- 建议基于个人数据
- 建议具体可执行
- 按优先级排序
- 有预期效果说明
- 可设置提醒执行

### 3.2 医生视角

**US-004：查看患者健康评估**
作为医生，我希望查看患者的健康评估报告，这样能快速了解患者状况。

验收标准：
- 可查看患者综合评分
- 可查看各维度详情
- 可查看风险评估
- 可查看历史趋势
- 可在线标注和回复

### 3.3 家属视角

**US-005：关注家人健康风险**
作为家属，我希望关注家人的健康风险，这样能及时关心和提醒。

验收标准：
- 可查看家人健康评分
- 高风险时收到通知
- 可查看健康趋势
- 可查看医生建议
- 可发送关怀消息

## 5. 数据模型

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 评估 ID |
| user_id | UUID | 用户 ID |
| total_score | Int | 综合评分 |
| dimension_scores | JSON | 各维度评分 |
| risk_assessment | JSON | 风险评估结果 |
| predictions | JSON | 趋势预测 |
| recommendations | JSON | 个性化建议 |
| assessment_date | Date | 评估日期 |
| created_at | DateTime | 创建时间 |

### 5.2 风险评估

## 6. 非功能需求

### 6.1 性能要求

- 健康评估计算 < 5 秒
- 报告生成 < 10 秒
- 页面加载 < 1 秒

### 6.2 准确性要求

- 风险评估准确率 > 80%
- 评分与医生评估一致性 > 75%
- 建议相关性 > 85%

### 6.3 安全要求

- 健康数据加密存储
- 评估结果仅本人可见
- 分享需授权
- 操作可审计
