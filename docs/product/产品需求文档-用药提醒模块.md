# 产品需求文档-用药提醒模块

> 本文档是家健镜系统用药提醒模块的完整产品需求说明，覆盖功能需求、用户故事、交互设计、验收标准。

## 1. 概述

### 1.1 产品目标

1. 提高用药依从性：按时服药率 > 90%
2. 减少漏服误服：漏服率 < 5%
3. 多渠道提醒：APP 推送、短信、语音
4. 灵活配置：支持多种用药计划
5. 家属协同：家属可查看和提醒

### 1.2 用户角色

| 角色 | 权限 |
| --- | --- |
| 患者 | 接收提醒、确认服药、管理自己的用药计划 |
| 家属 | 查看服药情况、代为设置提醒、接收未服药通知 |
| 医生 | 查看用药依从性报告、调整用药方案 |

## 3. 用户故事

### 3.1 患者视角

**US-001：创建用药计划**
作为患者，我希望创建用药计划，这样系统能按时提醒我服药。

验收标准：
- 可以选择药品（从药品库或手动输入）
- 可以设置剂量（如 1 片、5ml）
- 可以设置频率（每日 1/2/3 次、每周 X 次、按需）
- 可以设置具体提醒时间
- 可以设置开始日期和结束日期

**US-002：接收提醒并确认**
作为患者，我希望在用药时间收到提醒，并能快速确认已服药。

验收标准：
- 提醒时间到达时收到推送通知
- 通知显示药品名称和剂量
- 点击通知可直接确认服药
- 未确认时 10 分钟后重复提醒
- 最多重复 3 次

**US-003：查看服药记录**
作为患者，我希望查看历史服药记录，了解自己的用药情况。

验收标准：
- 日历视图显示每日服药情况
- 绿色表示已服药，红色表示漏服
- 点击某天可查看详细记录
- 支持按药品筛选

### 3.2 家属视角

**US-004：查看家属服药情况**
作为家属，我希望查看家人的服药情况，及时发现漏服。

验收标准：
- 可查看已绑定家属的服药记录
- 漏服时收到通知
- 可代为发送提醒
- 可查看依从性统计

**US-005：代为设置提醒**
作为家属，我希望为家人设置用药提醒，特别是老人不会操作时。

验收标准：
- 可代为创建用药计划
- 需患者确认后生效
- 可修改和删除计划

### 3.3 医生视角

**US-006：查看患者依从性**
作为医生，我希望查看患者的用药依从性，评估治疗效果。

验收标准：
- 可查看授权患者的依从性报告
- 支持按时间段筛选
- 可查看漏服详情
- 可导出报告

## 5. 非功能需求

### 5.1 性能要求

- 提醒推送延迟 < 5 秒
- 页面加载 < 1 秒
- 支持 10 万用户同时在线

### 5.2 可靠性要求

- 提醒送达率 > 99%
- 系统可用性 > 99.9%
- 数据不丢失

### 5.3 兼容性要求

- iOS 13+
- Android 8.0+
- 支持后台推送

### 6.1 用药计划

| --- | --- | --- |

| user_id | UUID | 用户 ID |
