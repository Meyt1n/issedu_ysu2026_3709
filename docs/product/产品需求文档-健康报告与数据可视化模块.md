# 产品需求文档-健康报告与数据可视化模块

> 本文档是家健镜系统健康报告与数据可视化模块的完整产品需求说明，覆盖报告生成、数据图表、趋势分析、报告分享、PDF导出。

## 1. 概述

### 1.1 产品目标

1. 报告生成 < 10 秒
2. 数据可视化清晰直观
3. 支持多维度健康分析
4. 报告可分享可导出
5. 历史报告可对比

### 1.2 报告类型

| 类型 | 说明 | 生成频率 |
| --- | --- | --- |
| 日报 | 每日健康摘要 | 每日自动 |
| 周报 | 每周健康分析 | 每周自动 |
| 月报 | 每月健康总结 | 每月自动 |
| 年报 | 年度健康回顾 | 每年自动 |
| 专项报告 | 特定指标深度分析 | 手动生成 |
| 体检报告 | 体检数据解读 | 手动上传 |

## 3. 用户故事

### 3.1 患者视角

**US-001：查看健康周报**
作为用户，我希望每周收到健康周报，这样能了解自己的健康状况变化。

验收标准：
- 每周一自动生成上周报告
- 报告包含血压、血糖、体重等趋势
- 有健康评分和建议
- 收到推送通知
- 可查看历史周报

**US-002：分享健康报告**
作为用户，我希望分享健康报告给家人或医生，这样能获得更多关心和建议。

验收标准：
- 可生成分享链接
- 可生成分享图片
- 可导出PDF
- 可设置分享有效期
- 可随时取消分享

**US-003：对比历史报告**
作为用户，我希望对比不同时期的健康报告，这样能看到健康改善效果。

验收标准：
- 可选择两期报告对比
- 关键指标并排展示
- 变化趋势清晰可见
- 标注改善和恶化项

### 3.2 医生视角

**US-004：查看患者报告**
作为医生，我希望查看患者的健康报告，这样能更好地了解患者情况。

验收标准：
- 患者授权后可查看
- 报告数据完整准确
- 可查看历史报告
- 可标注重点关注项
- 可给出在线建议

## 6. 报告生成

### 6.1 生成流程

```
定时触发
    ↓
收集周期数据
    ↓
数据清洗与统计
    ↓
计算健康评分
    ↓
生成图表数据
    ↓
AI 生成分析和建议
    ↓
生成报告
    ↓
推送通知用户
```

### 6.2 评分算法

```python
class HealthScoreCalculator:
    WEIGHTS = {
        'blood_pressure': 0.20,
        'blood_glucose': 0.20,
        'weight': 0.15,
        'exercise': 0.15,
        'sleep': 0.10,
        'medication': 0.10,
        'diet': 0.10,
    }

    def calculate(self, data: dict) -> dict:
        scores = {}
        total = 0

        for dimension, weight in self.WEIGHTS.items():
            score = self._calculate_dimension_score(dimension, data)
            scores[dimension] = score
            total += score * weight

        return {
            'total': round(total),
            'dimensions': scores,
            'level': self._get_level(total),
        }

    def _calculate_dimension_score(self, dimension: str, data: dict) -> int:
        if dimension == 'blood_pressure':
            return self._score_blood_pressure(data.get('blood_pressure', []))
        elif dimension == 'blood_glucose':
            return self._score_blood_glucose(data.get('blood_glucose', []))
        # ... 其他维度
        return 70

    def _get_level(self, score: float) -> str:
        if score >= 90:
            return '优秀'
        elif score >= 75:
            return '良好'
        elif score >= 60:
            return '一般'
        else:
            return '需关注'
```

### 6.3 AI 建议生成

```python
class ReportGenerator:
    def __init__(self, llm_service):
        self.llm = llm_service

    async def generate_analysis(self, user_data: dict, scores: dict) -> str:
        prompt = self._build_prompt(user_data, scores)
        analysis = await self.llm.chat([
            {'role': 'system', 'content': '你是一个专业的健康分析师。'},
            {'role': 'user', 'content': prompt},
        ])
        return analysis

    async def generate_recommendations(self, user_data: dict, scores: dict) -> list[str]:
        # 基于评分最低的维度生成建议
        weak_dimensions = sorted(scores['dimensions'].items(), key=lambda x: x[1])[:3]
        recommendations = []
        for dim, score in weak_dimensions:
            rec = await self._generate_dimension_advice(dim, score, user_data)
            recommendations.append(rec)
        return recommendations
```

## 7. 非功能需求

### 7.1 性能要求

- 报告生成 < 10 秒
- 报告加载 < 1 秒
- 图表渲染 60fps
- 支持 10 万用户同时生成

### 7.2 数据要求

- 数据准确无误
- 历史数据可追溯
- 支持数据修正
- 报告不可篡改
