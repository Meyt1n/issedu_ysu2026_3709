# 产品需求文档-体征记录模块

> 本文档是家健镜系统体征记录模块的产品需求说明，覆盖体征类型、记录方式、趋势分析、异常提醒。

## 1. 模块概述

### 1.1 目标

帮助家庭成员方便地记录和管理生命体征数据，通过趋势分析和异常提醒，实现健康状况的持续监控。

### 1.2 体征类型

| 类型 | 单位 | 正常范围 | 记录频率 |
| --- | --- | --- | --- |
| 血压 | mmHg | 90-140/60-90 | 每日 1-2 次 |
| 血糖 | mmol/L | 3.9-6.1（空腹） | 按需 |
| 心率 | 次/分 | 60-100 | 按需 |
| 体温 | ℃ | 36.0-37.3 | 按需 |
| 体重 | kg | BMI 18.5-24 | 每周 |
| 血氧 | % | 95-100 | 按需 |

### 1.3 功能清单

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 手动记录 | 手动输入体征数据 | P0 |
| 设备同步 | 蓝牙设备自动同步 | P1 |
| 趋势图表 | 可视化趋势分析 | P0 |
| 异常提醒 | 超出范围自动提醒 | P0 |
| 数据导出 | 导出为 PDF/Excel | P1 |
| 分享医生 | 分享给医生查看 | P2 |

## 2. 用户故事

### 2.1 手动记录

**作为**家庭成员，**我想要**快速记录血压，**以便**追踪我的血压变化。

**验收标准：**
- 支持收缩压和舒张压输入
- 自动计算脉压差
- 记录时间可修改
- 可添加备注
- 保存后显示是否正常

### 2.2 趋势分析

**作为**家庭成员，**我想要**查看血压趋势图，**以便**了解血压变化情况。

**验收标准：**
- 支持日/周/月/年视图
- 显示正常范围参考线
- 异常数据高亮
- 可查看具体数值
- 显示平均值和波动范围

### 2.3 异常提醒

**作为**家庭成员，**我想要**在体征异常时收到提醒，**以便**及时采取措施。

**验收标准：**
- 超出正常范围立即提醒
- 连续异常加强提醒
- 提醒包含建议
- 可设置提醒阈值
- 可关闭特定类型提醒

## 3. 交互流程

### 3.1 记录流程

```
用户点击"记录体征"
    ↓
选择体征类型
    ↓
输入数值（血压需输入两个值）
    ↓
系统自动判断是否正常
    ↓
显示正常/异常状态
    ↓
用户可添加备注
    ↓
保存成功
    ↓
异常时显示建议
```

### 3.2 趋势查看流程

```
用户进入体征详情
    ↓
默认显示最近 7 天趋势
    ↓
用户可切换时间范围（7天/30天/90天/1年）
    ↓
用户可缩放查看具体日期
    ↓
点击数据点查看详情
    ↓
可查看统计信息（平均、最高、最低）
```

## 4. 页面设计

### 4.1 体征列表页

**布局：**
- 顶部：今日概览卡片
- 体征类型列表（血压、血糖、心率等）
- 每个类型显示最新值和趋势

**体征卡片：**
- 体征名称和图标
- 最新数值
- 正常/异常状态
- 迷你趋势图
- 记录时间

### 4.2 记录页

**布局：**
- 体征类型选择
- 数值输入区域（大数字键盘）
- 时间选择
- 备注输入
- 保存按钮

### 4.3 趋势详情页

**布局：**
- 顶部：体征名称和当前值
- 时间范围切换（日/周/月/年）
- 趋势图表
- 统计信息（平均、最高、最低）
- 异常记录列表
- 记录按钮（FAB）

## 5. 数据模型

### 5.1 体征记录

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 记录 ID |
| member_id | UUID | 成员 ID |
| type | Enum | 体征类型 |
| value | Float | 数值（单值类型） |
| value2 | Float? | 第二数值（血压舒张压） |
| unit | String | 单位 |
| measured_at | DateTime | 测量时间 |
| source | Enum | 手动/设备 |
| device_id | String? | 设备 ID |
| is_abnormal | Boolean | 是否异常 |
| notes | String? | 备注 |
| created_at | DateTime | 创建时间 |

## 6. 异常判断

### 6.1 判断规则

| 体征 | 正常 | 偏高 | 严重 |
| --- | --- | --- | --- |
| 收缩压 | < 140 | 140-160 | > 160 |
| 舒张压 | < 90 | 90-100 | > 100 |
| 空腹血糖 | < 6.1 | 6.1-7.0 | > 7.0 |
| 心率 | 60-100 | 100-120 | > 120 |
| 体温 | < 37.3 | 37.3-38.5 | > 38.5 |

### 6.2 连续异常

- 连续 3 次异常 → 加强提醒
- 连续 7 次异常 → 建议就医
- 趋势持续上升 → 预警
