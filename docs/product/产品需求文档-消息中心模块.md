# 产品需求文档-消息中心模块

> 本文档是家健镜系统消息中心模块的完整产品需求说明，覆盖消息类型、消息列表、消息设置、推送管理、已读未读。

## 1. 概述

### 1.1 产品目标

1. 消息集中管理
2. 重要消息不遗漏
3. 用户可自定义通知
4. 消息分类清晰
5. 支持多渠道触达

### 1.2 消息类型

| 类型 | 说明 | 优先级 |
| --- | --- | --- |
| 用药提醒 | 服药时间提醒 | 高 |
| 健康预警 | 健康数据异常 | 高 |
| 系统通知 | 系统公告、更新 | 中 |
| 家属消息 | 家属互动消息 | 中 |
| 医生建议 | 医生回复建议 | 高 |
| 营销活动 | 活动推广 | 低 |

## 3. 用户故事

### 3.1 患者视角

**US-001：查看用药提醒**
作为患者，我希望在消息中心查看所有用药提醒，这样我不会错过任何一次服药。

验收标准：
- 用药提醒按时间排序
- 显示药品名称、剂量、时间
- 未读消息有红点提示
- 点击可跳转到用药详情

**US-002：设置免打扰**
作为患者，我希望设置免打扰时段，这样晚上睡觉不会被消息吵醒。

验收标准：
- 可设置开始和结束时间
- 免打扰时段不推送通知
- 重要消息（健康预警）可选择突破免打扰
- 设置后立即生效

**US-003：管理消息通知**
作为患者，我希望可以按类型开关通知，这样我只接收关心的消息。

验收标准：
- 每种消息类型有独立开关
- 关闭后不再推送该类型
- 消息中心仍会保留消息
- 可随时重新开启

### 3.2 家属视角

**US-004：接收家属消息**
作为家属，我希望收到家人的健康动态消息，这样我能及时了解家人状况。

验收标准：
- 家人漏服药时收到通知
- 家人健康数据异常时收到通知
- 可查看消息详情
- 可回复消息

### 3.3 医生视角

**US-005：发送医生建议**
作为医生，我希望可以给患者发送健康建议，这样患者能收到专业指导。

验收标准：
- 可选择患者发送建议
- 支持文字和图片
- 患者收到推送通知
- 可查看发送记录

## 5. 数据模型

### 5.1 消息

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 消息 ID |
| user_id | UUID | 接收用户 ID |
| type | Enum | 消息类型 |
| title | String | 标题 |
| content | Text | 内容 |
| data | JSON | 附加数据 |
| is_read | Boolean | 是否已读 |
| read_at | DateTime | 阅读时间 |
| created_at | DateTime | 创建时间 |
| expires_at | DateTime | 过期时间 |

### 5.2 消息设置

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| user_id | UUID | 用户 ID |
| notification_enabled | Boolean | 总开关 |
| type_settings | JSON | 各类型开关 |
| dnd_enabled | Boolean | 免打扰开关 |
| dnd_start | Time | 免打扰开始 |
| dnd_end | Time | 免打扰结束 |
| vibration | Boolean | 振动 |
| sound | Boolean | 声音 |
| lock_screen | Boolean | 锁屏显示 |

## 6. 非功能需求

### 6.1 性能要求

- 消息推送延迟 < 5 秒
- 消息列表加载 < 1 秒
- 支持百万级消息存储

### 6.2 可靠性要求

- 消息不丢失
- 推送送达率 > 99%
- 系统可用性 > 99.9%
