## 3. 用户故事

### 3.1 普通用户

**US-001：发布健康动态**
作为用户，我希望发布健康动态，这样能记录和分享我的健康生活。

验收标准：
- 可发布文字内容
- 可上传图片（最多9张）
- 可添加话题标签
- 可选择是否公开
- 发布后在社区可见

**US-002：互动交流**
作为用户，我希望与其他用户互动，这样能交流健康经验。

验收标准：
- 可点赞动态和评论
- 可发表评论
- 可回复他人评论
- 可收藏感兴趣的动态
- 收到互动有通知

**US-003：关注用户**
作为用户，我希望关注感兴趣的用户，这样能看到他们的最新动态。

验收标准：
- 可关注其他用户
- 可查看关注列表
- 可查看粉丝列表
- 关注后在首页看到其动态
- 可取消关注

### 3.2 内容创作者

**US-004：分享健康经验**
作为健康达人，我希望分享疾病管理经验，这样能帮助更多人。

验收标准：
- 可发布长文经验分享
- 可添加图片和标签
- 可查看阅读量和互动数据
- 优质内容可获得推荐
- 可获得粉丝关注

### 3.3 管理员

**US-005：内容审核**
作为管理员，我希望审核社区内容，这样能维护社区秩序。

验收标准：
- 可查看待审核内容
- 可通过或驳回内容
- 可下架违规内容
- 可禁言违规用户
- 审核记录可追溯

## 7. 审核机制

### 7.1 自动审核

```python
class ContentModerator:
    def __init__(self):
        self.sensitive_words = self._load_sensitive_words()
        self.ai_model = self._load_ai_model()

    async def moderate(self, content: str, images: list = None) -> dict:
        result = {
            'passed': True,
            'risk_level': 'low',
            'reasons': [],
        }

        # 1. 敏感词检测
        word_hits = self._check_sensitive_words(content)
        if word_hits:
            result['risk_level'] = 'high'
            result['passed'] = False
            result['reasons'].append(f'包含敏感词：{word_hits}')

        # 2. AI 内容审核
        ai_result = await self.ai_model.classify(content)
        if ai_result['toxicity'] > 0.8:
            result['risk_level'] = 'high'
            result['passed'] = False
            result['reasons'].append('内容包含有害信息')

        # 3. 图片审核
        if images:
            for img in images:
                img_result = await self._check_image(img)
                if not img_result['safe']:
                    result['passed'] = False
                    result['reasons'].append(f'图片违规：{img_result["reason"]}')

        return result
```

### 7.2 人工审核流程

```
用户发布内容
    ↓
自动审核
    ├── 通过 → 直接发布
    ├── 可疑 → 进入人工审核队列
    └── 违规 → 拦截并通知用户
                    ↓
              人工审核
              ├── 通过 → 发布
              └── 驳回 → 通知用户原因
```
