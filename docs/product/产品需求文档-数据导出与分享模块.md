# 产品需求文档-数据导出与分享模块

> 本文档是家健镜系统数据导出与分享模块的完整产品需求说明，覆盖数据导出、报告生成、分享功能、隐私控制、历史记录。

## 1. 概述

### 1.1 产品目标

1. 数据可导出备份
2. 报告专业美观
3. 分享便捷安全
4. 隐私可控
5. 支持多种格式

### 1.2 导出类型

| 类型 | 格式 | 用途 |
| --- | --- | --- |
| 健康报告 | PDF | 给医生看 |
| 用药记录 | CSV/Excel | 数据分析 |
| 体征数据 | CSV/Excel | 长期跟踪 |
| 运动数据 | CSV/GPX | 运动分析 |
| 全部数据 | JSON | 数据备份 |

## 3. 用户故事

### 3.1 患者视角

**US-001：导出健康报告给医生**
作为患者，我希望导出健康报告给医生，这样医生能了解我的健康状况。

验收标准：
- 可选择报告类型（周报/月报/自定义）
- 可选择时间范围
- 生成 PDF 格式
- 包含用药、体征、运动数据
- 有图表和趋势分析
- 可直接分享给医生

**US-002：导出原始数据备份**
作为患者，我希望导出所有健康数据备份，这样数据不会丢失。

验收标准：
- 可导出全部数据
- 支持 CSV 和 JSON 格式
- 包含所有历史数据
- 导出文件可下载
- 有导出进度提示

**US-003：分享给家属查看**
作为患者，我希望把健康数据分享给家属，这样家属能关心我。

验收标准：
- 可选择分享给指定家属
- 可设置分享权限（只读/可下载）
- 可设置有效期
- 可随时撤销
- 家属可查看报告

### 3.2 医生视角

**US-004：查看患者分享的报告**
作为医生，我希望查看患者分享的健康报告，这样我能给出专业建议。

验收标准：
- 可查看患者分享的报告
- 可下载报告 PDF
- 可查看历史报告
- 可在线标注和回复
- 报告数据完整

### 3.3 家属视角

**US-005：接收家人健康报告**
作为家属，我希望收到家人的健康报告，这样我能了解家人状况。

验收标准：
- 收到分享通知
- 可查看健康报告
- 可查看趋势图表
- 可下载报告
- 异常数据有提醒

## 5. 数据模型

### 5.1 导出任务

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 任务 ID |
| user_id | UUID | 用户 ID |
| data_type | Enum | 数据类型 |
| start_date | Date | 开始日期 |
| end_date | Date | 结束日期 |
| format | Enum | 导出格式 |
| status | Enum | 状态（pending/processing/completed/failed） |
| progress | Int | 进度百分比 |
| file_url | String | 导出文件 URL |
| file_size | Long | 文件大小 |
| created_at | DateTime | 创建时间 |
| completed_at | DateTime | 完成时间 |

### 5.2 分享记录

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 分享 ID |
| user_id | UUID | 分享者 ID |
| recipient_type | Enum | 接收者类型（user/link） |
| recipient_id | UUID | 接收者 ID |
| report_id | UUID | 报告 ID |
| permission | Enum | 权限（view/download） |
| expires_at | DateTime | 过期时间 |
| password_hash | String | 访问密码哈希 |
| access_count | Int | 访问次数 |
| is_revoked | Boolean | 是否撤销 |
| created_at | DateTime | 创建时间 |

## 6. 非功能需求

### 6.1 性能要求

- 导出 1 年数据 < 30 秒
- 报告生成 < 10 秒
- 分享链接生成 < 1 秒

### 6.2 安全要求

- 导出文件加密存储
- 分享链接带签名
- 访问需要鉴权
- 敏感数据脱敏
