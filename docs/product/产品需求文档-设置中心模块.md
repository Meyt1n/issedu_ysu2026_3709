# 产品需求文档-设置中心模块

> 本文档是家健镜系统设置中心模块的完整产品需求说明，覆盖账号设置、通知设置、隐私设置、通用设置、关于我们。

## 1. 概述

### 1.1 产品目标

1. 设置项集中管理
2. 操作简单直观
3. 隐私可控
4. 个性化配置
5. 安全可靠

### 1.2 设置分类

| 分类 | 内容 |
| --- | --- |
| 账号设置 | 个人信息、密码、手机号、绑定 |
| 通知设置 | 推送、免打扰、声音振动 |
| 隐私设置 | 数据权限、授权管理、数据导出 |
| 通用设置 | 语言、主题、字体、缓存 |
| 关于我们 | 版本、协议、帮助、反馈 |

## 3. 用户故事

### 3.1 患者视角

**US-001：修改个人资料**
作为患者，我希望修改个人资料，这样我的信息是准确的。

验收标准：
- 可修改头像、昵称、性别、生日
- 修改后立即生效
- 头像支持拍照和相册选择
- 有修改成功提示

**US-002：设置深色模式**
作为患者，我希望设置深色模式，这样晚上使用不刺眼。

验收标准：
- 支持浅色、深色、跟随系统三种模式
- 切换后立即生效
- 所有页面适配深色模式
- 设置被记住

**US-003：导出个人数据**
作为患者，我希望导出我的健康数据，这样我可以备份或给医生看。

验收标准：
- 可选择导出范围（全部/指定时间段）
- 支持导出为 PDF 或 CSV
- 导出文件可下载
- 导出有进度提示

### 3.2 家属视角

**US-004：管理通知权限**
作为家属，我希望设置接收哪些通知，这样我不会被打扰。

验收标准：
- 可按类型开关通知
- 可设置免打扰时段
- 重要通知可选择突破免打扰
- 设置立即生效

### 3.3 老人视角

**US-005：调大字体**
作为老人，我希望调大字体，这样我能看清楚。

验收标准：
- 提供 4 档字体大小
- 切换后所有页面字体变化
- 布局不溢出
- 设置被记住

## 5. 数据模型

### 5.1 用户设置

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| user_id | UUID | 用户 ID |
| theme | Enum | 主题（light/dark/system） |
| font_size | Enum | 字体大小（small/medium/large/xlarge） |
| language | String | 语言（zh-CN/en） |
| notification_enabled | Boolean | 推送总开关 |
| notification_settings | JSON | 各类型开关 |
| dnd_enabled | Boolean | 免打扰开关 |
| dnd_start | Time | 免打扰开始 |
| dnd_end | Time | 免打扰结束 |
| vibration | Boolean | 振动 |
| sound | Boolean | 声音 |
| auto_update | Boolean | 自动更新 |
| updated_at | DateTime | 更新时间 |

## 6. 非功能需求

### 6.1 性能要求

- 设置页加载 < 500ms
- 设置保存 < 1 秒
- 设置同步 < 5 秒

### 6.2 兼容性要求

- iOS 13+
- Android 8.0+
- 深色模式适配
