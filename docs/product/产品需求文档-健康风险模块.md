# 产品需求文档-健康风险模块

> 本文档是家健镜系统健康风险模块的产品需求说明，覆盖风险识别、风险展示、风险处理、风险统计。面向产品经理、开发者和测试人员，作为健康风险模块的权威依据。

## 1. 模块概述

### 1.1 目标

自动识别家庭成员的健康风险，及时提醒并给出可操作建议，帮助家庭预防健康问题。

### 1.2 风险类型

| 类型 | 说明 | 等级 |
| --- | --- | --- |
| 过敏冲突 | 药品成分与过敏史冲突 | 严重 |
| 重复成分 | 多种药品含相同成分 | 高 |
| 药品过期 | 药品已过有效期 | 严重 |
| 药品临期 | 药品 7 天内过期 | 高 |
| 库存不足 | 药品库存低于阈值 | 中 |
| 漏服药物 | 未按时服药 | 高 |
| 体征异常 | 生命体征超出正常范围 | 高 |
| 环境提醒 | 天气变化相关健康建议 | 信息 |

## 2. 用户故事

### 2.1 风险识别

**作为**家庭成员，**我想要**系统自动识别健康风险，**以便**及时发现潜在问题。

**验收标准：**
- 添加药品时自动检查过敏冲突
- 添加药品时自动检查重复成分
- 每日自动检查药品过期和库存
- 体征记录后自动检查异常
- 风险识别在 1 分钟内完成

### 2.2 风险展示

**作为**家庭成员，**我想要**清晰地看到当前的健康风险，**以便**了解需要关注的问题。

**验收标准：**
- 风险按严重程度排序（严重 > 高 > 中 > 信息）
- 严重风险红色高亮
- 每个风险显示标题、描述、原因
- 每个风险有明确的处理建议
- 风险数量在 Tab 上显示角标

### 2.3 风险处理

**作为**家庭成员，**我想要**对风险进行处理，**以便**消除或降低风险。

**验收标准：**
- 可标记风险为"已知晓"
- 已知晓的风险不再提醒
- 可查看风险的详细信息
- 可查看风险的证据来源
- 处理后风险从活跃列表移除

### 2.4 风险统计

**作为**家庭管理员，**我想要**查看风险统计，**以便**了解家庭健康状况。

**验收标准：**
- 显示本月风险总数
- 按风险类型分类统计
- 按风险等级分类统计
- 显示风险趋势图
- 可导出风险报告

## 3. 交互流程

### 3.1 风险提醒流程

```
系统识别到风险
    ↓
生成风险事件
    ↓
判断风险等级
    ↓
严重/高 → 立即推送通知
中/信息 → 每日汇总推送
    ↓
用户点击通知
    ↓
打开风险详情页
    ↓
用户查看详情和建议
    ↓
用户处理风险（已知晓/采取行动）
```

### 3.2 风险确认流程

```
用户点击"已知晓"
    ↓
显示确认对话框
    ↓
用户确认
    ↓
风险标记为已确认
    ↓
从活跃列表移除
    ↓
记录确认事件
```

## 4. 页面设计

### 4.1 风险列表页

**布局：**
- 顶部：风险概览（严重 X / 高 X / 中 X）
- 筛选：全部 / 严重 / 高 / 中 / 信息
- 中部：风险卡片列表
- 空状态："暂无健康风险，继续保持！"

**风险卡片：**
- 左侧色条（红/橙/黄/蓝）
- 风险标题
- 风险描述
- 风险建议（灯泡图标）
- 时间
- "已知晓"按钮

### 4.2 风险详情页

**布局：**
- 顶部：风险等级标签 + 标题
- 风险描述
- 证据列表（药品、过敏史、体征记录）
- 处理建议
- 相关操作按钮（查看药品、咨询医生等）
- 已知晓按钮

## 5. 通知策略

### 5.1 通知频率

| 风险等级 | 通知方式 | 频率限制 |
| --- | --- | --- |
| 严重 | 立即推送 + 短信 | 无限制 |
| 高 | 立即推送 | 无限制 |
| 中 | App 内通知 | 每日最多 5 条 |
| 信息 | 每日汇总 | 每日最多 3 条 |

### 5.2 通知内容

- 严重/高：显示风险标题和简要描述
- 中/信息：只显示"您有新的健康提醒"
- 不泄露具体健康数据

## 6. 验收标准

### 6.1 功能验收

- [ ] 过敏冲突识别准确
- [ ] 重复成分识别准确
- [ ] 药品过期提醒及时
- [ ] 库存不足提醒准确
- [ ] 风险按等级排序
- [ ] 风险确认功能正常
- [ ] 通知策略正确

### 6.2 性能验收

- [ ] 风险识别 < 1s
- [ ] 风险列表加载 < 500ms
- [ ] 通知到达 < 1min

## 7. 非功能需求

- 风险规则可配置
- 风险识别可追溯
- 用户可自定义通知偏好
- 支持免打扰时段

---

*健康风险是安全的防线。及时、准确、可操作的风险提醒，让健康问题早发现早处理。*
