# 产品需求文档-家庭成员管理模块

> 本文档是家健镜系统家庭成员管理模块的产品需求说明，覆盖成员管理、角色权限、家庭切换、邀请加入。

## 1. 模块概述

### 1.1 目标

帮助用户管理家庭成员信息，支持多角色协作，实现家庭健康数据的共享和管理。

### 1.2 用户角色

| 角色 | 权限 | 说明 |
| --- | --- | --- |
| 家庭管理员 | 全部权限 | 创建家庭的用户 |
| 普通成员 | 查看和管理自己的数据 | 被邀请加入的成员 |
| 照护者 | 查看和管理被照护者数据 | 专业照护人员 |
| 只读成员 | 只能查看 | 仅查看的家庭成员 |

### 1.3 功能清单

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 创建家庭 | 创建新的家庭群组 | P0 |
| 邀请成员 | 通过邀请码/链接邀请 | P0 |
| 成员列表 | 查看所有家庭成员 | P0 |
| 成员信息 | 查看和编辑成员资料 | P0 |
| 角色管理 | 分配和修改角色 | P1 |
| 家庭切换 | 切换不同家庭 | P1 |
| 移除成员 | 移除家庭成员 | P1 |
| 家庭设置 | 修改家庭名称、头像 | P2 |

## 2. 用户故事

### 2.1 创建家庭

**作为**新用户，**我想要**创建一个家庭，**以便**管理家人的健康数据。

**验收标准：**
- 注册后自动创建默认家庭
- 可设置家庭名称和头像
- 创建者自动成为家庭管理员
- 家庭创建后可邀请成员

### 2.2 邀请成员

**作为**家庭管理员，**我想要**邀请家人加入家庭，**以便**共同管理健康数据。

**验收标准：**
- 生成邀请码（6 位数字）
- 生成邀请链接
- 邀请码 24 小时有效
- 可设置成员角色
- 被邀请人接受后加入家庭

### 2.3 成员信息管理

**作为**家庭成员，**我想要**管理自己和家人的信息，**以便**记录准确的健康数据。

**验收标准：**
- 可查看成员基本信息
- 可编辑自己的信息
- 管理员可编辑所有成员信息
- 敏感信息（身份证等）需验证后查看

### 2.4 角色管理

**作为**家庭管理员，**我想要**为成员分配角色，**以便**控制数据访问权限。

**验收标准：**
- 可分配普通成员/照护者/只读角色
- 角色变更实时生效
- 管理员角色不可变更
- 角色变更有记录

## 3. 交互流程

### 3.1 邀请成员流程

```
管理员点击"邀请成员"
    ↓
选择邀请方式：邀请码 / 邀请链接
    ↓
生成邀请码/链接
    ↓
管理员分享给被邀请人
    ↓
被邀请人输入邀请码/点击链接
    ↓
显示家庭信息确认页
    ↓
被邀请人确认加入
    ↓
加入成功，跳转到家庭首页
```

### 3.2 家庭切换流程

```
用户点击家庭名称
    ↓
显示家庭列表（用户所属的所有家庭）
    ↓
用户选择目标家庭
    ↓
切换家庭上下文
    ↓
刷新首页数据
```

## 4. 页面设计

### 4.1 成员列表页

**布局：**
- 顶部：家庭名称 + 设置按钮
- 成员卡片列表（按角色排序）
- 底部：邀请成员按钮

**成员卡片：**
- 头像
- 姓名
- 角色标签
- 在线状态
- 健康摘要（今日用药、体征）

### 4.2 成员详情页

**布局：**
- 顶部：头像 + 姓名 + 角色
- 基本信息：年龄、性别、血型、过敏史
- 健康数据入口：药品、体征、风险
- 操作按钮：编辑、角色设置、移除

### 4.3 邀请页

**布局：**
- 邀请码显示（大号字体）
- 复制按钮
- 分享按钮（微信/短信）
- 邀请链接
- 有效期提示

## 5. 数据模型

### 5.1 家庭

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 家庭 ID |
| name | String | 家庭名称 |
| avatar | String | 家庭头像 |
| created_by | UUID | 创建者 |
| created_at | DateTime | 创建时间 |

### 5.2 家庭成员

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 成员 ID |
| household_id | UUID | 家庭 ID |
| user_id | UUID | 用户 ID |
| role | Enum | 角色 |
| nickname | String | 家庭内昵称 |
| joined_at | DateTime | 加入时间 |

### 5.3 邀请

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 邀请 ID |
| household_id | UUID | 家庭 ID |
| code | String | 邀请码 |
| role | Enum | 默认角色 |
| expires_at | DateTime | 过期时间 |
| used_by | UUID? | 使用人 |
| used_at | DateTime? | 使用时间 |

## 6. 权限矩阵

| 操作 | 管理员 | 普通成员 | 照护者 | 只读 |
| --- | --- | --- | --- | --- |
| 查看成员列表 | 是 | 是 | 是 | 是 |
| 编辑自己信息 | 是 | 是 | 是 | 是 |
| 编辑他人信息 | 是 | 否 | 被照护者 | 否 |
| 邀请成员 | 是 | 否 | 否 | 否 |
| 移除成员 | 是 | 否 | 否 | 否 |
| 角色管理 | 是 | 否 | 否 | 否 |
| 查看健康数据 | 全部 | 自己 | 被照护者 | 全部 |
| 编辑健康数据 | 全部 | 自己 | 被照护者 | 否 |

## 7. 验收标准

### 7.1 功能验收

- [ ] 家庭创建正常
- [ ] 邀请码生成和使用正常
- [ ] 邀请链接有效
- [ ] 成员列表显示正确
- [ ] 成员信息编辑正常
- [ ] 角色分配正常
- [ ] 权限控制正确
- [ ] 家庭切换正常
- [ ] 移除成员正常

### 7.2 安全验收

- [ ] 邀请码不可猜测
- [ ] 邀请码过期失效
- [ ] 权限校验严格
- [ ] 敏感信息脱敏

## 8. 非功能需求

- 支持一个用户加入多个家庭
- 支持一个家庭最多 20 个成员
- 邀请码 24 小时有效
- 家庭数据隔离
