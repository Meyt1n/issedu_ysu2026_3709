# 产品需求文档-家庭成员管理模块

> 本文档是家健镜系统家庭成员管理模块的完整产品需求说明，覆盖成员添加、成员管理、权限控制、数据共享、消息互动。

## 1. 概述

### 1.1 产品目标

1. 家庭成员管理便捷
2. 健康数据共享安全
3. 权限控制灵活
4. 多角色支持
5. 互动体验良好

### 1.2 成员角色

| 角色 | 权限 | 说明 |
| --- | --- | --- |
| 管理员 | 全部权限 | 家庭创建者 |
| 成员 | 查看自己数据 | 普通家庭成员 |
| 看护人 | 查看被看护人数据 | 照顾老人/小孩 |
| 医生 | 查看授权患者数据 | 专业医疗人员 |

## 3. 用户故事

### 3.1 管理员视角

**US-001：添加家庭成员**
作为家庭管理员，我希望添加家庭成员，这样我们可以一起管理健康。

验收标准：
- 可通过手机号添加
- 可通过扫码添加
- 可发送邀请链接
- 对方确认后加入
- 有添加成功通知

**US-002：设置成员权限**
作为家庭管理员，我希望设置成员权限，这样能保护每个人的隐私。

验收标准：
- 可设置数据可见范围
- 可设置操作权限
- 可设置成员角色
- 权限变更有记录
- 成员能看到自己的权限

**US-003：移除家庭成员**
作为家庭管理员，我希望移除家庭成员，这样家庭列表保持准确。

验收标准：
- 可移除成员
- 移除前有确认
- 移除后数据保留
- 被移除者收到通知

### 3.2 看护人视角

**US-004：查看老人健康数据**
作为看护人，我希望查看老人的健康数据，这样能及时发现问题。

验收标准：
- 可查看被看护人体征数据
- 可查看用药记录
- 异常数据有提醒
- 可设置提醒阈值
- 数据实时更新

**US-005：提醒老人服药**
作为看护人，我希望提醒老人服药，这样老人不会忘记吃药。

验收标准：
- 可代为设置用药提醒
- 提醒发送给老人
- 老人服药后我能看到
- 漏服时我收到通知
- 可发送关怀消息

### 3.3 医生视角

**US-006：查看患者数据**
作为医生，我希望查看患者授权的健康数据，这样能给出专业建议。

验收标准：
- 患者授权后可查看
- 可查看历史数据
- 可查看健康报告
- 可在线回复建议
- 授权到期自动失效

### 3.4 普通成员视角

**US-007：管理我的数据共享**
作为普通成员，我希望管理我的数据共享，这样我能控制谁能看到我的数据。

验收标准：
- 可设置谁能看到我的数据
- 可按数据类型设置
- 可随时撤销
- 可查看共享记录
- 有数据被查看通知

## 5. 数据模型

### 5.1 家庭

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 家庭 ID |
| name | String | 家庭名称 |
| creator_id | UUID | 创建者 ID |
| member_count | Int | 成员数量 |
| created_at | DateTime | 创建时间 |

### 5.2 家庭成员

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 成员 ID |
| family_id | UUID | 家庭 ID |
| user_id | UUID | 用户 ID |
| role | Enum | 角色 |
| nickname | String | 家庭昵称 |
| joined_at | DateTime | 加入时间 |
| status | Enum | 状态（active/invited/removed） |

### 5.3 数据共享

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | UUID | 共享 ID |
| owner_id | UUID | 数据所有者 |
| shared_with_id | UUID | 共享对象 |
| data_types | Array | 共享数据类型 |
| expires_at | DateTime | 过期时间 |
| created_at | DateTime | 创建时间 |
| is_revoked | Boolean | 是否撤销 |

## 6. 非功能需求

### 6.1 安全要求

- 数据传输加密
- 数据存储加密
- 权限实时生效
- 操作可审计

### 6.2 性能要求

- 成员列表加载 < 1 秒
- 权限校验 < 100ms
- 支持 50 人家庭
