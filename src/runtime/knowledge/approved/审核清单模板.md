# 正式知识审核清单模板

用于 `src/runtime/knowledge/approved/` 下获批资料入库前的人工审核。**不要把未审核 PDF 直接丢进运行时知识目录。**

## 元数据（必填）

| 字段 | 填写 |
|---|---|
| 文档标题 | |
| 相对路径（UTF-8 `.md`/`.txt`） | |
| 来源说明（不得粘贴受版权说明书全文） | |
| 许可 / 授权范围 | |
| 文档 version | |
| content_sha256（UTF-8 文本） | |
| 权限域 permission_scope | |
| 生效 / 失效窗口 | |
| 删除责任人 | |
| 审核人 / 日期 | |

## 内容边界勾选

- [ ] 已脱敏，无真实姓名、证件、可识别健康细节
- [ ] 无剂量/停药/换药/诊断结论表述（或已改写为「需咨询医生/药师」）
- [ ] 无买药、问诊、广告导流
- [ ] 教学/获批引用范围已写清
- [ ] 已在独立清单登记，并选用独立 `--index-version`

## Dry-run

```powershell
uv run python scripts/ingest_local_knowledge.py `
  --manifest src/runtime/knowledge/approved/正式知识清单.json `
  --source-root src/runtime/knowledge/approved `
  --actor-id knowledge-steward `
  --index-version approved-inserts-v1 `
  --dry-run
```

`ok=true` 且无 `CONTENT_HASH_MISMATCH` 后方可正式入库。
