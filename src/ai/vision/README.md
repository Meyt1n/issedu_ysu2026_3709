# HomeCare Twin Vision

视觉模块以 YOLO11n 为 P0 基线，检测药盒、药瓶、药板及药名、规格、有效期、条码、健康报告表格和医嘱区域；PaddleOCR、条码、包装特征和药品主数据共同生成候选。

输出必须允许 `MATCHED`、`CONFLICT`、`UNKNOWN` 和 `REVIEW`，并携带证据帧、框、字段来源、模型/阈值/OCR/主数据版本。高分不等于药品身份确认，正式入库必须人工复核。

数据按实体药盒、采集日期、设备和视频会话分组划分。发布至少报告每类指标、未知 SKU 转人工率、自动通过精确率、CPU/GPU 延迟、失败样例和旧类别退化，并支持 V1/V2 回滚。
