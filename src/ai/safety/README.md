# HomeCare Twin Safety

安全模块维护五类路由：`DIRECT`、`EVIDENCE_REQUIRED`、`RISK_ONLY`、`REFUSE`、`URGENT_ESCALATE`，并负责工具参数授权、成员/字段可见范围、JSON Schema、引用完整性、禁止内容和紧急升级检查。

必须拒绝诊断、处方、停药、换药和个体剂量决定；风险等级只能来自版本化规则，普通提示词、检索文档或模型输出不能修改安全策略。无证据时必须拒答或返回结构化事实；家庭版不把健康上下文发送到云端。

安全策略还阻断买药、问诊、广告、佣金和健康消费导流意图，确保产品只承担居家照护任务。

安全回归覆盖跨家庭/成员越权、撤权、提示词注入、恶意文档、引用伪造、上下文泄露、工具参数篡改、资源耗尽、模型/索引替换和危险医疗请求。
