# HomeCare Twin AI 模块

- `vision/`：OpenCV 质量门控、YOLO 区域检测、OCR/条码、候选融合、开放集拒识和视觉评估。
- `rag/`：版本化文档解析、权限过滤、切片、Embedding、检索、重排和引用验证。
- `safety/`：意图/风险路由、工具权限、结构化输出、医疗拒答、紧急升级和红队回归。

AI 模块通过稳定适配器供 FastAPI 调用，不能直接修改家庭事实。模型预测只有在人工确认后才能形成 `health_event`；风险由确定性规则计算，LLM 负责工具选择、澄清、引用和通俗解释。

模型进入默认链路前必须登记基础模型、许可证、数据版本、参数、固定集指标、阈值、失败样例、制品哈希、资源消耗、禁止用途和回滚版本。
